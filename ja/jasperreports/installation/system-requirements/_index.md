{{% alert color="primary" %}}

Aspose.PDF for JasperReports を実行するには、次のソフトウェアが必要です。

- Java 2 Platform Standard Edition 5.0 or higher.
- JasperReports 6.7.0 以降。
- JasperServer 6.7.0 以降 (JasperServer で JasperReports に Aspose.PDF を使用する場合)。

{{% /alert %}}
