{{% alert color="primary" %}}

インストール中に、選択したすべてのサイト コレクションに対して Aspose.PDF for SharePoint が有効化されます。インストール後は、サイト コレクションのルート Web サイトの「Site Actions」メニューを使用して、Aspose.PDF for SharePoint を有効化および無効化できます。

{{% /alert %}}
