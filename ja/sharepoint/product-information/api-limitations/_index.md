## PDF作成者情報

{{% alert color="primary" %}}

**Application** および **Producer** フィールドに対して値を設定することはできないことに注意してください。これは、Aspose Ltd. および Aspose.PDF for SharePoint x.x.x がこれらのフィールドに対して表示されるためです。 

{{% /alert %}}
