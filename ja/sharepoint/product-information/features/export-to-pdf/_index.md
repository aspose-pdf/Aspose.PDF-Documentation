{{% alert color="primary" %}}

Aspose.PDF for SharePoint を使用すると、リスト、リスト アイテム、および SharePoint Wiki ページを SharePoint ライブラリから PDF 形式にエクスポートできます。

{{% /alert %}}

{{% alert color="primary" %}}

ドキュメントを生成するために、Aspose.PDF for SharePoint は組み込みバージョンの [.NET 用 Aspose.PDF](http://www.aspose.com/categories/.net-components/aspose.pdf-for-.net/default.aspx).

{{% /alert %}}
