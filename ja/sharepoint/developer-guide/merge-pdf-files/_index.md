{{% alert color="primary" %}}

複数の PDF ファイルを 1 つの PDF ファイルに結合/連結することは、PDF ファイル処理アプリケーションでは非常に一般的であり、要求の高い機能です。この重要な機能については、 [SharePoint 2.2.0 用 Aspose.PDF](https://releases.aspose.com/pdf/sharepoint/new-releases/aspose.pdf-for-sharepoint-2.2.0/) バージョン。 2 つのファイルを結合すると、最初のファイルの末尾に 2 番目のファイルが追加されて 1 つのファイルが作成されます。

{{% /alert %}}

## PDF ファイルを結合する

次のように、SharePoint ドキュメント ライブラリから複数の PDF ファイルを 1 つの PDF に結合します。

1.  SharePoint ドキュメント ライブラリから結合する PDF ファイルを選択します。

![PDFファイルの選択](merge-pdf-files_1.png)

2.  ライブラリ ツールの [Aspose ツール] タブをクリックします。

![「Aspose ツール」をクリックします](merge-pdf-files_2.png)

3.  ライブラリ ツールから [PDF に結合] オプションをクリックして、選択したすべての PDF ファイルを結果の PDF に結合します。

![PDFに結合](merge-pdf-files_3.png)

4.  結果の PDF ファイルを適切な名前でダウンロード/保存するように求めるプロンプトが表示されます。

![出力](merge-pdf-files_4.png)
