## PDF ファイルにバーコードを追加する

{{% alert color="primary" %}}

Aspose.PDF for SharePoint を使用すると、PDF ドキュメントにバーコードを追加できます。ユーザーは、ライブラリに追加された PDF ドキュメントの各ページの左下隅にバーコードを追加できます。下の画像は、バーコードが追加された PDF ドキュメントがどのように見えるかを示しています。

### 左下隅にバーコード

![PDF ファイルにバーコードを追加する - 例 1](add-barcode-to-a-pdf-file_1.png)

{{% /alert %}}

{{% alert color="primary" %}}

特定のライブラリのバーコード機能を有効にするには、以下に示すように、**ライブラリ ツール**の**Aspose PDF Watermark Tools** タブにある**透かし設定** ボタンを使用します。

### PDFの透かし設定

![PDF ファイルにバーコードを追加する - 例 2](add-barcode-to-a-pdf-file_2.png)

特定のライブラリのバーコードを有効にすると、Aspose.PDF for SharePoint は、そのライブラリに追加された PDF ドキュメントにバーコードを追加します。

{{% /alert %}}
