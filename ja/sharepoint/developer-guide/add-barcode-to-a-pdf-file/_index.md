## PDF ファイルにバーコードを追加

{{% alert color="primary" %}}

Aspose.PDF for SharePoint を使用すると、PDF ドキュメントにバーコードを追加できます。ユーザーは、ライブラリに追加された PDF ドキュメントの各ページの左下隅にバーコードを追加できます。以下の画像は、バーコードが追加された PDF ドキュメントがどのように見えるかのイメージです。

### 左下隣のバーコード

![PDF ファイルにバーコードを追加-例 1](add-barcode-to-a-pdf-file_1.png)

{{% /alert %}}

{{% alert color="primary" %}}

特定のライブラリでバーコード機能を有効にするには、以下のように **Library Tools** の **Aspose PDF Watermark Tools** タブにある **Watermark Settings** ボタンを使用します。

### PDF ウォーターマーク設定

![PDF ファイルにバーコードを追加-例 2](add-barcode-to-a-pdf-file_2.png)

特定のライブラリでバーコードを有効にした後、Aspose.PDF for SharePoint はそのライブラリに追加されたすべての PDF ドキュメントにバーコードを追加します。

{{% /alert %}}
