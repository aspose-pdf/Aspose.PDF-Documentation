この記事では、Aspose.PDF for SharePoint を使用して、選択した複数のファイルを 1 回の変換操作で PDF ファイルに変換する方法を説明します。

{{% /alert %}}

## 選択した複数のファイルを PDF に変換

{{% alert color="primary" %}}

選択した複数のファイルを変換するには、次の手順を実行します。

1. 変換するファイルを選択します

![ファイルの選択](convert-multiple-selected-files-to-pdf-files-with-single-conversion-request_1.jpg)

2. ライブラリツールのAsposeツールタブをクリックします

![「Aspose ツール」をクリックします](convert-multiple-selected-files-to-pdf-files-with-single-conversion-request_2.jpg)

3. 「PDF に変換」をクリックして、選択したすべてのファイルを結果の PDF ファイルに変換します。

![PDFに変換](convert-multiple-selected-files-to-pdf-files-with-single-conversion-request_3.jpg)

4. 変換されたファイルをダウンロードするためのプロンプトが表示されます。

![変換されたファイルをダウンロードする](convert-multiple-selected-files-to-pdf-files-with-single-conversion-request_4.jpg)

![変換されたファイルをダウンロードする](convert-multiple-selected-files-to-pdf-files-with-single-conversion-request_5.jpg)
