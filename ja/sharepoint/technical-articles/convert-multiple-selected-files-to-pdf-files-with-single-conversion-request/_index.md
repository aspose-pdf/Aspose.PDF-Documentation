{{% alert color="primary" %}}

この記事では、Aspose.PDF for SharePoint を使用して、単一の変換操作で複数の選択されたファイルを PDF ファイルに変換する方法を示します。

{{% /alert %}}

## 複数の選択されたファイルを PDF に変換する

{{% alert color="primary" %}}

複数の選択されたファイルを変換するには、次の手順を実行してください：

1. 変換するファイルを選択します

![ファイルの選択](convert-multiple-selected-files-to-pdf-files-with-single-conversion-request_1.jpg)

2. Library Tools の Aspose Tools タブをクリックします

![Aspose Tools をクリックします](convert-multiple-selected-files-to-pdf-files-with-single-conversion-request_2.jpg)

3. Convert to PDF をクリックして、選択したすべてのファイルを結果の PDF ファイルに変換します。

![PDFに変換](convert-multiple-selected-files-to-pdf-files-with-single-conversion-request_3.jpg)

4. 変換されたファイルをダウンロードするためのプロンプトが表示されます。

![変換されたファイルをダウンロード](convert-multiple-selected-files-to-pdf-files-with-single-conversion-request_4.jpg)

![変換されたファイルをダウンロード](convert-multiple-selected-files-to-pdf-files-with-single-conversion-request_5.jpg)
