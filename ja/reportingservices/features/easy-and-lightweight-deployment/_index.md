**Aspose.PDF for Reporting Services** は、Microsoft SQL Server 2016/2017/2019/2022 Reporting Services および Power BI Report Server 用のカスタムレンダリング拡張機能です。Aspose.PDF for Reporting Services は、次のいずれかを実行しているコンピューターにインストールできる単一の MSI インストーラとして提供されます。

- Microsoft SQL Server 2016 Reporting Services  
- Microsoft SQL Server 2017 Reporting Services  
- Microsoft SQL Server 2019 Reporting Services  
- Microsoft SQL Server 2022 Reporting Services  
- Microsoft Power BI Report Server
 
Aspose.PDF for Reporting Services は、.NET アセンブリ Aspose.Pdf.ReportingServices.dll が 1 つだけで構成されており、完全に C# で記述され、CLS に準拠し、安全なマネージドコードのみを含んでいるため、展開および管理が容易です。サーバーには .NET Framework 4.8.1 がインストールされている必要があります。

Aspose.Pdf.ReportingServices.dll は ReportServer\\bin ディレクトリにコピーし、設定ファイルを更新して Reporting Services が新しいレンダリング拡張機能を認識できるようにする必要があります。これらの手順は Aspose.PDF for Reporting Services のインストーラによって実行されますが、本文書でさらに説明されているように手動でも実行できます。
