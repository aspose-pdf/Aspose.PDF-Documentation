{{% alert color="primary" %}}

RS2016、RS2017、RS2019、RS2022、Power BI の RDL 仕様では、カスタム プロパティを追加することでほぼすべてのレポート アイテムを拡張できます。現在、Reporting Services 2016、2017、2019、2022、Power BI の Aspose.PDF は、次の 3 つのプロパティをサポートしています。

- 目次、表または図のリスト。
- 線の矢印。
- 脚注/文末脚注。

使用方法については、 [レポート項目のプロパティを展開する](/pdf/ja/reportingservices/expand-report-items-properties/) 記事。

{{% /alert %}}
