MSI インストーラーを使用して、Aspose.PDF for Reporting Services をインストールできます。 Aspose.Pdf.ReportingServices.msi を実行し、インストーラーによって提供される手順に従います。インストーラーはアセンブリとその他のファイルを指定されたディレクトリにコピーし、Reporting Services の既定のインスタンスに製品をインストールします。 「Reporting Services 用の Aspose.PDF の構成」セクションで説明されているように特別な構成パラメーターを追加しない限り、ファイルを手動でコピーまたは変更する必要はありません。

自動インストールは、ほとんどの場合に機能する最良のオプションです。ただし、次のような状況では、製品を手動でインストールする必要がある場合があります。

- I/O セキュリティの問題により自動インストールが失敗します。
- 製品を Reporting Services 2016 の名前付き (既定ではない) インスタンスまたは複数のインスタンスにインストールする必要があります。
- 最新バージョンにアップグレードする場合、古いバージョンをアンインストールして MSI インストーラーを使用して新しいバージョンをインストールするのではなく、アセンブリを交換するだけで済みます。
 
{{% alert color="primary" %}}

注: 後者の場合、他のコンポーネント (オフライン ドキュメントなど) が対応するバージョンにアップグレードされない可能性があることに注意してください。

{{% /alert %}}
