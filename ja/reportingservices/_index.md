## Aspose.PDF for Reporting Services へようこそ

Microsoft SQL Server Reporting Services は、多くの組織が抱えるニーズ、すなわちビジネスインテリジェンスとレポーティングソリューションを構築する必要性を満たします。これまで、開発者はレポートをアプリケーションに埋め込む必要があり、または組織は高価で時に問題のあるサードパーティ製レポーティングソリューションを購入しなければなりませんでした。現在、Microsoft SQL Server Reporting Services は、エンタープライズ全体にレポートを配布するための包括的なソリューションを提供し、企業がより良く、より速く意思決定できるようにします。
