パラメータ化されたレポートとは、レポート処理で使用される入力値を受け取るレポートです。パラメータ化されたレポートを使用すると、レポート実行時に設定された値に基づいてレポートの出力を変えることができます。Aspose.PDF for Reporting Services は、report server parameters と report parameters の 2 種類のパラメータをサポートします。report server parameters は、レポート サーバー上のすべてのレポートで使用されます。特定のレポートに適したパラメータを作成したい場合は、report parameters を使用すべきです。

現在、Aspose.Pdf renderer は、以下のような幅広いパラメータをサポートしています。
