PDF ドキュメントの解析とは、既存の PDF ファイルから構造化されたコンテンツまたは生データを抽出し、検査、エクスポート、インデックス作成、または他の Workflow で再利用できるようにすることを指します。

このセクションでは次のことを扱います：

- [PDFからテキストを抽出](/pdf/ja/java/extract-text-from-pdf/) 使用 `TextAbsorber`, `ParagraphAbsorber`、および関連する API。
- [PDFから画像を抽出](/pdf/ja/java/extract-images-from-the-pdf-file/) ページリソースから。
- [PDFからフォントを抽出](/pdf/ja/java/extract-fonts-from-pdf/) ドキュメントで使用されているフォントを検査するために。
- [AcroForm からデータを抽出](/pdf/ja/java/extract-data-from-acroform/) フィールド値を JSON、XML、FDF、または XFDF にエクスポート。
- [テーブルからデータを抽出](/pdf/ja/java/extract-data-from-table-in-pdf/) 使用 `TableAbsorber` または検出されたテーブルを Excel にエクスポートします。
- [PDF からベクターデータを抽出](/pdf/ja/java/extract-vector-data-from-pdf/) と `GraphicsAbsorber` およびSVGエクスポートメソッド。
