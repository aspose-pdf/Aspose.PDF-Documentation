PDF ドキュメントの解析とは、既存の PDF ファイルから構造化されたコンテンツまたは生データを抽出し、検査、エクスポート、インデックス作成、または他の Workflow で再利用できるようにすることを指します。

このセクションでは次のことを扱います：

- [PDF からテキスト抽出](/pdf/ja/java/extract-text-from-pdf/) — `TextAbsorber`、`ParagraphAbsorber`、および関連する API を使用します。
- [PDF から画像抽出](/pdf/ja/java/extract-images-from-the-pdf-file/) — ページリソースから画像を抽出します。
- [PDF からフォント抽出](/pdf/ja/java/extract-fonts-from-pdf/) — ドキュメントで使用されているフォントを検査します。
- [AcroForm からデータ抽出](/pdf/ja/java/extract-data-from-acroform/) — フィールド値を JSON、XML、FDF、または XFDF にエクスポートします。
- [テーブルからデータ抽出](/pdf/ja/java/extract-data-from-table-in-pdf/) では、`TableAbsorber` を使用するか、検出されたテーブルを Excel にエクスポートします。
- [PDF からベクターデータ抽出](/pdf/ja/java/extract-vector-data-from-pdf/) と `GraphicsAbsorber` およびSVGエクスポートメソッド。
