アノテーションは、既存の PDF ファイルに対してメモの追加、テキストのハイライト、図形の描画、リンクの作成、レダクションの適用、および文書レビュー ワークフローの強化を可能にするインタラクティブな PDF 要素です。

このセクションでは、以下の作業を行います。

- [注釈の追加、削除、取得](/pdf/ja/java/add-delete-and-get-annotation/)（グループ化された注釈ファミリー用）
- [注釈のインポートとエクスポート](/pdf/ja/java/import-export-annotations/)（PDF ファイル間で注釈をコピーするため）
