アノテーションは、既存の PDF ファイルに対してメモを追加したり、テキストをハイライトしたり、図形を描いたり、リンクを作成したり、レダクションを適用したり、文書レビューのワークフローを強化したりできるインタラクティブな PDF 要素です。

このセクションを使用して:

- [注釈の追加、削除、取得](/pdf/ja/java/add-delete-and-get-annotation/) グループ化された注釈ファミリー用。
- [注釈のインポートとエクスポート](/pdf/ja/java/import-export-annotations/) PDFファイル間で注釈をコピーするために。
