ZUGFeRD は、人が読みやすい PDF 請求書と、ドキュメント内に埋め込まれた構造化された XML データを組み合わせます。現在の Java サンプルセットでは、対象となるワークフローは請求書 XML を PDF に添付し、結果を `PDF_A_3A` に変換することです。
