高度な操作セクションでは、基本的な作成、開く、保存、結合、分割操作に加えて、既存の PDF ドキュメントの編集、検査、セキュリティ強化、機能拡張に使用される Java ワークフローをまとめています。

- [ドキュメントの操作](/pdf/ja/java/working-with-documents/) - 文書の圧縮、分割、結合、およびその他の全体文書に対する操作を行います。
- [ページの操作](/pdf/ja/java/working-with-pages/) - ページの追加、移動、削除、トリミング、および透かしやスタンプなどの追加を行います。
- [画像の操作](/pdf/ja/java/working-with-images/) - PDF 文書から画像を追加、抽出、または削除します。
- [添付ファイル](/pdf/ja/java/attachments/) - Python を使用して PDF に添付ファイルをプログラムで追加および削除する方法を学んでください。
- [ナビゲーションとインタラクション](/pdf/ja/java/navigation-and-interaction/) - アクション、ブックマークの処理、ページのナビゲーションを行います。
- [注釈](/pdf/ja/java/annotations/) - 注釈により、ユーザーは PDF ページにカスタムコンテンツを追加できます。PDF ドキュメントから注釈を追加、削除、変更できます。
- [テーブルの操作](/pdf/ja/java/working-with-tables/) - PDF に表を挿入・装飾し、表形式データを抽出します。
- [Form の操作](/pdf/ja/java/working-with-forms/) - インタラクティブな PDF ドキュメントを扱い、FormField を追加し、データを抽出します。
- [Text の操作](/pdf/ja/java/working-with-text/) - PDF 内のテキストを追加・書式設定し、検索・置換します。
- [PDF ドキュメントの比較](/pdf/ja/java/compare-pdf-documents/) - PDFドキュメントの内容を比較できます。
- [PDF のメタデータ](/pdf/ja/java/pdf-file-metadata/) - ドキュメントのメタデータの取得・設定およびXMPデータの取り扱いが可能です。
- [グラフの操作](/pdf/ja/java/working-with-graphs/) - ページ上のシェイプを操作できます。
- [アーティファクト](/pdf/ja/java/artifacts/) - PDFのウォーターマークやその他の特殊オブジェクトを扱えます。
- [PDF レイヤーの操作](/pdf/ja/java/working-with-pdf-layers/) - レイヤーのロック、要素の抽出、フラット化、およびPDFレイヤーのマージが可能です。
- [保護と署名](/pdf/ja/java/securing-and-signing/) - プログラムでPDFドキュメントを保護・署名できます。
- [ベクトルグラフィックスの操作](/pdf/ja/java/working-with-vector-graphics/) - PDF文書内のベクターグラフィックスを操作できます。
- [ZUGFeRD の使用](/pdf/ja/java/working-with-zugferd/) - ZUGFeRD準拠のPDF文書を扱えます。
- [PDFオペレーターの使用](/pdf/ja/java/working-with-operators/) - 高度なPDF操作のためにPDFオペレーターを使用できます。
