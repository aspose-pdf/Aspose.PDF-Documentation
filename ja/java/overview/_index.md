_このページは Aspose.PDF for Java の機能の概要です。_

**Aspose for Java** は、Adobe Acrobat を使用せずにゼロから PDF ドキュメントを作成できる堅牢な Java コンポーネントです。Aspose.PDF for Java は、開発者向けに学習・使用が簡単な非常にシンプルなアプリケーションプログラミングインターフェイス (API) を提供します。

このライブラリを使用すると、ゼロから PDF ファイルを作成する豊富な機能を実装したり、Adobe Acrobat をインストールせずに既存の PDF ドキュメントを完全に処理したりできます。Aspose.PDF for Java は、**幅広い機能** をサポートしています。

### 文書圧縮

PDF 文書を圧縮すると、ファイルサイズが減少し、保存・共有・ネットワーク上での転送が容易になります。特に、高解像度の画像やグラフィックを含む大きな PDF ファイルを扱う場合に重要です。サイズが小さくなると、PDF 文書をオンラインやメール添付でアクセスする際の読み込み時間が短縮されます。圧縮された PDF は読み込みが速くなり、ユーザー体験と生産性が向上します。
**Aspose.PDF for Java Library** は、PDF のサイズを削減するためのさまざまな方法を提供します。例えば：

- すべての画像を縮小または圧縮する
- 未使用の PDF オブジェクトを削除する
- 未使用の PDF ストリームを削除する
- 重複した PDF ストリームをリンクする
- フォントの埋め込み解除
- 注釈の削除またはフラット化
- AcroForm フィールドの削除
- flateDecode 圧縮の使用
- XImageCollection への画像の保存（再利用可能な画像）
- PDF の RGB カラースペースからグレースケールへの変換

詳細については、Docs ページをご確認ください： [PDF の最適化](/pdf/ja/java/optimize-pdf/)

### テーブルの作成と操作

テーブルは、PDF ドキュメント内で情報を提示するための構造化された整理された形式を提供します。ユーザーはデータを行と列に分類および配置でき、複雑なデータセットをより容易に理解できるようになります。

PDF 文書でテーブルを作成および操作することで、**Aspose.PDF for Java** は、データの整理の向上、可読性の改善、分析機能の向上、情報を効果的に提示する柔軟性の増加など、多くの利点を提供します。

詳細については、次のセクションをご確認ください： [テーブルの操作](/pdf/ja/java/working-with-tables/)

### Graph オブジェクトのサポート

**Aspose.PDF for Java** は、PDF 文書へのグラフの追加をサポートしています。このタスクのために `Graph` クラスが提供されています。
PDF 文書へのグラフの追加は、データの可視化を改善し、明確さと理解度を高め、意思決定の支援を強化し、読者とのエンゲージメントを高めます。

詳細については、Docs ページをご確認ください：[グラフの操作](/pdf/ja/java/working-with-graphs/)

### 豊富なハイパーリンク機能

ハイパーリンクを使用すると、ユーザーは PDF 文書内を迅速かつ効率的にナビゲートできます。ハイパーリンクをクリックすることで、読者は文書を手動でスクロールすることなく、さまざまなセクション、章、ページへジャンプできます。

**Aspose.PDF for Java** は、ナビゲーションの改善、相互参照、外部リソースへのアクセス、インタラクティブ性、コミュニケーションの向上など、数多くの利点を提供します。これらは、ユーザーにとってより魅力的で、情報豊かかつアクセスしやすい読書体験に寄与します。

詳細については、次のセクションをご確認ください：[アクション](/pdf/ja/java/actions/)

### 拡張セキュリティ制御

デジタル署名などのセキュリティ機能は、PDF ドキュメントの完全性を確保するのに役立ちます。ドキュメントにデジタル署名を行うことで、送信者は署名後に内容が改ざんや変更されていないことを確認でき、受取人に対して文書の真正性に関する保証を提供します。

**Aspose.PDF for Java** を使用すると、スマートカードから PDF に署名したり、ファイルを暗号化・復号化したり、画像を抽出したり、署名情報を取得したりできます。

詳細については、Docs ページをご確認ください：[保護と署名](/pdf/ja/java/securing-and-signing/)

### ブックマークの追加または削除

ブックマークは、大規模または複雑な PDF ドキュメントをナビゲートするための便利な手段を提供します。特定のセクション、章、見出しにブックマークを作成することで、ユーザーはクリックひとつで関連コンテンツにジャンプでき、時間と労力を節約できます。

**Aspose.PDF for Java** ライブラリを使用すると、PDF ファイルにブックマークを追加したり、子ブックマークを追加したり、ドキュメントからすべてまたは特定のブックマークを削除したりできます。

詳細については、次のセクションをご確認ください：[ブックマーク](/pdf/ja/java/add-and-delete-bookmark/)

### 目次の作成

TOC は、PDF ドキュメントの内容を迅速かつ効率的にナビゲートする手段を提供します。主要なセクション、章、トピックとそれに対応するページ番号を一覧表示することで、ユーザーはドキュメント内の特定の情報を簡単に見つけてアクセスできます。
**Aspose.PDF for Java** ライブラリでは、既存の PDF ファイルに TOC を追加する方法と、Aspose.Pdf 名前空間の `Heading` クラスの使用方法について説明します。

詳細については、Docs ページをご確認ください：[TOC の操作](/pdf/ja/java/manipulate-pdf-document/)

###  添付ファイルと注釈の追加・更新・削除

添付ファイルや注釈を追加すると、PDF ドキュメントがよりインタラクティブで読者を引きつけるものになります。ユーザーは、文書内に埋め込まれたマルチメディアファイル、リンク、コメントなどの追加コンテンツと対話でき、読む体験が向上します。

Aspose.PDF for Java ライブラリには、さまざまな操作が用意されています。[注釈](/pdf/ja/java/annotations/)の追加方法は以下の通りです。

- テキスト注釈
- ハイライト注釈
- 図注釈
- マルチメディア注釈
- 付箋注釈
- 追加注釈

また、当社のライブラリでは、PDF から添付ファイルの追加・抽出・削除が可能です。
詳細については、[ドキュメントページ](/pdf/ja/java/attachments/) を参照してください。

###  PDF ファイルメタデータ

メタデータは、タイトル、作者、作成日、テーマなど、PDF ドキュメントに関する重要な情報を提供します。これにより、ユーザーは文書を素早く識別・分類でき、大量の PDF ファイルコレクションの管理と整理が容易になります。

PDF ファイルのメタデータは、文書の識別、属性付与、バージョン追跡、説明、検索性、アクセシビリティ、セキュリティ、相互運用性、保存、コンプライアンスなど、さまざまな目的に役立ちます。

**Aspose.PDF for Java** ライブラリを使用して、PDF ドキュメントの[メタデータ](/pdf/ja/java/pdf-file-metadata/)を簡単かつ迅速に管理してください。

### テキストと画像の追加、置換、削除

テキストや画像を追加、置換、または削除することで、ユーザーは PDF ドキュメントの内容を編集し、必要に応じて更新・修正・強化を行うことができます。この柔軟性により、ドキュメントの内容を変更や改訂に正確に反映させることができます。

Aspose.PDF を使用すると、PDF 内のテキストを編集・置換・回転したり、検索・取得したりできます。

また、画像の追加・位置変更・削除など、さらに多くの操作が可能です。[複雑な操作](/pdf/ja/java/working-with-images/)も PDF に画像が含まれている場合に実行できます。

### ページの分割、連結、抽出、挿入

その [PDF ページの操作](/pdf/ja/java/working-with-pages/) ドキュメントのセクションでは、PDF のページを追加、移動、削除、回転、または分割する方法が説明されています。

ページの分割、連結、抽出、または挿入は、ユーザーが PDF ドキュメントをより効果的に管理するのに役立ちます。ユーザーはページを整理、再配置、または結合して新しいドキュメントを作成でき、ドキュメントの構成とアクセシビリティが向上します。

### ページを画像に変換

PDF のページを画像に変換すると、PDF ドキュメントを直接閲覧または操作するのが困難なユーザーにとってコンテンツがよりアクセシブルになります。画像はスマートフォン、タブレット、コンピューターなど、さまざまなデバイスで簡単に閲覧でき、専門的なソフトウェアを必要としません。

Aspose.PDF では、Java を使用して PDF をさまざまな画像形式に変換できます。以下が利用可能です。

- TIFF
- BMP
- EMF
- JPG
- PNG
- GIF
- SVG

Aspose.PDF ライブラリの `DocumentDevice` クラスまたは `ImageDevice` クラスを使用して、PDF から画像に変換してください。詳細は [さまざまな画像形式への PDF の変換](/pdf/ja/java/convert-pdf-to-images-format/) を参照してください。

### PDF 文書の印刷

PDF ドキュメントの印刷により、ユーザーは電子デバイスを必要とせずに、簡単に持ち運びでき、アクセスできる物理的なコピーを作成できます。

Aspose.PDF for Java では、PDF ファイルを印刷するさまざまな方法が提供されています。

- Java Framework 4.x を使用した PDF の印刷
- Java Core での PDF の印刷
- Facades を使用した PDF の XPS プリンターへの印刷（コンソールアプリ）
- WPF アプリケーションでの PDF の印刷
- PDF を PostScript に変換することや、印刷ジョブのステータスを確認することなど、さまざまな追加操作

さらに、Aspose.PDF for Java は、テキスト、画像、SVG、HTML を PDF に簡単に変換し、PDF をさまざまな文書形式に変換することができ、優れたパフォーマンスと高品質を提供します。
