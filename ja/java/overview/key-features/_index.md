## 一般機能

- 完全に Java で書かれており、JDK 1.8 以降で動作します
- すべての Java アプリケーションをサポートします
- JavaDoc 形式の API リファレンス
- 32 ビット OS のサポート。
- 64 ビット OS のサポート。

## サポートされている PDF バージョン

Aspose.PDF for Java は PDF バージョン 1.2、1.3、1.4、1.5、1.6、および 1.7 をサポートしています。

## フォント

- 14 のコアフォント。
- PostScript Type1 フォント。
- TrueType フォント。
- Type 3 フォント。
- PDFにフォント情報を埋め込む
- CJKフォント。
- Unicodeサポート。

## テキスト

- テキストを置換する。
- テキストを抽出する（PDF全体、特定のページ、またはページ範囲から）。
- テキストを追加します。

## グラフ

- 線、円、弧、曲線など、さまざまな形状のグラフがサポートされています。
- グラフは座標で指定された任意のページ位置に描画できます。
- グラフは回転、拡大縮小、塗りつぶしが可能で、破線や多段破線のラインスタイルを定義できます。
- グラフは座標に基づいて描画され、相対位置ではなく絶対位置です。
- CMYK とグレー カラースペースがサポートされています。

## 画像

- PDF ファイルに画像を追加します。
- 画像を削除します。
- 画像を置き換えます。
- 画像を抽出します（PDF 全体、特定のページ、またはページ範囲から）。
- PDF を JPEG に変換（特定のページまたはすべてのページ）。
- PDF を TIFF に変換（単一ページまたはすべてのページ、またはピクセル化された TIFF 画像へ）。
- PDF を PNG に変換（特定のページまたはすべてのページ）。
- PDF を BMP に変換（特定のページまたはすべてのページ）。
- PDF を SVG に変換。
- PDF を EMF に変換。
- PDF を GIF に変換します。
