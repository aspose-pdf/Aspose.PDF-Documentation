**Aspose.PDF Java for Python** を使用して PDF ドキュメントを DOC または DOCX 形式に変換するには、単に **PdfToDoc** モジュールを呼び出すだけです。

```python
doc= self.Document()
pdf = self.Document()
pdf=self.dataDir + 'Template.pdf'
doc.save(self.dataDir + 'template.docx')
print "Document has been converted successfully"
```
