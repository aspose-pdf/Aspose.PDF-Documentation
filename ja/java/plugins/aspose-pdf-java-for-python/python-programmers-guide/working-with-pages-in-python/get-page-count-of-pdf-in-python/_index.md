**Aspose.PDF Java for Python** を使用して PDF ドキュメントのページ数を取得するには、**GetNumberOfPages** クラスを呼び出してください。

```Python
doc= self.Document()
pdf = self.Document()
pdf=self.dataDir + 'input1.pdf'
page_count = pdf.getPages().size()
print "Page Count:" . page_count

```
