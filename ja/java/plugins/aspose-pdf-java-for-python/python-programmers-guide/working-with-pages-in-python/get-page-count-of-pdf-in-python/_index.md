**Aspose.PDF Java for Python** を使用して PDF ドキュメントのページ数を取得するには、単に **GetNumberOfPages** クラスを呼び出します。

```Python
doc= self.Document()
pdf = self.Document()
pdf=self.dataDir + 'input1.pdf'
page_count = pdf.getPages().size()
print "Page Count:" . page_count

```
