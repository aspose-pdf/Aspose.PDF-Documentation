## サポート

最初の頃から、Asposeは単に優れた製品を提供するだけでは不十分だと考えていました。優れたサービスも提供する必要があります。私たち自身も開発者であり、技術的な問題やソフトウェアの不具合が作業の妨げになることがどれほど苛立たしいかを理解しています。私たちは問題を解決するためにあり、問題を作り出すためではありません。

このため、無償サポートを提供しています。製品を購入された方でも、評価版をご利用の方でも、すべてのユーザーが私たちの十分な注意と敬意を受ける権利があります。

以下のプラットフォームのいずれかを使用して、\u0412\u00A0Aspose.PDF Java for Python に関連する問題や提案を記録できます。

- [Github](https://github.com/aspose-pdf/Aspose.PDF-for-Java/issues)

## 拡張と貢献

Aspose.PDF Java for Python はオープンソースで、ソースコードは以下に示す主要なソーシャルコーディングサイトで入手できます。開発者はソースコードをダウンロードし、新機能の提案や追加、既存機能の改善などで貢献することが奨励されています。これにより、他のユーザーも恩恵を受けられます。
