## サポート

Aspose は、創業当初から、優れた製品を提供するだけでは不十分だと考えていました。優れたサービスの提供も必要です。私たち自身も開発者であり、技術的な問題やソフトウェアの不具合が作業を妨げることのいかに苛立たしいかを理解しています。私たちは、問題を解決するために存在し、問題を生み出すために存在しません。

このため、無償サポートを提供しています。製品を購入された方でも、評価版をご利用の方でも、すべてのユーザーが私たちの十分な注意と敬意を受ける権利があります。

以下のプラットフォームのいずれかを使用して、Aspose.PDF Java for Python に関連する問題や提案を記録してください。

- [Github](https://github.com/aspose-pdf/Aspose.PDF-for-Java/issues)

## 拡張と貢献

Aspose.PDF Java for Python はオープンソースであり、そのソースコードは以下に示す主要なソーシャルコーディングサイトで入手できます。開発者はソースコードをダウンロードし、新機能の提案や追加、既存機能の改善などに貢献することを奨励されています。これにより、他のユーザーも恩恵を受けられるようになります。
