## インストール

**Aspose.PDF Java for NetBeans (Maven)** プラグインは、プラグインダイアログの利用可能な **Plugin** タブから簡単にインストールできます。

- プラグインダイアログを開くには、NetBeans の **Tools** メニューから **Tools** を選択してください。

![todo:image_alt_text](installing-and-using-aspose-pdf-for-netbeans-maven_1.png)

- このプラグインをインストールすると、NetBeans IDE の New Project ウィザードに **Aspose.PDF Maven Project** が、New File ウィザードに **Java** が追加されます。

## 使用

### Aspose.PDF Maven Project (ウィザード)

ウィザードで **Aspose.PDF Maven Project** を作成して [Aspose.PDF for Java API](http://www.aspose.com/java/pdf-component.aspx) を使用するには：

1. **New Project** を選択してください。
2. **Aspose.PDF Maven Project** カテゴリで **Aspose.PDF Maven Project** を選択してください。
3. **Next** をクリックしてください。

Maven プロジェクトの **Project Name, Location, GroupId, ArtifactId** と **Version** を入力し、**Finish.** をクリックしてください。

これにより取得されます [Aspose.PDF for Java](http://www.aspose.com/java/pdf-component.aspx) 最新 [Maven 依存関係](http://maven.aspose.com/repository/ext-release-local/com/aspose/aspose-pdf/) 参照元 [Aspose Cloud Maven リポジトリ](https://repository.aspose.com/webapp/#/artifacts/browse/tree/General/repo) そして **pom.xml** に設定します。**Also Download Code Examples,** を選択した場合、**Code Examples** のダウンロードも開始されます。 [Aspose.PDF for Java API Examples リポジトリ。 ](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples)
ウィザードの完了後、**NetBeans IDE** 上に次の **Aspose.PDF Maven Project** プロジェクトが作成されます。

作成された **Aspose.PDF Maven Project** は **Aspose.PDF for Java API** を使用するように設定されており、プロジェクトの要件に合わせて拡張できる状態です。
ダウンロードを選択した場合、[コード例](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples)をインポートするために **Aspose.PDF Code Example (wizard)** を使用し、[Aspose.PDF for Java](http://www.aspose.com/java/pdf-component.aspx) API の必要な **Code Examples** をプロジェクトに取り込んでください。

### Aspose.PDF Code Example (wizard)

**Aspose.PDF Code Example wizard** は、[Aspose.PDF for Java](http://www.aspose.com/java/pdf-component.aspx) API 用に提供されている多数のサンプルを試すことができます。

{{% alert color="primary" %}}

**Aspose.PDF Code Example wizard** を快適に使用できるようにするには、**Aspose.PDF Maven Project** **Aspose.PDF Maven Project** で **Aspose.PDF Maven Project** を作成する際に常に **wizard** を選択することを推奨します。

{{% /alert %}}

例を使用するには、次のようにしてください。

1. **NetBeans** で **NetBeans** をクリックしてください。
2. プロジェクトを選択し、次に **Java** カテゴリで **Java** を選択してください。
3. **Next** をクリックしてください。

ツリーを展開して **Code Example** カテゴリを選択し、**Finish** をクリックしてください。

これにより、選択したカテゴリ **Code Examples** の Java ファイルが、プロジェクト内の **com.aspose.pdf.examples** パッケージ以下にコピーされます。また、コード例で必要なリソースは **src/main/resources** フォルダーにコピーされます（以下参照）。

例のコードを確認し、コンパイルして実行してください。
これで、他の例をテストし、[Aspose.PDF for Java API](http://www.aspose.com/java/pdf-component.aspx) を使用して独自のアプリケーションの構築を開始できます。
