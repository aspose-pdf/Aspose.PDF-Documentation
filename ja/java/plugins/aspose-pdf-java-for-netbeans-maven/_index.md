## 概要

### NetBeans IDE

NetBeans は、すべて Java で記述された、豊富な機能を備える Java IDE です。主に Java 開発を目的としていますが、PHP、C/C++、HTML5 などの言語にも対応しています。

NetBeans IDE では、Java のデスクトップ、モバイル、Web アプリケーションや、HTML、JavaScript、CSS を使用した HTML5 アプリケーションをすばやく簡単に開発できます。無料のオープンソースソフトウェアであり、世界中に多くのユーザーと開発者からなるコミュニティがあります。

NetBeans チームは製品を積極的にサポートし、幅広いコミュニティから機能の提案を受け付けています。各リリースの前には、コミュニティによるテストとフィードバックのための期間が設けられています。

### Aspose.PDF for Java

[Aspose.PDF for Java](https://products.aspose.com/pdf/java/) は、Adobe Acrobat を使用せずに Java アプリケーションで PDF ドキュメントを読み取り、書き込み、操作できる、堅牢な PDF ドキュメント作成 API です。

Aspose.PDF for Java は、PDF の圧縮オプション、テーブルの作成と操作、グラフのサポート、画像機能、豊富なハイパーリンク機能、高度なセキュリティ制御、カスタムフォントの処理など、多くの機能を提供します。

### Aspose.PDF Java for NetBeans (Maven)

- Aspose.PDF Java for NetBeans (Maven) は、**Aspose** が提供する **NetBeans IDE** 用のプラグインです。Maven プラットフォームで Java を開発し、プロジェクトで Aspose.PDF for Java を使用する開発者を対象としています。このプラグインでは、Aspose.PDF for Java API を使用する Maven プロジェクトを作成し、API の[コード例](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples)をダウンロードできます。
- このプラグインは、**NetBeans IDE** 内で Aspose.PDF for Java API を快適に使用するために、次の機能を提供します。

## ウィザード

プラグインには、2 つのウィザードが含まれています。

### Aspose.PDF Maven プロジェクト ウィザード

- この新規プロジェクトウィザードでは、**New Project -> Maven -> Aspose.PDF Maven Project** の順に選択して、Aspose.PDF for Java を使用する **Maven** プロジェクトを作成できます。
- Aspose.PDF for Java API の Maven 依存関係は、[Aspose Maven Repository](https://repository.aspose.com/webapp/#/artifacts/browse/tree/General/repo/com/aspose/aspose-pdf) から自動的に取得され、`pom.xml` に追加されます。
- 作成したプロジェクトには、常に Aspose.PDF for Java API の最新バージョンの **Maven** 依存関係が含まれます。
- ウィザードの手順には、Aspose.PDF for Java API を使用するコード例をダウンロードするオプションもあります。

### Aspose.PDF コード例 ウィザード

- この新規ファイル ウィザードでは、**New File -> Java -> Aspose.PDF Code Example** から、ダウンロードした[コード例](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples)をプロジェクトにコピーし、Aspose.PDF for Java を使用できます。
- 利用可能なサンプルはツリー形式で表示され、カテゴリ別に選択できます。
- 選択したカテゴリのすべての例は、プロジェクトの **com.aspose.pdf.examples** パッケージフォルダーにコピーされます。例の実行に必要なリソースも **src/main/resources** フォルダーにコピーされます。
- Aspose.PDF for Java API のコード例は、API のさまざまな機能を示すために用意されています。
- ウィザードは、[Aspose.PDF for Java のサンプルリポジトリ](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples)で新しく公開された更新も確認します。

## システム要件と対応プラットフォーム

### システム要件

- **システムメモリ:** 2 GB 以上（推奨）
- **OS:** Java VM（仮想マシン）に対応するオペレーティングシステム
- **インターネット接続:** 2 MB 以上の速度（推奨）

### 対応プラットフォーム

- NetBeans 8.1（推奨）
- NetBeans 8.0

## ダウンロード

### NetBeans のダウンロード

**Aspose.PDF Java for NetBeans (Maven)** プラグインをダウンロードする前に、NetBeans IDE をインストールしておく必要があります。

**Aspose.PDF Java for NetBeans (Maven)** プラグインは、**NetBeans IDE 8.0 と 8.1** に対応しています。NetBeans IDE は最新バージョンのみを使用することを推奨します。

NetBeans IDE をダウンロードするには、次の手順に従ってください。

1. <https://netbeans.apache.org/download/index.html> にアクセスしてください。
1. **Download** をクリックし、適切な NetBeans IDE バンドルをダウンロードしてください。

現在の最新リリースである **NetBeans IDE 8.1** の、Java EE / SE に対応するダウンロードバンドルのみをダウンロードしてください。

### Aspose.PDF Java for NetBeans (Maven) のダウンロード

- プラグインは、NetBeans のプラグインホスティング URL <http://plugins.netbeans.org/plugin/63218> から直接ダウンロードし、その後、次の IDE オプションを使用してインストールしてください。
  - **Tools** > **Plugins** > **Downloaded** を開いてください。
  - **Add Plugins...** をクリックし、ダウンロードした **Aspose.PDF Java for NetBeans (Maven)** の .nbm 拡張子のプラグインファイルを選択してください。
  - **Install** をクリックしてプラグインをインストールしてください。
- また、NetBeans のプラグインホスティング URL から手動でダウンロードせずに、次の IDE オプションを使用して直接インストールできます。
  - **Tools** > **Plugins** > **Available Plugins** を開いてください。
  - 検索ボックスに **Aspose** と入力してください。
  - **Aspose.PDF Java NetBeans (Maven)** プラグインを選択してください。
  - **Install** をクリックしてください。

### Aspose ライセンスの適用

このプラグインでは、Aspose.PDF の評価版を使用します。評価結果に満足したら、[Aspose の Web サイト](https://purchase.aspose.com/buy)でライセンスを購入できます。
評価メッセージと機能の制限を解除するには、製品ライセンスを適用する必要があります。製品を購入すると、ライセンスファイルが提供されます。ライセンスを適用するには、次の手順に従ってください。

- ライセンスファイルの名前が **Aspose.PDF.Java.lic** であることを確認してください。
- **Aspose.PDF.Java.lic** ファイルを、`Aspose.PDF.jar` が含まれるフォルダーに配置してください。
- 次のコードを使用してライセンスを有効にしてください。

```java
License license = new License();
license.setLicense("Aspose.PDF.Java.lic");
```

### Aspose.PDF Java for NetBeans (Maven) のソースコードの設定

次の手順で、NetBeans IDE 内に **Aspose.PDF Java for NetBeans (Maven)** プラグインのソースコードを設定できます。

1. ソースコードをダウンロードするか、クローンしてください。
1. **File** > **Open Project** を選択してください。
1. ダウンロードした最新のプロジェクトソースを参照し、プロジェクトを開いてください。
1. これで、Aspose.PDF Java for NetBeans (Maven) プラグインのコードを拡張できる状態になります。
