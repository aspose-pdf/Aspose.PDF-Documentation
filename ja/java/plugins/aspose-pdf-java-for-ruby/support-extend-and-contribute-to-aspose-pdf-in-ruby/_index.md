## サポート

Aspose が創業した初期の段階から、優れた製品を提供するだけでは不十分であると考えてきました。優れたサービスの提供も必要です。私たち自身も開発者であり、技術的な問題やソフトウェアの不具合が原因で、やりたいことができなくなるフラストレーションを理解しています。私たちは問題を解決するためにあり、問題を作り出すためではありません。

そのため、無償サポートを提供しています。製品を購入された方でも、評価版をご利用の方でも、すべてのユーザーが私たちの完全な注意と敬意を受ける権利があります。

以下のいずれかのプラットフォームを使用して、Ruby 向け Aspose.PDF Java に関する問題や提案を報告してください。

- [GitHub](https://github.com/aspose-pdf/Aspose.PDF-for-Java/issues)

## 拡張と貢献

Aspose.PDF Java for Ruby はオープンソースであり、そのソースコードは以下に挙げる主要なソーシャルコーディングサイトで入手可能です。開発者はソースコードをダウンロードし、新機能の提案や追加、既存機能の改善を通じて貢献することが奨励されており、他のユーザーもそれにより利益を得られます。
