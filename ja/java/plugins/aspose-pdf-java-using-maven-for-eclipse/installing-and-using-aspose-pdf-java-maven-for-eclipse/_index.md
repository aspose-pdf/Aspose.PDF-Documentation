## インストール

**Aspose.PDF Java (Maven) for Eclipse** プラグインは、プラグイン ダイアログの利用可能な **Plugin** タブから簡単にインストールできます。

- 開くには、Eclipse の **Tools** メニューから **Tools** を選択します。

![todo:image_alt_text](https://i.imgur.com/PCMRMUT.png)

- これにより、Eclipse IDE の [New Project] ウィザードに **Aspose.PDF Maven Project** が追加され、[New File] ウィザードに **Java** が追加されます。

## 使用

### Aspose.PDF Maven プロジェクト（ウィザード）

ウィザードで **Aspose.PDF Maven Project** を作成し、[Aspose.PDF for Java API](http://www.aspose.com/java/pdf-component.aspx) を使用するための手順です。

1. **New Project** を選択してください。
1. **Aspose.PDF Maven Project** カテゴリで **Aspose.PDF Maven Project** を選択してください。
1. **Next** をクリックしてください。

![todo:image_alt_text](https://i.imgur.com/6iywqND.png)

1. Maven プロジェクトの **Project Name, Location, GroupId, ArtifactId** と **Version** を指定し、**Finish.** をクリックしてください。

![todo:image_alt_text](https://i.imgur.com/zURjIn1.png)

1. これにより取得されます [Aspose.PDF for Java](http://www.aspose.com/java/pdf-component.aspx) 最新 [Maven 依存関係](https://repository.aspose.com/webapp/#/artifacts/browse/tree/General/repo/com/aspose/aspose-pdf/) 参照元 [Aspose Cloud Maven リポジトリ](https://repository.aspose.com/webapp/#/artifacts/browse/tree/General/repo) それを **pom.xml** に設定し、**Also Download Code Examples,** を選択した場合、**Code Examples** のダウンロードもこちらから開始されます。 [Aspose.PDF for Java API サンプルリポジトリ。](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples)
1. ウィザードの完了後、以下の **Aspose.PDF Maven Project** プロジェクトが **Eclipse IDE** に作成されます。

![todo:image_alt_text](https://i.imgur.com/xRfHrku.png)

1. 作成された **Aspose.PDF Maven Project** は **Aspose.PDF for Java API** を使用するように構成されており、プロジェクト要件に合わせて拡張できる状態です。
ダウンロードを選択した場合、[コード例](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples) をインポートするために、**Aspose.PDF Code Example (wizard)** を使用してください。これにより、[Aspose.PDF for Java](http://www.aspose.com/java/pdf-component.aspx) API の必要な **Code Examples** をプロジェクトにインポートできます。

### Aspose.PDF Code Example (wizard)

**Aspose.PDF Code Example wizard** を使用すると、[Aspose.PDF for Java](http://www.aspose.com/java/pdf-component.aspx) API で提供されている多数のサンプルを試すことができます。

{{% alert color="primary" %}}

**Aspose.PDF Code Example wizard** を快適に使用できるようにするには、**Aspose.PDF Maven Project** **Aspose.PDF Maven Project** で **Aspose.PDF Maven Project** を作成する際に常に **wizard** を選択することを推奨します、

{{% /alert %}}

サンプルを使用するには、次のようにしてください。

1. **Eclipse**で**Eclipse**をクリックしてください。
1. プロジェクトを選択し、次に**Java**カテゴリで**Java**を選択してください。
1. **Next** をクリックしてください。

![todo:image_alt_text](https://i.imgur.com/AuWybe8.png)

ツリーを展開して**Code Example**カテゴリを選択し、**Finish**をクリックしてください。

![todo:image_alt_text](https://i.imgur.com/PToFZjJ.png)

1. これにより、選択したカテゴリ **Code Examples** の Java ファイルが **com.aspose.pdf.examples** パッケージ配下のプロジェクトにコピーされます。また、コード例に必要なリソースが **src/main/resources** フォルダーにコピーされます。
1. サンプルコードを確認し、コンパイルして実行してください。
1. これで他のサンプルをテストし、使用して独自のアプリケーションの構築を開始できます。[Aspose.PDF for Java API](http://www.aspose.com/java/pdf-component.aspx)。
