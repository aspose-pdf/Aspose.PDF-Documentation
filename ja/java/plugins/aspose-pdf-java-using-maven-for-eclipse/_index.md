## はじめに

### Eclipse IDE

Eclipse IDE は著名な Java 統合開発環境 (IDE) です。この IDE は Eclipse オープンソースプロジェクトの中で最も知られた製品です。現在、約 60% のシェアで Java の主要な開発環境となっています。

Eclipse IDE は追加のソフトウェアコンポーネントで拡張可能です。Eclipse ではこれらのソフトウェアコンポーネントを Plug-ins と呼びます。複数のオープンソースプロジェクトや企業が Eclipse IDE の拡張や、Eclipse フレームワーク上にスタンドアロンアプリケーション (Eclipse RCP) の作成を行っています。

### Aspose.PDF for Java

[Aspose.PDF for Java](https://products.aspose.com/pdf/java/) は、Adobe Acrobat を使用せずに Java アプリケーションが PDF ドキュメントを読み取り、書き込み、操作できる堅牢な PDF ドキュメント作成 API です。

Aspose.PDF for Java は非常に豊富な機能を提供します。これには、PDF 圧縮オプション、テーブルの作成と操作、グラフのサポート、画像機能、包括的なハイパーリンク機能、拡張されたセキュリティ制御、カスタムフォントの取り扱いが含まれます。

### Aspose.PDF Java (Maven) for Eclipse

- Aspose.PDF Java (Maven) for Eclipse は **Eclipse IDE** 用の **Aspose.** が提供するプラグインです。このプラグインは、Java 開発に Maven プラットフォームを使用し、プロジェクトで Aspose.PDF for Java を利用したい開発者を対象としています。プラグインを使用すると、Aspose.PDF for Java API を利用するための Maven プロジェクトを作成し、さらにダウンロードも可能です。 [コード例](https://github.com/aspose-pdf/Aspose.Pdf-for-Java) API の。
- このプラグインは、**Eclipse IDE** 内で Aspose.PDF for Java API を快適に操作するための以下の機能を提供します。

![todo:image_alt_text](https://i.imgur.com/KWKGljg.png)

**ウィザード**:
このプラグインには 2 つのウィザードが含まれています。

**Aspose.PDF Maven プロジェクト (ウィザード)**

- この新規プロジェクト ウィザードでは、[New] → [Project] → [Maven] → [Aspose.PDF Maven Project] から、Aspose.PDF for Java を使用するための **Maven** プロジェクトを作成できます。
- Aspose.PDF for Java API の Maven 依存関係の参照は、[Aspose Cloud Maven リポジトリ](https://repository.aspose.com/webapp/#/artifacts/browse/tree/General/repo) から自動的に取得され、`pom.xml` に追加されます。
- 作成されたプロジェクトには、常に最新の利用可能なバージョンの **Maven** 依存関係（Aspose.PDF for Java API 用）が含まれます。
- ウィザードの手順では、Aspose.PDF for Java API を使用するための[コード例](https://github.com/aspose-pdf/Aspose.Pdf-for-Java)をダウンロードするオプションも表示されます。
Aspose.PDF コード例（ウィザード）

- この新規ファイルウィザードでは、ダウンロードした [コード例](https://github.com/aspose-pdf/Aspose.Pdf-for-Java) をプロジェクトにコピーし、Aspose.PDF for Java を使用できるようになります。操作手順は、「New -> Other -> Java -> Aspose.PDF Code Example」から行います。
- 利用可能なサンプルはツリーフォーマットで表示され、ユーザーはカテゴリ別に選択できます。
- 選択したカテゴリ内のすべての例は、プロジェクトの "**com.aspose.pdf.examples**" パッケージフォルダーへコピーされ、例を実行するために必要なリソースが含まれる "**src/main/resources**" フォルダーも同時にコピーされます。
- Aspose.PDF for Java API のコード例は、API のさまざまな機能を実証することを目的としています。
- ウィザードは、Aspose.PDF for Java のサンプルリポジトリから新たに利用可能な Code Examples を検索し、更新します。

## システム要件とサポート対象プラットフォーム

### システム要件

- **システムメモリ:** 2 GB 以上（推奨）
- **OS:** Java VM（仮想マシン）をサポートする任意のオペレーティングシステム
- **インターネット接続:** 2 MB 以上（推奨）

### 対応プラットフォーム

- Eclipse Mars.1 (4.5.1)（推奨）
- Eclipse Juno 以降。

## ダウンロード

### Eclipse IDE のダウンロード

まず、Eclipse IDE をインストールし、その後で Aspose.PDF Java (Maven) for Eclipse プラグインをダウンロードしてください。

Eclipse IDE のダウンロード

1. 移動先：[https://eclipse.org](https://eclipse.org/) にアクセスしてください。
1. Java SE / EE 開発者向けに推奨されている Eclipse IDE をダウンロードしてインストールしてください。

### Aspose.PDF Java (Maven) for Eclipse のダウンロード

以下は、Aspose.PDF Java (Maven) for Eclipse プラグインのダウンロードとインストールを成功させるために推奨される 3 つの方法です。

- [Eclipse Marketplace](https://marketplace.eclipse.org/content/asposepdf-java-maven-eclipse) から、ドラッグアンドドロップで Eclipse ワークスペースへインストールしてください。
- または、**Help** > **Install New Software...** > **Work with** に以下の更新サイト URL を入力してください。
次に、「Aspose.PDF Java (Maven) for Eclipse」を選択し、**Finish** をクリックしてください。ライセンス契約に同意したうえで、プラグインをインストールしてください。

### Aspose ライセンスの適用方法

このプラグインは Aspose.PDF の評価版を使用しています。評価に満足したら、[Aspose のウェブサイト](https://purchase.aspose.com/buy) からライセンスを購入できます。
評価メッセージと機能制限を解除するには、製品ライセンスを適用する必要があります。製品を購入するとライセンス ファイルが提供されます。ライセンスを適用するには、以下の手順に従ってください。

- ライセンス ファイルの名前が `Aspose.PDF.Java.lic` であることを確認してください。
- `Aspose.PDF.jar` が含まれるフォルダーに **Aspose.PDF.Java.lic** ファイルを配置してください。
- ライセンスを有効化するには、以下のコードを使用してください：

{{< highlight java >}}

 License license = new License();

license.setLicense("Aspose.PDF.Java.lic");

{{< /highlight >}}

### Aspose.PDF Java (Maven) for Eclipse のソースコードを構成する方法

以下の簡単な手順に従うことで、Eclipse IDE で **"Aspose.PDF Java (Maven) for Eclipse"** プラグインのソースコードをスムーズに構成できます。

1. ソースコードをダウンロード / クローンしてください。
1. **File** > Import > General > Existing Projects into Workspace を選択してください。
1. ダウンロードした最新のプロジェクトソースへ参照してください。
1. インポートしたい Eclipse プロジェクトを選択してください。
1. Finish をクリックしてください。
1. Aspose.PDF Java for Eclipse プラグインのコードは、これで拡張できるようになりました。
