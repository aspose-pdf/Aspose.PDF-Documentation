## はじめに

### Eclipse IDE

Eclipse IDE は有名な Java 統合開発環境 (IDE) です。この IDE は Eclipse オープンソースプロジェクトの中で最も知られている製品で間違いありません。現在、約 60% のシェアで Java の主要な開発環境となっています。

Eclipse IDE は追加のソフトウェアコンポーネントで拡張できます。Eclipse はこれらのソフトウェアコンポーネントを Plug-ins と呼びます。複数のオープンソースプロジェクトや企業が Eclipse IDE を拡張したり、Eclipse フレームワーク上にスタンドアロンアプリケーション (Eclipse RCP) を作成したりしています。

### Aspose.PDF for Java

[Aspose.PDF for Java](https://products.aspose.com/pdf/java/)は、Adobe Acrobat を使用せずに Java アプリケーションが PDF ドキュメントを読み取り、書き込み、操作できる堅牢な PDF ドキュメント作成 API です。

Aspose.PDF for Java は、非常に豊富な機能を提供します。これには PDF 圧縮オプション、テーブルの作成と操作、グラフのサポート、画像機能、包括的なハイパーリンク機能、拡張されたセキュリティ制御、カスタム フォントの取り扱いが含まれます。

## システム要件とサポート対象プラットフォーム

### システム要件

- **システムメモリ:** 2 GB 以上 (推奨)
- **OS:** Java VM（仮想マシン）をサポートする任意のオペレーティングシステム。
- **インターネット接続:** 2 MB 以上 (推奨)

### 対応プラットフォーム

- Eclipse Mars.1 (4.5.1) - 推奨
- Eclipse Juno 以降。

## ダウンロード中

### Eclipse IDE をダウンロード

まず、Eclipse IDE をインストールしてから、Aspose.PDF Java (Maven) for Eclipse プラグインをダウンロードする必要があります。

Eclipse IDE をダウンロードするには

1. 移動先 [https://eclipse.org](https://eclipse.org/).
1. Java SE / EE 開発者向けに推奨されている Eclipse IDE をダウンロードしてインストールしてください。

### Aspose.PDF Java (Maven) for Eclipse をダウンロード

以下は、Aspose.PDF Java (Maven) for Eclipse プラグインのダウンロードとインストールを成功させるために推奨される 3 つの方法です：

- ドラッグアンドドロップでインストールする [Eclipse Marketplace](https://marketplace.eclipse.org/content/asposepdf-java-maven-eclipse) Eclipse ワークスペースへ。
- または **Help** > **Install New Software...** > **Work with** に以下の更新サイト URL を入力します
次に "Aspose.PDF Java (Maven) for Eclipse" を選択し、**Finish** をクリックします。ライセンス契約に同意し、プラグインをインストールします。

### Aspose ライセンスの適用方法は？

このプラグインは Aspose.PDF の評価版を使用しています。評価に満足したら、以下からライセンスを購入できます。 [Aspose のウェブサイト](https://purchase.aspose.com/buy).
評価メッセージと機能制限を解除するには、製品ライセンスを適用する必要があります。製品を購入するとライセンス ファイルが提供されます。ライセンスを適用するには、以下の手順に従ってください。

- ライセンス ファイルの名前が Aspose.PDF.Java.lic であることを確認してください
- Aspose.PDF.jar が含まれるフォルダーに **Aspose.PDF.Java.lic** ファイルを配置してください
- ライセンスを有効化するには、以下のコードを使用してください：

{{< highlight java >}}

 License license = new License();

license.setLicense("Aspose.PDF.Java.lic");

{{< /highlight >}}

### Aspose.PDF Java (Maven) for Eclipse のソースコードを構成する方法

以下の簡単な手順に従うことで、Eclipse IDE で **"Aspose.PDF Java (Maven) for Eclipse"** プラグインのソースコードをスムーズに構成できます。

1. ソースコードをダウンロード / クローンしてください。
1. **File** > Import > General > Existing Projects into Workspace を選択します。
1. ダウンロードした最新のプロジェクトソースへ参照してください
1. インポートしたい Eclipse プロジェクトを選択してください。
1. Finish をクリック
1. Aspose.PDF Java for Eclipse プラグインコードは、これで拡張できるようになりました。
