## はじめに

### IntelliJ IDEA

IntelliJ IDEA はソフトウェア開発者向けの Java 統合開発環境 (IDE) です。JetBrains が開発しています。当初は Java 用に作られましたが、現在では JavaScript、Groovy、HTML、CSS、RSS、R、Haskell、PHP、Ruby、Python、Scala、Clojure、Kotlin など、多種多様な言語をサポートしています。

2010 年の Infoworld レポートで、IntelliJ は Eclipse、IntelliJ IDEA、NetBeans、Oracle JDeveloper の4つの主要な Java プログラミングツールの中で、テストセンタースコアが最も高い評価を受けました。

### Aspose.PDF for Java

Aspose.PDF for Java は、PDF 文書作成コンポーネントであり、Java アプリケーションが Adobe Acrobat を使用せずに PDF 文書を読み取り、書き込み、操作できるようにします。

### IntelliJ IDEA 用 Aspose.PDF Java - Maven

- Aspose.PDF Java for IntelliJ IDEA (Maven) は、IntelliJ IDEA のプラグインで、Maven プロジェクトを作成でき（例：作成されたプロジェクトに Aspose.PDF for Java API の Maven 依存関係が含まれます）し、Aspose.PDF for Java API を使用するための APIВ  のソースコード例をダウンロードできます。
- このプラグインは、お好みの IntelliJ IDEA 内で Aspose.PDF for Java API を使用して作業するのに役立ちます。

![todo:image_alt_text](https://i.imgur.com/KWKGljg.png)

ウィザード:
プラグインには2つのウィザードが含まれています

ウィザード 1: Aspose.PDF Maven プロジェクト

- Pluginの Aspose Maven Project Wizard は、開発者が Aspose.PDF for Java API Maven プロジェクトを作成できるようにします。
- Aspose.PDF for Java API の maven 依存関係の参照は自動的に取得されます [Aspose Cloud Maven リポジトリ](https://repository.aspose.com/webapp/#/artifacts/browse/tree/General/repo) そして pom.xml に追加されます。
- 作成されたプロジェクトには、常に最新の利用可能な Aspose.PDF for Java API 用 Maven Dependency が含まれます。
- ウィザードの手順でも\u0412\u00A0ダウンロードのオプションが表示されます。 [Aspose.PDF for Java API を使用するためのソースコード例](https://github.com/aspose-pdf/Aspose.PDF-for-Java)

ウィザード 2: Aspose.PDF の例

- Aspose.PDF Examples Wizard を使用すると、ダウンロードされた\u0412\u00A0Aspose.PDF for Java API のソースコード例をプロジェクトに作成/コピーできます。選択されたカテゴリのすべての例は、プロジェクト\u0027s\u0412\u00A0 \u0022com.aspose.pdf.examples\u0022 パッケージフォルダにコピーされ、例の実行に必要なリソースが \u0022src/main/resources\u0022 フォルダ内に含まれます。
- Aspose.PDF for Java API のソースコード例は、API のさまざまな使用方法を示すことを目的としています。

## ダウンロード中

### IntelliJ IDEA をダウンロード中

IntelliJ IDEA CE / UE を最初にインストールしてから、Aspose.PDF Java for IntelliJ IDEA (Maven) プラグインをダウンロードする必要があります。

IntellliJ IDEA をダウンロードするには

1. 移動 <https://www.jetbrains.com/idea/download/>
1. 実行中のOSを選択してください。
1. UEまたはCEのダウンロードをクリックしてください。

### Aspose.PDF Java for IntelliJ IDEA プラグイン (Maven) をダウンロードしています

- プラグインは直接ダウンロードできます [JetBrains プラグインホスティング URL](https://goo.gl/z06gC0) - IntelliJ IDEA プラグインリポジトリで
  その後、IDE のオプションを使用してインストールできます:
  - File > Settings... > Plugins へ移動
  - "Install plugin from Disk" を選択
- または、IDE のオプションを使用して直接インストールできます（JetBrains プラグインホスティング URL から手動でダウンロードせずに）:
  - File > Settings... > Plugins へ移動
  - "Browse Repositories" を選択
  - 検索ボックスに「Aspose」と入力してください。
  - 「Aspose.PDF Java for IntelliJ IDEA Maven」プラグインを選択してインストールします。
