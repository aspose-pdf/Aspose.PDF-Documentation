## はじめに

### IntelliJ IDEA

IntelliJ IDEA はソフトウェア開発者向けの Java 統合開発環境 (IDE) です。JetBrains が開発しています。当初は Java 用に作られましたが、現在では JavaScript、Groovy、HTML、CSS、RSS、R、Haskell、PHP、Ruby、Python、Scala、Clojure、Kotlin など、多種多様な言語をサポートしています。

2010 年の Infoworld レポートで、IntelliJ は Eclipse、IntelliJ IDEA、NetBeans、Oracle JDeveloper の 4 つの主要な Java プログラミングツールの中で、テストセンタースコアが最も高い評価を受けました。

### Aspose.PDF for Java

Aspose.PDF for Java は PDF 文書作成コンポーネントであり、Java アプリケーションが Adobe Acrobat を使用せずに PDF 文書を読み取り、書き込み、操作できるようにします。

### IntelliJ IDEA 用 Aspose.PDF Java - Maven

- Aspose.PDF Java for IntelliJ IDEA（Maven）は、IntelliJ IDEA のプラグインであり、Maven プロジェクトの作成（例：作成されたプロジェクトには Aspose.PDF for Java API の Maven 依存関係が含まれます）および Aspose.PDF for Java API のソースコード例のダウンロードが可能です。
- このプラグインは、お使いの IntelliJ IDEA 内で Aspose.PDF for Java API を使用して作業するのに役立ちます。

ウィザード
このプラグインには 2 つのウィザードが含まれています。

ウィザード 1: Aspose.PDF Maven プロジェクト

- プラグインの Aspose Maven Project Wizard を使用すると、開発者は Aspose.PDF for Java API Maven プロジェクトを作成できます。
- Aspose.PDF for Java API の Maven 依存関係の参照は、自動的に [Aspose Cloud Maven リポジトリ](https://repository.aspose.com/webapp/#/artifacts/browse/tree/General/repo) から取得され、`pom.xml` に追加されます。
- 作成されたプロジェクトには、常に最新の利用可能な Aspose.PDF for Java API 用 Maven 依存関係が含まれます。
- ウィザードの手順では、[Aspose.PDF for Java API を使用するためのソースコード例](https://github.com/aspose-pdf/Aspose.PDF-for-Java) をダウンロードするオプションも表示されます。

ウィザード 2: Aspose.PDF の例

- Aspose.PDF Examples Wizard を使用すると、ダウンロードされた\u0412\u00A0Aspose.PDF for Java API のソースコード例をプロジェクトに作成/コピーできます。選択されたカテゴリのすべての例は、プロジェクト\u0027s\u0412\u00A0 \`u0022com.aspose.pdf`.examples\u0022 パッケージフォルダにコピーされ、例の実行に必要なリソースが \u0022src/main/resources\u0022 フォルダ内に含まれます。
- Aspose.PDF for Java API のソースコード例は、API のさまざまな使用方法を示すことを目的としています。

## システム要件およびサポートプラットフォーム

### システム要件

- Microsoft Windows 8/7/Vista/2003/XP（64 ビット版を含む）、Linux GNOME または KDE デスクトップ、Mac OS X 10.5 以降
- 最低 1 GB の RAM、推奨 2 GB の RAM
- 300 MB のハードディスク領域と、キャッシュ用に少なくとも 1 GB
- 最小画面解像度 1024×768
- JDK 1.8 以上を推奨
- インターネット接続（2 MB/s 以上を推奨）

### 対応プラットフォーム

プラグインは以下の IntelliJ IDEA バージョンをサポートします：

- 13.1.2В  (CE / UE)
- 14.0.2 (CE/ UE)
- 14.1.5 (CE/ UE)

## ダウンロード

### IntelliJ IDEA のダウンロード

IntelliJ IDEA CE / UE を最初にインストールしてから、Aspose.PDF Java for IntelliJ IDEA (Maven) プラグインをダウンロードしてください。

IntellliJ IDEA をダウンロードするには

1. 移動 <https://www.jetbrains.com/idea/download/>
1. 実行中の OS を選択してください。
1. UE または CE のダウンロードをクリックしてください。

### Aspose.PDF Java for IntelliJ IDEA プラグイン (Maven) のダウンロード

- プラグインは、IntelliJ IDEA プラグインリポジトリの [JetBrains プラグインホスティング URL](https://goo.gl/z06gC0) から直接ダウンロードできます。
その後、IDE のオプションを使用してインストールできます。
  - 「File > Settings... > Plugins」へ移動してください。
  - 「Install plugin from Disk」を選択してください。
- または、IDE のオプションを使用して直接インストールできます（JetBrains プラグインホスティング URL から手動でダウンロードせずに）。
  - 「File > Settings... > Plugins」へ移動してください。
  - 「Browse Repositories」を選択してください。
  - 検索ボックスに「Aspose」と入力してください。
  - 「Aspose.PDF Java for IntelliJ IDEA Maven」プラグインを選択してインストールしてください。
