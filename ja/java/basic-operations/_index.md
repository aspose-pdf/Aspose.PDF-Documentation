**Basic operations** セクションでは、Aspose.PDF for Java で実行できる最初で最もシンプルな PDF タスクについて説明します：

- [PDF ドキュメントを作成](/pdf/ja/java/create-document/) - Java でプログラム的に新しい PDF ドキュメントを作成します。
- [PDF ドキュメントを開く](/pdf/ja/java/open-pdf-document/) - パス、ストリーム、またはパスワードから PDF ファイルを開く。
- [PDF ドキュメントを保存](/pdf/ja/java/save-pdf-document/) - ドキュメントをファイル、ストリーム、または PDF 標準として保存します。
- [PDF を結合](/pdf/ja/java/merge-pdf/) - 複数の PDF ファイルを 1 つの出力ドキュメントに結合します。
- [PDF を分割](/pdf/ja/java/split-pdf/) - PDF ページを個別の単一ページ PDF ファイルに分割します。
- [PDF ファイルの暗号化と復号化](/pdf/ja/java/protect-pdf-file/) - PDF ファイルにパスワード、権限、復号化を適用します。
