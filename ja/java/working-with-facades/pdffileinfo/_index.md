Java の `PdfFileInfoExamples` クラスは、Facades API を通じて利用可能な主要な検査およびメタデータ ワークフローを示しています。

このセクションを使用して、以下の方法を学びます。

- PDF バージョンとドキュメント権限を読み取る
- ページの幅、高さ、回転、オフセットを検査する
- XMP を使用してドキュメント メタデータを取得、設定、クリア、保存する
