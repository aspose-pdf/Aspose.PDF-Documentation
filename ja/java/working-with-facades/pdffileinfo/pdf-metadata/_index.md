保存、インデックス作成、または配布の前にドキュメント情報を検査または正規化する必要がある場合は、これらの例を使用してください。

このセクションでは、以下の方法について説明します：

- 標準およびカスタムのメタデータ フィールドを読み取る
- メタデータの値を更新し、結果を保存する
- 既存のドキュメント情報をクリアする
- 更新された情報を XMP で書き戻す
