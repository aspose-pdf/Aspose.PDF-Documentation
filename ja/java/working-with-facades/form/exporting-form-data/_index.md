Java `FormExamples` クラスには、これらの形式に対する直接エクスポートワークフローが含まれています:

- XML と `form.exportXml(...)`
- FDF と `form.exportFdf(...)`
- XFDF と `form.exportXfdf(...)`

このセクションの子ページを具体的な例として使用してください。このリポジトリ内の現在の Java サンプルセットには、専用のものは含まれていません。 `Form` JSON エクスポートまたは XFA 抽出のためのファサード例で、これらのページは合成コードのウォークスルーではなくスコープノートとして維持されます。
