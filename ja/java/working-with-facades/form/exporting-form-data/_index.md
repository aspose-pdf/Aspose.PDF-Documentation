Java の `FormExamples` クラスには、これらの形式に対する直接エクスポートワークフローが含まれています。

- XML と `form.exportXml(...)`
- FDF と `form.exportFdf(...)`
- XFDF と `form.exportXfdf(...)`

具体的な例については、このセクションの子ページをご利用ください。このリポジトリ内の現在の Java サンプルセットには、JSON エクスポートまたは XFA 抽出のための専用 `Form` ファサード例は含まれていません。そのため、これらのページは合成コードのウォークスルーではなくスコープノートとして維持されています。
