そのJava `FormExamples` クラスは、Facades API によって公開されている主なフォーム処理ワークフローを示します。

このセクションを使用して、次のことを学びます：

- テキスト、チェックボックス、ラジオボタン、リストボックス、バーコードフィールドに入力する
- フォームデータをXML、FDF、XFDFにエクスポートする
- XML、FDF、XFDFからフォームデータをインポートする
- すべてのフォームフィールドをフラット化し、既存のフィールドの名前を変更する
- フィールド名と現在の値を検査する
- 入力ストリームから画像ボタンフィールドに入力する
