Java の `FormExamples` クラスには、これらの形式の直接インポートワークフローが含まれています。

- XML と `form.importXml(...)`
- FDF と `form.importFdf(...)`
- XFDF と `form.importXfdf(...)`

このセクションの子ページを具体的な例として使用してください。このリポジトリの現在の Java サンプルセットには、専用の `Form` ファサード例が JSON インポートまたは XFA 置換用に含まれていませんので、これらのページはスコープノートとして維持されます。
