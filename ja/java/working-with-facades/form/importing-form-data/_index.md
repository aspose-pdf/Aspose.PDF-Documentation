Java `FormExamples` クラスは、これらの形式の直接インポートワークフローを含んでいます。

- XML と `form.importXml(...)`
- FDF と `form.importFdf(...)`
- XFDF と `form.importXfdf(...)`

このセクションの子ページを具体的な例として使用してください。このリポジトリの現在の Java サンプルセットには、専用のものが含まれていません `Form` JSONインポートまたはXFA置換のためのファサード例で、これらのページはスコープノートとして維持されます。
