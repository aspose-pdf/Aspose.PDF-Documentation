Java `FormExamples` クラスはメインを示します `Form.fillField(...)` そして `Form.fillBarcodeField(...)` インタラクティブ PDF フォームを入力するために使用される Workflow。

このセクションを使用して、次の方法を確認できます：

- フィールド名でテキストフィールドに入力する
- チェックボックスとラジオボタンの値を選択する
- リストボックスの値を設定する
- バーコードフィールドに入力する
- 動的な名前-値ペアのために、独自のループで同じフィールド入力APIを適用する
