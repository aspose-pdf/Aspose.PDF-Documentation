そのJava `FormExamples` クラスは直接的な例を含んでいます:

- `flattenAllFields(...)`
- `renameFormFields(...)`

リポジトリには現在、別個の Java が含まれていません。 `Form` 選択されたサブセットのフィールドだけをフラット化するファサードの例で、子ページが作成されたサンプルコードではなく、スコープノートとして文書化されます。
