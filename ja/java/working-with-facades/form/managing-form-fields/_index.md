Java の `FormExamples` クラスには、以下の直接的な例が含まれています。

- `flattenAllFields(...)`
- `renameFormFields(...)`

リポジトリには現在、選択されたサブセットのフィールドだけをフラット化するための別個の Java `Form` ファサードの例は含まれていません。そのようなケースについては、子ページを作成するのではなく、スコープノートとして文書化されます。
