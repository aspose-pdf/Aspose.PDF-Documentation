そのJava `PdfFileSecurityExamples` クラスは、Facades API を通じて利用可能な主要なセキュリティワークフローを示します。

このセクションを使用して、次の方法を学びます：

- ユーザーとオーナーパスワードで PDF を暗号化する
- 文書権限を適用または更新する
- オーナーパスワードで PDF の暗号化を解除する
- パスワードを変更し、必要に応じてセキュリティ設定をリセットする
