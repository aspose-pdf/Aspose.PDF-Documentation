Java の `PdfFileEditorExamples` クラスには、PDF ファイルをマージするための直接的な `concatenate` サンプルが含まれています。

このセクションでは、以下の内容が確認できます。

- 配列ベースのソース バックマージ カバレッジ `concatenate` ワークフロー
- 同じ Java サンプルを使用する同等の 2 ファイル記事に関するガイダンス
- 大規模バッチ、最適化、フォーム固有、および `try` マージのバリアントに対する明示的なスコープノート。これらのバリアントは、現在のリポジトリ例セットでは専用メソッドとして実装されていません。
