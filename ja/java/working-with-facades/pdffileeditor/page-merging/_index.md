Java `PdfFileEditorExamples` クラスは直接含んでいます `concatenate` PDF ファイルをマージするサンプル。

このセクションでは次のものが見つかります:

- 配列ベースのソースバックマージカバレッジ `concatenate` ワークフロー
- 同じ Java サンプルを使用する同等の 2 ファイル記事に関するガイダンス
- 大規模バッチ、最適化、フォーム固有、そして向けの明示的なスコープノート `try` 現在のリポジトリ例セットで、専用メソッドとして実装されていないバリアントをマージする
