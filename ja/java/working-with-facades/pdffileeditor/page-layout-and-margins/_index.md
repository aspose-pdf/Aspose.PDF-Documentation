PDF のレイアウトを最初から再構築せずにクリーンアップする必要がある場合は、これらの PdfFileEditor ワークフローを使用してください。

このセクションでは、以下の方法について説明します。

- 選択したページに余白を追加する
- 特定のページのコンテンツボックスのサイズを変更する
- ページを定義された垂直位置で改ページとともに分割する
