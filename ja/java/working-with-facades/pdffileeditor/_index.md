そのJava `PdfFileEditorExamples` クラスは、Facades API によって提供される主要なドキュメント編集ワークフローを示します。

このセクションを使用して、以下の方法を学びます：

- PDFファイルを結合する `concatenate` メソッド
- 文書を最初から最後まで、または単一ページファイルに分割する
- ページを抽出、削除、挿入、追加する
- 冊子形式および N-Up 出力を作成して印刷する
- 余白を追加し、ページ内容のサイズを変更し、改ページを挿入する
