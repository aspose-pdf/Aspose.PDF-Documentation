Java の `PdfFileEditorExamples` クラスは、Facades API によって提供される主要なドキュメント編集ワークフローを示します。

このセクションでは、以下の方法を学習します。

- PDFファイルを結合するには、`concatenate` メソッドを使用してください。
- 文書を最初から最後まで、または単一ページファイルに分割してください。
- ページを抽出、削除、挿入、追加してください。
- 冊子形式および N-Up 出力を生成して印刷してください。
- 余白を追加し、ページ内容のサイズを変更し、改ページを挿入してください。
