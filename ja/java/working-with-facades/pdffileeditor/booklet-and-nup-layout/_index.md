印刷やコンパクトなレビューのために既存の PDF をリフローする必要がある場合は、PdfFileEditor ファサードを使用してください。

このセクションでは、以下の内容について説明します。

- 既存のドキュメントからブックレット対応の PDF を作成する
- N-Up レイアウトを使用して、各出力シートに複数のソースページを配置する
- Java サンプルセットの `try` スタイルで使用されるブール型の戻り値を処理する方法
