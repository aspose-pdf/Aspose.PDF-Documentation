印刷やコンパクトレビューのために既存の PDF をリフローする必要がある場合は、PdfFileEditor ファサードを使用します。

このセクションでは、次の方法について説明します：

- 既存のドキュメントからブックレット対応の PDF を作成する
- N-Up レイアウトを使用して、各出力シートに複数のソースページを配置する
- boolean の戻り値を処理する `try` Javaサンプルセットのスタイル例
