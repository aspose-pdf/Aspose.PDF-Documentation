文書を再利用、配布、または下流処理のために小さな出力に分割する必要がある場合は、このセクションを使用してください。

このセクションでは、以下の方法について説明します。

- 最初のページを新しい PDF に抽出する
- 選択したページから最後までのすべてのページを抽出する
- 各ページを個別のファイルに、指定した出力命名パターンでエクスポートする
