このセクションは、PDF ファイル内のアノテーションを作成、検査、削除、転送するために使用される Java アノテーションワークフローをまとめています。

現在のリポジトリには専用の `PdfAnnotationEditorExamples.java` クラスが含まれていません。このセクションの内容は、`en/java/src/main/java/com/aspose/pdf/examples/workingwithannotations` 配下の Java の例から取得しています。

このセクションでは、以下の作業を行います。

- [注釈の追加、削除、取得](/pdf/ja/java/pdfannotationeditor-class/add-delete-and-get-annotation/)：グループ化された注釈ファミリ用です。
- [注釈のインポートとエクスポート](/pdf/ja/java/pdfannotationeditor-class/import-export-annotations/)：PDF ファイル間で注釈をコピーするために使用します。
