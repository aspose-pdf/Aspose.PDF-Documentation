このセクションは、PDF ファイル内のアノテーションを作成、検査、削除、転送するために使用される Java アノテーションワークフローをまとめています。

現在のリポジトリには専用のものが含まれていません `PdfAnnotationEditorExamples.java` クラス。このセクションでは、記事の内容は以下の Java の例から取得されています。 `en/java/src/main/java/com/aspose/pdf/examples/workingwithannotations`.

このセクションを使用して：

- [注釈の追加、削除、取得](/pdf/ja/java/pdfannotationeditor-class/add-delete-and-get-annotation/) グループ化された注釈ファミリ用。
- [注釈のインポートとエクスポート](/pdf/ja/java/pdfannotationeditor-class/import-export-annotations/) PDF ファイル間で注釈をコピーするために。
