その Java `PdfFileSignatureExamples` クラスは、Facades API を通じて利用可能な主要な署名ワークフローを示します。

このセクションでは、以下の方法を学習します。

- PDF ドキュメントに署名して認証する
- 署名名、署名者の詳細、タイムスタンプを検査する
- 署名の有効性と文書全体へのカバレッジを検証する
- 署名証明書を抽出し、既存の署名を削除する
