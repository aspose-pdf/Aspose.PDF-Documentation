そのJava `PdfFileStampExamples` クラスは、Facades API で利用できる主要なスタンピング ワークフローを示しています。

このセクションを使用して次のことを学びます：

- PDFに画像スタンプを追加する
- テキストと画像のヘッダーまたはフッターを配置する
- ヘッダーとフッターの余白を制御する
- デフォルト、座標ベース、揃え、またはローマ数字のレイアウトでページ番号を追加する
