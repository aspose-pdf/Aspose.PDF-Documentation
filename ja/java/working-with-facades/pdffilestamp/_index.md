Java の `PdfFileStampExamples` クラスは、Facades API で利用可能な主要なスタンピング ワークフローを示しています。

このセクションを使用して次のことを学びます：

- PDF に画像スタンプを追加する
- テキストと画像のヘッダーまたはフッターの配置
- ヘッダーとフッターの余白の制御
- デフォルト、座標ベース、揃え、またはローマ数字のレイアウトによるページ番号の追加
