Java の `PdfContentEditorExamples` クラスは、Facades API が提供する主要なコンテンツ編集ワークフローを示します。

このセクションを使用して、以下を学びます：

- テキスト、ライン、ポリゴン、ムービー、およびゴムスタンプの注釈を追加してください。
- ドキュメントの添付ファイルを追加または削除してください。
- ストリームから PDF をバインドし、結果を保存してください。
- ドキュメントのオープンアクションを追加または削除してください。
- テキストと画像を置換してください。
- ビューア設定を取得して変更してください。
