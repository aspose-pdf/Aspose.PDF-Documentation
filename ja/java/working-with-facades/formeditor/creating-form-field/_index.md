Java の `FormEditorExamples` クラスは、入力ドキュメントをバインドし、`addField(...)` または `addSubmitBtn(...)` を呼び出すことで、既存の PDF ページ上に一般的なフィールドタイプをいくつか作成し、結果を保存します。

このセクションの子ページで、具体的なフィールド作成例をご覧ください。
