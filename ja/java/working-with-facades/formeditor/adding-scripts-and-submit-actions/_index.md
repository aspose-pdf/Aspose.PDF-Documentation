そのJava `FormEditorExamples` class は、フォーム構造が既に作成された後に、フィールドアクションを操作する方法を示します。
このセクションを次の目的で使用します:

- フィールドにJavaScriptアクションを追加する
- 既存のフィールドスクリプトを置き換える
- 送信URLと送信フラグを設定する
- フィールドアクションを削除する
