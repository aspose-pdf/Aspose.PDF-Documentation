Java の `FormEditorExamples` クラスは、Facades API で利用可能な主なフィールド編集ワークフローを示しています。

このセクションでは、以下の方法を学習します。

- テキスト、チェックボックス、コンボボックス、リストボックス、ラジオボタン、送信ボタンのフィールドを作成してください。
- 既存のフィールドを追加、削除、移動、名前変更、コピー、または変換してください。
- 配置、外観、制限、およびコンブ数をカスタマイズしてください。
- スクリプトを添付し、送信 URL を設定し、フィールドアクションを削除してください。
