## Welcome to the Aspose.PDF for JasperReports documentation

Aspose.PDF para JasperReports es un componente flexible diseñado para exportar informes de JasperReports y JasperServer a formato de documento portátil (PDF). Las funciones importantes de los informes, como tablas, gráficos e imágenes, se convierten a PDF con el mayor grado de precisión.

{{% /alert %}}

### Product Description

Para crear documentos PDF, Aspose.PDF para JasperReports se basa en una versión integrada de [Aspose.PDF para Java](https://products.aspose.com/pdf/java/), la biblioteca líder en el mercado de Aspose. No es necesario instalar Adobe Acrobat Professional en el sistema para generar documentos PDF con Aspose.PDF para JasperReports.
