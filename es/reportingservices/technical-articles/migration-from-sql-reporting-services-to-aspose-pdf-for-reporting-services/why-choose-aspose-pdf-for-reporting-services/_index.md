**Aspose.PDF para Reporting Services** es una sólida solución .NET que le permite generar informes en PDF utilizando Microsoft SQL Server 2016, 2017, 2019 y 2022 Reporting Services y Microsoft Power BI Report Server. Aspose.PDF para Reporting Services no funciona de forma independiente, sino que es una extensión de representación para SQL Reporting Services. No solo admite los elementos básicos del informe, como tablas, gráficos, imágenes, encabezados/pies de página, líneas, etc., sino que también brinda la capacidad de agregar propiedades personalizadas, lo que le brinda una ventaja adicional sobre SQL Reporting Services. Al utilizar estas propiedades, puede generar una lista de contenidos que no es compatible con Report Designer. Es posible que tenga notas al pie/notas finales en el documento PDF resultante que el Generador de informes no admite de forma nativa. Otra característica interesante es tener flechas de línea, que tampoco son compatibles con SQL Reporting Services, pero Aspose.PDF para Reporting Services puede proporcionar la capacidad de agregar flechas al principio o al final del elemento de línea. Además, Aspose.PDF para Reporting Services proporciona la funcionalidad para especificar la información de alineación del texto (Justificar o Justificar Completamente) que no es compatible con Report Designer. Estos modos de texto hacen que el documento resultante tenga mejor formato y sea más fácil de leer.

Además de las funciones mencionadas anteriormente, también puede establecer otros parámetros de configuración para los informes, para obtener funciones que no son compatibles de forma nativa con SQL Reporting Services. A continuación se muestra un breve resumen de las funciones que ofrece Aspose.PDF para Reporting Services.

## Configuración de seguridad

A veces es posible que desee exportar un documento PDF protegido con una contraseña, con privilegios limitados de copia e impresión de texto. Lamentablemente, Reporting Services no admite esta posibilidad. Sin embargo, aún puede implementarlo utilizando Aspose.PDF para Reporting Services. Simplemente agregue los parámetros de seguridad correspondientes al informe o al servidor de informes para obtener un documento PDF seguro con privilegios limitados. Para obtener más información, consulte la sección 'Configuración de seguridad'.

## Incrustación de fuentes personalizadas

El diseñador de Reporting Services no admite la fuente incrustada para texto; con Aspose.PDF para Reporting Services puede incrustar fácilmente información de fuentes en su documento PDF. Para obtener más información, consulte la sección 'IsFontEmbedded'.

## Metadatos XMP

El diseñador de Reporting Services no admite la inserción de metadatos XMP. Aspose.PDF para Reporting Services proporciona cuatro parámetros (CreationDate, ModifyDate, MetaDataDate y CreatorTool) para configurar los metadatos XMP correspondientes. Para obtener más información, consulte la sección 'Metadatos XMP'.

## PDF/A

Cuando utiliza SQL Server Reporting Services, solo puede generar el documento PDF en formato simple, mientras que no se admite la generación de documentos PDF/A. Pero Aspose.PDF para Reporting Services proporciona la función de crear documentos compatibles con PDF/A con la adición de un único parámetro de configuración. Para obtener más información, consulte la sección "Conformidad de PDF".

## Ángulo de rotación de página

Al utilizar Aspose.PDF para Reporting Services, puede establecer el número de grados que se debe girar la página en el sentido de las agujas del reloj cuando se muestra o imprime. Para obtener más información, consulte la sección 'Ángulo de rotación de página'.

## Tamaño del margen de página

El diseñador de Reporting Services no admite la configuración del tamaño de los márgenes de la página. Aspose.PDF para Reporting Services, por otro lado, proporciona cuatro parámetros para establecer el tamaño del margen de página correspondiente. Son PageMarginLeft, PageMarginRight, PageMarginTop y PageMarginBottom. Para obtener más información, consulte la sección "Tamaño del margen de página".
