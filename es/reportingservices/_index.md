## Bienvenido a Aspose.PDF para servicios de informes

Microsoft SQL Server Reporting Services satisface una necesidad que tienen muchas organizaciones: la necesidad de crear soluciones de informes y inteligencia empresarial. Hasta ahora, los desarrolladores debían incorporar informes en sus aplicaciones, o las organizaciones debían comprar soluciones de generación de informes de terceros costosas y a veces problemáticas. Ahora, Microsoft SQL Server Reporting Services ofrece una solución completa para distribuir informes en toda la empresa; permitiendo a las empresas tomar decisiones mejor y más rápido.
