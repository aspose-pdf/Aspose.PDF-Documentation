**La versión de evaluación de Aspose.PDF para Reporting Services** proporciona el mismo conjunto de características que la versión con licencia, excepto por la marca de agua de evaluación en el PDF resultante cuando se usa la versión de evaluación. Visite nuestro sitio web, descargue la versión del producto y comience a explorar nuestro producto con un conjunto completo de funciones en modo de evaluación.

Cuando esté satisfecho con su evaluación, [compre una licencia](https://purchase.aspose.com/buy). Antes de comprar, asegúrese de comprender y aceptar los términos de suscripción de la licencia.

La licencia estará disponible para descargar desde la página de pedido una vez pagado el pedido. La licencia es un archivo XML de texto claro y firmado digitalmente. La licencia contiene información como el nombre del cliente, el producto adquirido y el tipo de licencia. No modifique el contenido del archivo de licencia ya que invalidará la licencia.

## Licencia de un servidor

Descargue el archivo de licencia y cópielo en la carpeta C:\Program Files\Microsoft SQL Server\<Instance>\Reporting Services\ReportServer\bin, o C:\Program Files\Microsoft SQL Server\SSRS\ReportServer\bin, o C:\Program Files\Microsoft Power BI Report Server\PBIRS\ReportServer\bin en el servidor (la misma carpeta donde se Se coloca Aspose.Pdf.ReportingServices.dll).

`<Instance>` es el nombre del subdirectorio que corresponde a la instancia de Microsoft SQL Server 2016 cuya licencia desea obtener.

El directorio de instancia predeterminado para Microsoft SQL Server 2016 es MSRS13.MSSQLSERVER.
Para Microsoft SQL Server 2017 y versiones posteriores, la ruta de instancia predeterminada es C:\Program Files\Microsoft SQL Server\SSRS.
Para Power BI Report Server, la ruta de instancia predeterminada es C:\Program Files\Microsoft Power BI Report Server\PBIRS.
