**Aspose.PDF para Reporting Services** es una extensión de representación personalizada para Microsoft SQL Server 2016/2017/2019/2022 Reporting Services y Power BI Report Server. Aspose.PDF para Reporting Services se proporciona como un único instalador MSI que puede instalarse en las computadoras que ejecutan uno de los siguientes:

- Servicios de informes de Microsoft SQL Server 2016  
- Servicios de informes de Microsoft SQL Server 2017  
- Servicios de informes de Microsoft SQL Server 2019  
- Servicios de informes de Microsoft SQL Server 2022  
- Servidor de informes de Microsoft Power BI
 
Aspose.PDF para Reporting Services es fácil de implementar y administrar, ya que se compone de un solo ensamblado .NET Aspose.Pdf.ReportingServices.dll, escrito completamente en C#, compatible con CLS y que contiene solo código administrado seguro. Es necesario tener instalado .NET Framework 4.8.1 en el servidor.

Aspose.Pdf.ReportingServices.dll se debe copiar al directorio ReportServer\bin y el archivo de configuración se debe actualizar para que Reporting Services conozca la nueva extensión de representación. Estos pasos los realiza el instalador Aspose.PDF para Reporting Services, pero también puede realizarlos manualmente como se describe más adelante en esta documentación.
