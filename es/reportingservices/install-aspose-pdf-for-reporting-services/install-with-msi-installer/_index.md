Puede instalar Aspose.PDF para Reporting Services utilizando un instalador MSI. Ejecute Aspose.Pdf.ReportingServices.msi y siga los pasos que ofrece el instalador. El instalador copiará el ensamblado y otros archivos al directorio especificado e instalará el producto en la instancia predeterminada de Reporting Services. No necesita copiar ni modificar ningún archivo manualmente a menos que desee agregar parámetros de configuración especiales como se describe en la sección 'Configurar Aspose.PDF para Reporting Services'.

La instalación automática es la mejor opción que funciona en la mayoría de los casos. Sin embargo, es posible que necesites instalar el producto manualmente en algunas situaciones como:

- La instalación automática falla debido a problemas de seguridad de E/S.
- Debe instalar el producto en una instancia con nombre (no predeterminada) de Reporting Services 2016 o en varias instancias.
- Actualiza a la última versión y solo desea reemplazar el ensamblaje en lugar de desinstalar la versión anterior e instalar la nueva usando el instalador MSI.
 
{{% alert color="primary" %}}

Nota: Tenga en cuenta que en este último caso puede terminar con otros componentes (como la documentación fuera de línea) no actualizados a la versión correspondiente.

{{% /alert %}}
