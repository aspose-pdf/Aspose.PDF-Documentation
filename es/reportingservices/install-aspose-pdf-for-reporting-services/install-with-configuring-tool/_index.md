La herramienta de configuración Aspose.PDF for Reporting Services puede ayudarle a configurar la extensión Aspose.PDF for Reporting Services para cualquiera de las versiones compatibles del servidor de informes (RS). Actualmente es compatible con RS2016, RS2017, RS2019, RS2022 y Power BI Report Server. La herramienta de configuración requiere .NET Framework 4.8.

Si desea instalar la extensión y registrarla en el servidor de informes, seleccione el tipo de acción `Register`. Para cancelar el registro y desinstalar la extensión, seleccione el tipo de acción `Unregister`.

![Install with configuring tool](install-with-configuring-tool_1.png)

**Los siguientes pasos describen cómo usarlo en detalle:**

1. Ingrese o busque la ruta del archivo DLL para la extensión Aspose.PDF para Reporting Services;
1. Seleccione el tipo de acción correspondiente: Registrarse o Darse de baja;
1. Seleccione la pestaña correspondiente a la versión del servidor de informes que desea configurar. Asegúrese de haber seleccionado el archivo DLL adecuado para su versión RS. Si la versión solicitada del producto no está instalada en la máquina, la herramienta de configuración le informará con sugerencias. Si está configurando la extensión para la instancia RS2016 nombrada (no la predeterminada 'MSSQLSERVER'), ingrese el nombre de la instancia personalizada y luego presione el botón 'Actualizar'.
1. Asegúrese de que las rutas y los nombres de los archivos de configuración que se muestran en los cuadros de texto inferiores sean correctos. Si no es así, puede presionar el botón 'Actualizar' para intentar encontrar la instancia de RS nuevamente, o puede buscarlas manualmente.
1. Presione el botón 'Configurar'. La herramienta ahora intentará realizar la configuración solicitada y le informará si la configuración se realizó correctamente o no.
