{{% alert color="primary" %}}

Esta página indica la diferencia entre la versión con licencia y la de evaluación de Aspose.PDF para Reporting Services

{{% /alert %}}

Puedes descargar fácilmente [Aspose.PDF para servicios de informes](https://downloads.aspose.com/pdf/reportingservices) para evaluación. La descarga de evaluación es la misma que la descarga comprada. La versión de evaluación simplemente obtiene la licencia cuando coloca el archivo de licencia en la carpeta que contiene Aspose.PDF.ReportingServices.dll o algunas líneas de código para inicializar la licencia cuando usa el componente con Report Viewer en modo local. La versión de evaluación de Aspose.PDF para Reporting Services (sin una licencia especificada) proporciona funcionalidad completa del producto, pero inserta una marca de agua de evaluación en la parte superior del documento al representar el archivo .RDL en formato PDF. Puede visitar la siguiente página para obtener más instrucciones sobre [cómo obtener la licencia de Aspose.PDF para Reporting Services](/pdf/es/reportingservices/license-aspose-pdf-for-reporting-services/)

![Evaluación](evaluate-aspose-pdf-for-reporting-services_1.png)

{{% alert color="primary" %}}

Si desea probar Aspose.PDF para Reporting Services sin las limitaciones de la versión de evaluación, también puede solicitar una licencia temporal de 30 días. Por favor consulte [¿Cómo obtener una Licencia Temporal?](<https://about.aspose.com/>)

{{% /alert %}}
