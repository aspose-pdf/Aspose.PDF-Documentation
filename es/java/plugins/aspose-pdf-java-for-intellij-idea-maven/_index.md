## Introducción

### IntelliJ IDEA

IntelliJ IDEA es un entorno de desarrollo integrado (IDE) de Java para desarrolladores de software. Es desarrollado por JetBrains. Originalmente creado para Java, actualmente soporta una amplia variedad de lenguajes, incluidos JavaScript, Groovy, HTML, CSS, RSS, R, Haskell, PHP, Ruby, Python, Scala, Clojure y Kotlin.

En un informe de Infoworld de 2010, IntelliJ obtuvo la puntuación más alta en el centro de pruebas de entre las cuatro principales herramientas de programación Java: Eclipse, IntelliJ IDEA, NetBeans y Oracle JDeveloper.

### Aspose.PDF for Java

Aspose.PDF for Java es un componente de creación de documentos PDF que permite a sus aplicaciones Java leer, escribir y manipular documentos PDF sin usar Adobe Acrobat.

### Aspose.PDF Java para IntelliJ IDEA - Maven

- Aspose.PDF Java for IntelliJ IDEA (Maven) es un complemento de IntelliJ IDEA que le permite crear proyectos maven (es decir, el proyecto creado contiene la dependencia maven de Aspose.PDF for Java API) y descargar ejemplos de código fuente de la APIВ  para usar Aspose.PDF for Java API.
- Este complemento le ayuda a trabajar con la API Aspose.PDF for Java dentro de su IntelliJ IDEA favorito.

ASISTENTES:
El plugin contiene dos asistentes

Asistente 1: Proyecto Maven de Aspose.PDF

- El asistente de proyecto Maven de Aspose del plugin permite a los desarrolladores crear un proyecto Maven de la API Aspose.PDF for Java.
- La referencia de la dependencia Maven de la API Aspose.PDF for Java se obtiene automáticamente de [Repositorio Maven de Aspose Cloud](https://repository.aspose.com/webapp/#/artifacts/browse/tree/General/repo) y se agrega en el pom.xml.
- El proyecto creado siempre contendrá la versión más reciente disponible de la dependencia Maven para Aspose.PDF for Java API.
- Los pasos del asistente también presentan\u0412\u00A0con la opción de descarga. [Ejemplos de código fuente para usar Aspose.PDF for Java API](https://github.com/aspose-pdf/Aspose.PDF-for-Java)

Asistente 2: Ejemplos de Aspose.PDF

- El asistente de ejemplos de Aspose.PDF le permite crear/copiar ejemplos de código fuente descargados\u0412\u00A0de Aspose.PDF for Java API en su proyecto. Todos los ejemplos de la categoría seleccionada se copiarán a la carpeta del paquete \u0022com.aspose.pdf.examples\u0022 del proyecto\u2019s\u0412\u00A0 junto con los recursos requeridos dentro de la carpeta \u0022src/main/resources\u0022 necesarios para ejecutar los ejemplos.
- Los ejemplos de código fuente de Aspose.PDF for Java API están diseñados para demostrar los diferentes usos de la API.

## Descargando

### Descargando IntelliJ IDEA

Necesitará instalar primero IntelliJ IDEA CE / UE antes de descargar el plugin Aspose.PDF Java for IntelliJ IDEA (Maven).

Para descargar IntellliJ IDEA

1. Ir a <https://www.jetbrains.com/idea/download/>
1. Seleccione su sistema operativo en ejecución
1. Haga clic en la descarga UE o CE.

### Descargando el complemento Aspose.PDF Java para IntelliJ IDEA (Maven)

- El complemento se puede descargar directamente desde el [URL de alojamiento de complementos de JetBrains](https://goo.gl/z06gC0) - en el repositorio de complementos de IntelliJ IDEA
  y luego puede instalarse usando la opción del IDE:
  - Ir a Archivo > Configuración... > Complementos
  - Seleccionar "Instalar complemento desde disco"
- O puede instalarse directamente (sin descargar manualmente desde la URL de alojamiento de complementos de JetBrains) usando las opciones del IDE:
  - Ir a Archivo > Configuración... > Complementos
  - Seleccionar "Examinar repositorios"
  - En el cuadro de búsqueda escribe: "Aspose"
  - Selecciona el complemento "Aspose.PDF Java for IntelliJ IDEA Maven" para instalar.
