## Introducción

### IntelliJ IDEA

IntelliJ IDEA es un entorno de desarrollo integrado (IDE) de Java para desarrolladores de software. Fue desarrollado por JetBrains. Originalmente creado para Java, actualmente soporta una amplia variedad de lenguajes, incluidos JavaScript, Groovy, HTML, CSS, RSS, R, Haskell, PHP, Ruby, Python, Scala, Clojure y Kotlin.

En un informe de Infoworld de 2010, IntelliJ obtuvo la puntuación más alta del centro de pruebas entre las cuatro principales herramientas de programación Java: Eclipse, IntelliJ IDEA, NetBeans y Oracle JDeveloper.

### Aspose.PDF for Java

Aspose.PDF for Java es un componente de creación de documentos PDF que permite a sus aplicaciones Java leer, escribir y manipular documentos PDF sin usar Adobe Acrobat.

### Aspose.PDF Java para IntelliJ IDEA - Maven

- Aspose.PDF Java for IntelliJ IDEA (Maven) es un complemento de IntelliJ IDEA que le permite crear proyectos Maven (es decir, el proyecto creado contiene la dependencia Maven de la API de Aspose.PDF for Java) y descargar ejemplos de código fuente de la API  para usar la API de Aspose.PDF for Java.
- Este complemento le ayuda a trabajar con la API de Aspose.PDF for Java dentro de su IntelliJ IDEA favorito.

ASISTENTES:
El complemento contiene dos asistentes

Asistente 1: Aspose.PDF Maven Project

- El asistente de proyecto Maven de Aspose del complemento permite a los desarrolladores crear un proyecto Maven de la API Aspose.PDF for Java.
- La referencia de la dependencia Maven de la API Aspose.PDF for Java se obtiene automáticamente de [Aspose Cloud Maven Repository](https://repository.aspose.com/webapp/#/artifacts/browse/tree/General/repo) y se agrega en el pom.xml.
- El proyecto creado siempre contendrá la versión más reciente disponible de la dependencia Maven para la API de Aspose.PDF for Java.
- Los pasos del asistente también presentan con la opción de descargar [Ejemplos de código fuente para usar la API de Aspose.PDF for Java](https://github.com/aspose-pdf/Aspose.PDF-for-Java)

Asistente 2: Ejemplos de Aspose.PDF

- El asistente de ejemplos de Aspose.PDF le permite crear/copiar los Ejemplos de código fuente descargados de la API de Aspose.PDF for Java en su proyecto. Todos los ejemplos de la categoría seleccionada se copiarán a la directorio del paquete "com.aspose.pdf.examples" del proyecto , junto con los recursos necesarios dentro de la directorio "src/main/resources" requeridos para ejecutar los ejemplos.
- Los ejemplos de código fuente de la API de Aspose.PDF for Java están destinados a demostrar los diferentes usos de la API.

## Requisitos del sistema y plataformas compatibles

### Requisitos del sistema

- Microsoft Windows 8/7/Vista/2003/XP (incl.64-bit)  / Linux GNOME o escritorio KDE / Mac OS X 10.5 o superior
- 1 GB de RAM como mínimo, 2 GB de RAM recomendados
- 300 MB de espacio en disco duro + al menos 1 G para cachés
- Resolución de pantalla mínima 1024x768
- Se recomienda JDK 1.8 o superior
- Conexión a Internet (se recomienda 2 MB o más rápido)

- 14.1.5 (CE/ UE)

## Descargar

### Descargar IntelliJ IDEA

Primero necesitará instalar IntelliJ IDEA CE / UE antes de descargar el complemento Aspose.PDF Java para IntelliJ IDEA (Maven).

Para descargar IntellliJ IDEA

1. Vaya <https://www.jetbrains.com/idea/download/>.
1. Seleccione su sistema operativo en ejecución.
1. Haga clic en la descarga UE o CE.

### Descargar el complemento Aspose.PDF Java para IntelliJ IDEA (Maven)

- El complemento se puede descargar directamente desde el [URL de alojamiento del complemento JetBrains](https://goo.gl/z06gC0) - en el repositorio de complementos de IntelliJ IDEA
  y luego puede instalarse usando la opción del IDE:
  - Ir a Archivo > Configuración... > Complementos
  - Seleccionar "Instalar complemento desde disco"
- O puede instalarse directamente (sin descargar manualmente desde la URL de alojamiento de complementos de JetBrains) usando las opciones del IDE:
  - Ir a Archivo > Configuración... > Complementos
  - Seleccionar "Explorar repositorios"
  - En el cuadro de búsqueda escribe: "Aspose"
  - Selecciona el complemento "Aspose.PDF Java for IntelliJ IDEA Maven" para instalar.
