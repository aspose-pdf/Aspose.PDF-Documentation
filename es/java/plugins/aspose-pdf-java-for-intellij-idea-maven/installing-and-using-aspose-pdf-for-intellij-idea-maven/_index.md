## Instalación

### Instalar Aspose.PDF Java para IntelliJ IDEA (Maven)

Los pasos a continuación demuestran cómo instalar el plugin **Aspose.PDF Java para IntelliJ IDEA (Maven)**.

El plugin The  está listado en la versión CE de IntelliJ IDEA [sitio web oficial del complemento](https://plugins.jetbrains.com/plugin/7974-aspose-pdf-java-for-intellij-idea-maven/) - repositorio de complementos como **Aspose.PDF Java for IntelliJ IDEA Maven**, por lo que no necesita descargarlo manualmente e instalarlo desde el disco, pero esta opción adicional aún existe en IntelliJ IDEA.

El complemento **Aspose.PDF Java for IntelliJ IDEA (Maven)** se puede instalar fácilmente (sin descarga manual) desde IntelliJ IDEA. Para hacerlo:

1. Seleccione **Settings** del menú **File**.
2. Haga clic en **Plugins**, luego explora los repositorios en IntelliJ IDEA.

![todo:image_alt_text](https://i.imgur.com/NDZtoKw.jpg)

## Utilizar

### Asistente de proyecto Maven de Aspose.PDF

Para crear un proyecto Maven Aspose.PDF para usar [API de Aspose.PDF for Java](https://products.aspose.com/pdf/java/) Dentro de IntelliJ IDEA, necesita tener conexión a internet.

Luego siga los pasos a continuación:

1. Seleccione **New Project**.
2. Seleccione **Aspose.PDF Maven Project**.
3. Haga clic **Next**.

![todo:image_alt_text](https://i.imgur.com/hd2mYnW.jpg)

4. Proporcione un **GroupId, ArtifactId** y Version.
para su proyecto maven y haga clic en Next.

![todo:image_alt_text](https://i.imgur.com/aNlx0Qe.jpg)

5. Puede seleccionar la casilla "Also Download Examples Source Code" para descargar los ejemplos de uso de la API (como se muestra en la captura de arriba)

6. Proporcione un **Project Name** y **Location** como al crear cualquier aplicación Java.

![todo:image_alt_text](https://i.imgur.com/8VEeFun.jpg)

7. Haga clic en **Finish**.

Esto recuperará el [API de Aspose.PDF for Java](https://products.aspose.com/pdf/java/) última referencia de dependencia Maven del Aspose Cloud Maven Repository y la configurará en pom.xml
Si ha seleccionado la casilla "Also Download Examples Source Code". La descarga de los ejemplos también comenzará desde el [Repositorio GitHub de la API Aspose.PDF for Java](https://goo.gl/cPAbJM)

![todo:image_alt_text](https://i.imgur.com/bG2mdam.jpg)

![todo:image_alt_text](https://i.imgur.com/aNYhLl5.jpg)

¡Felicitaciones !  Ha creado con éxito un proyecto Maven de Aspose.PDF para usar [API de Aspose.PDF for Java](https://products.aspose.com/pdf/java/).

![todo:image_alt_text](https://i.imgur.com/UJlSbuM.jpg)

El proyecto Maven de la API Aspose.PDF for Java creado está listo para modificarse según los requisitos de su proyecto.

Si ha optado por descargar [Ejemplos de código fuente](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples).

### Asistente de ejemplos de Aspose.PDF

Para importar/ copiar [Ejemplos de código fuente](https://goo.gl/cPAbJM)en el proyecto usando **Aspose.PDF Examples Wizard**, necesita primero descargar los ejemplos al optar  "Also Download Examples Source Code" en Aspose.PDF Maven Project Wizard.

Luego siga los pasos a continuación en IntelliJ IDEA:

1. Seleccione **File** > **New -** como se muestra a continuación:

![todo:image_alt_text](https://i.imgur.com/N8tT9Q0.jpg)

-OR- **Right Click** (en la ventana del proyecto) => **New**  - Como se muestra a continuación:

![todo:image_alt_text](https://i.imgur.com/aUBWkhp.jpg)

2. Seleccione la opción **Aspose.PDF Example** del menú - Como se muestra a continuación:

![todo:image_alt_text](https://i.imgur.com/hvH2V0m.jpg)

El asistente actualizará / comprobará la última disponible\u0412 [Ejemplos de API de Aspose.PDF for Java](https://goo.gl/cPAbJM)

![todo:image_alt_text](https://i.imgur.com/5PZwsuq.jpg)

3. **Asistente de ejemplos de Aspose.PDF** aparecerá, donde puede seleccionar cualquier categoría de ejemplos para crear / copiar los ejemplos en su proyecto.
Selecciona cualquier categoría de ejemplos y haz clic en **Crear**:

![todo:image_alt_text](https://i.imgur.com/l2oGUBW.jpg)

Esto creará / copiará  los ejemplos de la categoría seleccionada en el proyecto bajo el paquete **com.aspose.pdf.examples**.
Además, cualquier recurso necesario para la ejecución de los ejemplos será copiado a la directorio **src/main/resources** - Como se muestra a continuación:

![todo:image_alt_text](https://i.imgur.com/8GQL3Yb.jpg)

¡Felicidades ! Has realizado con éxito lo siguiente:

1. Ha creado un proyecto Maven de Aspose.PDF usando el Asistente de proyecto Maven de Aspose.PDF,

2. Ha descargado [Aspose.PDF for Java API - Código fuente de ejemplo](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples)
3. Ha creado / copiado códigos fuente de ejemplos en su proyecto usando el Asistente de ejemplos de Aspose.PDF.
