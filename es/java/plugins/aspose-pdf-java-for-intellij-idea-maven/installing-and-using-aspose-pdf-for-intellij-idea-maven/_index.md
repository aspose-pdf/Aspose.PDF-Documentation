## 
Instalación


### 
Cómo instalar Aspose.PDF Java para IntelliJ IDEA (Maven)

Los pasos a continuación muestran cómo instalar el complemento **Aspose.PDF Java para IntelliJ IDEA (Maven)**.



El complemento figura en el CE [sitio web oficial del complemento] de IntelliJ IDEA(https://plugins.jetbrains.com/plugin/7974-aspose-pdf-java-for-intellij-idea-maven/): repositorio de complementos como **Aspose.PDF Java para IntelliJ IDEA Maven**, por lo que no es necesario descargarlo manualmente e instalarlo desde el disco, pero esta opción adicional todavía existe en IntelliJ IDEA.



**El complemento Aspose.PDF Java para IntelliJ IDEA (Maven)** se puede instalar fácilmente (sin descarga manual) desde IntelliJ IDEA. Para hacerlo:


1. Seleccione **Configuración** en el menú **Archivo**.

2. Haga clic en **Complementos** y luego explore los repositorios en IntelliJ IDEA.

![todo:image_alt_text](https://i.imgur.com/NDZtoKw.jpg)

### Asistente de proyectos Aspose.PDF Maven



**Proyecto Aspose.PDF Maven**: en IntelliJ IDEA, que le permitirá crear un proyecto basado en Aspose.PDF Maven para usar [Aspose.PDF para Java API.](https://products.aspose.com/pdf/java/).


![todo:image_alt_text](https://i.imgur.com/hd2mYnW.jpg)

### 
Asistente de ejemplo de Aspose.PDF



Una opción para crear [Códigos fuente de ejemplo para usar Aspose.PDF para Java API](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples) en el proyecto también aparecerá después de la instalación en el menú "Nuevo" (usando el clic derecho -> Nuevo **O** menú Archivo->Nuevo)

## Usando


### 
Asistente de proyectos Aspose.PDF Maven



Para crear el proyecto Aspose.PDF Maven para usar [Aspose.PDF para Java API](https://products.aspose.com/pdf/java/) dentro de IntelliJ IDEA, necesita tener conexión a Internet.



Luego siga los pasos a continuación:


1. Seleccione **Nuevo proyecto**.
2. Seleccione **Proyecto Aspose.PDF Maven**.

3. Haga clic en **Siguiente**.


![todo:image_alt_text](https://i.imgur.com/hd2mYnW.jpg)

4. Proporcione un **GroupId, ArtifactId** y una versión.


para su proyecto maven y haga clic en Siguiente.


![todo:image_alt_text](https://i.imgur.com/aNlx0Qe.jpg)

5. Puede seleccionar la casilla de verificación "Descargar también el código fuente de ejemplos" para descargar los ejemplos de uso de muestra de la API (como se muestra en la instantánea anterior)

6. Proporcione un **Nombre del proyecto** y una **Ubicación** como al crear cualquier aplicación Java.


![todo:image_alt_text](https://i.imgur.com/8VEeFun.jpg)

7. Haga clic en **Finalizar**.



Esto recuperará la última referencia de dependencia de Maven de [Aspose.PDF para Java API](https://products.aspose.com/pdf/java/) del Repositorio Maven de Aspose Cloud y la configurará en pom.xml.


Si ha seleccionado la casilla de verificación "Descargar también código fuente de ejemplos". La descarga de los ejemplos también comenzará desde [Aspose.PDF para el repositorio GitHub de la API de Java](https://goo.gl/cPAbJM)


![todo:image_alt_text](https://i.imgur.com/bG2mdam.jpg)

![todo:image_alt_text](https://i.imgur.com/aNYhLl5.jpg)


¡Felicitaciones!  Ha creado con éxito el proyecto Aspose.PDF Maven para usar [Aspose.PDF para Java API](https://products.aspose.com/pdf/java/).

![todo:image_alt_text](https://i.imgur.com/UJlSbuM.jpg)

El proyecto Aspose.PDF para Java API Maven creado está listo para modificarse según los requisitos de su proyecto.



Si ha optado por descargar [Códigos fuente de ejemplo](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples).


### 
Asistente de ejemplos de Aspose.PDF



Para importar/copiar [Códigos fuente de ejemplo](https://goo.gl/cPAbJM) al proyecto usando el **Asistente de ejemplos de Aspose.PDF**, primero debe descargar los ejemplos optando por "Descargar también el código fuente de ejemplos" en el Asistente de proyectos Maven de Aspose.PDF.



Luego siga los pasos a continuación en IntelliJ IDEA:

1. Seleccione **Archivo** > **Nuevo -** Como se muestra a continuación:


![todo:image_alt_text](https://i.imgur.com/N8tT9Q0.jpg)


-O- **Clic derecho** (en la ventana del proyecto) => **Nuevo**В  - Como se muestra a continuación:


![todo:image_alt_text](https://i.imgur.com/aUBWkhp.jpg)

2. Seleccione la opción **Aspose.PDF Ejemplo** del menú, como se muestra a continuación:


![todo:image_alt_text](https://i.imgur.com/hvH2V0m.jpg)


El asistente actualizará/buscará la última versión disponible[Aspose.PDF para ejemplos de API de Java](https://goo.gl/cPAbJM)


![todo:image_alt_text](https://i.imgur.com/5PZwsuq.jpg)

3. Aparecerá el cuadro de diálogo **Asistente de ejemplos de Aspose.PDF**, donde puede seleccionar cualquier categoría de ejemplos para crear/copiar los ejemplos en su proyecto.
Seleccione cualquier categoría de ejemplos y haga clic en **Crear**:


![todo:image_alt_text](https://i.imgur.com/l2oGUBW.jpg)


Esto creará/copiará los ejemplos de la categoría seleccionada en el proyecto en el paquete **com.aspose.pdf.examples**.


Además, todos los recursos necesarios para la ejecución de los ejemplos se copiarán en la carpeta **src/main/resources**, como se muestra a continuación:


![todo:image_alt_text](https://i.imgur.com/8GQL3Yb.jpg)


¡Felicitaciones! Ha realizado con éxito lo siguiente:


1. Ha creado el proyecto Aspose.PDF Maven utilizando el asistente de proyectos Aspose.PDF Maven.

2. Ha descargado [Aspose.PDF para Java API - Códigos fuente de ejemplo](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples)

3. Ha creado/copiado códigos fuente de ejemplo en su proyecto utilizando el Asistente de ejemplo Aspose.PDF.
