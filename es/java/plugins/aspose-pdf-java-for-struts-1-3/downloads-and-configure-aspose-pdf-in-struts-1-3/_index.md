## Descargando Aspose.PDF Java para Struts 1.3

Puedes descargar / obtener el código fuente del proyecto desde las siguientes ubicaciones:

- [Github](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Plugins/Aspose_Pdf_for_Struts)

## Compilando Aspose.PDF Java para Struts 1.3 desde el código fuente

Después de obtener el código fuente de cualquiera de los repositorios anteriores, aplique los siguientes comandos mvn:

{{< highlight java >}}

 $ mvn -U clean package

{{< /highlight >}}

Esto generará "Strutsbookapp.war" en la carpeta target.

Para desplegar el archivo .war, simplemente cópielo al directorio webapp del servidor Apache Tomcat en ejecución.
