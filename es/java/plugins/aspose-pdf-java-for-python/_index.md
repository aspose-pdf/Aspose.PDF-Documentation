## Introducción a Aspose.PDF Java para Python

## JPype

JPype es un esfuerzo para permitir que los programas Python tengan acceso completo a las bibliotecas de clases Java. Esto se logra sin volver a implementar Python, como lo han hecho Jython/JPython, sino mediante la interconexión a nivel nativo en ambas máquinas virtuales.

Leer más en [readthedocs.org](http://jpype.readthedocs.org/en/latest/userguide.html)

## Aspose.PDF for Java

Aspose.PDF for Java es una biblioteca de clases avanzada para Java que le permite realizar una amplia gama de tareas de procesamiento de documentos directamente dentro de sus aplicaciones Java.

Aspose.PDF for Java admite el procesamiento de Word (DOC, DOCX, OOXML, RTF), HTML, OpenDocument, PDF, EPUB, XPS, SWF y todos los formatos de imagen. Con Aspose.PDF puede generar, modificar y convertir documentos sin usar Microsoft Word.

Leer más en [aspose.com](https://products.aspose.com/words/java)

## Aspose.PDF Java para Python

El proyecto Aspose.PDF for Python muestra cómo se pueden realizar diferentes tareas utilizando las API de Aspose.PDF Java en Python. Este proyecto tiene como objetivo proporcionar ejemplos útiles para desarrolladores Python que desean utilizar Aspose.PDF for Java en sus proyectos Python usando [JPype](http://jpype.readthedocs.org/en/latest/userguide.html).
