## Introducción

### IDE NetBeans

NetBeans es un IDE Java con todas las funciones, escrito completamente en Java. Está principalmente destinado al desarrollo en Java, pero también admite otros lenguajes, en particular PHP, C/C++, y HTML5.

El IDE NetBeans le permite desarrollar rápida y fácilmente aplicaciones Java de escritorio, móviles y web, así como aplicaciones HTML5 con HTML, JavaScript y CSS. Es gratuito y de código abierto y cuenta con una gran comunidad de usuarios y desarrolladores en todo el mundo.

El equipo de NetBeans brinda apoyo activo al producto y busca sugerencias de características de la comunidad más amplia. Cada versión es precedida por tiempo para pruebas y retroalimentación de la comunidad.

### Aspose.PDF for Java

[Aspose.PDF for Java](https://products.aspose.com/pdf/java/)es una robusta API de creación de documentos PDF que permite a sus aplicaciones Java leer, escribir y manipular documentos PDF sin usar Adobe Acrobat.

Aspose.PDF for Java ofrece una increíble cantidad de funcionalidades, que incluyen opciones de compresión de PDF, creación y manipulación de tablas, soporte de gráficos, funciones de imagen, amplia funcionalidad de hipervínculos, controles de seguridad ampliados y manejo de fuentes personalizadas.

### Aspose.PDF Java for NetBeans (Maven)

- Aspose.PDF Java for NetBeans (Maven) es un Plugin para **NetBeans IDE** de **Aspose.** El Plugin está destinado a desarrolladores que utilizan la plataforma Maven para desarrollos Java y desean usar Aspose.PDF for Java en sus proyectos. El Plugin le permite crear proyectos maven para usar Aspose.PDF for Java APIand también descargar [Ejemplos de código](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples)de la API.

## Asistentes

El complemento contiene dos asistentes

### Proyecto Maven de Aspose.PDF (asistente)

- Este asistente de Nuevo Proyecto permite a los desarrolladores crear un proyecto **Maven** para usar Aspose.PDF for Java desde Nuevo Proyecto -> Maven-> Proyecto Maven de Aspose.PDF.
- La referencia de la dependencia Maven de la API de Aspose.PDF for Java se obtiene automáticamente de [Repositorio Maven de Aspose](https://repository.aspose.com/webapp/#/artifacts/browse/tree/General/repo/com/aspose/aspose-pdf) y se agrega en el pom.xml.
- El proyecto creado siempre contendrá la versión más reciente disponible de la dependencia **Maven** para la API de Aspose.PDF for Java.
- Los pasos del asistente también se presentan con la opción de descargar Ejemplos de Código para usar Aspose.PDF for Java API.

### Ejemplo de código de Aspose.PDF (asistente)

- Este asistente Nuevo archivo le permite copiar lo descargado [Ejemplos de código](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples)en su proyecto para usar Aspose.PDF for Java desde **New File -> Java -> Aspose.PDF Code Example.**
- Los ejemplos disponibles se muestran en formato de árbol desde donde el usuario puede seleccionarlos categóricamente.
- Todos los ejemplos dentro de la categoría seleccionada se copiarán a la directorio del paquete **com.aspose.pdf.examples** del proyecto, junto con los recursos necesarios dentro de la directorio **src/main/resources** requeridos para ejecutar los ejemplos.
- Los ejemplos de código de Aspose.PDF for Java API están destinados a demostrar la variedad de la API.
- El asistente también buscará y actualizaciones para los recién disponibles de [Repositorio de ejemplos de Aspose.PDF for Java.](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples)

## Descargar

### Descargar NetBeans

Debe tener NetBeans IDE preinstalado antes de descargar **Aspose.PDF Java for NetBeans (Maven)**plugin.

El plugin **Aspose.PDF Java for NetBeans (Maven)** admite **NetBeans IDE8.0 y 8.1**. Recomendamos usar solo la última versión de NetBeans IDE.

Para descargar NetBeans IDE,

1. Navegue a:<https://netbeans.apache.org/download/index.html>.
1. Haga clic en Descargar para obtener el paquete adecuado de NetBeans IDE.

Descargue solo el paquete de descarga de NetBeans compatible con Java EE / SE de la última versión actual, es decir, **NetBeans IDE 8.1**.

### Descargar Aspose.PDF Java para NetBeans (Maven)

- El complemento se puede descargar directamente desde la URL de alojamiento de complementos de NetBeans:<http://plugins.netbeans.org/plugin/63218>
  y luego puede instalarse usando la opción del IDE:
  - Ir a**Tools**>**Plugins**>**Downloaded**
  - Haga clic en **Add Plugins...** y busque el archivo de complemento con extensión .nbm descargado para **Aspose.PDF Java for NetBeans (Maven)**.
  - Haga clic**"Install"**para instalar el plugin
- O se puede instalar directamente (sin descargar manualmente desde la URL de alojamiento del plugin de NetBeans) usando las opciones del IDE:
  - Ir a**Tools**>**Plugins**>**Available Plugins**
  - En el cuadro de búsqueda escriba: "Aspose"
  - Seleccione el plugin **Aspose.PDF Java NetBeans (Maven)**
  - Haga clic**"Install"**

## Utilizar el complemento

Usando Aspose.PDF for NetBeans - Maven

### Aplicar la licencia de Aspose

Este complemento utiliza una versión de evaluación de Aspose.PDF. Una vez que esté satisfecho con su evaluación, puede comprar una licencia en el [Sitio web de Aspose](https://purchase.aspose.com/buy).
Para eliminar el mensaje de evaluación y las limitaciones de funciones, se debe aplicar una licencia del producto. Recibirá un archivo de licencia después de haber comprado el producto. Por favor, siga los pasos a continuación para aplicar la licencia.

- Asegúrese de que el archivo de licencia se llame **Aspose.PDF.Java.lic
- Coloque el archivo **Aspose.PDF.Java.lic** en la directorio que contiene el Aspose.PDF.jar
- Utilice el siguiente código para activar la licencia:

```java
License license = new License();
license.setLicense("Aspose.PDF.Java.lic");
```
