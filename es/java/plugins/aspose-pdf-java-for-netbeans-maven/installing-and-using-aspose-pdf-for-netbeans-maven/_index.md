## 
Instalación



El complemento **Aspose.PDF Java para NetBeans (Maven)** se puede instalar fácilmente desde la pestaña **Complemento** disponible en el cuadro de diálogo Complemento.

- Para abrirlo, seleccione **Complementos** en el menú **Herramientas** en NetBeans.


![todo:image_alt_text](installing-and-using-aspose-pdf-for-netbeans-maven_1.png)

- Esto agrega el **Proyecto Aspose.PDF Maven** en el asistente para Nuevo proyecto y el **Ejemplo de código Aspose.PDF** en el asistente para Nuevo archivo de NetBeans IDE.


## 
Usando


### 
Proyecto Aspose.PDF Maven (asistente)



Para crear **Proyecto Maven** mediante un asistente para usar [Aspose.PDF para API de Java](http://www.aspose.com/java/pdf-component.aspx):

1. Seleccione **Nuevo proyecto**.

2. Seleccione **Proyecto Aspose.PDF Maven** en la categoría **Maven**.

3. Haga clic en **Siguiente**.



Proporcione **Nombre del proyecto, Ubicación, ID de grupo, ID de artefacto** y **Versión** para su proyecto Maven y haga clic en **Finalizar.**



Esto recuperará la última referencia de [Aspose.PDF para Java](http://www.aspose.com/java/pdf-component.aspx) [Dependencia de Maven](http://maven.aspose.com/repository/ext-release-local/com/aspose/aspose-pdf/) del [Aspose Cloud Maven Repository](https://repository.aspose.com/webapp/#/artifacts/browse/tree/General/repo) y la configurará en **pom.xml**. Si ha optado por **Descargar también ejemplos de código**, la descarga de **Ejemplos de código** también comenzará desde el [Aspose.PDF para el repositorio de ejemplos de API de Java. ](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples)
Se creará el siguiente proyecto **Maven** en su **NetBeans IDE** al finalizar el asistente:



El **Proyecto Maven** creado está configurado para usar **Aspose.PDF para Java API** y está listo para mejorarse según los requisitos de su proyecto.

   
Si ha optado por descargar [Ejemplos de código](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples), puede utilizar **Ejemplo de código Aspose.PDF (asistente)** para importar los **Ejemplos de código** necesarios de la API [Aspose.PDF para Java](http://www.aspose.com/java/pdf-component.aspx) a su proyecto.


### 
Ejemplo de código Aspose.PDF (asistente)



**Asistente de ejemplo de código de Aspose.PDF** le permite probar muchos ejemplos proporcionados para la API [Aspose.PDF para Java](http://www.aspose.com/java/pdf-component.aspx).

{{% alert color="primary" %}}

Para poder utilizar el **Asistente de ejemplo de código de Aspose.PDF** cómodamente: se recomienda seleccionar siempre **También descargar ejemplos de código** al crear el **Proyecto Maven** en el **Proyecto Aspose.PDF Maven** **asistente**.


{{% /alert %}}


Para usar ejemplos, simplemente:


1. Haga clic en **Nuevo archivo** en **NetBeans**.

2. Elija su proyecto y luego seleccione **Ejemplo de código Aspose.PDF** en la categoría **Java**.

3. Haga clic en **Siguiente**.

Expanda el árbol para seleccionar la categoría **Ejemplo de código** y haga clic en **Finalizar**.


 
Esto copiará los archivos Java de **Ejemplos de código** de la categoría seleccionada en el proyecto en el paquete **com.aspose.pdf.examples**. Además, todos los recursos necesarios para los ejemplos de código se copiarán en la carpeta **src/main/resources**, como se muestra a continuación:


 
Revise el código de ejemplo, compílelo y ejecútelo.

 
Ahora puede probar otros ejemplos y comenzar a crear su propia aplicación utilizando [Aspose.PDF para Java API](http://www.aspose.com/java/pdf-component.aspx).
