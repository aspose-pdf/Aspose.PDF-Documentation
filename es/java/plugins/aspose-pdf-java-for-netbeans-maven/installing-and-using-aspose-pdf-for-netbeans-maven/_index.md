## Instalación

**Aspose.PDF Java para NetBeans (Maven)** plugin se puede instalar fácilmente desde la pestaña **Plugin** disponible en el cuadro de diálogo del plugin.

- Para abrirlo, seleccione **Plugins** del menú **Herramientas** en NetBeans.

![todo:image_alt_text](installing-and-using-aspose-pdf-for-netbeans-maven_1.png)

- Esto agrega el **Aspose.PDF Maven Project** en el asistente Nuevo Proyecto y **Aspose.PDF Code Example** en el asistente Nuevo Archivo del IDE NetBeans.

## Utilizar

### Aspose.PDF Maven Project (asistente)

Para crear **Maven Project** mediante el asistente para usar [Aspose.PDF for Java API](http://www.aspose.com/java/pdf-component.aspx):

1. Seleccione **New Project**.
2. Seleccione **Aspose.PDF Maven Project** en la categoría **Maven**.
3. Haga clic en **Next**.

Proporcione **Project Name, Location, GroupId, ArtifactId** y **Version** para su proyecto Maven y haga clic en **Finish.**

Esto recuperará el [Aspose.PDF for Java](http://www.aspose.com/java/pdf-component.aspx) más reciente [Dependencia Maven](http://maven.aspose.com/repository/ext-release-local/com/aspose/aspose-pdf/) referencia de [Repositorio Maven de Aspose Cloud](https://repository.aspose.com/webapp/#/artifacts/browse/tree/General/repo) y configúralo en **pom.xml**. Si has optado por **También descargar ejemplos de código,** la descarga de los **Ejemplos de código** también comenzará desde el [Repositorio de ejemplos de API de Aspose.PDF for Java. ](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples)
El siguiente proyecto **Maven** se creará en su **NetBeans IDE** al completar el asistente:

El proyecto **Maven** creado está configurado para usar **Aspose.PDF for Java API** y está listo para ser ampliado según los requisitos de su proyecto.
   Si ha optado por descargar [Ejemplos de código](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples), puede usar **Aspose.PDF Code Example (wizard)** para importar los **Ejemplos de código** necesarios de [Aspose.PDF for Java](http://www.aspose.com/java/pdf-component.aspx) API en su proyecto.

### Aspose.PDF Code Example (wizard)

**Aspose.PDF Code Example wizard** permite probar muchos ejemplos proporcionados para [Aspose.PDF for Java](http://www.aspose.com/java/pdf-component.aspx) API.

{{% alert color="primary" %}}

Para poder usar **Aspose.PDF Code Example wizard** cómodamente: se recomienda siempre seleccionar **Also Download Code Examples** al crear **Maven Project** en **Aspose.PDF Maven Project** **wizard**,

{{% /alert %}}

Para usar los ejemplos, simplemente:

1. Haga clic en **New File** en **NetBeans**.
2. Seleccione su proyecto y luego seleccione **Aspose.PDF Code Example** en la categoría **Java**.
3. Haga clic en **Next**.

Expanda el árbol para seleccionar la categoría **Code Example** y haga clic en **Finish**.

 Esto copiará los archivos Java de la categoría seleccionada **Code Examples** al proyecto bajo el paquete **com.aspose.pdf.examples**. Además, cualquier recurso necesario para los Code Examples se copiará en la directorio **src/main/resources**, como se muestra a continuación:

 Revise el código de ejemplo, compile y ejecute.
 Ahora puede probar otros ejemplos y comenzar a crear su propia aplicación usando [Aspose.PDF for Java API](http://www.aspose.com/java/pdf-component.aspx).
