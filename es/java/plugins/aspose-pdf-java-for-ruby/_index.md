## 
Introducción


### 
Rjb - Puente Ruby Java

RJB es un programa puente que conecta entre Ruby y Java con la interfaz nativa de Java. Rake + Rjb es la herramienta de compilación más potente y útil que Maven y Ant. Puede probar su clase de lógica empresarial Java con el simulacro de Rjb. Ayuda a migrar el objeto modelo de Struts a su aplicación RoR. Pero tenga cuidado con la aplicación buildSwing, Ruby (y Rjb) no considera el manejo de subprocesos nativos de JVM.


### 
Aspose.PDF para Java



Aspose.PDF para Java es un componente de creación de documentos PDF que permite a sus aplicaciones Java leer, escribir y manipular documentos PDF sin utilizar Adobe Acrobat.



Aspose.PDF para Java es un componente de precio asequible que ofrece una increíble riqueza de funciones, que incluyen: opciones de compresión de PDF, creación y manipulación de tablas, compatibilidad con gráficos, funciones de imágenes, amplia funcionalidad de hipervínculos, controles de seguridad ampliados y manejo de fuentes personalizadas.



Aspose.PDF para Java le permite crear archivos PDF directamente a través de las plantillas API y XML proporcionadas. El uso de Aspose.PDF para Java también le permitirá agregar capacidades de PDF a sus aplicaciones en poco tiempo.

### Aspose.PDF Java para Ruby



El proyecto Aspose.PDF Java para Ruby muestra cómo se pueden realizar diferentes tareas utilizando las API de Aspose.PDF Java en Ruby. Este proyecto tiene como objetivo proporcionar ejemplos útiles para los desarrolladores de Ruby que quieran utilizar Aspose.PDF para Java en sus proyectos Ruby utilizando Rjb (Ruby Java Bridge).

## Instalación y uso


### 
Instalación



Es muy simple y fácil de instalar Aspose.PDF Java para Ruby gem, siga estos sencillos pasos:


1. Ejecute el siguiente comando.


{{< highlight java >}}

 
$ instalación de gemas aspose-pdfjava

{{< /highlight >}}

1. Descargue el Aspose.PDF requerido para el componente Java desde el siguiente enlace.

   
<https://downloads.aspose.com/pdf/java>

1. Cree la carpeta "jars" en la raíz de la gema Aspose.PDF Java para Ruby y copie el componente descargado en ella.


### 
Usando



Incluya los archivos necesarios para trabajar con el ejemplo de helloworld.
