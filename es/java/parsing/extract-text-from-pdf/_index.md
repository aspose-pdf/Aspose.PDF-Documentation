- [Limitar la extracción a una región de página específica o inspeccionar la geometría del párrafo](/pdf/es/java/region-based-extraction/).
- [Extraer texto de resaltados, anotaciones de sello y contenido en superíndice o subíndice](/pdf/es/java/annotation-and-special-text/).
