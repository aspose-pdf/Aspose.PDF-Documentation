El Java `FormExamples` clase incluye ejemplos directos para:

- `flattenAllFields(...)`
- `renameFormFields(...)`

El repositorio no contiene actualmente un Java separado `Form` ejemplo de fachada para aplanar solo un subconjunto seleccionado de campos, de modo que la página hija se documente como una nota de alcance en lugar de código de muestra fabricado.
