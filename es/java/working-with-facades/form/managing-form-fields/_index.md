- 
`flattenAllFields(...)`

- 
`renameFormFields(...)`



Actualmente, el repositorio no contiene un ejemplo de fachada Java `Form` separado para aplanar solo un subconjunto seleccionado de campos, de modo que la página secundaria se documente como una nota de alcance en lugar de un código de muestra fabricado.
