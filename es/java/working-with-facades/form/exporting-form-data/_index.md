Abstract: Esta sección cubre los ejemplos de exportación de formularios en Java implementados con la fachada Form en Aspose.PDF para Java. El conjunto actual de ejemplos incluye la exportación de datos AcroForm a XML, FDF y XFDF, mientras que los temas JSON y XFA no compatibles se señalan explícitamente para evitar crear rutas de código que no están presentes en este repositorio.
---
El Java `FormExamples` la clase incluye flujos de trabajo de exportación directa para estos formatos:

- XML con `form.exportXml(...)`
- FDF con `form.exportFdf(...)`
- XFDF con `form.exportXfdf(...)`

Utilice las páginas hijas en esta sección para los ejemplos concretos. El conjunto actual de ejemplos de Java en este repositorio no incluye uno dedicado `Form` ejemplo de fachada para exportación JSON o extracción XFA, de modo que esas páginas se mantengan como notas de alcance en lugar de guías sintéticas de código.
