El Java `FormExamples` La clase incluye flujos de trabajo de exportación directa para estos formatos:

- XML con `form.exportXml(...)`
- FDF con `form.exportFdf(...)`
- XFDF con `form.exportXfdf(...)`

Utiliza las páginas hijas en esta sección para los ejemplos concretos. El conjunto actual de ejemplos Java en este repositorio no incluye uno dedicado. `Form` ejemplo de fachada para exportación JSON o extracción XFA, de modo que esas páginas se mantengan como notas de alcance en lugar de recorridos sintéticos de código.
