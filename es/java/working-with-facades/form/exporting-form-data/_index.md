Abstract: Esta sección cubre los ejemplos de exportación de formularios Java implementados con la fachada de formulario en Aspose.PDF para Java. El conjunto de ejemplos actual incluye la exportación de datos de AcroForm a XML, FDF y XFDF, mientras que los temas JSON y XFA no compatibles se indican explícitamente para evitar la fabricación de rutas de código que no están presentes en este repositorio.
---
La clase Java `FormExamples` incluye flujos de trabajo de exportación directa para estos formatos:


- XML con `form.exportXml(...)`

- FDF con `form.exportFdf(...)`

- XFDF con `form.exportXfdf(...)`



Utilice las páginas secundarias de esta sección para ver ejemplos concretos. El conjunto de muestras de Java actual en este repositorio no incluye un ejemplo de fachada `Form` dedicado para la exportación JSON o la extracción XFA, por lo que esas páginas se mantienen como notas de alcance en lugar de tutoriales de código sintético.
