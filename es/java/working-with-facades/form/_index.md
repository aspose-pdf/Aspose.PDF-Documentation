El Java `FormExamples` La clase demuestra los principales flujos de trabajo de procesamiento de formularios expuestos por la API de Facades.

Utilice esta sección para aprender cómo:

- Rellenar campos de texto, casilla de verificación, botón de opción, lista y código de barras
- Exportar datos del Form a XML, FDF y XFDF
- Importar datos del Form desde XML, FDF y XFDF
- Aplanar todos los campos del Form y renombrar los campos existentes
- Inspeccionar nombres de campo y valores actuales
- Rellenar un campo de botón de imagen desde un flujo de entrada
