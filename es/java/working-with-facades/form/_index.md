Abstract: Esta sección explica cómo usar la fachada Form en Aspose.PDF for Java para manejar formularios PDF interactivos. Los ejemplos en Java cubren el llenado de campos de texto, casilla de verificación, botón de opción, lista y código de barras; la exportación e importación de datos XML, FDF y XFDF; el aplanado de campos; el renombrado de campos; la inspección de valores de campos; y la adición de apariencias de imagen a los campos de botón.

El Java `FormExamples` La clase demuestra los principales flujos de trabajo de procesamiento de formularios expuestos por la API de Facades.

Utilice esta sección para aprender a:

- Rellenar campos de texto, casilla de verificación, botón de opción, cuadro de lista y campos de código de barras
- Exportar datos del formulario a XML, FDF y XFDF
- Importar datos del formulario desde XML, FDF y XFDF
- Aplanar todos los campos del formulario y renombrar los campos existentes
- Inspeccionar nombres de campo y valores actuales
- Rellenar un campo de botón de imagen desde un flujo de entrada
