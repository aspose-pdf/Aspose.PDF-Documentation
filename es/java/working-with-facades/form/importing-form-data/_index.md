El conjunto actual de ejemplos incluye la importación de datos AcroForm desde XML, FDF y XFDF, mientras que los temas no compatibles de reemplazo JSON y XFA se indican explícitamente para mantener la documentación alineada con las fuentes del repositorio.
---
El Java `FormExamples` la clase incluye flujos de trabajo de importación directa para estos formatos:

- XML con `form.importXml(...)`
- FDF con `form.importFdf(...)`
- XFDF con `form.importXfdf(...)`

Utilice las páginas secundarias en esta sección para los ejemplos concretos. El conjunto actual de ejemplos de Java en este repositorio no incluye un dedicado `Form` ejemplo de fachada para importación de JSON o sustitución de XFA, de modo que esas páginas se mantengan como notas de alcance.
