Abstract: Esta sección cubre los ejemplos de importación de formularios de Java implementados con la fachada de formulario en Aspose.PDF para Java. El conjunto de ejemplos actual incluye la importación de datos de AcroForm desde XML, FDF y XFDF, mientras que los temas de reemplazo de JSON y XFA no compatibles se indican explícitamente para mantener la documentación alineada con las fuentes del repositorio.
---
La clase Java `FormExamples` incluye flujos de trabajo de importación directa para estos formatos:


- 
XML con `form.importXml(...)`

- 
FDF con `form.importFdf(...)`

- 
XFDF con `form.importXfdf(...)`



Utilice las páginas secundarias de esta sección para ver ejemplos concretos. El conjunto de muestras de Java actual en este repositorio no incluye un ejemplo de fachada `Form` dedicado para la importación de JSON o el reemplazo de XFA, por lo que esas páginas se mantienen como notas de alcance.
