El Java `FormExamples` la clase incluye flujos de trabajo de importación directa para estos formatos:

- XML con `form.importXml(...)`
- FDF con `form.importFdf(...)`
- XFDF con `form.importXfdf(...)`

Utilice las páginas secundarias en esta sección para los ejemplos concretos. El conjunto de ejemplos de Java actual en este repositorio no incluye un dedicado `Form` ejemplo de fachada para importación de JSON o reemplazo de XFA, de modo que esas páginas se mantengan como notas de alcance.
