El Java `PdfFileStampExamples` La clase demuestra los principales flujos de trabajo de estampado disponibles a través de la API de Facades.

Utilice esta sección para aprender cómo:

- agregar una marca de imagen a un PDF
- colocar encabezados o pies de página de texto e imagen
- controlar los márgenes de encabezado y pie de página
- agregar números de página con diseños predeterminados, basados en coordenadas, alineados o con numeración romana
