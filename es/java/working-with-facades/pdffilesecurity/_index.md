El Java `PdfFileSecurityExamples` La clase demuestra los principales flujos de trabajo de seguridad disponibles a través de la API Facades.

Utilice esta sección para aprender a:

- cifrar un PDF con contraseñas de usuario y propietario
- aplicar o actualizar los privilegios del documento
- descifrar un PDF con una contraseña de propietario
- cambiar contraseñas y opcionalmente restablecer la configuración de seguridad
