El Java `PdfFileInfoExamples` La clase demuestra los flujos de trabajo principales de inspección y metadatos disponibles a través de la API de Facades.

Utilice esta sección para aprender cómo:

- leer la versión de PDF y los privilegios del documento
- inspeccionar el ancho, la altura, la rotación y los desplazamientos de la página
- obtener, establecer, eliminar y guardar los metadatos del documento con XMP
