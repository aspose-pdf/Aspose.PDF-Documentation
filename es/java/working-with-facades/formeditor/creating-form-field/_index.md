El Java `FormEditorExamples` la clase crea varios tipos de campos comunes en páginas PDF existentes al vincular el documento de entrada, llamando `addField(...)` o `addSubmitBtn(...)`, y guardando el resultado.

Utilice las subpáginas de esta sección para ejemplos concretos de creación de campos.
