El Java `FormEditorExamples` la clase crea varios tipos de campos comunes en páginas PDF existentes vinculando el documento de entrada, llamando `addField(...)` o `addSubmitBtn(...)`, y guardando el resultado.

Utilice las páginas secundarias en esta sección para ejemplos concretos de creación de campos.
