La clase Java `FormEditorExamples` crea varios tipos de campos comunes en páginas PDF existentes vinculando el documento de entrada, llamando a `addField(...)` o `addSubmitBtn(...)` y guardando el resultado.



Utilice las páginas secundarias de esta sección para ver ejemplos concretos de creación de campos.
