Utilice estos flujos de trabajo cuando necesite reconstruir la estructura del documento sin editar cada página manualmente.

Esta sección cubre cómo:

- agregar páginas de otro PDF
- eliminar páginas específicas
- extraer páginas seleccionadas a un nuevo archivo
- insertar páginas elegidas de un PDF en otro
