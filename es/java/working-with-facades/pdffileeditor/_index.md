El Java `PdfFileEditorExamples` La clase demuestra los principales flujos de trabajo de edición de documentos expuestos por la API de Facades.

Utilice esta sección para aprender cómo:

- fusionar archivos PDF con el `concatenate` método
- dividir un documento desde el principio hasta el final, o en archivos de una sola página
- extraer, eliminar, insertar y agregar páginas
- crear folleto y salida N-Up para impresión
- agregar márgenes, redimensionar el contenido de la página e insertar saltos de página
