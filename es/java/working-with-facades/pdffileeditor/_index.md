El Java `PdfFileEditorExamples` La clase demuestra los principales flujos de trabajo de edición de documentos expuestos por la Facades API.

Utilice esta sección para aprender cómo:

- combinar archivos PDF con el `concatenate` método
- dividir un documento desde el principio hasta el final, o en archivos de una sola página
- extraer, eliminar, insertar y añadir páginas
- crear salida en formato de folleto y N-Up para impresión
- añadir márgenes, cambiar el tamaño del contenido de la página e insertar saltos de página
