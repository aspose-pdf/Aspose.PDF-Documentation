Esta sección cubre cómo:

- crear un PDF listo para folleto a partir de un documento existente
- colocar varias páginas de origen en cada hoja de salida con un diseño N-Up
- manejar el valor de retorno booleano utilizado por el `try` ejemplos de estilo en el conjunto de ejemplos de Java
