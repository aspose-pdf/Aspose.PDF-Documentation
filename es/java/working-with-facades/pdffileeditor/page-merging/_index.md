El Java `PdfFileEditorExamples` clase incluye un directo `concatenate` ejemplo para combinar archivos PDF.

En esta sección puede encontrar:

- Cobertura de fusión respaldada por la fuente para el basado en matrices `concatenate` Workflow
- Guía sobre el artículo equivalente de dos archivos que utiliza el mismo ejemplo Java
- notas de alcance explícitas para lotes grandes, optimizados, específicos de formulario y `try` fusionar variantes que no están implementadas como métodos dedicados en el conjunto de ejemplos del repositorio actual
