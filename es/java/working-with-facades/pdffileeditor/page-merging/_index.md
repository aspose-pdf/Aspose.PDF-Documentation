En esta sección puede encontrar:

- Cobertura de fusión basada en origen para el basado en matrices `concatenate` workflow
- Orientación sobre el artículo equivalente de dos archivos que utiliza el mismo ejemplo Java
- notas de alcance explícitas para lotes de gran tamaño, optimizados, específicos del formulario, y `try` fusionar variantes que no están implementadas como métodos dedicados en el conjunto de ejemplos del repositorio actual
