Utilice esta sección cuando un documento necesite dividirse en salidas más pequeñas para reutilización, distribución o procesamiento posterior.

Esta sección cubre cómo:

- extraer las primeras páginas en un nuevo PDF
- extraer todas las páginas desde una página seleccionada hasta el final
- exportar cada página a su propio archivo con un patrón de nombres de salida
