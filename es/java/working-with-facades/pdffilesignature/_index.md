El Java `PdfFileSignatureExamples` class demuestra los principales flujos de trabajo de firma disponibles a través de la API Facades.

Utilice esta sección para aprender a:

- firmar y certificar documentos PDF
- inspeccionar nombres de firmas, datos del firmante y marcas de tiempo
- verificar la validez de la firma y la cobertura de todo el documento
- extraer un certificado de firma y eliminar una firma existente
