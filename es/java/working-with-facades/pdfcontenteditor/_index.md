El Java `PdfContentEditorExamples` La clase demuestra los principales flujos de trabajo de edición de contenido expuestos por la API de Facades.

Utilice esta sección para aprender cómo:

- agregar anotaciones de texto, línea, polígono, película y sello de goma
- agregar o eliminar archivos adjuntos del documento
- vincular un PDF desde un flujo y guardar el resultado
- agregar o eliminar acciones de apertura del documento
- reemplazar texto e imágenes
- obtener y cambiar las preferencias del visor
