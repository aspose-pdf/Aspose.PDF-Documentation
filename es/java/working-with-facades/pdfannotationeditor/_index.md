Esta sección agrupa los flujos de trabajo de anotaciones Java usados para crear, inspeccionar, eliminar y transferir anotaciones en archivos PDF.

El repositorio actual no incluye un dedicado `PdfAnnotationEditorExamples.java` clase. Para esta sección, el contenido del artículo se extrae de los ejemplos de Java bajo `en/java/src/main/java/com/aspose/pdf/examples/workingwithannotations`.

Utilice esta sección para:

- [Añadir, eliminar y obtener anotación](/pdf/es/java/pdfannotationeditor-class/add-delete-and-get-annotation/) para familias de anotaciones agrupadas.
- [Importar y exportar anotaciones](/pdf/es/java/pdfannotationeditor-class/import-export-annotations/) para copiar anotaciones entre archivos PDF.
