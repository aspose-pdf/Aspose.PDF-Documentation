Esta sección agrupa los flujos de trabajo de anotaciones Java utilizados para crear, inspeccionar, eliminar y transferir anotaciones en archivos PDF.

El repositorio actual no incluye un dedicado `PdfAnnotationEditorExamples.java` clase. Para esta sección, el contenido del artículo se basa en los ejemplos de Java bajo `en/java/src/main/java/com/aspose/pdf/examples/workingwithannotations`.

Use esta sección para:

- [Agregar, eliminar y obtener anotación](/pdf/es/java/pdfannotationeditor-class/add-delete-and-get-annotation/) para familias de anotaciones agrupadas.
- [Importar y exportar anotaciones](/pdf/es/java/pdfannotationeditor-class/import-export-annotations/) para copiar anotaciones entre archivos PDF.
