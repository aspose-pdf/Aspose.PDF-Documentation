## Descripción general



Para producir documentos PDF, la máquina que ejecuta [Aspose.PDF para Java](https://products.aspose.com/pdf/java/) no necesita tener [Adobe Acrobat](https://www.adobe.com/acrobat/acrobat-pro.html) instalado ya que Aspose.PDF para Java en sí es un motor de creación de documentos PDF. Sin embargo, para ver documentos PDF producidos por Aspose.PDF para Java, la máquina necesita al menos un [Adobe Acrobat Reader](https://www.adobe.com/acrobat/pdf-reader.html). Se puede descargar gratis.

## 
Versiones de Java compatibles



Aspose.PDF para Java admite las siguientes versiones de Java:

- J2SE 8.0 (1.8) o superior (*por ejemplo Java 10*)

- Soporte de Aspose.Pdf para Java en IBM i (Iseries o As/400)
