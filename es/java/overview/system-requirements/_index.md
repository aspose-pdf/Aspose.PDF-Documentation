## Resumen

Para producir documentos PDF, la máquina para ejecutar [Aspose.PDF for Java](https://products.aspose.com/pdf/java/) no necesita tener [Adobe Acrobat](https://www.adobe.com/acrobat/acrobat-pro.html) instalado ya que Aspose.PDF for Java en sí es un motor de creación de documentos PDF. Sin embargo, para visualizar documentos PDF producidos por Aspose.PDF for Java, la máquina necesita al menos un [Adobe Acrobat Reader](https://www.adobe.com/acrobat/pdf-reader.html). Se puede descargar de forma gratuita.

## Sistemas operativos compatibles

Aspose.PDF for Java admite cualquier sistema operativo de 32 bits o 64 bitsВ que ejecuta el tiempo de ejecución de Java, incluyendo, pero no limitado a:

### Windows

- Microsoft Windows 2000 Professional ( x64, x86)
- Microsoft Windows 2000 Server (x64, x86)
- Microsoft Windows 2003 Server (x64, x86)
- Microsoft Windows 2008 Server (x64, x86)
- Microsoft Windows 2012 Server (x64, x86)
- Microsoft Windows 2012 R2 Server (x64, x86)
- Microsoft Windows 2016 Server (x64, x86)
- Microsoft Windows 2019 Server (x64, x86)
- Microsoft Windows Vista (x64, x86)
- Microsoft Windows XP (x64, x86)
- Microsoft Windows 7 (x64, x86)
- Microsoft Windows 8, 8.1 (x64, x86)
- Microsoft Windows 10 (x64, x86)
- Microsoft Azure

### Linux

- Linux (Ubuntu, CentOS y otros)

### Mac

- Mac OS X

## Versiones de Java compatibles

Aspose.PDF for Java soporta las siguientes versiones de Java:

- J2SE 8.0 (1.8) o superior (*por ejemplo Java 10*)В
- Compatibilidad de Aspose.PDF for Java en IBM i (Iseries o As/400)
