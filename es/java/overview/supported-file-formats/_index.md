Abstract: Este artículo proporciona una tabla completa que detalla los formatos de archivo que Aspose.PDF para Python puede manejar. Describe las capacidades de la biblioteca para cargar y guardar varios tipos de documentos, ofreciendo información sobre su versatilidad para administrar diferentes formatos de archivos. Los formatos cubiertos incluyen tipos conocidos como PDF, EPUB, HTML y XML, todos los cuales pueden ser cargados y guardados por la biblioteca. También admite formatos de imagen como JPEG, PNG y TIFF para ambas operaciones. Sin embargo, algunos formatos como CGM, MHT, PCL, PS, XSLFO y MD solo están disponibles para cargar, mientras que otros como XLS, XLSX, PPTX, DOC, DOCX y MobiXML solo están disponibles para guardar. Esta tabla sirve como una guía práctica para los usuarios que buscan comprender la compatibilidad de formatos de Aspose.PDF para Python, destacando tanto sus fortalezas como sus limitaciones en la compatibilidad con formatos de documentos e imágenes.
