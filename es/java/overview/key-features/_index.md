Abstract: Aspose.PDF para Python a través de .NET es una biblioteca sólida que ofrece amplias funciones para administrar y manipular documentos PDF. Admite estándares de PDF establecidos y facilita la lectura y exportación de archivos PDF a varios formatos de imagen, como BMP, GIF, JPEG y PNG. Los usuarios pueden configurar propiedades de documentos, atributos de página y administrar texto, párrafos, hipervínculos, gráficos y archivos adjuntos. La biblioteca se destaca por sus capacidades de conversión, lo que permite una transformación perfecta de archivos PDF a formatos Word, Excel, PowerPoint y HTML, entre otros, al mismo tiempo que convierte varios formatos nuevamente a PDF.

## Características generales


- Escrito completamente en Java, funciona con JDK 1.8 y superior

- Soporta todas las aplicaciones Java

- Referencia de API en formato JavaDoc

- Compatibilidad con sistemas operativos de 32 bits.
- Compatibilidad con sistemas operativos de 64 bits.


## 
Versiones de PDF compatibles



Aspose.PDF para Java admite las versiones de PDF 1.2, 1.3, 1.4, 1.5, 1.6 y 1.7.

## Gráfico


- Se admiten diferentes formas de gráficos, como línea, círculo, arco y curva.

- Los gráficos se pueden dibujar en cualquier ubicación de página especificada por coordenadas.

- Los gráficos se pueden rotar, escalar o rellenar, y se pueden definir estilos de línea de guión y poli-guión.

- Los gráficos se dibujan en base a coordenadas y tienen una posición obsoleta en lugar de relativa.
- Se admiten espacios de color CMYK y grises.
