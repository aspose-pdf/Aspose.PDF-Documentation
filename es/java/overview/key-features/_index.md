Abstract: Aspose.PDF for Python via .NET es una biblioteca robusta que ofrece amplias características para gestionar y manipular documentos PDF. Soporta estándares PDF establecidos y facilita la lectura y exportación de PDFs a varios formatos de imagen como BMP, GIF, JPEG y PNG. Los usuarios pueden configurar las propiedades del documento, los atributos de página y gestionar texto, párrafos, hipervínculos, gráficos y adjuntos. La biblioteca sobresale en capacidades de conversión, permitiendo una transformación fluida de PDFs a formatos Word, Excel, PowerPoint y HTML, entre otros, y también convirtiendo varios formatos de vuelta a PDF.

## Características generales

- Escrito completamente en Java, funciona con JDK 1.8 y superiores
- Compatible con todas las aplicaciones Java
- Referencia de API en formato JavaDoc
- Soporte para sistemas operativos de 32 bits.
- Soporte para sistemas operativos de 64 bits.

## Versiones de PDF compatibles

Aspose.PDF for Java admite versiones PDF 1.2, 1.3, 1.4, 1.5, 1.6 y 1.7.

## Gráfico

- Se admiten diferentes formas de gráficos, como línea, círculo, arco y curva.
- Los gráficos pueden dibujarse en cualquier ubicación de página especificada por coordenadas.
- Los gráficos pueden rotarse, escalarse o rellenarse, y pueden definirse estilos de línea guionada y poliguionada.
- Los gráficos se dibujan basándose en coordenadas y tienen una posición obsoleta en lugar de relativa.
- Se admiten los espacios de color CMYK y gris.
