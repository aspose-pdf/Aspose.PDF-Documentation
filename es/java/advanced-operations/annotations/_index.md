Las anotaciones son elementos PDF interactivos que le permiten agregar notas, resaltar texto, dibujar formas, crear vínculos, aplicar redacciones y enriquecer los flujos de trabajo de revisión de documentos en archivos PDF existentes.

- 
[Agregar, eliminar y obtener anotación](/pdf/java/add-delete-and-get-annotation/) para familias de anotaciones agrupadas.

-
