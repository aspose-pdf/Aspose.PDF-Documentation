La sección de operaciones avanzadas agrupa los flujos de trabajo de Java utilizados para editar, inspeccionar, proteger y enriquecer documentos PDF existentes más allá de las operaciones básicas de crear, abrir, guardar, fusionar y dividir.

- [Trabajar con documentos](/pdf/java/working-with-documents/): comprime, divide y fusiona documentos y realiza otras operaciones con todo el documento.
- [Working with Pages](/pdf/java/working-with-pages/) - add, move or remove, crop pages, add watermarks, stamps, and etc.
- [Trabajar con imágenes](/pdf/java/working-with-images/): agregue, extraiga o elimine imágenes de documentos PDF.
- [Attachments](/pdf/java/attachments/) - you will learn how to add and delete the attachment from PDF programmatically with Python.
- [Navegación e interacción](/pdf/java/navigation-and-interaction/): trata con acciones, marcadores, navega por páginas.
- [Annotations](/pdf/java/annotations/) - annotations allow users to add custom content on PDF pages. You can add, delete and modify the annotation from the PDF documents.
- [Working with Tables](/pdf/java/working-with-tables/) - insert, decorate table in PDF, extract tabular data.
- [Working with Forms](/pdf/java/working-with-forms/) - deal with interact PDF documents, add formfields, extract data.
- [Working with Text](/pdf/java/working-with-text/) - add, format, search and replace text in PDF.
- [Compare PDF documents](/pdf/java/compare-pdf-documents/) - possible to compare PDF documents content.
- [Metadata in PDFs](/pdf/java/pdf-file-metadata/) - get or set meta data in documents, dealing with XMP data.
- [Working with Graphs](/pdf/java/working-with-graphs/) - manipulate with shapes on the page.
- [Artifacts](/pdf/java/artifacts/) - deal with watermarks and other special objects in PDF.
- [Working with PDF layers](/pdf/working-with-pdf-layers/) - lock layers, extract elements, flatten, and merge PDF layers.
- [Securing and Signing](/pdf/java/securing-and-signing/) - protect and sign your PDF document programmatically
- [Working with Vector Graphics](/pdf/java/working-with-vector-graphics/) - manipulate vector graphics in PDF documents.
- [Trabajar con ZUGFeRD](/pdf/java/working-with-zugferd/): trabaje con documentos PDF compatibles con ZUGFeRD.
- [Working with PDF Operators](/pdf/java/working-with-operators/) - work with PDF operators for advanced PDF manipulation.
