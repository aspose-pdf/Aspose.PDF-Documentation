{{% alert color="primary" %}}

Para desinstalar Aspose.PDF for SharePoint, simplemente ejecute el programa de instalación. Si Aspose.PDF for SharePoint ya está instalado, el programa de instalación sugiere eliminarlo.

![Desinstalar Aspose.PDF for SharePoint](uninstalling-aspose-pdf-for-sharepoint_1.png)

Durante la desinstalación, el programa de instalación desactiva la función Aspose.PDF for SharePoint para todas las colecciones de sitios y retira la solución del conjunto de servidores.

{{% /alert %}}
