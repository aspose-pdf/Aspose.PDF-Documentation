{{% alert color="primary" %}}

Para desinstalar Aspose.PDF para SharePoint, simplemente ejecute el programa de instalación. Si Aspose.PDF para SharePoint ya está instalado, el programa de instalación sugiere eliminarlo.

![Desinstalar Aspose.PDF para SharePoint](uninstalling-aspose-pdf-for-sharepoint_1.png)

Durante la desinstalación, el programa de instalación desactiva la función Aspose.PDF para SharePoint para todas las colecciones de sitios y retira la solución de la granja de servidores.

{{% /alert %}}
