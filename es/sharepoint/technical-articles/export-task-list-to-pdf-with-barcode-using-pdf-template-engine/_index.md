{{% alert color="primary" %}}

This article shows how to set up and export a task list to PDF with barcodes using Aspose.PDF for SharePoint.

{{% /alert %}}

Para exportar una lista de tareas a PDF con un código de barras usando el motor de plantillas, siga los siguientes pasos:

1. Crea y sube una plantilla.
1. Complete los campos de la plantilla y guarde la plantilla.
1. Create and save a new task.
1. Exporte el documento a PDF.

El proceso se detalla a continuación.

## Exportar lista de tareas a PDF

{{% alert color="primary" %}}

1. Cree una lista de plantillas PDF.

![Create PDF Template List](export-task-list-to-pdf-with-barcode-using-pdf-template-engine_1.png)

2. Después de crear la plantilla, haga clic en **Agregar nuevo elemento** en la lista y cargue el archivo XML.

![Upload XML File](export-task-list-to-pdf-with-barcode-using-pdf-template-engine_2.png)

3. Cuando se complete la carga, haga clic en **Aceptar**.
4. Complete los campos del formulario.
5. Guarde la plantilla.

![Configure Template](export-task-list-to-pdf-with-barcode-using-pdf-template-engine_3.png)

La plantilla ha sido configurada.

6. Vaya a la lista de **Tareas** y cree una nueva tarea.
7. Guarde la tarea.

![Create Task](export-task-list-to-pdf-with-barcode-using-pdf-template-engine_4.png)

8. En la pestaña **Herramientas de Aspose**, haga clic en **Exportar a PDF**.

![Export To PDF](export-task-list-to-pdf-with-barcode-using-pdf-template-engine_5.png)

9. Seleccione la plantilla configurada y haga clic en **Exportar**.

![Select Template](export-task-list-to-pdf-with-barcode-using-pdf-template-engine_6.png)

El PDF exportado:

![Exported PDF](export-task-list-to-pdf-with-barcode-using-pdf-template-engine_7.png)

{{% /alert %}}
