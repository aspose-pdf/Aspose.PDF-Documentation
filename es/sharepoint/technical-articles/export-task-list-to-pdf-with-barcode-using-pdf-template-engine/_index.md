{{% alert color="primary" %}}

Este artículo muestra cómo configurar y exportar una lista de tareas a PDF con códigos de barras usando Aspose.PDF for SharePoint.

{{% /alert %}}

Para exportar una lista de tareas a PDF con un código de barras usando el motor de plantillas, siga los siguientes pasos:

1. Crear y cargar una plantilla.
1. Completar los campos de la plantilla y guardar la plantilla.
1. Crear y guardar una nueva tarea.
1. Exportar el documento a PDF.

El proceso se detalla a continuación.

## Exportar la lista de tareas a PDF

{{% alert color="primary" %}}

1. Crear una lista de plantillas PDF.

![Crear lista de plantillas PDF](export-task-list-to-pdf-with-barcode-using-pdf-template-engine_1.png)

2. Después de crear la plantilla, haga clic en **Add New Item** en la lista y cargue el archivo XML.

![Cargar archivo XML](export-task-list-to-pdf-with-barcode-using-pdf-template-engine_2.png)

3. Cuando la carga se complete, haga clic en **OK**.
4. Rellene los campos del formulario.
5. Guardar la plantilla.

![Configurar plantilla](export-task-list-to-pdf-with-barcode-using-pdf-template-engine_3.png)

La plantilla ha sido configurada.

6. Vaya a la lista **Tasks** y cree una nueva tarea.
7. Guardar la tarea.

![Crear Tarea](export-task-list-to-pdf-with-barcode-using-pdf-template-engine_4.png)

8. En la pestaña **Aspose Tools**, haga clic en **Export To PDF**.

![Exportar a PDF](export-task-list-to-pdf-with-barcode-using-pdf-template-engine_5.png)

9. Seleccione la plantilla configurada y haga clic en **Export**.

![Seleccionar plantilla](export-task-list-to-pdf-with-barcode-using-pdf-template-engine_6.png)

El PDF exportado:

![PDF exportado](export-task-list-to-pdf-with-barcode-using-pdf-template-engine_7.png)

{{% /alert %}}
