{{% alert color="primary" %}}

Para comprobar que una licencia se ha instalado correctamente, convierta cualquier documento al formato deseado. Si el documento no contiene ninguna Advertencia de Evaluación, la licencia se activó exitosamente.

{{% /alert %}}
