{{% alert color="primary" %}}

Aspose.PDF for SharePoint le permite convertir varios documentos, o uno a la vez. Este artículo muestra cómo exportar un elemento de una lista.

{{% /alert %}}

Para exportar un elemento específico de una lista: seleccione **Export to Pdf** desde el Bloque de Control de Edición (BCE) del elemento.
