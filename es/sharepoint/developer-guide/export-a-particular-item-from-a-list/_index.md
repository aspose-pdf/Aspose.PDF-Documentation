{{% alert color="primary" %}}

Aspose.PDF para SharePoint le permite convertir varios documentos o uno a la vez. Este artículo muestra cómo exportar un elemento de una lista.

{{% /alert %}}

Para exportar un elemento en particular de una lista: seleccione **Exportar a Pdf** en el bloque de control de edición (ECB) del elemento.
