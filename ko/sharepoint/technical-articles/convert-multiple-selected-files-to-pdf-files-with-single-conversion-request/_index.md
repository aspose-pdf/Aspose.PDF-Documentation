{{% alert color="primary" %}}

이 문서에서는 SharePoint용 Aspose.PDF를 사용하여 단일 변환 작업으로 선택한 여러 파일을 PDF 파일로 변환하는 방법을 보여줍니다.

{{% /alert %}}

## 선택한 여러 파일을 PDF로 변환

{{% alert color="primary" %}}

선택한 여러 파일을 변환하려면 다음 단계를 수행하십시오.

1. 변환할 파일을 선택하세요

![파일 선택](convert-multiple-selected-files-to-pdf-files-with-single-conversion-request_1.jpg)

2. 라이브러리 도구에서 Aspose 도구 탭을 클릭하세요.

![Aspose 도구를 클릭하세요.](convert-multiple-selected-files-to-pdf-files-with-single-conversion-request_2.jpg)

3. 선택한 모든 파일을 결과 PDF 파일로 변환하려면 PDF로 변환을 클릭합니다.

![PDF로 변환](convert-multiple-selected-files-to-pdf-files-with-single-conversion-request_3.jpg)

4. 변환된 파일을 다운로드하라는 메시지가 표시됩니다.

![변환된 파일 다운로드](convert-multiple-selected-files-to-pdf-files-with-single-conversion-request_4.jpg)

![변환된 파일 다운로드](convert-multiple-selected-files-to-pdf-files-with-single-conversion-request_5.jpg)

{{% /alert %}}
