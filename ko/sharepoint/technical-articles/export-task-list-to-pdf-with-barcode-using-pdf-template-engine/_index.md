{{% alert color="primary" %}}

이 문서는 Aspose.PDF for SharePoint를 사용하여 바코드가 포함된 작업 목록을 PDF로 설정하고 내보내는 방법을 보여줍니다.

{{% /alert %}}

템플릿 엔진을 사용하여 바코드가 포함된 작업 목록을 PDF로 내보내려면 다음 단계를 수행하십시오:

1. 템플릿을 만들고 업로드합니다.
1. 템플릿 필드를 완성하고 템플릿을 저장합니다.
1. 새 작업을 만들고 저장합니다.
1. 문서를 PDF로 내보냅니다.

아래에 자세히 설명된 프로세스입니다.

## 작업 목록을 PDF로 내보내기

{{% alert color="primary" %}}

1. PDF 템플릿 목록을 만듭니다.

![PDF 템플릿 목록 만들기](export-task-list-to-pdf-with-barcode-using-pdf-template-engine_1.png)

2. 템플릿을 만든 후 목록에서 **Add New Item**을 클릭하고 XML 파일을 업로드합니다.

![XML 파일 업로드](export-task-list-to-pdf-with-barcode-using-pdf-template-engine_2.png)

3. 업로드가 완료되면 **OK**를 클릭합니다.
4. 양식 필드를 입력합니다.
5. 템플릿을 저장합니다.

![템플릿 구성](export-task-list-to-pdf-with-barcode-using-pdf-template-engine_3.png)

템플릿이 구성되었습니다.

6. **Tasks** 목록으로 이동하여 새 작업을 생성합니다.
7. 작업을 저장합니다.

![작업 생성](export-task-list-to-pdf-with-barcode-using-pdf-template-engine_4.png)

8. **Aspose Tools** 탭에서 **Export To PDF**를 클릭합니다.

![Export To PDF](export-task-list-to-pdf-with-barcode-using-pdf-template-engine_5.png)

9. 구성된 템플릿을 선택하고 **Export**를 클릭합니다.

![템플릿 선택](export-task-list-to-pdf-with-barcode-using-pdf-template-engine_6.png)

내보낸 PDF:

![내보낸 PDF](export-task-list-to-pdf-with-barcode-using-pdf-template-engine_7.png)

{{% /alert %}}
