## PDF 파일에 바코드 추가

{{% alert color="primary" %}}

SharePoint용 Aspose.PDF를 사용하면 PDF 문서에 바코드를 추가할 수 있습니다. 사용자는 라이브러리에 추가된 PDF 문서의 모든 페이지 왼쪽 하단에 바코드를 추가할 수 있습니다. 아래 이미지는 바코드가 추가된 PDF 문서가 어떻게 보이는지에 대한 아이디어를 제공합니다.

### 왼쪽 하단에 바코드

![PDF 파일에 바코드 추가 - 예 1](add-barcode-to-a-pdf-file_1.png)

{{% /alert %}}

{{% alert color="primary" %}}

특정 라이브러리에 대한 바코드 기능을 활성화하려면 아래와 같이 **라이브러리 도구**의 **Aspose PDF 워터마크 도구** 탭에서 **워터마크 설정** 버튼을 사용하세요.

### PDF 워터마크 설정

![PDF 파일에 바코드 추가 - 예 2](add-barcode-to-a-pdf-file_2.png)

특정 라이브러리에 대해 바코드를 활성화하면 SharePoint용 Aspose.PDF는 해당 라이브러리에 추가된 모든 PDF 문서에 바코드를 추가합니다.
