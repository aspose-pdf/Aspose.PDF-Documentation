{{% alert color="primary" %}}

Aspose.PDF for SharePoint는 PDF 문서를 SharePoint 문서 라이브러리에서 HTML 형식으로 변환하는 기능을 지원합니다. 이 기사에서는 PDF를 HTML로 변환하는 방법을 보여줍니다.

{{% /alert %}}

## PDF 문서를 HTML로 변환

다음과 같이 PDF 문서를 SharePoint 문서 라이브러리에서 HTML로 변환합니다.

1. PDF 문서의 ECB 메뉴에서 **HTML로 변환**을 클릭하세요.

![PDF를 HTML로 변환-예제 1](convert-pdf-to-html_1.png)

2. 결과 HTML 파일을 다운로드하여 디스크에 저장합니다.

![PDF를 HTML로 변환 예 2](convert-pdf-to-html_2.png)
