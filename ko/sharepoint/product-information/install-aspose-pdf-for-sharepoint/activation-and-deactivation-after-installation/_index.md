{{% alert color="primary" %}}

설치하는 동안 선택한 모든 사이트 모음에 대해 SharePoint용 Aspose.PDF가 활성화됩니다. 설치 후 사이트 모음의 루트 웹 사이트에서 사이트 작업 메뉴를 사용하여 SharePoint용 Aspose.PDF를 활성화 및 비활성화할 수 있습니다.

{{% /alert %}}
