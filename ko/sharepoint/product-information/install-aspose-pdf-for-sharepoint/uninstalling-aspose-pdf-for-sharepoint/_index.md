{{% alert color="primary" %}}

SharePoint용 Aspose.PDF를 제거하려면 설치 프로그램을 실행하기만 하면 됩니다. SharePoint용 Aspose.PDF가 이미 설치되어 있으면 설치 프로그램에서 이를 제거할 것을 제안합니다.

![SharePoint용 Aspose.PDF 제거](uninstalling-aspose-pdf-for-sharepoint_1.png)

제거하는 동안 설치 프로그램은 모든 사이트 모음에 대해 SharePoint용 Aspose.PDF 기능을 비활성화하고 서버 팜에서 솔루션을 철회합니다.

{{% /alert %}}
