## 서버 요구 사항

SharePoint용 Aspose.PDF를 설치하려면 Microsoft SharePoint Server 2010을 실행하는 컴퓨터가 필요합니다.

## 클라이언트 요구 사항

SharePoint 사이트에 액세스하려면 브라우저가 필요합니다. SharePoint용 Aspose.PDF는 다음 브라우저에서 테스트되었습니다.

- 마이크로소프트 인터넷 익스플로러 8
- 모질라 파이어폭스 3.5
- 구글 크롬 3
- 사파리 4
