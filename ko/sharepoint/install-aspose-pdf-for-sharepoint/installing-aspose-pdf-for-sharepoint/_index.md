{{% alert color="primary" %}}

Aspose.PDF for SharePoint는 Aspose.PDF.SharePoint.zip 아카이브 형태로 다운로드할 수 있습니다.

{{% /alert %}}

이 아카이브에는 다음이 포함됩니다:

- Aspose.PDF.SharePoint.wsp
  SharePoint 솔루션 파일. Aspose.PDF for SharePoint는 서버 팜 전체에 걸쳐 배포/철수 및 기능 활성화/비활성화를 용이하게 하기 위해 SharePoint 솔루션으로 패키징됩니다.
- Aspose_LicenseAgreement.rtf

**최종 사용자 라이선스 계약:**

- Aspose.PDF for SharePoint.pdf

**사용자 문서:**

- Aspose.PDF for SharePoint 문서.chm

**사용자 문서와 공개 API 참조:**

- setup.exe

**설치 프로그램:**

- setup.exe.config

**설정 구성 파일:**

설치 프로그램은 진행하기 전에 다음 조건들을 확인합니다:

- SharePoint 2010이 설치되어 있습니다.
- 사용자는 SharePoint 솔루션을 설치할 권한이 있습니다.
- SharePoint 데이터베이스가 온라인 상태입니다.
- SharePoint 관리 서비스가 시작되었습니다.
- SharePoint Timer 서비스가 시작되었습니다. SharePoint 관리 서비스와 타이머 서비스는 일부 설치 작업이 서버 팜의 모든 서버에 전파되는 타이머 작업에 의존하기 때문에 필요합니다.

**Aspose.PDF for SharePoint를 설치하려면:**

- Aspose.PDF.SharePoint zip 파일을 로컬 드라이브에 압축 해제합니다.
- setup.exe를 실행하고 화면의 지침을 따릅니다.

**설정 프로그램은 다음 작업을 수행합니다:**

- 설치 전제 조건을 확인합니다. 검사 중 하나라도 실패하면 설정이 계속되지 않습니다.

![설치 전제 조건 확인](installing-aspose-pdf-for-sharepoint_1.png)

- 최종 사용자 라이선스 계약을 표시합니다. 사용자는 진행하기 위해 계약에 동의해야 합니다.

![라이선스 계약 표시](installing-aspose-pdf-for-sharepoint_2.png)

- 배포 대상 선택 대화 상자를 표시합니다. 사용자는 기능이 활성화될 웹 애플리케이션 및 사이트 컬렉션을 선택합니다. 아래 그림을 참조하십시오.

![배포 대상 선택 표시](installing-aspose-pdf-for-sharepoint_3.png)

- 기능을 서버 팜에 배포합니다.

![기능 배포](installing-aspose-pdf-for-sharepoint_4.png)

- 선택한 사이트 컬렉션에 기능을 활성화하고 해당 상위 웹 애플리케이션을 구성합니다.
- 기능이 배포 및 활성화된 웹 애플리케이션과 사이트 컬렉션 목록을 표시합니다.

![배포된 기능 표시](installing-aspose-pdf-for-sharepoint_5.png)
