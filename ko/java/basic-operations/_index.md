**기본 작업** 섹션에서는 Aspose.PDF for Java로 수행할 수 있는 첫 번째이자 가장 간단한 PDF 작업을 설명합니다.


- 
[PDF 문서 생성](/pdf/java/create-document/) - Java에서 프로그래밍 방식으로 새 PDF 문서를 생성합니다.

- 
[PDF 문서 열기](/pdf/java/open-pdf-document/) - 경로, 스트림 또는 비밀번호를 사용하여 PDF 파일을 엽니다.

- 
[PDF 문서 저장](/pdf/java/save-pdf-document/) - 문서를 파일, 스트림 또는 PDF 표준으로 저장합니다.

- 
[PDF 병합](/pdf/java/merge-pdf/) - 여러 PDF 파일을 하나의 출력 문서로 결합합니다.
- [PDF 분할](/pdf/java/split-pdf/) - PDF 페이지를 별도의 단일 페이지 PDF 파일로 분할합니다.

- 
[PDF 파일 암호화 및 복호화](/pdf/java/protect-pdf-file/) - PDF 파일에 비밀번호, 권한 및 복호화를 적용합니다.
