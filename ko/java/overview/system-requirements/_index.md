Linux 시스템의 경우 특정 요구 사항에는 GCC-6 런타임 라이브러리, .NET Core Runtime의 종속성(런타임 자체가 필요 없음) 및 버전 3.5~3.7용 Python의 pymalloc 빌드가 포함됩니다. 또한 올바른 라이브러리 경로 인식을 위해 구성 조정이 필요할 수 있는 공유 libpython 라이브러리가 필요합니다.

## 
개요



PDF 문서를 생성하기 위해 [Aspose.PDF for Java](https://products.aspose.com/pdf/java/)를 실행하는 머신에 [Adobe Acrobat](https://www.adobe.com/acrobat/acrobat-pro.html)을 설치할 필요는 없습니다. Aspose.PDF for Java 자체가 PDF 문서 생성 엔진이기 때문입니다. 그러나 Aspose.PDF에서 생성된 Java용 PDF 문서를 보려면 컴퓨터에 최소한 [Adobe Acrobat Reader](https://www.adobe.com/acrobat/pdf-reader.html)가 필요합니다. 무료로 다운로드할 수 있습니다.
