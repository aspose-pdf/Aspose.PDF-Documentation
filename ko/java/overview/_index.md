_이 페이지는 Java 기능을 위한 Aspose.PDF의 개요입니다._



**Aspose for Java**는 개발자가 Adobe Acrobat을 사용하지 않고도 처음부터 PDF 문서를 만들 수 있는 강력한 Java 구성 요소입니다. Aspose.PDF for Java는 개발자가 배우고 사용하기 쉬운 매우 간단한 API(응용 프로그래밍 인터페이스)를 제공합니다.



이 라이브러리를 사용하면 처음부터 PDF 파일을 생성하는 풍부한 기능을 구현하거나 Adobe Acrobat을 설치하지 않고도 기존 PDF 문서를 완전히 처리할 수 있습니다. Java용 Aspose.PDF는 **다양한 기능**을 지원합니다.


### 
문서 압축



PDF 문서를 압축하면 파일 크기가 줄어들어 네트워크를 통해 더 쉽게 저장, 공유 및 전송할 수 있습니다. 이는 고해상도 이미지나 그래픽이 포함된 대용량 PDF 파일을 처리할 때 특히 중요합니다. 파일 크기가 작을수록 로딩 시간이 빨라지며, 특히 온라인이나 이메일 첨부 파일을 통해 PDF 문서에 액세스할 때 더욱 그렇습니다. 압축된 PDF는 더 빠르게 로드되어 사용자 경험과 생산성을 향상시킵니다.
**Java 라이브러리용 Aspose.PDF**는 다음과 같이 PDF 크기를 줄이는 다양한 방법을 제공합니다.


- 
모든 이미지 축소 또는 압축

- 
사용하지 않는 PDF 개체 제거

- 
사용하지 않는 PDF 스트림 제거

- 
중복 PDF 스트림 연결
- 글꼴 포함 취소

- 
주석 제거 또는 병합

- 
AcroForm 필드 제거

- 
flateDecode 압축 사용

- 
XImageCollection에 이미지 저장(재사용 가능한 이미지)
- PDF를 RGB 색상 공간에서 회색조로 변환



자세한 내용은 문서 페이지를 확인하세요. [PDF 최적화](/pdf/java/optimize-pdf/)


### 
테이블 생성 및 조작



표는 PDF 문서에 정보를 표시하기 위한 체계적이고 체계적인 형식을 제공합니다. 이를 통해 사용자는 데이터를 행과 열로 분류하고 배열할 수 있으므로 복잡한 데이터 세트를 더 쉽게 이해할 수 있습니다.



**Aspose.PDF for Java**를 사용하면 PDF 문서에서 테이블을 생성하고 조작하면 데이터 구성 개선, 가독성 향상, 분석 기능 향상, 정보를 효과적으로 표시하는 유연성 향상 등 다양한 이점을 얻을 수 있습니다.

자세한 내용은 다음 섹션을 확인하세요. [테이블 작업](/pdf/java/working-with-tables/)


### 
그래프 개체 지원



**Java용 Aspose.PDF**는 PDF 문서에 그래프 추가를 지원합니다. 이 작업을 위해 Graph 클래스가 제공됩니다.


PDF 문서에 그래프를 추가하면 데이터 시각화가 향상되고 명확성과 이해력이 향상되며 의사 결정 지원이 향상되고 독자 참여도가 높아집니다.



자세한 내용은 Docs 페이지를 확인하세요: [그래프 작업](/pdf/java/working-with-graphs/)

### 광범위한 하이퍼링크 기능



하이퍼링크를 사용하면 사용자가 PDF 문서 내에서 빠르고 효율적으로 탐색할 수 있습니다. 하이퍼링크를 클릭하면 독자는 문서를 수동으로 스크롤하지 않고도 다른 섹션, 장 또는 페이지로 이동할 수 있습니다.



**Java용 Aspose.PDF**는 향상된 탐색, 상호 참조, 외부 리소스에 대한 액세스, 상호 작용 및 향상된 커뮤니케이션을 포함한 많은 이점을 제공합니다. 이는 사용자에게 더욱 매력적이고 유익하며 접근 가능한 독서 경험을 제공하는 데 기여합니다.



자세한 내용은 다음 섹션을 확인하세요. [작업](/pdf/java/actions/)


### 
확장된 보안 제어

디지털 서명과 같은 보안 기능은 PDF 문서의 무결성을 보장하는 데 도움이 됩니다. 문서에 디지털 서명을 함으로써 발신자는 문서가 서명된 이후 내용이 변조되거나 변경되지 않았음을 확인할 수 있어 수신자에게 문서의 신뢰성을 보장할 수 있습니다.



**Aspose.PDF for Java**를 사용하면 스마트 카드에서 PDF에 서명하고, 파일을 암호화 및 해독하고, 이미지와 서명 정보를 추출하는 등의 작업이 가능합니다.



자세한 내용은 Docs 페이지를 확인하세요: [보안 및 서명](/pdf/java/securing-and-signing/)


### 
북마크 추가 또는 제거



책갈피는 사용자에게 크거나 복잡한 PDF 문서를 탐색할 수 있는 편리한 방법을 제공합니다. 특정 섹션, 장 또는 제목에 대한 북마크를 생성하면 사용자는 클릭 한 번으로 관련 콘텐츠로 쉽게 이동할 수 있어 시간과 노력이 절약됩니다.

**Aspose.PDF for Java** 라이브러리를 사용하면 PDF 파일에 책갈피를 추가하거나, 하위 책갈피를 추가하거나, 문서에서 전체 또는 특정 책갈피를 삭제할 수 있습니다.



자세한 내용은 다음 섹션을 확인하세요. [북마크](/pdf/java/add-and-delete-bookmark/)


### 
목차 만들기



TOC는 사용자에게 PDF 문서의 내용을 탐색할 수 있는 빠르고 효율적인 방법을 제공합니다. 해당 페이지 번호와 함께 주요 섹션, 장 또는 주제를 나열함으로써 사용자는 문서 내의 특정 정보를 쉽게 찾고 액세스할 수 있습니다.


**Aspose.PDF for Java** 라이브러리는 기존 PDF 파일에 목차를 추가하는 방법을 설명하고 Aspose.Pdf 네임스페이스의 Heading 클래스를 사용합니다.

자세한 내용은 문서 페이지를 확인하세요. [TOC 작업](/pdf/java/manipulate-pdf-document/)


###  
첨부 파일 및 주석 추가, 업데이트, 삭제



첨부 파일과 주석을 추가하면 PDF 문서가 더욱 대화형이고 독자의 관심을 끌게 됩니다. 사용자는 문서에 포함된 멀티미디어 파일, 링크, 댓글 등의 추가 콘텐츠와 상호 작용하여 독서 경험을 향상시킬 수 있습니다.



Aspose.PDF for Java 라이브러리는 [주석](/pdf/java/annotations/)을 사용하여 다르게 조작합니다. 다음과 같은 유형을 추가할 수 있습니다.


- 
텍스트 주석
- 하이라이트 주석

- 
그림 주석

- 
멀티미디어 주석

- 
고정 주석

- 
추가 주석

또한 당사 라이브러리를 사용하면 PDF에서 첨부 파일을 추가, 추출 및 제거할 수 있습니다.


자세한 내용은 다음 [문서 페이지](/pdf/java/attachments/)를 확인하세요.


###  
PDF 파일 메타데이터



메타데이터는 제목, 작성자, 생성 날짜, 주제 등 PDF 문서에 대한 필수 정보를 제공합니다. 이를 통해 사용자는 문서를 빠르게 식별하고 분류할 수 있으므로 대규모 PDF 파일 컬렉션을 더 쉽게 관리하고 구성할 수 있습니다.



PDF 파일 메타데이터는 문서 식별, 속성, 버전 추적, 설명, 검색 가능성, 접근성, 보안, 상호 운용성, 보존 및 규정 준수 등 다양한 목적으로 사용됩니다.

**Aspose.PDF for Java** 라이브러리를 사용하여 PDF 문서의 [메타데이터](/pdf/java/pdf-file-metadata/)를 쉽고 빠르게 관리하세요.


### 
텍스트 및 이미지 추가, 교체 또는 제거



텍스트와 이미지를 추가, 교체 또는 제거하면 사용자는 필요에 따라 PDF 문서의 내용을 업데이트, 수정 또는 향상할 수 있습니다. 이러한 유연성 덕분에 사용자는 변경 사항이나 개정 내용을 정확하게 반영하도록 문서 내용을 수정할 수 있습니다.



Aspose.PDF를 사용하면 PDF 내의 텍스트를 편집하고, 바꾸거나 회전하고, PDF에서 텍스트를 검색하거나 가져올 수 있습니다.



PDF의 이미지를 추가, 위치 변경, 삭제하고 더 많은 [복잡한 작업](/pdf/java/working-with-images/)을 수행할 수도 있습니다.

### 페이지 분할, 연결, 추출 또는 삽입



Docs의 [PDF 페이지 작업](/pdf/java/working-with-pages/) 섹션에서는 PDF에서 페이지를 추가, 이동, 삭제, 회전 또는 분할하는 방법을 설명합니다.



페이지 분할, 연결, 추출 또는 삽입은 사용자가 PDF 문서를 보다 효과적으로 관리하는 데 도움이 됩니다. 사용자는 페이지를 구성, 재배열 또는 결합하여 새 문서를 만들 수 있으므로 문서 구성 및 접근성이 향상됩니다.


### 
페이지를 이미지로 변환



PDF 페이지를 이미지로 변환하면 PDF 문서를 직접 보거나 상호 작용하는 데 어려움을 겪는 사용자가 콘텐츠에 더 쉽게 접근할 수 있습니다. 특별한 소프트웨어 없이도 스마트폰, 태블릿, 컴퓨터 등 다양한 기기에서 이미지를 쉽게 볼 수 있습니다.

Aspose.PDF를 사용하면 Java를 사용하여 PDF를 다른 이미지 형식으로 변환할 수 있습니다. 다음이 있습니다:


- 
티파니

- 
BMP

- 
EMF

- 
JPG
- PNG

- 
GIF

- 
SVG



DocumentDevice를 사용하는 Aspose.PDF 라이브러리 또는 PDF를 이미지로 변환하기 위한 ImageDevice 클래스입니다.[PDF를 다른 이미지 형식으로 변환](/pdf/java/convert-pdf-to-images-format/).


### 
PDF 문서 인쇄

PDF 문서를 인쇄하면 사용자는 전자 장치 없이도 쉽게 이동하고 액세스할 수 있는 실제 복사본을 만들 수 있습니다.



Java용 Aspose.PDF는 PDF 파일을 인쇄하는 다양한 방법을 제공합니다.


- 
Java Framework 4.x를 사용하여 PDF 인쇄

- 
Java Core/Java에서 PDF 인쇄

- 
Facades(콘솔 앱)를 사용하여 XPS 프린터로 PDF 인쇄
- WPF 응용 프로그램에서 PDF 인쇄

- 
PDF에서 PostScript로의 변환, 인쇄 작업 상태 확인 등과 같은 다양한 추가 작업



또한 Aspose.PDF for Java를 적용하면 텍스트, 이미지, SVG, HTML을 쉽게 PDF로 변환할 수 있으며 PDF를 뛰어난 성능과 좋은 품질로 다양한 문서 형식으로 변환할 수 있습니다.
