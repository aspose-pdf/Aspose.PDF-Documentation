Aspose.PDF를 사용하면 모든 제품에 대해 무료 기술 지원을 사용할 수 있습니다. Aspose.PDF에 대해 궁금한 점이 있으면 다음 문서를 확인하세요.


- 
가장 인기 있는 지원 소스는 [Aspose.Forums](https://forum.aspose.com/)입니다. [Aspose.PDF 포럼](https://forum.aspose.com/c/pdf/10) 섹션에서 질문을 하시면 빠른 시일 내에 답변을 받으실 수 있습니다.


- 
Aspose는 전화를 통한 기술 지원을 제공하지 않는다는 것을 알아야 합니다. 전화상담은 판매 및 구매문의만 가능합니다.


- 
시간대 차이가 있으므로 응답 속도에 영향을 미칠 수 있다는 점을 기억하세요.



Aspose.PDF 문제에 대한 도움이 필요한 경우 다음 권장 사항에 따라 문제가 가장 효율적인 방법으로 해결되었는지 확인하세요.


- 
Aspose는 [Aspose Repository](https://repository.aspose.com/webapp/#/artifacts/browse/tree/General/repo/com/aspose/aspose-pdf)에서 모든 Java API를 호스팅합니다. 간단한 구성으로 Maven 프로젝트에서 직접 Aspose.PDF for Java API를 쉽게 사용할 수 있습니다.


- 
아마도 문제에 대한 해결책이 이미 논의되어 해결책이 있을 수 있습니다. 이에 대한 문제를 보고하기 전에 포럼과 문서를 연구하고 [API 참조](https://reference.aspose.com/pdf/java)를 확인하세요.


- 
질문을 작성할 때 원본 문서와 문제를 일으키는 코드 조각을 포함해 주십시오. 여러 파일이 있는 경우 이러한 파일을 하나의 문서로 압축할 수 있습니다.


- 
걱정하지 마십시오. 귀하와 Aspose 개발자만이 고정 파일에 접근할 수 있습니다.
