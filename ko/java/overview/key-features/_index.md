## 일반 기능


- 
완전히 Java로 작성되었으며 JDK 1.8 이상에서 작동합니다.

-

- 
JavaDoc 형식의 API 참조

- 
32비트 OS 지원.
- 64비트 OS 지원.

## 그래프


- 
선, 원, 호, 곡선 등 다양한 모양의 그래프가 지원됩니다.

- 
좌표로 지정된 모든 페이지 위치에 그래프를 그릴 수 있습니다.

- 
그래프는 회전, 크기 조정 또는 채울 수 있으며 대시 및 다중 대시 선 스타일을 정의할 수 있습니다.

- 
그래프는 좌표를 기준으로 그려지며 상대 위치가 아닌 오래된 위치를 갖습니다.
- CMYK 및 회색 색상 공간이 지원됩니다.
