## 
설치 중



**Aspose.PDF NetBeans용 Java(Maven)** 플러그인은 플러그인 대화 상자의 사용 가능한 **플러그인** 탭에서 쉽게 설치할 수 있습니다.


- 
플러그인을 열려면 NetBeans의 **도구** 메뉴에서 **플러그인**을 선택하세요.


![todo:image_alt_text](installing-and-using-aspose-pdf-for-netbeans-maven_1.png)

- 
그러면 새 프로젝트 마법사에 **Aspose.PDF Maven 프로젝트**가 추가되고 NetBeans IDE의 새 파일 마법사에 **Aspose.PDF 코드 예제**가 추가됩니다.


## 
사용


### 
Aspose.PDF Maven 프로젝트(마법사)



[Aspose.PDF for Java API](http://www.aspose.com/java/pdf-component.aspx)를 사용하기 위해 마법사로 **Maven 프로젝트**를 생성하려면:


1. 
**새 프로젝트**를 선택합니다.

2. 
**Maven** 카테고리에서 **Aspose.PDF Maven Project**를 선택합니다.

3. 
**다음**을 클릭하세요.



Maven 프로젝트에 대한 **프로젝트 이름, 위치, GroupId, ArtifactId** 및 **버전**을 제공하고 **Finish.**를 클릭합니다.



그러면 [Aspose Cloud Maven Repository](https://repository.aspose.com/webapp/#/artifacts/browse/tree/General/repo)에서 [Aspose.PDF for Java](http://www.aspose.com/java/pdf-component.aspx) 최신 [Maven 종속성](http://maven.aspose.com/repository/ext-release-local/com/aspose/aspose-pdf/) 참조를 검색하여 **pom.xml**에 구성합니다. **코드 예제도 다운로드**를 선택한 경우 **코드 예제** 다운로드는 [Java API 예제 저장소용 Aspose.PDF]에서도 시작됩니다. ](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples)


마법사가 완료되면 **NetBeans IDE**에 다음 **Maven** 프로젝트가 생성됩니다.



생성된 **Maven 프로젝트**는 **Aspose.PDF for Java API**를 사용하도록 구성되었으며 프로젝트 요구 사항에 따라 향상될 준비가 되었습니다.

   
[코드 예제](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples)를 다운로드하기로 선택한 경우 **Aspose.PDF 코드 예제(마법사)**를 사용하여 [Aspose.PDF for Java](http://www.aspose.com/java/pdf-component.aspx) API의 필요한 **코드 예제**를 프로젝트로 가져올 수 있습니다.


### 
Aspose.PDF 코드 예제(마법사)



**Aspose.PDF 코드 예제 마법사**를 사용하면 [Aspose.PDF for Java](http://www.aspose.com/java/pdf-component.aspx) API에 제공되는 다양한 샘플을 시험해 볼 수 있습니다.


{{% alert color="primary" %}}


**Aspose.PDF 코드 예제 마법사**를 편안하게 사용하려면 **Aspose.PDF Maven 프로젝트** **마법사**에서 **Maven 프로젝트**를 생성하는 동안 항상 **코드 예제 다운로드**를 선택하는 것이 좋습니다.


{{% /alert %}}


예제를 사용하려면 다음을 수행하세요.


1. 
**NetBeans**에서 **새 파일**을 클릭합니다.

2. 
프로젝트를 선택한 다음 **Java** 카테고리에서 **Aspose.PDF Code 예제**를 선택합니다.

3. 
**다음**을 클릭하세요.



트리를 확장하여 **코드 예제** 카테고리를 선택하고 **마침**을 클릭합니다.


 
그러면 선택한 범주 **코드 예제** Java 파일이 **com.aspose.pdf.examples** 패키지 아래의 프로젝트에 복사됩니다. 또한 코드 예제에 필요한 모든 필수 리소스는 아래와 같이 **src/main/resources** 폴더에 복사됩니다.


 
예제 코드를 검토하고 컴파일하고 실행하세요.

 
이제 [Java API용 Aspose.PDF](http://www.aspose.com/java/pdf-component.aspx)를 사용하여 다른 예제를 테스트하고 자신만의 애플리케이션 구축을 시작할 수 있습니다.
