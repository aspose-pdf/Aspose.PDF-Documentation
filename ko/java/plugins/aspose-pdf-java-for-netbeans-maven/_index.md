## 
소개


### 
넷빈즈 IDE

NetBeans는 완전히 Java로 작성된 모든 기능을 갖춘 Java IDE입니다. 주로 Java 개발을 위한 것이지만 다른 언어, 특히 PHP, C/C++ 및 HTML5도 지원합니다.



NetBeans IDE를 사용하면 Java 데스크톱, 모바일, 웹 애플리케이션은 물론 HTML, JavaScript, CSS를 사용하는 HTML5 애플리케이션을 빠르고 쉽게 개발할 수 있습니다. 무료 오픈 소스이며 전 세계에 대규모 사용자 및 개발자 커뮤니티가 있습니다.



NetBeans 팀은 제품을 적극적으로 지원하고 더 넓은 커뮤니티로부터 기능 제안을 구합니다. 모든 릴리스에는 커뮤니티 테스트 및 피드백 시간이 선행됩니다.


### 
Java용 Aspose.PDF



[Aspose.PDF for Java](https://products.aspose.com/pdf/java/)는 Adobe Acrobat을 사용하지 않고도 Java 응용 프로그램이 PDF 문서를 읽고 쓰고 조작할 수 있게 해주는 강력한 PDF 문서 생성 API입니다.

Aspose.PDF for Java는 PDF 압축 옵션, 테이블 생성 및 조작, 그래프 지원, 이미지 기능, 광범위한 하이퍼링크 기능, 확장된 보안 제어 및 사용자 정의 글꼴 처리를 포함하여 엄청나게 풍부한 기능을 제공합니다.


### 
Aspose.PDF NetBeans용 Java(Maven)


- 
Aspose.PDF Java for NetBeans(Maven)은 **Aspose.**의 **NetBeans IDE**용 플러그인입니다. 이 플러그인은 Java 개발을 위해 Maven 플랫폼을 사용하고 프로젝트에서 Java용 Aspose.PDF를 사용하려는 개발자를 위한 것입니다. 플러그인을 사용하면 Java API용 Aspose.PDF를 사용하기 위한 Maven 프로젝트를 생성하고 API의 [코드 예제](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples)를 다운로드할 수도 있습니다.

- 
플러그인은 **NetBeans IDE** 내에서 Java API용 Aspose.PDF를 편안하게 사용할 수 있도록 다음 기능을 제공합니다.

## 
마법사

플러그인에는 두 개의 마법사가 포함되어 있습니다.


### 
Aspose.PDF Maven 프로젝트(마법사)


- 
이 새 프로젝트 마법사를 사용하면 개발자는 새 프로젝트 -> Maven-> Aspose.PDF Maven 프로젝트에서 Java용 Aspose.PDF를 사용하기 위한 **Maven** 프로젝트를 생성할 수 있습니다.

- 
Java API maven 종속성에 대한 Aspose.PDF의 참조는 [Aspose Maven Repository](https://repository.aspose.com/webapp/#/artifacts/browse/tree/General/repo/com/aspose/aspose-pdf)에서 자동으로 가져와서 pom.xml에 추가됩니다.

- 
생성된 프로젝트에는 항상 사용 가능한 최신 버전 **Maven** Java API용 Aspose.PDF 종속성이 포함됩니다.
- 마법사 단계에는 Java API용 Aspose.PDF를 사용하기 위한 코드 예제를 다운로드하기 위한 옵션도 제공됩니다.


### 
Aspose.PDF 코드 예제(마법사)


- 
이 새 파일 마법사를 사용하면 **새 파일 -> Java -> Aspose.PDF 코드 예제**에서 Java용 Aspose.PDF를 사용하기 위해 다운로드한 [코드 예제](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples)를 프로젝트에 복사할 수 있습니다.

- 
사용 가능한 샘플은 사용자가 범주별로 선택할 수 있는 트리 형식으로 표시됩니다.

- 
선택한 카테고리 내의 모든 예제는 예제를 실행하는 데 필요한 **src/main/resources** 폴더 내의 필수 리소스와 함께 프로젝트의 **com.aspose.pdf.examples** 패키지 폴더에 복사됩니다.
- Java API용 Aspose.PDF의 코드 예제는 API의 다양성을 보여주기 위한 것입니다.

- 
또한 마법사는 [Java 예제 저장소용 Aspose.PDF](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples)에서 새로 사용 가능한 항목을 찾아 업데이트합니다.

## 다운로드 중


### 
넷빈즈 다운로드



**NetBeans(Maven)용 Aspose.PDF Java**플러그인을 다운로드하기 전에 NetBeans IDE가 사전 설치되어 있어야 합니다.



**NetBeans(Maven)용 Aspose.PDF Java** 플러그인은 **NetBeans IDE8.0 및 8.1**을 지원합니다. 최신 버전의 NetBeans IDE만 사용하는 것이 좋습니다.



NetBeans IDE를 다운로드하려면,

1. 다음으로 이동하세요:<https://netbeans.apache.org/download/index.html>

1. 
다운로드를 클릭하여 NetBeans IDE에 적합한 번들을 다운로드하세요.



현재 최신 릴리스(예: **NetBeans IDE 8.1**)의 Java EE/SE 지원 NetBeans 다운로드 번들만 다운로드하세요.


### 
NetBeans용 Aspose.PDF Java 다운로드(Maven)


- 
플러그인은 NetBeans 플러그인 호스팅 URL:<http://plugins.netbeans.org/plugin/63218>에서 직접 다운로드할 수 있습니다.
  이후 버전은 IDE 옵션을 사용하여 설치할 수 있습니다.

  - 
이동**도구**>**플러그인**>**다운로드됨

  - 
**플러그인 추가...**를 클릭하고 **Aspose.PDF Java for NetBeans(Maven)**용으로 다운로드한 .nbm 확장 플러그인 파일을 찾아보세요.

  - 
플러그인을 설치하려면**"설치"**를 클릭하세요.

- 
또는 IDE 옵션을 사용하여 (NetBeans 플러그인 호스팅 URL에서 수동으로 다운로드하지 않고) 직접 설치할 수 있습니다.
  - 이동**도구**>**플러그인**>**사용 가능한 플러그인**

  - 
검색창에 "Aspose"를 입력하세요.

  - 
**Aspose.PDF Java NetBeans(Maven)** 플러그인을 선택합니다.

  - 
**"설치"**를 클릭하세요

### 
Aspose 라이센스를 적용하는 방법은 무엇입니까?



이 플러그인은 Aspose.PDF의 평가판을 사용합니다. 평가 결과가 만족스러우면 [Aspose 웹사이트](https://purchase.aspose.com/buy)에서 라이선스를 구매하실 수 있습니다.
평가 메시지와 기능 제한을 제거하려면 제품 라이선스를 적용해야 합니다. 제품을 구매하시면 라이센스 파일을 받으실 수 있습니다. 라이센스를 적용하려면 아래 단계를 따르십시오.


- 
라이센스 파일 이름이 **Aspose.PDF.Java.lic인지 확인하세요.

- 
Aspose.PDF.jar이 포함된 폴더에 **Aspose.PDF.Java.lic** 파일을 넣습니다.

- 
라이센스를 활성화하려면 다음 코드를 사용하십시오.


```java
License license = new License();
license.setLicense("Aspose.PDF.Java.lic");
```

### 
#NetBeans(Maven)용 Aspose.PDF Java의 소스 코드를 구성하는 방법



아래의 간단한 단계를 따르면 NetBeans IDE에서 **"Aspose.PDF NetBeans용 Java(Maven)'** 플러그인 소스 코드를 성공적으로 구성할 수 있습니다.

**파일**>프로젝트 열기를 선택합니다.

1. 
다운로드한 최신 프로젝트 소스를 찾아 프로젝트를 엽니다.

1. 
이제 Aspose.PDF Java for NetBeans(Maven) 플러그인 코드를 향상할 준비가 되었습니다.
