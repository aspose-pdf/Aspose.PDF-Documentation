## 
설치 중


### 
IntelliJ IDEA(Maven)용 Aspose.PDF Java를 설치하는 방법



아래 단계는 IntelliJ IDEA(Maven)** 플러그인용 **Aspose.PDF Java를 설치하는 방법을 보여줍니다.



플러그인은 IntelliJ IDEA의 CE [공식 플러그인 웹사이트](https://plugins.jetbrains.com/plugin/7974-aspose-pdf-java-for-intellij-idea-maven/)에 나열되어 있습니다. 플러그인 저장소는 **IntelliJ IDEA Maven용 Aspose.PDF Java**이므로 수동으로 다운로드하여 디스크에서 설치할 필요는 없지만 이 추가 옵션은 여전히 IntelliJ IDEA에 있습니다.



**IntelliJ IDEA(Maven)용 Aspose.PDF Java** 플러그인은 IntelliJ IDEA 내에서 (수동 다운로드 없이) 쉽게 설치할 수 있습니다. 이를 수행하려면:


1. 
**파일** 메뉴에서 **설정**을 선택합니다.

2. 
**플러그인**을 클릭한 다음 IntelliJ IDEA에서 저장소를 찾아보세요.


![todo:image_alt_text](https://i.imgur.com/NDZtoKw.jpg)

### 
Aspose.PDF 메이븐 프로젝트 마법사



**Aspose.PDF Maven 프로젝트** – IntelliJ IDEA에 추가하면 [Aspose.PDF for Java API.](https://products.aspose.com/pdf/java/)를 사용하기 위한 Aspose.PDF Maven 기반 프로젝트를 생성할 수 있습니다.

## 
사용


### 
Aspose.PDF 메이븐 프로젝트 마법사



IntelliJ IDEA 내에서 [Aspose.PDF for Java API](https://products.aspose.com/pdf/java/)를 사용하기 위한 Aspose.PDF Maven 프로젝트를 생성하려면 인터넷 연결이 필요합니다.



그런 다음 아래 단계를 따르십시오.


1. 
**새 프로젝트**를 선택합니다.

2. 
**Aspose.PDF Maven 프로젝트**를 선택합니다.

3. 
**다음**을 클릭하세요.


![todo:image_alt_text](https://i.imgur.com/hd2mYnW.jpg)

4. 
**GroupId, ArtifactId** 및 В 버전 제공


Maven 프로젝트를 선택하고 Next를 클릭하세요.


![todo:image_alt_text](https://i.imgur.com/aNlx0Qe.jpg)

5. 
"예제 소스 코드도 다운로드" 확인란을 선택하여 API의 샘플 사용 예를 다운로드할 수 있습니다(위 스냅샷 참조).


6. 
Java 애플리케이션을 생성할 때와 마찬가지로 **프로젝트 이름** 및 **위치**를 제공하세요.


![todo:image_alt_text](https://i.imgur.com/8VEeFun.jpg)

7. 
**마침**을 클릭합니다.



그러면 Aspose Cloud Maven Repository에서 [Java API용 Aspose.PDF](https://products.aspose.com/pdf/java/) 최신 Maven 종속성 참조를 검색하고 이를 pom.xml에서 구성합니다.


"예제 소스 코드도 다운로드" 확인란을 선택한 경우. 예제 다운로드는 [Java API GitHub Repository용 Aspose.PDF](https://goo.gl/cPAbJM)에서도 시작됩니다.


![todo:image_alt_text](https://i.imgur.com/bG2mdam.jpg)

![todo:image_alt_text](https://i.imgur.com/aNYhLl5.jpg)


축하합니다!  [Aspose.PDF for Java API](https://products.aspose.com/pdf/java/)를 사용하기 위한 Aspose.PDF Maven 프로젝트를 성공적으로 생성했습니다.


![todo:image_alt_text](https://i.imgur.com/UJlSbuM.jpg)


Java API Maven 프로젝트용으로 생성된 Aspose.PDF는 프로젝트 요구 사항에 따라 수정할 준비가 되었습니다.



[예제 소스 코드](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples)를 다운로드하기로 선택한 경우.


### 
Aspose.PDF 예제 마법사



**Aspose.PDF 예제 마법사**를 사용하여 프로젝트에 [예제 소스 코드](https://goo.gl/cPAbJM)를 가져오거나 복사하려면 먼저 Aspose.PDF Maven 프로젝트 마법사에서 "예제 소스 코드도 다운로드"를 선택하여 예제를 다운로드해야 합니다.



그런 다음 IntelliJ IDEA에서 아래 단계를 따르세요.


1. 
아래와 같이 **파일** > **새로 만들기 -**를 선택합니다.


![todo:image_alt_text](https://i.imgur.com/N8tT9Q0.jpg)


-또는- **오른쪽 클릭**(프로젝트 창에서) => **새로 만들기**В - 아래와 같이:


![todo:image_alt_text](https://i.imgur.com/aUBWkhp.jpg)

2. 
아래 그림과 같이 메뉴에서 **Aspose.PDF 예제** 옵션을 선택합니다.


![todo:image_alt_text](https://i.imgur.com/hvH2V0m.jpg)


마법사는 사용 가능한 최신 항목을 새로 고치거나 확인합니다.В [Java API 예제용 Aspose.PDF](https://goo.gl/cPAbJM)


![todo:image_alt_text](https://i.imgur.com/5PZwsuq.jpg)

3. 
**Aspose.PDF 예제 마법사** 대화 상자가 나타나며, 여기에서 예제 카테고리를 선택하여 예제를 프로젝트에 생성/복사할 수 있습니다.


예제 카테고리를 선택하고 **만들기**를 클릭하세요.

또한 예제 실행에 필요한 모든 리소스는 아래와 같이 **src/main/resources** 폴더에 복사됩니다.


![todo:image_alt_text](https://i.imgur.com/8GQL3Yb.jpg)

1.

2. 
[Java API용 Aspose.PDF - 예제 소스 코드](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples)를 다운로드했습니다.

3. 
Aspose.PDF 예제 마법사를 사용하여 예제 소스 코드를 프로젝트에 생성/복사했습니다.
