## 
소개


### 
IntelliJ 아이디어

IntelliJ IDEA는 소프트웨어 개발자를 위한 Java IDE(통합 개발 환경)입니다. JetBrains에서 개발했습니다. 원래 Java용으로 제작되었지만 현재 JavaScript, Groovy, HTML, CSS, RSS, R, Haskell, PHP, Ruby, Python, Scala, Clojure 및 Kotlin을 포함한 다양한 언어를 지원합니다.



2010년 Infoworld 보고서에서 IntelliJ는 Eclipse, IntelliJ IDEA, NetBeans 및 Oracle JDeveloper 등 4가지 주요 Java 프로그래밍 도구 중에서 가장 높은 테스트 센터 점수를 받았습니다.


### 
Java용 Aspose.PDF



Aspose.PDF for Java는 Java 응용 프로그램이 Adobe Acrobat을 사용하지 않고도 PDF 문서를 읽고, 쓰고, 조작할 수 있게 해주는 PDF 문서 생성 구성 요소입니다.


### 
IntelliJ IDEA용 Aspose.PDF Java - Maven

- IntelliJ IDEA(Maven)용 Aspose.PDF Java는 Maven 프로젝트(즉, 생성된 프로젝트에 Java API Maven 종속성을 위한 Aspose.PDF가 포함되어 있음)를 생성하고 Java API용 Aspose.PDF를 사용하기 위한 API의 소스 코드 예제를 다운로드할 수 있는 IntelliJ IDEA 플러그인입니다.

- 
이 플러그인은 즐겨 사용하는 IntelliJ IDEA 내에서 Java API용 Aspose.PDF로 작업하는 데 도움이 됩니다.


![todo:image_alt_text](https://i.imgur.com/KWKGljg.png)


마법사:


플러그인에는 두 개의 마법사가 포함되어 있습니다.



마법사 1: Aspose.PDF Maven 프로젝트

- 플러그인의 Aspose Maven 프로젝트 마법사를 사용하면 개발자는 Java API Maven 프로젝트용 Aspose.PDF를 만들 수 있습니다.

- 
Java API maven 종속성에 대한 Aspose.PDF 참조는 [Aspose Cloud Maven Repository](https://repository.aspose.com/webapp/#/artifacts/browse/tree/General/repo)에서 자동으로 가져와서 pom.xml에 추가됩니다.

- 
생성된 프로젝트에는 항상 Java API용 Aspose.PDF에 대한 사용 가능한 최신 버전의 Maven 종속성이 포함됩니다.

- 
마법사 단계에는 [Java API용 Aspose.PDF 사용을 위한 소스 코드 예제](https://github.com/aspose-pdf/Aspose.PDF-for-Java)를 다운로드할 수 있는 옵션도 제공됩니다.



마법사 2: Aspose.PDF 예

- Aspose.PDF 예제 마법사를 사용하면 다운로드한 Aspose.PDF for Java API의 소스 코드 예제를 프로젝트에 생성/복사할 수 있습니다. 선택한 카테고리의 모든 예제는 예제를 실행하는 데 필요한 "src/main/resources" 폴더 내의 필수 리소스와 함께 프로젝트의 "com.aspose.pdf.examples" 패키지 폴더에 복사됩니다.

- 
Java API용 Aspose.PDF의 소스 코드 예제는 API의 다양한 사용법을 보여주기 위한 것입니다.

## 
다운로드 중


### 
IntelliJ IDEA 다운로드



IntelliJ IDEA(Maven) 플러그인용 Aspose.PDF Java를 다운로드하기 전에 먼저 IntelliJ IDEA CE/UE를 설치해야 합니다.



IntellliJ IDEA를 다운로드하려면

1. <https://www.jetbrains.com/idea/download/>로 이동

1. 
실행 중인 OS를 선택하세요.

1. 
UE 또는 CE 다운로드를 클릭하세요.


### 
IntelliJ IDEA 플러그인용 Aspose.PDF Java 다운로드(Maven)


- 
플러그인은 IntelliJ IDEA 플러그인 저장소의 [JetBrains 플러그인 호스팅 URL](https://goo.gl/z06gC0)에서 직접 다운로드할 수 있습니다.
  이후 버전은 IDE 옵션을 사용하여 설치할 수 있습니다.

  - 
파일 > 설정...>플러그인으로 이동

  - 
"디스크에서 플러그인 설치"를 선택하세요.

- 
또는 IDE 옵션을 사용하여 JetBrains 플러그인 호스팅 URL에서 수동으로 다운로드하지 않고 직접 설치할 수 있습니다.

  - 
파일 > 설정...>플러그인으로 이동
  - "저장소 찾아보기"를 선택하십시오.

  - 
검색창에 "Aspose"를 입력하세요.

  - 
설치하려면 "IntelliJ IDEA Maven용 Aspose.PDF Java" 플러그인을 선택하세요.
