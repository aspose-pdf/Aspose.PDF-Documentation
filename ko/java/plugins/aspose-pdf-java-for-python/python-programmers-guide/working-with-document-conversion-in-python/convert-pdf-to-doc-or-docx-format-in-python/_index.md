**Aspose.PDF Java for Python**을 사용하여 PDF 문서를 DOC 또는 DOCX 형식으로 변환하려면 **PdfToDoc** 모듈을 호출하기만 하면 됩니다.


```python
doc= self.Document()
pdf = self.Document()
pdf=self.dataDir + 'Template.pdf'
doc.save(self.dataDir + 'template.docx')
print "Document has been converted successfully"
```
