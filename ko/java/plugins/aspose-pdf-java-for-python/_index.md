## 
Python용 Aspose.PDF Java 소개


## 
JPype

JPype는 Python 프로그램이 Java 클래스 라이브러리에 대한 전체 액세스를 허용하려는 노력입니다. 이는 Jython/JPython이 수행한 것처럼 Python을 다시 구현하는 것이 아니라 두 가상 머신의 기본 수준에서 인터페이스를 통해 달성됩니다.



[readthedocs.org](http://jpype.readthedocs.org/en/latest/userguide.html)에서 자세한 내용을 읽어보세요.


## 
Java용 Aspose.PDF



Aspose.PDF for Java는 Java 애플리케이션 내에서 직접 다양한 문서 처리 작업을 수행할 수 있는 Java용 고급 클래스 라이브러리입니다.



Java용 Aspose.PDF는 워드(DOC, DOCX, OOXML, RTF) HTML, OpenDocument, PDF, EPUB, XPS, SWF 및 모든 이미지 형식 처리를 지원합니다. Aspose.PDF를 사용하면 Microsoft Word를 사용하지 않고도 문서를 생성, 수정 및 변환할 수 있습니다.

[aspose.com](https://products.aspose.com/words/java)에서 자세한 내용을 읽어보세요.


## 
Aspose.PDF Python용 자바



Python용 Project Aspose.PDF는 Python에서 Aspose.PDF Java API를 사용하여 다양한 작업을 수행하는 방법을 보여줍니다. 이 프로젝트는 [JPype](http://jpype.readthedocs.org/en/latest/userguide.html)를 사용하는 Python 프로젝트에서 Java용 Aspose.PDF를 활용하려는 Python 개발자에게 유용한 예제를 제공하는 것을 목표로 합니다.
