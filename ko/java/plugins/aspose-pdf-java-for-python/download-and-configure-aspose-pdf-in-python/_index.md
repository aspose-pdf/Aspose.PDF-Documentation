## 
소스 코드를 구성하는 방법



다음을 사용하는 동안 소스 코드를 열고 확장하려면 다음의 간단한 단계를 따르세요.


1. 
<https://www.python.org/downloads/>에서 Python 2.7.x.x만 설치하세요.

2. 
JPype 설치 위치: <http://sourceforge.net/projects/jpype/files/JPype/>

3. 
Java JDK 설치: <http://www.oracle.com/technetwork/java/javase/downloads>

4. 
Python 프로젝트에 사용하려는 Java API용 Aspose.PDF를 <http://www.aspose.com/community/files/72/java-components/default.aspx>에서 다운로드하고 다운로드한 API의 .jar을 %Python%/lib 폴더에 복사하세요.

5. 
Github에서 [Aspose.PDF Python 예제용 Java](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Plugins/Aspose_Pdf_Java_for_Python)를 복제합니다.

6. 
CodePlex에서 [Aspose.PDF Python 예제용 Java](http://asposepdfjavapython.codeplex.com/)를 복제합니다.
