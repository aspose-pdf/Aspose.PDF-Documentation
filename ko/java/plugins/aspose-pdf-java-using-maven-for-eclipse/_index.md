## 
소개


### 
이클립스 IDE

Eclipse IDE는 유명한 Java IDE(통합 개발 환경)입니다. IDE는 확실히 Eclipse 오픈 소스 프로젝트의 가장 잘 알려진 제품입니다. 현재 이는 약 60%의 시장 점유율을 차지하는 선도적인 Java 개발 환경입니다.



Eclipse IDE는 추가 소프트웨어 구성 요소를 사용하여 확장될 수 있습니다. Eclipse는 이러한 소프트웨어 구성요소를 플러그인이라고 부릅니다. 여러 오픈 소스 프로젝트와 회사에서는 Eclipse IDE를 확장하거나 Eclipse 프레임워크 위에 독립형 애플리케이션(Eclipse RCP)을 만들었습니다.


### 
Java용 Aspose.PDF



[Aspose.PDF for Java](https://products.aspose.com/pdf/java/)는 Adobe Acrobat을 사용하지 않고도 Java 응용 프로그램이 PDF 문서를 읽고 쓰고 조작할 수 있게 해주는 강력한 PDF 문서 생성 API입니다.



Aspose.PDF for Java는 PDF 압축 옵션, 테이블 생성 및 조작, 그래프 지원, 이미지 기능, 광범위한 하이퍼링크 기능, 확장된 보안 제어 및 사용자 정의 글꼴 처리를 포함하여 엄청나게 풍부한 기능을 제공합니다.

### Aspose.PDF Eclipse용 Java(Maven)


- 
Aspose.PDF Eclipse용 Java(Maven)는 **Aspose.**의 **Eclipse IDE**용 플러그인입니다. 이 플러그인은 Java 개발을 위해 Maven 플랫폼을 사용하고 프로젝트에서 Java용 Aspose.PDF를 사용하려는 개발자를 위한 것입니다. 플러그인을 사용하면 Java API용 Aspose.PDF를 사용하기 위한 Maven 프로젝트를 생성하고 API의 [코드 예제](https://github.com/aspose-pdf/Aspose.Pdf-for-Java)를 다운로드할 수도 있습니다.

- 
플러그인은 **Eclipse IDE** 내에서 Java API용 Aspose.PDF를 편안하게 사용할 수 있도록 다음 기능을 제공합니다.


![todo:image_alt_text](https://i.imgur.com/KWKGljg.png)


**마법사**:


플러그인에는 두 개의 마법사가 포함되어 있습니다.

**Aspose.PDF Maven 프로젝트(마법사)**


- 
이 새 프로젝트 마법사를 사용하면 개발자는 New -> Project -> Maven-> Aspose.PDF Maven Project에서 Java용 Aspose.PDF를 사용하기 위한 **Maven** 프로젝트를 만들 수 있습니다.

- 
Java API maven 종속성에 대한 Aspose.PDF 참조는 [Aspose Cloud Maven Repository](https://repository.aspose.com/webapp/#/artifacts/browse/tree/General/repo)에서 자동으로 가져와서 pom.xml에 추가됩니다.

- 
생성된 프로젝트에는 항상 사용 가능한 최신 버전 **Maven** Java API용 Aspose.PDF 종속성이 포함됩니다.

- 
마법사 단계에는 Java API용 Aspose.PDF를 사용하기 위한 [코드 예제](https://github.com/aspose-pdf/Aspose.Pdf-for-Java)를 다운로드하는 옵션도 제공됩니다.
Aspose.PDF 코드 예제(마법사)


- 
이 새 파일 마법사를 사용하면 새로 만들기 -> 기타 -> Java -> Aspose.PDF 코드 예제에서 Aspose.PDF for Java를 사용하기 위해 다운로드한 [코드 예제](https://github.com/aspose-pdf/Aspose.Pdf-for-Java)를 프로젝트에 복사할 수 있습니다.

- 
사용 가능한 샘플은 사용자가 범주별로 선택할 수 있는 트리 형식으로 표시됩니다.

- 
선택한 카테고리 내의 모든 예제는 예제를 실행하는 데 필요한 "**src/main/resources**" 폴더 내의 필수 리소스와 함께 프로젝트의 "**com.aspose.pdf.examples**" 패키지 폴더에 복사됩니다.

- 
Java API용 Aspose.PDF의 코드 예제는 API의 다양한 기능을 시연하기 위한 것입니다.
- 또한 마법사는 Java 예제 저장소용 Aspose.PDF에서 새로 사용 가능한 코드 예제를 찾아 업데이트합니다.

그런 다음 "Aspose.PDF Java(Maven) for Eclipse"를 선택하고 **마침**을 선택합니다. 라이센스 계약에 동의하고 플러그인을 설치하십시오.

### 
Aspose 라이센스를 적용하는 방법은 무엇입니까?

이 플러그인은 Aspose.PDF의 평가판을 사용합니다. 평가 결과가 만족스러우면 [Aspose 웹사이트](https://purchase.aspose.com/buy)에서 라이선스를 구매하실 수 있습니다.


평가 메시지와 기능 제한을 제거하려면 제품 라이선스를 적용해야 합니다. 제품을 구매하시면 라이센스 파일을 받으실 수 있습니다. 라이센스를 적용하려면 아래 단계를 따르십시오.


- 
라이센스 파일 이름이 Aspose.PDF.Java.lic인지 확인하세요.

- 
Aspose.PDF.jar이 포함된 폴더에 **Aspose.PDF.Java.lic** 파일을 넣습니다.

- 
라이센스를 활성화하려면 다음 코드를 사용하십시오.

{{< highlight java >}}

 라이센스 라이센스 = new License();

### 
Aspose.PDF Java(Maven) for Eclipse 소스 코드 구성 방법



아래의 간단한 단계를 따르면 Eclipse IDE에서 **"Aspose.PDF Java (Maven) for Eclipse"** 플러그인 소스 코드를 성공적으로 구성할 수 있습니다.


1. 
소스 코드를 다운로드/복제합니다.

1. 
**파일** > 가져오기 > 일반 > 기존 프로젝트를 작업공간으로 선택
1. 다운로드한 최신 프로젝트 소스를 찾아보세요.

1. 
가져오려는 Eclipse 프로젝트를 선택하십시오.

1. 
마침을 클릭하세요

1. 
Aspose.PDF Eclipse 플러그인 코드용 Java가 이제 향상될 준비가 되었습니다.
