## 
소스 코드에서 Struts 1.3용 Aspose.PDF Java 빌드



위 저장소 중 하나에서 소스 코드를 확인한 후 다음 mvn 명령을 적용하십시오.


{{< highlight java >}}

 
$ mvn -U 클린 패키지


{{< /highlight >}}


그러면 대상 텔러에 "Strutsbookapp.war"가 빌드됩니다.



.war 파일을 배포하려면 실행 중인 Apache Tomcat 서버 webapp 디렉터리에 복사하기만 하면 됩니다.
