이 섹션에서는 다음 방법을 다룹니다.


- 
다른 PDF의 페이지 추가

- 
특정 페이지 제거

- 
선택한 페이지를 새 파일로 추출
- 한 PDF에서 선택한 페이지를 다른 PDF에 삽입
