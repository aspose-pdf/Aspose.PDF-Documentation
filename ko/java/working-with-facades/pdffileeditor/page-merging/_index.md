Java `PdfFileEditorExamples` 클래스에는 PDF 파일 병합을 위한 직접 `concatenate` 샘플이 포함되어 있습니다.



이 섹션에서는 다음을 확인할 수 있습니다.


- 
어레이 기반 `concatenate` 워크플로우에 대한 소스 지원 병합 적용 범위

- 
동일한 Java 샘플을 사용하는 동등한 두 파일 문서에 대한 지침

- 
현재 저장소 예제 세트에서 전용 메서드로 구현되지 않은 대규모 배치, 최적화, 양식별 및 `try` 병합 변형에 대한 명시적 범위 참고 사항
