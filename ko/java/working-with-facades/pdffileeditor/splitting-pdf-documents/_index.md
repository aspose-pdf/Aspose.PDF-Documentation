재사용, 배포 또는 다운스트림 처리를 위해 문서를 더 작은 출력으로 나누어야 하는 경우 이 섹션을 사용하세요.



이 섹션에서는 다음 방법을 다룹니다.


- 
첫 번째 페이지를 새 PDF로 추출

- 
선택한 페이지에서 끝까지 모든 페이지를 추출합니다.

- 
출력 명명 패턴을 사용하여 모든 페이지를 자체 파일로 내보냅니다.
