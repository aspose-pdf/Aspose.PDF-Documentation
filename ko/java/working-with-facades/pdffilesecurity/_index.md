Java `PdfFileSecurityExamples` 클래스는 Facades API를 통해 사용할 수 있는 주요 보안 작업 흐름을 보여줍니다.



이 섹션을 통해 다음 방법을 알아보세요.


- 
사용자 및 소유자 비밀번호로 PDF 암호화

- 
문서 권한 적용 또는 업데이트

- 
소유자 비밀번호로 PDF 해독
- 비밀번호를 변경하고 선택적으로 보안 설정을 재설정합니다.
