Java `FormExamples` 클래스에는 다음 형식에 대한 직접 가져오기 작업 흐름이 포함되어 있습니다.


- 
`form.importXml(...)`을 사용한 XML

- 
`form.importFdf(...)`의 FDF

- 
`form.importXfdf(...)`이 포함된 XFDF



구체적인 예를 보려면 이 섹션의 하위 페이지를 사용하세요. 이 저장소의 현재 Java 샘플 세트에는 JSON 가져오기 또는 XFA 대체를 위한 전용 `Form` 외관 예제가 포함되어 있지 않으므로 해당 페이지는 범위 참고 사항으로 유지됩니다.
