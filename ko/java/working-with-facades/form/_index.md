Java `FormExamples` 클래스는 Facades API에 의해 노출되는 주요 양식 처리 작업 흐름을 보여줍니다.



이 섹션을 통해 다음 방법을 알아보세요.


- 
텍스트 채우기, 확인란, 라디오 버튼, 목록 상자 및 바코드 필드

- 
양식 데이터를 XML, FDF 및 XFDF로 내보내기

- 
XML, FDF 및 XFDF에서 양식 데이터 가져오기
- 모든 양식 필드를 평면화하고 기존 필드의 이름을 바꿉니다.

- 
필드 이름 및 현재 값 검사

- 
입력 스트림에서 이미지 버튼 필드 채우기
