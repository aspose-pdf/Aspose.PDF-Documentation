- 
`flattenAllFields(...)`

- 
`renameFormFields(...)`



저장소에는 현재 선택한 필드 하위 집합만 평면화하기 위한 별도의 Java `Form` 외관 예제가 포함되어 있지 않으므로 하위 페이지가 조작된 샘플 코드 대신 범위 참고로 문서화됩니다.
