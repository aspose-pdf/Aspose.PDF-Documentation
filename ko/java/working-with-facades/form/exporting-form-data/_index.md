Java `FormExamples` 클래스에는 다음 형식에 대한 직접 내보내기 워크플로가 포함되어 있습니다.


- 
`form.exportXml(...)`을 사용한 XML

- 
`form.exportFdf(...)`의 FDF

- 
`form.exportXfdf(...)`이 포함된 XFDF



구체적인 예를 보려면 이 섹션의 하위 페이지를 사용하세요. 이 저장소의 현재 Java 샘플 세트에는 JSON 내보내기 또는 XFA 추출을 위한 전용 `Form` 외관 예제가 포함되어 있지 않으므로 해당 페이지는 합성 코드 연습이 아닌 범위 참고로 유지됩니다.
