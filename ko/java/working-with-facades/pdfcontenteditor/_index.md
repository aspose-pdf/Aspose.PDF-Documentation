Java `PdfContentEditorExamples` 클래스는 Facades API에 의해 노출되는 주요 콘텐츠 편집 작업 흐름을 보여줍니다.



이 섹션을 통해 다음 방법을 알아보세요.


- 
텍스트, 선, 다각형, 동영상 및 도장 주석 추가

- 
문서 첨부 추가 또는 제거

- 
스트림에서 PDF를 바인딩하고 결과를 저장합니다.
- 문서 열기 작업 추가 또는 제거

- 
텍스트와 이미지 교체

- 
시청자 기본 설정 가져오기 및 변경
