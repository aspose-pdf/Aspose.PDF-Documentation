Facades API는 하위 수준 문서 개체 모델을 직접 사용하지 않고도 일반적인 PDF 작업을 위한 상위 수준 도우미를 제공합니다.



이 섹션을 통해 다음 방법을 알아보세요.


- 
PDF 양식 채우기 및 편집

- 
주석 및 컨텐츠 작업

- 
PDF 파일 병합, 분할 및 재구성
- 메타데이터 및 페이지 정보 검사

- 
보안, 서명, 스탬프 및 페이지 번호 매기기 적용

- 
뷰어 파사드를 사용하여 PDF 페이지를 이미지로 렌더링
