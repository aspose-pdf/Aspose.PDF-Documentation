Java `PdfFileStampExamples` 클래스는 Facades API를 통해 사용할 수 있는 주요 스탬핑 작업 흐름을 보여줍니다.



이 섹션을 통해 다음 방법을 알아보세요.


- 
PDF에 이미지 스탬프 추가

- 
텍스트 및 이미지 머리글 또는 바닥글 배치

- 
머리글 및 바닥글 여백 제어
- 기본, 좌표 기반, 정렬 또는 로마 번호 매기기 레이아웃으로 페이지 번호 추가
