Java `FormEditorExamples` 클래스는 Facades API를 통해 사용할 수 있는 주요 필드 편집 작업 흐름을 보여줍니다.



이 섹션을 통해 다음 방법을 알아보세요.


- 
텍스트, 확인란, 콤보 상자, 목록 상자, 라디오 버튼 및 제출 버튼 필드 만들기

- 
기존 필드 추가, 삭제, 이동, 이름 바꾸기, 복사 또는 변환

- 
정렬, 모양, 제한 및 빗살 수를 사용자 정의합니다.

- 
스크립트 첨부, URL 제출, 필드 작업 제거
