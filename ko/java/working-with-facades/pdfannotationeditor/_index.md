현재 저장소에는 전용 `PdfAnnotationEditorExamples.java` 클래스가 포함되어 있지 않습니다. 이 섹션의 기사 내용은 `en/java/src/main/java/com/aspose/pdf/examples/workingwithannotations`의 Java 예제에서 가져온 것입니다.



이 섹션을 사용하여 다음을 수행합니다.


-

-
