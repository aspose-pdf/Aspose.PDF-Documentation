Java `PdfFileInfoExamples` 클래스는 Facades API를 통해 사용할 수 있는 주요 검사 및 메타데이터 워크플로를 보여줍니다.



이 섹션을 통해 다음 방법을 알아보세요.


- 
PDF 버전 및 문서 권한 읽기

- 
페이지 너비, 높이, 회전 및 오프셋 검사

- 
XMP를 사용하여 문서 메타데이터 가져오기, 설정, 지우기 및 저장
