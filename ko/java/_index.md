## 
Java용 Aspose.PDF에 오신 것을 환영합니다.



Aspose.PDF는 개발자가 간단하든 복잡하든 프로그래밍 방식으로 즉석에서 PDF 문서를 만들 수 있도록 만들어진 Java 구성 요소입니다. Java용 Aspose.PDF를 사용하면 개발자는 테이블, 그래프, 이미지, 하이퍼링크, 사용자 정의 글꼴 등을 PDF 문서에 삽입할 수 있습니다. 또한 PDF 문서를 압축하는 것도 가능합니다. Aspose.PDF for Java는 안전한 PDF 문서를 개발하기 위한 뛰어난 보안 기능을 제공합니다. Aspose.PDF for Java의 가장 뚜렷한 특징은 API와 XML 템플릿을 모두 통해 PDF 문서 생성을 지원한다는 것입니다.



Java용 Aspose.PDF는 다음과 같은 주요 기능을 제공합니다.


- 
HTML, Doc/Docx, Pptx, Markdown, Jpeg 등의 문서를 변환합니다.

- 
PDF 문서에서 데이터를 로드하는 기능을 통해 다양한 AI 제공업체를 지원합니다.

- 
API와 XML 파일을 통해 PDF 문서 생성을 지원합니다.

- 
안전한 PDF 문서를 개발하기 위한 탁월한 인증서 기반 보안 및 비밀번호 보호 기능.

- 
강력한 디지털 서명과 호환됩니다.

- 
PDF 양식 생성(대화형 양식, AcroForms, 동적 XFA 양식)
