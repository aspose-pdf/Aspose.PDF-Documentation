고급 작업 섹션은 기본 생성, 열기, 저장, 병합 및 분할 작업을 넘어 기존 PDF 문서를 편집, 검사, 보안 및 강화하는 데 사용되는 Java 작업 흐름을 그룹화합니다.


- 
[문서 작업](/pdf/java/working-with-documents/) - 문서 전체를 압축, 분할, 병합하고 기타 작업을 수행합니다.

- 
[페이지 작업](/pdf/java/working-with-pages/) - 페이지 추가, 이동 또는 제거, 자르기, 워터마크, 스탬프 추가 등

- 
[이미지 작업](/pdf/java/working-with-images/) - PDF 문서에서 이미지를 추가, 추출 또는 제거합니다.

- 
[첨부 파일](/pdf/java/attachments/) - Python을 사용하여 프로그래밍 방식으로 PDF에서 첨부 파일을 추가하고 삭제하는 방법을 알아봅니다.

- 
[탐색 및 상호 작용](/pdf/java/navigation-and-interaction/) - 작업, 북마크, 페이지 탐색을 처리합니다.

- 
[주석](/pdf/java/annotations/) - 주석을 사용하면 사용자가 PDF 페이지에 사용자 정의 콘텐츠를 추가할 수 있습니다. PDF 문서에서 주석을 추가, 삭제 및 수정할 수 있습니다.

- 
[테이블 작업](/pdf/java/working-with-tables/) - PDF에 테이블 삽입, 장식, 테이블 형식 데이터 추출.

- 
[양식 작업](/pdf/java/working-with-forms/) - 상호 작용하는 PDF 문서를 처리하고, 양식 필드를 추가하고, 데이터를 추출합니다.

- 
[텍스트 작업](/pdf/java/working-with-text/) - PDF에서 텍스트를 추가, 서식 지정, 검색 및 교체합니다.

- 
[PDF 문서 비교](/pdf/java/compare-pdf-documents/) - PDF 문서 내용 비교가 가능합니다.

- 
[PDF의 메타데이터](/pdf/java/pdf-file-metadata/) - XMP 데이터를 처리하여 문서의 메타데이터를 가져오거나 설정합니다.

- 
[그래프 작업](/pdf/java/working-with-graphs/) - 페이지의 모양을 조작합니다.

- 
[아티팩트](/pdf/java/artifacts/) - PDF의 워터마크 및 기타 특수 개체를 다룹니다.

- 
[PDF 레이어 작업](/pdf/working-with-pdf-layers/) - 레이어 잠금, 요소 추출, 병합 및 PDF 레이어 병합.

- 
[보안 및 서명](/pdf/java/securing-and-signing/) - 프로그래밍 방식으로 PDF 문서를 보호하고 서명합니다.

- 
[벡터 그래픽 작업](/pdf/java/working-with-vector-graphics/) - PDF 문서에서 벡터 그래픽을 조작합니다.

- 
[ZUGFeRD 작업](/pdf/java/working-with-zugferd/) - ZUGFeRD 호환 PDF 문서로 작업합니다.

- 
[PDF 운영자와 협력](/pdf/java/working-with-operators/) - 고급 PDF 조작을 위해 PDF 운영자와 협력합니다.
