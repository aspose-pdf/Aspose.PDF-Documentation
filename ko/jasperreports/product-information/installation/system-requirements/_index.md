{{% alert color="primary" %}}

JasperReports용 Aspose.PDF를 실행하려면 다음 소프트웨어가 필요합니다.

- Java 2 플랫폼 Standard Edition 5.0 이상.
- JasperReports 6.7.0 이상.
- JasperServer 6.7.0 이상(JasperServer와 함께 JasperReports에 Aspose.PDF를 사용하려는 경우)

{{% /alert %}}
