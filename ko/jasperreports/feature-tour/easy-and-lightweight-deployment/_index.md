{{% alert color="primary" %}}

Aspose.PDF for JasperReports는 [JasperReports](http://www.jaspersoft.com/jasperreports)의 내보내기 확장입니다.

Aspose.PDF for JasperReports is provided as a single JAR file and can easily be integrated with JasperReports and JasperServer.

{{% /alert %}}

To install Aspose.PDF for JasperReports, simply copy the **Aspose-pdf-jasperreports.jar** file to the correct folder (JasperReports\lib). To integrate with JasperServer you also need to edit a JasperServer configuration file. [Read the installation section](/pdf/ko/jasperreports/installation/) for detailed installation steps.
