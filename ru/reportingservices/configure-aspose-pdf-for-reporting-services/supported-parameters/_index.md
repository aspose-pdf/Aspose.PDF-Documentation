Параметризованный отчёт — это отчёт, который принимает входные значения, используемые при его обработке. С параметризованным отчётом вы можете изменять вывод отчёта в зависимости от значений, заданных при запуске отчёта. Aspose.PDF for Reporting Services поддерживает два типа параметров: параметры сервера отчётов и параметры отчёта. Параметры сервера отчётов применяются ко всем отчётам на сервере отчётов. Если необходимо сделать некоторые параметры пригодными для конкретных отчётов, следует использовать параметры отчёта.
