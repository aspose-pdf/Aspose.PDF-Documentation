{{% alert color="primary" %}}

В этой галерее показаны отчеты в формате PDF, экспортированные Aspose.PDF для служб Reporting Services.

{{% /alert %}}

Большинство представленных здесь отчетов взяты из базы данных Adventure Works. Adventure Works — это образец базы данных для Microsoft SQL Server, доступный для загрузки с сайта Microsoft. [здесь](http://www.microsoft.com/downloads/details.aspx?familyid=E719ECF7-9F46-4312-AF89-6AD8702E4E6E&displaylang=en).
