## Поддерживаемые форматы загрузки

В следующей таблице указаны форматы файлов, которые может загружать Aspose.PDF для служб Reporting Services.

|**Формат**|**Описание**|
| :- | :- |
|РДЛ|Язык определения отчета|
|[HTML](https://docs.fileformat.com/web/html/)|Язык разметки гипертекста|

## Поддерживаемые форматы сохранения

В следующей таблице указаны форматы файлов, в которых документ можно сохранить с помощью Aspose.PDF для служб Reporting Services. 

|**Формат**|**Описание**|
| :- | :- |
|[PDF](https://docs.fileformat.com/pdf/)|Сохраняет документ в формате PDF.|
|PDF/А |Сохраняет документ в формате PDF/A.|
|[XPS](https://docs.fileformat.com/page-description-language/xps/)|Сохраняет документ в формате спецификации XML Paper.|
|EPUB|Сохраняет документ в формате электронной книги.|
