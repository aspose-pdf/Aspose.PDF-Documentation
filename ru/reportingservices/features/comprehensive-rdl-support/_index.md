{{% alert color="primary" %}}

Aspose.PDF для Reporting Services поддерживает спецификацию RDL. Это означает:

* Нет необходимости перепроектировать или настраивать существующие отчеты.
* Нет необходимости использовать конкретный дизайнер отчетов. Вы можете использовать любой дизайнер отчетов RDL, и отчет будет экспортирован именно так, как вы его разработали.

{{% /alert %}}

## Поддерживаемые элементы RDL
Aspose.PDF для служб Reporting Services поддерживает следующие элементы RDL:

- Разделы
- Заголовки, нижние колонтитулы
- Текстовые поля
- Изображения
- Графики
- Списки
- Таблицы
- Матрицы
- Стили
- Прямоугольники
- Линии
- Подотчет
- Панель приборов (RS2008)
- Табликс (RS2008)
