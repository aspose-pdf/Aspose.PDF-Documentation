Вы можете добавить пользовательские свойства для некоторых элементов отчета, чтобы расширить их использование, например ToC, стрелки линий и т. д. В этом разделе описан этот процесс.

{{% /alert %}}

Вы можете добавить настраиваемые свойства для некоторых элементов отчета, чтобы расширить их использование, например оглавление, стрелки линий и т. д. В этом разделе описан этот процесс.

Чтобы добавить пользовательские свойства, вам необходимо отредактировать файл кода документа RDL, выполнив следующие действия:

1. Как показано на следующем рисунке, откройте проект, перейдите к обозревателю решений и щелкните правой кнопкой мыши выбранный файл отчета, затем выберите пункт меню «Просмотреть код».

![Add Custom Properties](adding-custom-properties_1.png)

2. Отредактируйте файл кода XML. Например, если вы хотите добавить настраиваемое свойство для элемента отчета диаграммы, вам необходимо добавить код, аналогичный выделенному красным текстом в следующем примере.

## Пример

```xml
<chart Name="chart1">
    <Left>5.5cm</Left>
    <Top>0.5cm</Top>
      ......
    <Style>
      ......
    </style>     
    <CustomProperties>
      <CustomProperty>
        <Name>IsInList</Name>
        <Value>True</Value>
      </CustomProperty>
    </CustomProperties>
</chart> 
```

В этом примере фрагмента кода имя пользовательского свойства — IsInList, а значение — `True`.
