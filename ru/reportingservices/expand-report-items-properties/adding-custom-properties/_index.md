{{% alert color="primary" %}}

Вы можете добавить пользовательские свойства для некоторых элементов отчета, чтобы расширить их использование, например, таблицу содержания, стрелки линий и т.д. Этот раздел описывает этот процесс.

Чтобы добавить пользовательские свойства, вам нужно отредактировать файл кода документа RDL в следующих шагах:

1. Как показано на следующей схеме, откройте ваш проект, перейдите к обозревателю решений, щелкните правой кнопкой мыши выбранный файл отчёта, затем выберите пункт меню 'View Code'.

![todo:image_alt_text](adding-custom-properties_1.png)

2. Отредактируйте файл XML‑кода. Например, если вы хотите добавить пользовательское свойство для элемента отчёта диаграммы, вам нужно добавить код, похожий на выделенный красным текст в следующем примере.

**Пример**

{{< highlight csharp >}}

<chart Name="chart1">
    <Left>5,5см</Left>
    <Top>0,5см</Top>
      ......
    <Style>
      ......
    </style>     
    <CustomProperties>
      <CustomProperty>
        <Name>IsInList</Name>
        <Value>Верно</Value>
      </CustomProperty>
    </CustomProperties>
</chart> 

{{< /highlight >}}

В этом примере фрагмента кода имя пользовательского свойства — IsInList, а значение — 'True'.

{{% /alert %}}
