## Добро пожаловать в Aspose.PDF for Reporting Services!

Microsoft SQL Server Reporting Services удовлетворяет потребность, с которой сталкиваются многие организации, — потребность в построении решений бизнес‑аналитики и отчётности. До сих пор разработчикам требовалось встраивать отчёты в свои приложения, или организациям требовалось приобретать дорогие и иногда проблемные сторонние решения для отчётности. Сейчас Microsoft SQL Server Reporting Services предлагает полное решение для распространения отчётов по всей компании; позволяя бизнесу принимать решения лучше и быстрее.

**Aspose.PDF for Reporting Services** — это ещё одно уникальное решение от Aspose, которое делает возможным создание PDF‑отчётов в Microsoft SQL Server 2016/2017/2019/2022 Reporting Services и Power BI Report Server. Все функции отчётов RDL, включая таблицы, матрицы, диаграммы и изображения, преобразуются с высочайшей точностью в PDF.

Microsoft SQL Server Reporting Services имеет встроенные возможности экспорта отчётов в виде PDF‑документов, но не предоставляет необходимую техническую поддержку конечному пользователю. Aspose.Pdf стремится обеспечить превосходную и эффективную техническую поддержку.

Aspose.PDF for Reporting Services создает документы на сервере без использования Adobe.Pdf SDK. Aspose.PDF for Reporting Services внутри использует Aspose.PDF for .NET – компонент мирового класса для серверной обработки документов и конвертации.

## Aspose.PDF for Reporting Services делает возможным экспорт любого отчета в формате PDF.
