## Добро пожаловать в Aspose.PDF для служб отчетов!

Службы отчетов Microsoft SQL Server удовлетворяют потребность, с которой сталкиваются многие организации, — необходимость создания решений для бизнес-аналитики и отчетности. До сих пор разработчикам приходилось встраивать отчеты в свои приложения, а организациям приходилось приобретать дорогие, а иногда и проблематичные сторонние решения для создания отчетов. Теперь службы отчетов Microsoft SQL Server предлагают комплексное решение для распространения отчетов по предприятию; позволяя предприятиям принимать решения лучше и быстрее.

**Aspose.PDF for Reporting Services** — еще одно уникальное решение от Aspose, которое позволяет создавать отчеты в формате PDF в Microsoft SQL Server 2016/2017/2019/2022 Reporting Services и сервере отчетов Power BI. Все функции отчетов RDL, включая таблицы, матрицы, диаграммы и изображения, с высочайшей степенью точности преобразуются в PDF.

Службы отчетов Microsoft SQL Server имеют встроенные возможности экспорта отчетов в формате PDF, но не обеспечивают необходимой технической поддержки для конечного пользователя. Aspose.Pdf стремится обеспечить высочайшую и эффективную техническую поддержку.

Aspose.PDF for Reporting Services создает документы на сервере без использования Adobe.Pdf SDK. Aspose.PDF for Reporting Services внутренне использует Aspose.PDF for .NET — компонент мирового класса для обработки и преобразования документов на стороне сервера.

## Aspose.PDF for Reporting Services позволяет экспортировать любой отчет в формате PDF.
