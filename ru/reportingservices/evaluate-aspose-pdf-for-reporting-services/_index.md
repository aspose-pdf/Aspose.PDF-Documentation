{{% alert color="primary" %}}

На этой странице указана разница между лицензионной и ознакомительной версией Aspose.PDF для служб Reporting Services.

{{% /alert %}}

Вы можете легко скачать [Aspose.PDF для служб отчетов](https://downloads.aspose.com/pdf/reportingservices) для оценки. Оценочная загрузка такая же, как и приобретенная загрузка. Ознакомительная версия просто становится лицензированной, когда вы помещаете файл лицензии в папку, содержащую Aspose.PDF.ReportingServices.dll, или несколько строк кода для инициализации лицензии при использовании компонента с Report Viewer в локальном режиме. Ознакомительная версия Aspose.PDF для Reporting Services (без указанной лицензии) обеспечивает полную функциональность продукта, но вставляет оценочный водяной знак в верхней части документа при преобразовании файла .RDL в формат PDF. Вы можете посетить следующую страницу для получения дальнейших инструкций по [как лицензировать Aspose.PDF для служб отчетов](/pdf/ru/reportingservices/license-aspose-pdf-for-reporting-services/)

![Оценка](evaluate-aspose-pdf-for-reporting-services_1.png)

{{% alert color="primary" %}}

Если вы хотите протестировать Aspose.PDF для служб Reporting Services без ограничений ознакомительной версии, вы также можете запросить 30-дневную временную лицензию. Пожалуйста, обратитесь к [Как получить временную лицензию?](<https://about.aspose.com/>)

{{% /alert %}}
