{{% alert color="primary" %}}

Эта страница описывает разницу между лицензированной и оценочной версией Aspose.PDF for Reporting Services

{{% /alert %}}

Вы можете легко скачать [Aspose.PDF for Reporting Services](https://downloads.aspose.com/pdf/reportingservices) для оценки. Загрузка оценочной версии идентична загрузке приобретённой версии. Оценочная версия просто становится лицензированной, когда вы помещаете файл лицензии в папку, содержащую Aspose.PDF.ReportingServices.dll, либо добавляете несколько строк кода для инициализации лицензии при использовании компонента с Report Viewer в локальном режиме. Оценочная версия Aspose.PDF for Reporting Services (без указания лицензии) предоставляет полный функционал продукта, однако вставляет оценочный водяной знак в верхнюю часть документа при рендеринге файла .RDL в формат PDF. Вы можете посетить следующую страницу для получения дополнительных инструкций по [как лицензировать Aspose.PDF for Reporting Services](/pdf/ru/reportingservices/license-aspose-pdf-for-reporting-services/)

![Оценка](evaluate-aspose-pdf-for-reporting-services_1.png)

{{% alert color="primary" %}}

Если вы хотите протестировать Aspose.PDF for Reporting Services без ограничений версии оценки, вы также можете запросить 30‑дневную временную лицензию. Пожалуйста, обратитесь к [Как получить временную лицензию?](<https://about.aspose.com/>)

{{% /alert %}}
