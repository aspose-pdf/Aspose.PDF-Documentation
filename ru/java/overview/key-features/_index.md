## Общие возможности

- Полностью написано на Java, работает с JDK 1.8 и выше
- Поддерживает все Java‑приложения
- Справочник API в формате JavaDoc
- Поддержка 32‑битных ОС.
- Поддержка 64‑битных ОС.

## Поддерживаемые версии PDF

Aspose.PDF for Java поддерживает версии PDF 1.2, 1.3, 1.4, 1.5, 1.6 и 1.7.

- Поддержка Unicode.

## Граф

- Поддерживаются различные формы графов, такие как линия, круг, дуга и кривая.
- Графы можно нарисовать в любом месте страницы, указанном координатами.
- Графы можно вращать, масштабировать или заполнять, а также определять стили пунктирных и полупунктирных линий.
- Графы рисуются на основе координат и имеют устаревшее положение вместо относительного.
- Поддерживаются цветовые пространства CMYK и Gray.
