## Общие характеристики

- Полностью написан на Java, работает с JDK 1.8 и выше.
- Поддерживает все приложения Java
- Справочник API в формате JavaDoc
- Поддержка 32-битной ОС.
- Поддержка 64-битной ОС.

## Поддерживаемые версии PDF

Aspose.PDF для Java поддерживает PDF версий 1.2, 1.3, 1.4, 1.5, 1.6 и 1.7.

## График

- Поддерживаются различные формы графиков, такие как линия, круг, дуга и кривая.
- Графики можно рисовать в любом месте страницы, заданном координатами.
- Графики можно поворачивать, масштабировать или заполнять, а также можно определять стили штриховых и многопунктирных линий.
- Графики строятся на основе координат и имеют устаревшее, а не относительное положение.
- Поддерживаются цветовые пространства CMYK и Grey.
