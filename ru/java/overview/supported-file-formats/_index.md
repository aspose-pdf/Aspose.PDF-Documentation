Abstract: В этой статье представлена ​​подробная таблица с подробным описанием форматов файлов, которые поддерживает Aspose.PDF for Python. В нем описываются возможности библиотеки по загрузке и сохранению различных типов документов, а также дается представление о ее универсальности для управления различными форматами файлов. Охватываемые форматы включают такие известные типы, как PDF, EPUB, HTML и XML, каждый из которых может быть как загружен, так и сохранен библиотекой. Он также поддерживает форматы изображений, такие как JPEG, PNG и TIFF для обеих операций. Однако некоторые форматы, такие как CGM, MHT, PCL, PS, XSLFO и MD, доступны только для загрузки, тогда как другие, такие как XLS, XLSX, PPTX, DOC, DOCX и MobiXML, доступны только для сохранения. Эта таблица служит практическим руководством для пользователей, желающих понять совместимость формата Aspose.PDF для Python, подчеркивая как его сильные стороны, так и ограничения в поддержке форматов документов и изображений.
