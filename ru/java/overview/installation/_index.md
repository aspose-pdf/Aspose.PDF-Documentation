## Компонент Aspose.PDF for Java

{{% alert color="primary" %}}

**Aspose.PDF — это Java** компонент, позволяющий разработчикам программно создавать PDF‑документы, будь то простые или сложные, «на лету». Aspose.PDF for Java позволяет разработчикам вставлять таблицы, графики, изображения, гиперссылки, пользовательские шрифты — и многое другое — в PDF‑документы. Кроме того, также возможно сжимать PDF‑документы. Aspose.PDF for Java предоставляет отличные функции безопасности для создания защищённых PDF‑документов. И самая выдающаяся функция Aspose.PDF for Java заключается в том, что он поддерживает создание PDF‑документов как через API, так и из XML‑шаблонов

{{% /alert %}}

**Aspose.PDF for Java** реализован на Java и работает с JDK 1.8 и выше. Aspose.PDF for Java может быть интегрирован в любое приложение, например в веб‑приложение JSP/JSF или в Windows‑приложение.

**Aspose.PDF for Java** быстрый и легковесный. Он эффективно создает PDF‑документы и помогает вашему приложению работать лучше. Aspose.PDF for Java — первый выбор наших клиентов при создании PDF‑документов благодаря его цене, отличной производительности и отличной поддержке.
С помощью этой библиотеки вы можете реализовать расширенные возможности для создания PDF‑файлов с нуля или полностью обрабатывать существующие PDF‑документы без установки Adobe Acrobat.

{{% alert color="primary" %}}

Вы можете загрузить [Aspose.PDF for Java](https://releases.aspose.com/java/repo/com/aspose/aspose-pdf/) для оценки. Загрузка оценочной версии идентична загрузке покупной версии. Оценочная версия просто становится лицензированной, когда вы добавляете несколько строк кода к [применить лицензию](/pdf/ru/java/licensing/).

Оценочная версия Aspose.PDF предоставляет полный функционал продукта, но имеет два ограничения:

- Вставляет оценочный водяной знак.
- Не более четырёх элементов любой коллекции можно просматривать/редактировать.
- **Документ, показывающий оценочный водяной знак**

## Установите Aspose.PDF for Java из репозитория Aspose

Aspose размещает все Java API наВ. [Репозиторий Aspose](https://releases.aspose.com/java/repo/com/aspose/aspose-pdf/). Вы можетеВ легко использовать Aspose.PDF for Java API напрямую в ваших проектах Maven с простой конфигурацией.

### Укажите конфигурацию репозитория Aspose

Сначала вам нужно указать конфигурацию / расположение репозитория Aspose в вашем файле Maven pom.xml следующим образом:

```xml
 <repositories>
    <repository>
        <id>AsposeJavaAPI</id>
        <name>Aspose Java API</name>
        <url>https://releases.aspose.com/java/repo/</url>
    </repository>
</repositories>
```

### Определите зависимость API Aspose.PDF for Java

Затем определите зависимость API Aspose.PDF for Java В вашем pom.xml следующим образом:

```xml
 <dependencies>
    <dependency>
        <groupId>com.aspose</groupId>
        <artifactId>aspose-pdf</artifactId>
        <version>21.7</version>
    </dependency>
</dependencies>
```

После выполнения перечисленных выше шагов зависимость Aspose.PDF for Java будет окончательно определена в вашем Maven‑проекте.

### Руководство по совместимости и использованию JDK 11

API оптимизирована для среды Java 11, и все тесты и функции работают корректно. Однако для некоторых классов необходимо добавить внешнюю зависимость, чтобы включить в classpath класс: javax.xml.bind.annotation.adapters.HexBinaryAdapter, который был удалён из JRE.

Например:

```xml
 <dependency>
    <groupId>javax.xml.bind</groupId>
    <artifactId>jaxb-api</artifactId>
    <version>2.3.0</version>
</dependency>
```
