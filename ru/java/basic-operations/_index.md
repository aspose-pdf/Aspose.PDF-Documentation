В разделе **Основные операции** описаны первые и простейшие задачи PDF, которые вы можете выполнить с помощью Aspose.PDF для Java:

- [Создать PDF-документ](/pdf/java/create-document/) — создать новый PDF-документ программно на Java.
- [Открыть PDF-документ](/pdf/java/open-pdf-document/) — открывать PDF-файлы по пути, из потока или с помощью пароля.
- [Сохранить PDF-документ](/pdf/java/save-pdf-document/) — сохранить документ в файл, в поток или в формате PDF.
- [Объединить PDF](/pdf/java/merge-pdf/) — объединить несколько файлов PDF в один выходной документ.
- [Разделить PDF](/pdf/java/split-pdf/) — разделить страницы PDF на отдельные одностраничные PDF-файлы.
- [Зашифровать и расшифровать PDF-файл](/pdf/java/protect-pdf-file/) — применять пароли, разрешения и расшифровку к PDF-файлам.
