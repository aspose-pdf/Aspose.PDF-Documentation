## Установите

### Как установить Aspose.PDF Java для IntelliJ IDEA (Maven)

Ниже показано, как установить плагин **Aspose.PDF Java для IntelliJ IDEA (Maven)**.

Плагин указан на [официальном сайте плагина] CE IntelliJ IDEA(https://plugins.jetbrains.com/plugin/7974-aspose-pdf-java-for-intellij-idea-maven/) — репозитории плагинов как **Aspose.PDF Java для IntelliJ IDEA Maven**, поэтому вам не нужно загружать его вручную и устанавливать с диска, но эта дополнительная опция все еще существует в IntelliJ IDEA.

**Плагин Aspose.PDF Java для IntelliJ IDEA (Maven)** можно легко установить (без загрузки вручную) из IntelliJ IDEA. Чтобы это сделать:

1. Выберите **Настройки** в меню **Файл**.
2. Нажмите **Плагины**, затем просмотрите репозитории IntelliJ IDEA.

![todo:image_alt_text](https://i.imgur.com/NDZtoKw.jpg)

### Мастер проекта Aspose.PDF Maven

**Проект Aspose.PDF Maven** — в IntelliJ IDEA, который позволит вам создать проект на основе Aspose.PDF Maven для использования [Aspose.PDF for Java API.](https://products.aspose.com/pdf/java/).

![todo:image_alt_text](https://i.imgur.com/hd2mYnW.jpg)

### Мастер примеров Aspose.PDF

Опция для создания [Примеры исходных кодов для использования Aspose.PDF для Java API](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples) в проекте также появится после установки в меню «Новый» (с помощью щелчка правой кнопкой мыши -> Создать **ИЛИ** Меню «Файл» -> Создать)

## Using

### Мастер проекта Aspose.PDF Maven

To create Aspose.PDF Maven project for using [Aspose.PDF for Java API](https://products.aspose.com/pdf/java/) within IntelliJ IDEA, you need to have internet connection.

Затем выполните следующие действия:

1. Выберите **Новый проект**.
2. Выберите **Проект Aspose.PDF Maven**.
3. Нажмите **Далее**.

![todo:image_alt_text](https://i.imgur.com/hd2mYnW.jpg)

4. Укажите **GroupId, ArtifactId** и версию.
для вашего проекта maven и нажмите «Далее».

![todo:image_alt_text](https://i.imgur.com/aNlx0Qe.jpg)

5. Вы можете установить флажок «Также загрузить исходный код примеров», чтобы загрузить примеры использования API (как показано на снимке выше).

6. Укажите **Название проекта** и **Местоположение**, как при создании любого приложения Java.

![todo:image_alt_text](https://i.imgur.com/8VEeFun.jpg)

7. Нажмите **Готово**.

Это позволит получить последнюю ссылку на зависимость [Aspose.PDF for Java API](https://products.aspose.com/pdf/java/) из репозитория Aspose Cloud Maven и настроить ее в pom.xml.
Если вы установили флажок «Также загружать исходный код примеров». Загрузка примеров также начнется из [Репозитория Aspose.PDF for Java API GitHub](https://goo.gl/cPAbJM)

![todo:image_alt_text](https://i.imgur.com/bG2mdam.jpg)

![todo:image_alt_text](https://i.imgur.com/aNYhLl5.jpg)

Поздравляем!  Вы успешно создали проект Aspose.PDF Maven для использования [Aspose.PDF for Java API](https://products.aspose.com/pdf/java/).

![todo:image_alt_text](https://i.imgur.com/UJlSbuM.jpg)

Созданный проект Aspose.PDF для Java API Maven готов к изменению в соответствии с требованиями вашего проекта.

Если вы решили загрузить [Примеры исходного кода](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples).

### Мастер примеров Aspose.PDF

Чтобы импортировать/скопировать [Исходные коды примеров](https://goo.gl/cPAbJM) в проект с помощью **Мастера примеров Aspose.PDF**, вам необходимо сначала загрузить примеры, выбрав «Также загрузить исходный код примеров» в Мастере проектов Aspose.PDF Maven.

Затем выполните следующие действия в IntelliJ IDEA:

1. Выберите **Файл** > **Создать-** Как показано ниже:

![todo:image_alt_text](https://i.imgur.com/N8tT9Q0.jpg)

-ИЛИ- **Щелкните правой кнопкой мыши** (в окне проекта) => **Новый**В  – Как показано ниже:

![todo:image_alt_text](https://i.imgur.com/aUBWkhp.jpg)

2. Выберите опцию **Aspose.PDF example** в меню — как показано ниже:

![todo:image_alt_text](https://i.imgur.com/hvH2V0m.jpg)

Мастер обновит/проверит наличие последней доступной версии [Aspose.PDF для примеров API Java](https://goo.gl/cPAbJM)

![todo:image_alt_text](https://i.imgur.com/5PZwsuq.jpg)

3. Появится диалоговое окно **Мастер примеров Aspose.PDF**, в котором вы можете выбрать любую категорию примеров для создания/копирования примеров в свой проект.
Выберите любую категорию примеров и нажмите **Создать**:

![todo:image_alt_text](https://i.imgur.com/l2oGUBW.jpg)

При этом будут созданы/скопированы примеры выбранных категорий в проект в пакете **com.aspose.pdf.examples**.
Также все необходимые ресурсы для выполнения примеров будут скопированы в папку **src/main/resources** — как показано ниже:

![todo:image_alt_text](https://i.imgur.com/8GQL3Yb.jpg)

Поздравляем! Вы успешно сделали следующее:

1. Вы создали проект Aspose.PDF Maven с помощью мастера проектов Aspose.PDF Maven.

2. Вы загрузили [Aspose.PDF для Java API — примеры исходных кодов](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples)
3. Вы создали/скопировали исходные коды примеров в свой проект с помощью мастера примеров Aspose.PDF.
