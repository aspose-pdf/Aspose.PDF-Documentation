## Установка

### Как установить Aspose.PDF Java для IntelliJ IDEA (Maven)

Ниже приведены шаги, показывающие, как установить плагин **Aspose.PDF Java for IntelliJ IDEA (Maven)**.

Плагин The\u0412\u00A0 перечислен в IntelliJ IDEA\u0027s CE [официальный веб‑сайт плагина](https://plugins.jetbrains.com/plugin/7974-aspose-pdf-java-for-intellij-idea-maven/) - репозиторий плагина как **Aspose.PDF Java for IntelliJ IDEA Maven**, так что вам не нужно загружать его вручную и устанавливать с диска, но эта дополнительная опция всё ещё доступна в IntelliJ IDEA.

**Aspose.PDF Java for IntelliJ IDEA (Maven)** плагин можно легко установить (без ручной загрузки) изнутри IntelliJ IDEA. Чтобы сделать это:

1. Выберите **Settings** в меню **File**.
2. Нажмите **Plugins**, затем просмотрите репозитории в IntelliJ IDEA.

![todo:image_alt_text](https://i.imgur.com/NDZtoKw.jpg)

### Мастер проекта Aspose.PDF Maven

**Aspose.PDF Maven Project** – в IntelliJ IDEA, что позволит вам создать проект на основе Aspose.PDF Maven для использования [API Aspose.PDF for Java.](https://products.aspose.com/pdf/java/).

![todo:image_alt_text](https://i.imgur.com/hd2mYnW.jpg)

## Использование

### Мастер проекта Aspose.PDF Maven

Чтобы создать Maven‑проект Aspose.PDF для использования [API Aspose.PDF for Java](https://products.aspose.com/pdf/java/) в IntelliJ IDEA требуется подключение к интернету.

Затем выполните следующие шаги:

1. Выберите **New Project**.
2. Выберите **Aspose.PDF Maven Project**.
3. Нажмите **Next**.

![todo:image_alt_text](https://i.imgur.com/hd2mYnW.jpg)

4. Укажите **GroupId, ArtifactId** иВ Version
для вашего maven‑проекта и нажмите Next.

![todo:image_alt_text](https://i.imgur.com/aNlx0Qe.jpg)

5. Вы можете выбрать флажок "Also Download Examples Source Code", чтобы загрузить примеры использования API (как показано на приведённом выше снимке).

6. Укажите **Project Name** и **Location**, как при создании любого Java‑приложения.

![todo:image_alt_text](https://i.imgur.com/8VEeFun.jpg)

7. Нажмите **Finish**.

Это получит [API Aspose.PDF for Java](https://products.aspose.com/pdf/java/) последнюю ссылку на зависимость Maven из репозитория Aspose Cloud Maven Repository и настроит её в pom.xml
Если вы выбрали флажок "Also Download Examples Source Code". Загрузка примеров также начнётся с [GitHub репозиторий API Aspose.PDF for Java](https://goo.gl/cPAbJM)

![todo:image_alt_text](https://i.imgur.com/bG2mdam.jpg)

![todo:image_alt_text](https://i.imgur.com/aNYhLl5.jpg)

Поздравляем !  Вы успешно создали Maven‑проект Aspose.PDF для использования [API Aspose.PDF for Java](https://products.aspose.com/pdf/java/).

![todo:image_alt_text](https://i.imgur.com/UJlSbuM.jpg)

Созданный Maven‑проект API Aspose.PDF for Java готов к изменению в соответствии с требованиями вашего проекта

Если вы решили загрузить [Примеры исходного кода](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples).

### Мастер примеров Aspose.PDF

Для импорта/ копирования [Примеры исходного кода](https://goo.gl/cPAbJM)в проект с использованием **Aspose.PDF Examples Wizard**, вам необходимо сначала скачать примеры, выбравВ  "Also Download Examples Source Code" в мастере проекта Aspose.PDF Maven.

Затем выполните указанные ниже шаги в IntelliJ IDEA:

1. Выберите **File** > **New -** Как показано ниже:

![todo:image_alt_text](https://i.imgur.com/N8tT9Q0.jpg)

-ИЛИ- **Right Click** (в окне проекта) => **New**В  - Как показано ниже:

![todo:image_alt_text](https://i.imgur.com/aUBWkhp.jpg)

2. Выберите опцию **Aspose.PDF Example** из меню - Как показано ниже:

![todo:image_alt_text](https://i.imgur.com/hvH2V0m.jpg)

Мастер обновит / проверит наличие последней доступной\u0412 [Aspose.PDF for Java API Примеры](https://goo.gl/cPAbJM)

![todo:image_alt_text](https://i.imgur.com/5PZwsuq.jpg)

3. Отобразится диалог **Aspose.PDF Examples wizard**, где вы можете выбрать любую категорию примеров для создания / копирования примеров в ваш проект
Выберите любую категорию примеров и нажмите **Create**:

![todo:image_alt_text](https://i.imgur.com/l2oGUBW.jpg)

Это создаст / скопирует\u0412\u00A0 выбранные примеры категории в проект в пакет **com.aspose.pdf.examples**
Также все необходимые ресурсы для выполнения примеров будут скопированы в папку **src/main/resources** - как показано ниже:

![todo:image_alt_text](https://i.imgur.com/8GQL3Yb.jpg)

Поздравляем\u0412\u00A0! Вы успешно сделали следующее:

1. Вы\u0027 создали проект Aspose.PDF Maven с помощью мастера Aspose.PDF Maven Project Wizard,

2. Вы загрузили [Aspose.PDF for Java API - Примеры исходных кодов](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples)
3. Вы создали / скопировали Примеры исходных кодов в ваш проект, используя Aspose.PDF Example Wizard.
