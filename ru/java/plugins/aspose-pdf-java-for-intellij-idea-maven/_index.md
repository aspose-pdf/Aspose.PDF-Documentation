## Введение

### IntelliJ ИДЕЯ

IntelliJ IDEA — это интегрированная среда разработки Java (IDE) для разработчиков программного обеспечения. Он разработан JetBrains. Первоначально созданный для Java, в настоящее время он поддерживает широкий спектр языков, включая JavaScript, Groovy, HTML, CSS, RSS, R, Haskell, PHP, Ruby, Python, Scala, Clojure и Kotlin.

В отчете Infoworld за 2010 год IntelliJ получил высшую оценку центра тестирования из четырех лучших инструментов программирования Java: Eclipse, IntelliJ IDEA, NetBeans и Oracle JDeveloper.

### Aspose.PDF для Java

Aspose.PDF for Java — это компонент для создания PDF-документов, который позволяет вашим Java-приложениям читать, записывать и манипулировать PDF-документами без использования Adobe Acrobat.

### Aspose.PDF Java для IntelliJ IDEA — Maven

- Aspose.PDF Java для IntelliJ IDEA (Maven) — это подключаемый модуль IntelliJ IDEA, который позволяет создавать проекты maven (т. е. созданный проект содержит зависимость Aspose.PDF для Java API от maven) и загружать примеры исходного кода API  для использования Aspose.PDF для Java API.
- Этот плагин поможет вам работать с Aspose.PDF for Java API внутри вашей любимой IntelliJ IDEA.

ВОЛШЕБНИКИ:
Плагин содержит два мастера

Мастер 1: Проект Aspose.PDF Maven

- Мастер проектов Aspose Maven плагина позволяет разработчикам создавать Aspose.PDF для проекта Java API Maven.
- Ссылка на Aspose.PDF для зависимости Java API maven автоматически извлекается из [репозитория Aspose Cloud Maven](https://repository.aspose.com/webapp/#/artifacts/browse/tree/General/repo) и добавляется в pom.xml.
- Созданный проект всегда будет содержать самую последнюю доступную версию Maven Dependency for Aspose.PDF для Java API.
- В шагах мастера также предусмотрена возможность загрузки [Примеры исходного кода для использования Aspose.PDF для Java API](https://github.com/aspose-pdf/Aspose.PDF-for-Java)

Мастер 2: Примеры Aspose.PDF

- Мастер примеров Aspose.PDF позволяет создавать/копировать загруженные примеры исходного кода Aspose.PDF для API Java в ваш проект. Все примеры для выбранной категории будут скопированы в папку пакета проекта «com.aspose.pdf.examples» вместе с необходимыми ресурсами в папке «src/main/resources», необходимыми для запуска примеров.
- Примеры исходного кода Aspose.PDF для Java API предназначены для демонстрации различных вариантов использования API.

## Системные требования и поддерживаемые платформы

### Системные требования

- Microsoft Windows 8/7/Vista/2003/XP (вкл. 64-разрядную версию) / Linux GNOME или рабочий стол KDE / Mac OS X 10.5 или выше
- 1 GB RAM minimum, 2 GB RAM recommended
- 300 MB hard disk space + at least 1 G for caches
- 1024x768 minimum screen resolution
- Рекомендуется JDK 1.8 или выше
- Подключение к Интернету (рекомендуется 2 МБ или выше)

### Поддерживаемые платформы

Плагин поддерживает следующие версии IntelliJ IDEA:

- 13.0.1 (Сообщество / Ultimate Edition)
- 13.1.2В  (CE/UE)
- 14.0.2 (CE/UE)
- 14.1.5 (CE/UE)

## Загрузите

### Загрузка IntelliJ IDEA

Вам необходимо сначала установить IntelliJ IDEA CE/UE, прежде чем загружать плагин Aspose.PDF Java для IntelliJ IDEA (Maven).

Чтобы скачать IntelliJ IDEA

1. Перейти к <https://www.jetbrains.com/idea/download/>
1. Выберите свою работающую ОС
1. Нажмите на загрузку UE или CE.

### Загрузка Aspose.PDF Java для плагина IntelliJ IDEA (Maven)

- Плагин можно загрузить напрямую с [URL-адреса хостинга плагинов JetBrains](https://goo.gl/z06gC0) — в репозитории плагинов IntelliJ IDEA.
  и более поздние версии могут быть установлены с использованием опции IDE:
  - Перейдите в Файл > Настройки... > Плагины.
  - Выберите «Установить плагин с диска».
- Или его можно установить напрямую (без ручной загрузки с URL-адреса хостинга плагинов JetBrains), используя параметры IDE:
  - Перейдите в Файл > Настройки... > Плагины.
  - Выберите «Обзор репозиториев».
  - В поле поиска введите: «Aspose».
  - Выберите плагин «Aspose.PDF Java для IntelliJ IDEA Maven» для установки.
