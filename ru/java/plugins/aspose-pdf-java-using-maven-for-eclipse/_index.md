## Введение

### Eclipse IDE

Eclipse IDE — известная интегрированная среда разработки Java (IDE). Эта IDE определённо является самым известным продуктом проекта Eclipse Open Source. Сегодня она является ведущей средой разработки Java с долей рынка примерно 60%.

Eclipse IDE можно расширить дополнительными программными компонентами. Eclipse называет эти программные компоненты Plug‑ins. Несколько проектов с открытым исходным кодом и компаний расширили Eclipse IDE или создали автономные приложения (Eclipse RCP) поверх фреймворка Eclipse.

### Aspose.PDF for Java

[Aspose.PDF for Java](https://products.aspose.com/pdf/java/)является надёжным API для создания PDF‑документов, который позволяет вашим Java‑приложениям читать, записывать и изменять PDF‑документы без использования Adobe Acrobat.

Aspose.PDF for Java предлагает невероятно обширный набор возможностей, включая параметры сжатия PDF, создание и работу с таблицами, поддержку графиков, функции работы с изображениями, расширенную возможность гиперссылок, расширенный контроль безопасности и работу с пользовательскими шрифтами.

### Aspose.PDF Java (Maven) for Eclipse

- Aspose.PDF Java (Maven) for Eclipse — это плагин для **Eclipse IDE** от **Aspose**. Этот плагин предназначен для разработчиков, использующих платформу Maven для разработки Java и желающих использовать Aspose.PDF for Java в своих проектах. Плагин позволяет создавать Maven‑проекты для использования API Aspose.PDF for Java и также загружать [Примеры кода](https://github.com/aspose-pdf/Aspose.Pdf-for-Java) API.
- Плагин предоставляет следующие возможности для работы с Aspose.PDF for Java API в **Eclipse IDE** удобно:

**МАСТЕРА**:
Плагин содержит два мастера

**Aspose.PDF Maven Project (мастер)**

- Мастер New Project позволяет разработчикам создать **Maven** проект для использования Aspose.PDF for Java через New -> Project -> Maven -> Aspose.PDF Maven Project.
- Ссылка на Maven‑зависимость Aspose.PDF for Java API автоматически получается из [Aspose Cloud Maven Repository](https://repository.aspose.com/webapp/#/artifacts/browse/tree/General/repo) и добавляется в файл pom.xml.
- Созданный проект всегда будет содержать самую последнюю доступную версию **Maven**‑зависимости для Aspose.PDF for Java API.
- Шаги мастера также предоставляют возможность загрузки [Примеры кода](https://github.com/aspose-pdf/Aspose.Pdf-for-Java) для использования API Aspose.PDF for Java.
Пример кода Aspose.PDF (мастер)

- Этот мастер New File позволяет скопировать загруженный [Примеры кода](https://github.com/aspose-pdf/Aspose.Pdf-for-Java) в ваш проект для использования Aspose.PDF for Java из New -> Other -> Java -> Aspose.PDF Code Example.
- Доступные примеры отображаются в виде дерева, откуда пользователь может выбрать их по категориям.
- Все примеры в выбранной категории будут скопированы в папку пакета проекта "**com.aspose.pdf.examples**" вместе с необходимыми ресурсами в папке "**src/main/resources**", требуемыми для запуска примеров.
- Примеры кода API Aspose.PDF for Java предназначены для демонстрации различных функций API.
- Мастер также будет искать и обновлять новые доступные примеры кода) из репозитория примеров Aspose.PDF for Java.

## Системные требования и поддерживаемые платформы

### Системные требования

- **System Memory:** 2 ГБ или более (Рекомендуется)
- **OS:** Любая операционная система, поддерживающая Java VM (виртуальную машину)
- **Интернет-соединение:** 2 МБ или быстрее (Рекомендуется)

### Поддерживаемые платформы

- Eclipse Mars.1 (4.5.1) - Рекомендуется
- Eclipse Juno или новее.

## Загрузите

### Скачайте Eclipse IDE

Сначала вам нужно установить Eclipse IDE, прежде чем загружать плагин Aspose.PDF Java (Maven) for Eclipse.

Чтобы загрузить Eclipse IDE

1. Перейти к [https://eclipse.org](https://eclipse.org/).
1. Скачайте и установите рекомендованную Eclipse IDE для разработчиков Java SE / EE.

### Скачайте Aspose.PDF Java (Maven) for Eclipse

Ниже приведены три рекомендуемых метода успешного скачивания и установки плагина Aspose.PDF Java (Maven) для Eclipse:

- Установите перетаскиванием из [Eclipse Marketplace](https://marketplace.eclipse.org/content/asposepdf-java-maven-eclipse) в ваш рабочий каталог Eclipse.
- Или перейдите к **Help** > **Install New Software...** > Введите следующий URL сайта обновлений в **Work with**
Затем выберите "Aspose.PDF Java (Maven) for Eclipse" и **Finish**. Примите лицензионное соглашение и установите плагин.

### Как применить лицензию Aspose?

Этот плагин использует оценочную версию Aspose.PDF. Как только вы будете довольны оценкой, вы можете приобрести лицензию по адресу [Веб‑сайт Aspose](https://purchase.aspose.com/buy).
Чтобы удалить сообщение об оценочной версии и ограничения функций, необходимо применить лицензию продукта. Вы получите файл лицензии после покупки продукта. Пожалуйста, выполните следующие шаги, чтобы применить лицензию.

- Убедитесь, что файл лицензии называется Aspose.PDF.Java.lic
- Поместите файл **Aspose.PDF.Java.lic** в папку, содержащую Aspose.PDF.jar
- Используйте следующий код для активации лицензии:

{{< highlight java >}}

 License license = new License();

license.setLicense("Aspose.PDF.Java.lic");
