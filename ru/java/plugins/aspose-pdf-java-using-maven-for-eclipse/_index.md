## Введение

### Затмение IDE

Eclipse IDE — это известная интегрированная среда разработки Java (IDE). IDE, безусловно, является самым известным продуктом проекта Eclipse с открытым исходным кодом. Сегодня это ведущая среда разработки для Java с долей рынка около 60%.

Eclipse IDE можно расширить с помощью дополнительных программных компонентов. В Eclipse эти программные компоненты называются плагинами. Несколько проектов и компаний с открытым исходным кодом расширили Eclipse IDE или создали автономные приложения (Eclipse RCP) поверх платформы Eclipse.

### Aspose.PDF для Java

[Aspose.PDF for Java](https://products.aspose.com/pdf/java/) — это надежный API для создания PDF-документов, который позволяет вашим Java-приложениям читать, записывать и манипулировать PDF-документами без использования Adobe Acrobat.

Aspose.PDF для Java предлагает невероятное множество функций, в том числе параметры сжатия PDF, создание таблиц и манипулирование ими, поддержку графиков, функции изображений, обширную функциональность гиперссылок, расширенные элементы управления безопасностью и обработку настраиваемых шрифтов.

### Aspose.PDF Java (Maven) для Eclipse

- Aspose.PDF Java (Maven) для Eclipse — это плагин для **Eclipse IDE** от **Aspose.** Этот плагин предназначен для разработчиков, использующих платформу Maven для разработки Java и желающих использовать Aspose.PDF для Java в своих проектах. Плагин позволяет создавать проекты maven для использования Aspose.PDF для Java API, а также загружать [Примеры кода](https://github.com/aspose-pdf/Aspose.Pdf-for-Java) API.

**Проект Aspose.PDF Maven (мастер)**

- Этот мастер создания новых проектов позволяет разработчикам создавать проект **Maven** для использования Aspose.PDF для Java из раздела «Создать» -> «Проект» -> Maven-> «Aspose.PDF Maven Project».
- Ссылка на Aspose.PDF для зависимости Java API maven автоматически извлекается из [репозитория Aspose Cloud Maven](https://repository.aspose.com/webapp/#/artifacts/browse/tree/General/repo) и добавляется в pom.xml.
- Созданный проект всегда будет содержать самую последнюю доступную версию **Maven** Dependency for Aspose.PDF для Java API.
- В шагах мастера также предусмотрена возможность загрузки [Примеры кода](https://github.com/aspose-pdf/Aspose.Pdf-for-Java) для использования Aspose.PDF для Java API.
Пример кода Aspose.PDF (мастер)

- Этот мастер создания нового файла позволяет скопировать загруженные [Примеры кода](https://github.com/aspose-pdf/Aspose.Pdf-for-Java) в ваш проект для использования Aspose.PDF для Java из меню Создать -> Другое -> Java -> Пример кода Aspose.PDF.
- Доступные образцы отображаются в виде дерева, из которого пользователь может выбирать их по категориям.
- Все примеры в выбранной категории будут скопированы в папку пакета проекта «**com.aspose.pdf.examples**» вместе с необходимыми ресурсами в папке «**src/main/resources**», необходимыми для запуска примеров.
- Примеры кода Aspose.PDF для Java API предназначены для демонстрации различных функций API.
- Мастер также будет искать и обновлять новые доступные примеры кода из репозитория примеров Aspose.PDF для Java.

## Системные требования и поддерживаемые платформы

### Системные требования

- **Системная память:** 2 ГБ или более (рекомендуется)
- **ОС:** Любая операционная система, поддерживающая Java VM (виртуальную машину).
- **Подключение к Интернету:** 2 МБ или выше (рекомендуется)

### Поддерживаемые платформы

- Затмение Марс.1 (4.5.1) - Рекомендуется
- Eclipse Juno или новее.

### Как применить лицензию Aspose?

Этот плагин использует ознакомительную версию Aspose.PDF. Если вы удовлетворены своей оценкой, вы можете приобрести лицензию на [веб-сайте Aspose](https://purchase.aspose.com/buy).
Чтобы удалить оценочное сообщение и ограничения функций, необходимо применить лицензию на продукт. Вы получите файл лицензии после покупки продукта. Пожалуйста, следуйте инструкциям ниже, чтобы применить лицензию

- Убедитесь, что файл лицензии называется Aspose.PDF.Java.lic.
- Поместите файл **Aspose.PDF.Java.lic** в папку, содержащую Aspose.PDF.jar.
- Используйте следующий код для активации лицензии:

### Как настроить исходный код Aspose.PDF Java (Maven) для Eclipse

Следующие простые шаги плавно приведут к успешной настройке исходного кода плагина **"Aspose.PDF Java (Maven) for Eclipse"** в Eclipse IDE.

1. Загрузите/клонируйте исходный код.
1. Выберите **Файл** > Импорт > Общие > Существующие проекты в рабочую область.
1. Перейдите к последнему загруженному исходному коду проекта.
1. Выберите проект Eclipse, который вы хотите импортировать.
1. Нажмите «Готово».
1. Код плагина Aspose.PDF Java для Eclipse теперь готов к улучшению.
