## Введение

### Rjb — Ruby Java Bridge

RJB — это программа-мостик, соединяющая Ruby и Java с помощью собственного интерфейса Java. Rake + Rjb — более мощный и полезный инструмент сборки, чем Maven и Ant. Вы можете протестировать свой класс бизнес-логики Java с помощью макета Rjb. Это помогает перенести объект модели Struts в ваше приложение RoR. Но будьте осторожны с приложением buildSwing: Ruby (и Rjb) не учитывает обработку собственных потоков JVM.

### Aspose.PDF для Java

Aspose.PDF for Java — это компонент для создания PDF-документов, который позволяет вашим Java-приложениям читать, записывать и манипулировать PDF-документами без использования Adobe Acrobat.

Aspose.PDF для Java — это доступный по цене компонент, который предлагает невероятное множество функций, в том числе: параметры сжатия PDF, создание таблиц и манипулирование ими, поддержку графиков, функции изображений, обширные функции гиперссылок, расширенные средства управления безопасностью и обработку настраиваемых шрифтов.

Aspose.PDF для Java позволяет создавать PDF-файлы напрямую с помощью предоставленных API и шаблонов XML. Использование Aspose.PDF для Java также позволит вам мгновенно добавить возможности PDF в ваши приложения.

### Aspose.PDF Java для Ruby

Проект Aspose.PDF Java для Ruby показывает, как различные задачи можно выполнять с помощью Java API Aspose.PDF в Ruby. Целью этого проекта является предоставление полезных примеров разработчикам Ruby, которые хотят использовать Aspose.PDF для Java в своих проектах Ruby с использованием Rjb (Ruby Java Bridge).

## Установка и использование

### Установите

Установить Aspose.PDF Java для Ruby gem очень просто и легко. Для этого выполните следующие простые шаги:

1. Выполните следующую команду.

{{< highlight java >}}

 $ gem install aspose-pdfjava

{{< /highlight >}}

1. Загрузите необходимый Aspose.PDF для компонента Java по следующей ссылке.
   <https://downloads.aspose.com/pdf/java>
1. Создайте папку «jars» в корне драгоценного камня Aspose.PDF Java для Ruby и скопируйте в нее загруженный компонент.

### С использованием

Включите необходимые файлы для работы с примером helloworld.

{{< highlight java >}}

 требуется File.dirname(File.dirname(File.dirname(__FILE__))) + '/lib/aspose-pdfjava'

включить Asposepdfjava

включить Asposepdfjava::HelloWorld

инициализировать_aspose_pdf

{{< /highlight >}}

Давайте разберемся в приведенном выше коде.

1. Первая строка гарантирует, что aspose pdf загружен и доступен.
1. Включите файлы, необходимые для доступа к aspose pdf.
1. Инициализируйте библиотеки. Классы aspose JAVA загружаются по пути, указанному в файле aspose.yml/
