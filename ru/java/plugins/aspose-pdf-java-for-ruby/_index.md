## Введение

### Rbj - Ruby Java Bridge

RJB — это мостовая программа, соединяющая Ruby и Java с помощью Java Native Interface. Rake + Rjb — более мощный и полезный инструмент сборки, чем Maven и Ant. Вы можете тестировать ваш класс бизнес‑логики Java с помощью mock‑объекта Rjb. Это помогает перенести Model Object из Struts в ваше приложение RoR. Но будьте осторожны с приложениями buildSwing, Ruby (и Rjb) не учитывают обработку нативных потоков JVM.

### Aspose.PDF for Java

Aspose.PDF for Java — это компонент для создания PDF‑документов, который позволяет вашим Java‑приложениям читать, записывать и манипулировать PDF‑документами без использования Adobe Acrobat.

Aspose.PDF for Java является экономически доступным компонентом, который предлагает невероятно богатый набор функций, включая: варианты сжатия PDF, создание и манипулирование таблицами, поддержку графиков, функции работы с изображениями, обширную функциональность гиперссылок, расширенные средства контроля безопасности и обработку пользовательских Font.

Aspose.PDF for Java позволяет создавать PDF-файлы напрямую через предоставленный API и XML‑шаблоны. Использование Aspose.PDF for Java также позволит вам быстро добавить возможности работы с PDF в ваши приложения.

### Aspose.PDF Java для Ruby

Проект Aspose.PDF Java for Ruby демонстрирует, как можно выполнять различные задачи с использованием Aspose.PDF Java API в Ruby. Этот проект направлен на предоставление полезных примеров для разработчиков Ruby, желающих использовать Aspose.PDF for Java в своих Ruby‑проектах с помощью Rjb (Ruby Java Bridge).

## Установка и использование

### Установка

Установить Aspose.PDF Java for Ruby gem очень просто и легко, пожалуйста, следуйте этим простым шагам:

1. Выполните следующую команду.

{{< highlight java >}}

 $ gem install aspose-pdfjava

{{< /highlight >}}

1. Скачайте требуемый компонент Aspose.PDF for Java по следующей ссылке.
   <https://downloads.aspose.com/pdf/java>
1. Создайте папку "jars" в корне гем‑пакета Aspose.PDF Java for Ruby и скопируйте загруженный компонент туда.

### Использование

Включите необходимые файлы для работы с примером helloworld.

{{< highlight java >}}

 require File.dirname(File.dirname(File.dirname(__FILE__))) + '/lib/aspose-pdfjava'

include Asposepdfjava

include Asposepdfjava::HelloWorld

initialize_aspose_pdf

{{< /highlight >}}

Давайте разберём вышеуказанный код.

1. Первая строка гарантирует, что Aspose.PDF загружен и доступен.
1. Включите файлы, необходимые для доступа к Aspose.PDF.
1. Инициализируйте библиотеки. Классы Aspose JAVA загружаются из пути, указанного в файле aspose.yml/
