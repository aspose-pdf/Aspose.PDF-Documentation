## Введение

### NetBeans IDE

NetBeans — полнофункциональная IDE для Java, написанная полностью на Java. Она в первую очередь предназначена для разработки на Java, но также поддерживает другие языки, в частности PHP, C/C++ и HTML5.

NetBeans IDE позволяет быстро и легко разрабатывать настольные, мобильные и веб‑приложения на Java, а также приложения HTML5 с использованием HTML, JavaScript и CSS. Это бесплатный и открытый продукт с большой сообществом пользователей и разработчиков по всему миру.

Команда NetBeans активно поддерживает продукт и принимает предложения по новым функциям от широкой аудитории. Каждый выпуск предваряется периодом тестирования и обратной связи от сообщества.

### Aspose.PDF for Java

[Aspose.PDF for Java](https://products.aspose.com/pdf/java/) — мощный API для создания PDF‑документов, позволяющий вашим Java‑приложениям читать, записывать и изменять PDF‑файлы без использования Adobe Acrobat.

Aspose.PDF for Java предлагает огромный набор возможностей, включая варианты сжатия PDF, создание и работу с таблицами, поддержку графиков, функции работы с изображениями, расширенные возможности гиперссылок, расширенные средства безопасности и работу с пользовательскими шрифтами.

### Aspose.PDF Java для NetBeans (Maven)

- Aspose.PDF Java для NetBeans (Maven) — плагин для **NetBeans IDE** от **Aspose**. Плагин предназначен для разработчиков, использующих платформу Maven для Java‑разработки и желающих применять Aspose.PDF for Java в своих проектах. Плагин позволяет создавать Maven‑проекты для использования API Aspose.PDF for Java и также загружать [примеры кода](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples) API.

## МАСТЕРА (WIZARDS)

В плагине содержатся два мастера.

### Aspose.PDF Maven Project (мастер)

- Этот мастер **Новый проект** позволяет разработчикам создать **Maven**‑проект для использования Aspose.PDF for Java через **Новый проект → Maven → Aspose.PDF Maven Project**.
- Ссылка на зависимость Maven API Aspose.PDF for Java автоматически извлекается из [Aspose Maven Repository](https://repository.aspose.com/webapp/#/artifacts/browse/tree/General/repo/com/aspose/aspose-pdf) и добавляется в `pom.xml`.
- Созданный проект всегда будет содержать самую последнюю доступную версию **Maven**‑зависимости для API Aspose.PDF for Java.
- На шагах мастера также предлагается опция загрузки примеров кода для использования Aspose.PDF for Java API.

### Aspose.PDF Code Example (мастер)

- Этот мастер **Новый файл** позволяет скопировать загруженные [примеры кода](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples) в ваш проект для использования Aspose.PDF for Java через **Новый файл → Java → Aspose.PDF Code Example**.
- Доступные образцы отображаются в виде дерева, откуда пользователь может выбрать их по категориям.
- Все примеры из выбранной категории копируются в пакет проекта **com.aspose.pdf.examples** вместе с необходимыми ресурсами в папке **src/main/resources**, требуемыми для их выполнения.
- Примеры кода API Aspose.PDF for Java предназначены для демонстрации разнообразия возможностей API.
- Мастер также проверяет наличие и обновления новых примеров из [репозитория примеров Aspose.PDF for Java](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples).

## Загрузите

### Загрузите NetBeans

Перед загрузкой плагина **Aspose.PDF Java для NetBeans (Maven)** убедитесь, что NetBeans IDE уже установлен.

Плагин **Aspose.PDF Java для NetBeans (Maven)** поддерживает **NetBeans IDE 8.0 и 8.1**. Мы рекомендуем использовать последнюю версию NetBeans IDE.

Чтобы загрузить NetBeans IDE:

1. Перейдите по ссылке: <https://netbeans.apache.org/download/index.html>
2. Нажмите **Download**, чтобы скачать подходящий набор NetBeans.

Скачайте только набор, поддерживающий Java EE/SE, текущей последней версии, т.е. **NetBeans IDE 8.1**.

### Загрузите Aspose.PDF Java для NetBeans (Maven)

- Плагин можно загрузить напрямую по URL хостинга плагинов NetBeans: <http://plugins.netbeans.org/plugin/63218>, а затем установить через IDE:
  - **Tools > Plugins > Downloaded**  
  - Нажмите **Add Plugins...** и укажите загруженный файл с расширением `.nbm` для **Aspose.PDF Java for NetBeans (Maven)**.
  - Нажмите **"Install"**, чтобы установить плагин.
- Либо плагин можно установить непосредственно из IDE (без ручной загрузки) следующим образом:
  - **Tools > Plugins > Available Plugins**  
  - В поле поиска введите: «Aspose»  
  - Выберите плагин **Aspose.PDF Java NetBeans (Maven)**  
  - Нажмите **"Install"**.

### Как применить лицензию Aspose?

Этот плагин использует оценочную версию Aspose.PDF. После того как вы убедитесь в её пригодности, можете приобрести лицензию на [веб‑сайте Aspose](https://purchase.aspose.com/buy).  
Чтобы убрать сообщение об оценке и ограничения функций, необходимо применить лицензионный файл продукта. Вы получите файл лицензии после покупки. Выполните следующие шаги, чтобы применить лицензию.

- Убедитесь, что файл лицензии называется **Aspose.PDF.Java.lic**.
- Поместите файл **Aspose.PDF.Java.lic** в папку, где находится `Aspose.PDF.jar`.
- Используйте следующий код для активации лицензии:

```java
License license = new License();
license.setLicense("Aspose.PDF.Java.lic");
```
