## Введение

### NetBeans IDE

NetBeans — это полнофункциональная среда разработки Java, полностью написанная на Java. Он в первую очередь предназначен для разработки на Java, но поддерживает и другие языки, в частности PHP, C/C++ и HTML5.

IDE NetBeans позволяет быстро и легко разрабатывать настольные, мобильные и веб-приложения Java, а также приложения HTML5 с использованием HTML, JavaScript и CSS. Это бесплатный продукт с открытым исходным кодом, имеющий большое сообщество пользователей и разработчиков по всему миру.

Команда NetBeans активно поддерживает продукт и ищет предложения по функциям от более широкого сообщества. Каждому выпуску предшествует тестирование сообщества и получение отзывов.

### Aspose.PDF для Java

[Aspose.PDF for Java](https://products.aspose.com/pdf/java/) — это надежный API для создания PDF-документов, который позволяет вашим Java-приложениям читать, записывать и манипулировать PDF-документами без использования Adobe Acrobat.

Aspose.PDF для Java предлагает невероятное множество функций, в том числе параметры сжатия PDF, создание таблиц и манипулирование ими, поддержку графиков, функции изображений, обширную функциональность гиперссылок, расширенные элементы управления безопасностью и обработку настраиваемых шрифтов.

### Aspose.PDF Java для NetBeans (Maven)

- Aspose.PDF Java для NetBeans (Maven) — это плагин для **NetBeans IDE** от **Aspose.** Плагин предназначен для разработчиков, использующих платформу Maven для разработки Java и желающих использовать Aspose.PDF для Java в своих проектах. Плагин позволяет создавать проекты maven для использования Aspose.PDF для Java API, а также загружать [Примеры кода](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples) API.

## ВОЛШЕБНИКИ

Плагин содержит два мастера

### Проект Aspose.PDF Maven (мастер)

- Этот мастер создания новых проектов позволяет разработчикам создавать проект **Maven** для использования Aspose.PDF для Java из «Новый проект» -> Maven-> Aspose.PDF Maven Project.
- Ссылка на Aspose.PDF для зависимости Java API maven автоматически извлекается из [Репозитория Aspose Maven](https://repository.aspose.com/webapp/#/artifacts/browse/tree/General/repo/com/aspose/aspose-pdf) и добавляется в pom.xml.
- Созданный проект всегда будет содержать самую последнюю доступную версию **Maven** Dependency for Aspose.PDF для Java API.
- В шагах мастера также предусмотрена возможность загрузки примеров кода для использования Aspose.PDF для Java API.

### Пример кода Aspose.PDF (мастер)

- Этот мастер создания нового файла позволяет скопировать загруженные [Примеры кода](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples) в ваш проект для использования Aspose.PDF для Java из **Новый файл -> Java -> Пример кода Aspose.PDF.**
- Доступные образцы отображаются в виде дерева, из которого пользователь может выбирать их по категориям.
- Все примеры в выбранной категории будут скопированы в папку пакета **com.aspose.pdf.examples** проекта вместе с необходимыми ресурсами в папке **src/main/resources**, необходимыми для запуска примеров.
- Примеры кода Aspose.PDF для Java API предназначены для демонстрации разнообразия API.
- Мастер также будет искать и обновлять новые доступные файлы из [репозитория примеров Aspose.PDF для Java.](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples)

## Загрузите

### Скачать NetBeans

Прежде чем загружать подключаемый модуль **Aspose.PDF Java для NetBeans (Maven)**, у вас должна быть предварительно установлена ​​среда IDE NetBeans.

**Плагин Aspose.PDF Java для NetBeans (Maven)** поддерживает **NetBeans IDE8.0 и 8.1**. Мы рекомендуем использовать только последнюю версию IDE NetBeans.

To download NetBeans IDE,

1. Navigate to:<https://netbeans.apache.org/download/index.html>
1. Click Download to download NetBeans IDE appropriate bundle.

Download only Java EE / SE supported NetBeans download bundle of the current latest release i.e. **NetBeans IDE 8.1**.

### Загрузите Aspose.PDF Java для NetBeans (Maven)

- Плагин можно загрузить напрямую с URL-адреса хостинга плагина NetBeans: <http://plugins.netbeans.org/plugin/63218>.
  и более поздние версии могут быть установлены с использованием опции IDE:
  - Перейти к**Инструменты**>>**Плагины**>**Загружено
  - Нажмите **Добавить плагины...** и найдите загруженный файл плагина расширения .nbm для **Aspose.PDF Java для NetBeans (Maven)**.
  - Нажмите**"Установить"**, чтобы установить плагин.
- Или его можно установить напрямую (без ручной загрузки с URL-адреса хостинга плагинов NetBeans), используя параметры IDE:
  - Перейти к**Инструменты**>**Плагины**>**Доступные плагины**
  - В поле поиска введите: «Aspose».
  - Выберите плагин **Aspose.PDF Java NetBeans (Maven)**.
  - Нажмите**"Установить"**.

### Как применить лицензию Aspose?

Этот плагин использует ознакомительную версию Aspose.PDF. Если вы удовлетворены своей оценкой, вы можете приобрести лицензию на [веб-сайте Aspose](https://purchase.aspose.com/buy).
Чтобы удалить оценочное сообщение и ограничения функций, необходимо применить лицензию на продукт. Вы получите файл лицензии после покупки продукта. Пожалуйста, следуйте инструкциям ниже, чтобы применить лицензию.

- Убедитесь, что файл лицензии имеет имя **Aspose.PDF.Java.lic.
- Поместите файл **Aspose.PDF.Java.lic** в папку, содержащую Aspose.PDF.jar.
- Используйте следующий код для активации лицензии:

```java
License license = new License();
license.setLicense("Aspose.PDF.Java.lic");
```
