## Веб-фреймворк Apache Struts

Веб-фреймворк Apache Struts — это бесплатное решение с открытым исходным кодом для создания веб-приложений Java.

Веб-приложения отличаются от обычных веб-сайтов тем, что веб-приложения могут создавать динамический ответ. Многие веб-сайты предоставляют только статические страницы. Веб-приложение может взаимодействовать с базами данных и механизмами бизнес-логики для настройки ответа.

Одним из способов разделения задач в программном приложении является использование архитектуры Модель-Представление-Контроллер (MVC). Модель представляет собой бизнес-код или код базы данных, Представление представляет собой код дизайна страницы, а Контроллер представляет собой код навигации. Платформа Struts предназначена для того, чтобы помочь разработчикам создавать веб-приложения, использующие архитектуру MVC.

[Подробнее](http://struts.apache.org/birdseye.html)

### Aspose.PDF для Java

Aspose.PDF for Java — это компонент для создания PDF-документов, который позволяет вашим Java-приложениям читать, записывать и манипулировать PDF-документами без использования Adobe Acrobat.

Aspose.PDF для Java — это доступный по цене компонент, который предлагает невероятное множество функций, в том числе: параметры сжатия PDF, создание таблиц и манипулирование ими, поддержку графиков, функции изображений, обширные функции гиперссылок, расширенные средства управления безопасностью и обработку настраиваемых шрифтов.

Aspose.PDF для Java позволяет создавать PDF-файлы напрямую с помощью предоставленных API и шаблонов XML. Использование Aspose.PDF для Java также позволит вам мгновенно добавить возможности PDF в ваши приложения.

## Aspose.Words Java для Struts 1.3

Aspose.Words Java для Struts 1.3 — это простое веб-приложение для книжного магазина, написанное с использованием Struts 1.3 и Maven.

- Веб-приложение призвано продемонстрировать интеграцию и использование [Aspose.Words for Java](https://products.aspose.com/words/java/) в среде Struts 1.3 и Maven.
- Он работает в веб-контейнере, таком как Apache Tomcat, и требует maven для создания веб-приложения .war для развертывания.
- Текущий вариант использования в приложении экспортирует записи из сетки книг в формат документа MS-WORD, создавая документ MS-WORD, создавая в нем таблицу и записывая в нее тексты/данные.
