## Загрузка Aspose.PDF Java для Struts 1.3

Вы можете скачать/проверить исходные коды проекта из следующих мест:

- [Github](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Plugins/Aspose_Pdf_for_Struts)

## Сборка Aspose.PDF Java для Struts 1.3 из исходных кодов

После проверки исходных кодов из любого из вышеуказанных репозиториев примените следующие команды mvn:

{{< highlight java >}}

 $ mvn -U чистый пакет

{{< /highlight >}}

Это приведет к созданию Strutsbookapp.war в целевом счетчике.

Чтобы развернуть файл .war, просто скопируйте его в каталог веб-приложения работающего сервера Apache Tomcat.
