## Конвертация файла SVG в формат PDF на Python

Чтобы преобразовать файл SVG в формат PDF, используя **Aspose.PDF Java for Python**, просто вызовите модуль **SvgToPdf**.

Код Python:

```python
options = self.SvgLoadOptions();
```
