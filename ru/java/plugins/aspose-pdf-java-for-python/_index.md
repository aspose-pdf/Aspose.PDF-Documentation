## Введение в Aspose.PDF Java для Python

## JPype

JPype — это попытка предоставить программам Python полный доступ к библиотекам классов Java. Это достигается не за счет повторной реализации Python, как это было сделано в Jython/JPython, а за счет взаимодействия на собственном уровне в обеих виртуальных машинах.

Подробную информацию можно найти на сайте [readthedocs.org](http://jpype.readthedocs.org/en/latest/userguide.html)

## Aspose.PDF для Java

Aspose.PDF for Java — это расширенная библиотека классов для Java, которая позволяет вам выполнять широкий спектр задач по обработке документов непосредственно в ваших приложениях Java.

Aspose.PDF для Java поддерживает обработку текстов (DOC, DOCX, OOXML, RTF), HTML, OpenDocument, PDF, EPUB, XPS, SWF и всех форматов изображений. С помощью Aspose.PDF вы можете создавать, изменять и конвертировать документы без использования Microsoft Word.

Подробнее читайте на [aspose.com](https://products.aspose.com/words/java)

## Aspose.PDF Java для Python

Проект Aspose.PDF для Python показывает, как различные задачи можно выполнять с помощью Java API Aspose.PDF в Python. Целью этого проекта является предоставление полезных примеров разработчикам Python, которые хотят использовать Aspose.PDF для Java в своих проектах Python с использованием [JPype](http://jpype.readthedocs.org/en/latest/userguide.html).
