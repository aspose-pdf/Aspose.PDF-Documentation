## Введение

### Что такое Jython?

Jython — это реализация Python на Java, сочетающая выразительность с ясностью. Jython свободно доступен как для коммерческого, так и для некоммерческого применения и распространяется с исходным кодом. Jython дополняет Java и особенно подходит для следующих задач:

- **Embedded scripting** - программисты Java могут добавить библиотеки Jython в свою систему, позволяя конечным пользователям писать простые или сложные скрипты, которые добавляют функциональность приложению.
- **Интерактивные эксперименты** - Jython предоставляет интерактивный интерпретатор, который можно использовать для взаимодействия с пакетами Java или с работающими Java‑приложениями. Это позволяет программистам экспериментировать и отлаживать любую систему Java с помощью Jython.
- **Быстрая разработка приложений** - Программы на Python обычно короче на 2‑10 раз, чем эквивалентные программы на Java. Это напрямую приводит к повышенной продуктивности программистов. Бесшовное взаимодействие между Python и Java позволяет разработчикам свободно сочетать оба языка как в процессе разработки, так и при выпуске продуктов.

### Aspose.PDF for Java

Aspose.PDF for Java — это компонент для создания PDF‑документов, который позволяет вашим Java‑приложениям читать, записывать и изменять PDF‑документы без использования Adobe Acrobat.

Aspose.PDF for Java — это недорого стоящий компонент, предлагающий невероятно богатый набор функций, включая: параметры сжатия PDF, создание и обработку таблиц, поддержку графиков, функции работы с изображениями, обширные возможности гиперссылок, расширенные средства безопасности и работу с пользовательскими шрифтами.

Aspose.PDF for Java позволяет создавать PDF‑файлы напрямую с помощью предоставленного API и XML‑шаблонов. Использование Aspose.PDF for Java также даст вам возможность добавить функции PDF в ваши приложения за короткое время.

### Aspose.PDF Java для Jython

Aspose.PDF Java for Jython — это проект, который демонстрирует/предоставляет примеры использования API Aspose.PDF for Java в Jython.

Ниже приведены системные требования для использования Aspose.PDF Java for Jython:

### Установка

- Поместите загруженный файл jar Aspose.PDF for Java в каталог "lib".
- Замените "your-lib" на имя загруженного jar-файла в файле _*init*_.py.

### Использование

Вы можете преобразовать PDF в документ DOC, используя следующий пример кода:

```java
from aspose-pdf import Settings
from com.aspose.pdf import Document

class PdfToDoc:

    def __init__(self):
        dataDir = Settings.dataDir + 'WorkingWithDocumentConversion/PdfToDoc/'

        # Open the target document
        pdf = Document(dataDir + 'input1.pdf')

        # Save the concatenated output file (the target document)
        pdf.save(dataDir + "output.doc")

        print "Document has been converted successfully"

if __name__ == '__main__':

    PdfToDoc()
```
