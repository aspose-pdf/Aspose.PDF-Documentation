Java `PdfFileStampExamples` класс демонстрирует основные рабочие процессы штампования, доступные через Facades API.

Используйте этот раздел, чтобы узнать, как:

- добавить штамп‑изображение в PDF
- разместить текстовые и графические заголовки или нижние колонтитулы
- управлять полями заголовка и нижнего колонтитула
- добавить номера страниц с использованием макетов по умолчанию, координатных, выровненных или римской нумерации
