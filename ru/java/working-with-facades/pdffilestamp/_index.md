Класс Java `PdfFileStampExamples` демонстрирует основные рабочие процессы штамповки, доступные через API фасадов.

Используйте этот раздел, чтобы узнать, как:

- добавить штамп изображения в PDF
- размещать текстовые и графические заголовки или нижние колонтитулы
- контролировать поля верхнего и нижнего колонтитула
- добавлять номера страниц с макетами по умолчанию, на основе координат, с выравниванием или с римской нумерацией.
