Java `FormExamples` класс включает прямые примеры для:

- `flattenAllFields(...)`
- `renameFormFields(...)`

В данный момент репозиторий не содержит отдельного Java `Form` пример фасада для уплощения только выбранного подмножества полей, чтобы дочерняя страница была задокументирована как примечание к области вместо искусственно созданного примера кода.
