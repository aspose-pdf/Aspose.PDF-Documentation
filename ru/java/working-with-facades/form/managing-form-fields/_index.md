Класс Java `FormExamples` включает прямые примеры для:

- `flattenAllFields(...)`
- `renameFormFields(...)`

В настоящее время репозиторий не содержит отдельного примера фасада Java `Form` для выравнивания только выбранного подмножества полей, поэтому дочерняя страница документируется как примечание к области действия, а не как сфабрикованный образец кода.
