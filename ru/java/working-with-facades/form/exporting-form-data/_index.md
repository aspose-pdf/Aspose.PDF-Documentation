Класс Java `FormExamples` включает рабочие процессы прямого экспорта для следующих форматов:

- XML с `form.exportXml(...)`
- FDF с `form.exportFdf(...)`
- XFDF с `form.exportXfdf(...)`

Используйте дочерние страницы в этом разделе для конкретных примеров. Текущий набор примеров Java в этом репозитории не включает специальный пример фасада `Form` для экспорта JSON или извлечения XFA, поэтому эти страницы сохраняются как примечания к объему, а не как синтетические пошаговые руководства по коду.
