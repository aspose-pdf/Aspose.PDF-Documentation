Класс `FormExamples` на Java включает прямые рабочие процессы экспорта для этих форматов:

- XML с `form.exportXml(...)`
- FDF с `form.exportFdf(...)`
- XFDF с `form.exportXfdf(...)`

Используйте дочерние страницы в этом разделе для конкретных примеров. Текущий набор примеров Java в этом репозитории не включает отдельный пример использования фасада `Form` для экспорта JSON или извлечения XFA, поэтому эти страницы сохраняются как примечания к области, а не как синтетические пошаговые разборы кода.
