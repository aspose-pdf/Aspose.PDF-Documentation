Класс `FormExamples` на Java демонстрирует основные рабочие процессы обработки форм, предоставленные Facades API.

Используйте этот раздел, чтобы узнать, как:

- заполнить текстовые поля, флажки, радиокнопки, поля списка и поля штрих‑кода
- экспортировать данные формы в XML, FDF и XFDF
- импортировать данные формы из XML, FDF и XFDF
- преобразовать все поля формы в статическое содержимое и переименовать существующие поля
- проверить имена полей и текущие значения
- заполнить поле кнопки изображением из входного потока
