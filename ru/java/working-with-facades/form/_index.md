Класс Java `FormExamples` демонстрирует основные рабочие процессы обработки форм, предоставляемые API фасадов.

Используйте этот раздел, чтобы узнать, как:

- Заполните текст, флажок, переключатель, поле списка и поля штрих-кода.
- Экспорт данных формы в XML, FDF и XFDF.
- Импортируйте данные формы из XML, FDF и XFDF.
- Свести все поля формы и переименовать существующие поля.
- Проверьте имена полей и текущие значения
- Заполните поле кнопки изображения из входного потока
