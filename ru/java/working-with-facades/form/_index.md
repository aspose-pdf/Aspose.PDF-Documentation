Java `FormExamples` класс демонстрирует основные рабочие процессы обработки форм, предоставленные Facades API.

Используйте этот раздел, чтобы узнать, как:

- Заполнить текстовые, флажковые, радиокнопки, поля списка и поля штрих‑кода
- Экспортировать данные формы в XML, FDF и XFDF
- Импортировать данные формы из XML, FDF и XFDF
- Свести все поля формы в плоские и переименовать существующие поля
- Проверьте имена полей и текущие значения
- Заполнить поле кнопки-изображения из входного потока
