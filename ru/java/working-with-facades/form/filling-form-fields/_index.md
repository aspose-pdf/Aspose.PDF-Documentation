Класс Java `FormExamples` демонстрирует основные рабочие процессы `Form.fillField(...)` и `Form.fillBarcodeField(...)`, используемые для заполнения интерактивных форм PDF.

Используйте этот раздел, чтобы узнать, как:

- заполнить текстовые поля по имени поля
- выберите значения флажка и переключателя
- установить значения списка
- заполнить поле штрих-кода
- примените тот же API заполнения полей в своем собственном цикле для динамических пар имя-значение
