Класс `FormExamples` на Java демонстрирует основные рабочие процессы с использованием `Form.fillField(...)` и `Form.fillBarcodeField(...)`, используемые для заполнения интерактивных PDF-форм.

Используйте этот раздел, чтобы увидеть, как:

- заполнять текстовые поля по имени поля
- выбирать значения флажков и радиокнопок
- устанавливать значения списка
- заполнять поле штрихкода
- применять тот же API заполнения полей в собственном цикле для динамических пар «имя‑значение»
