Класс Java `FormExamples` включает рабочие процессы прямого импорта для следующих форматов:

- XML с `form.importXml(...)`
- FDF с `form.importFdf(...)`
- XFDF с `form.importXfdf(...)`

Используйте дочерние страницы в этом разделе для конкретных примеров. Текущий набор примеров Java в этом репозитории не включает специальный пример фасада `Form` для импорта JSON или замены XFA, поэтому эти страницы сохраняются как примечания к объему.
