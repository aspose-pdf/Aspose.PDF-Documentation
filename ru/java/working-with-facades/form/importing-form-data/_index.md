Java `FormExamples` класс включает прямые рабочие процессы импорта для этих форматов:

- XML с `form.importXml(...)`
- FDF с `form.importFdf(...)`
- XFDF с `form.importXfdf(...)`

Используйте дочерние страницы в этом разделе для конкретных примеров. Текущий набор примеров Java в этом репозитории не включает специализированный `Form` пример фасада для импорта JSON или замены XFA, чтобы эти страницы поддерживались как примечания к области.
