Класс Java `FormEditorExamples` демонстрирует, как работать с действиями в полях после того, как структура формы уже создана.
Используйте этот раздел, чтобы:

- добавить действие JavaScript в поле
- заменить существующий сценарий поля
- настроить URL-адрес отправки и флаг отправки
- удалить действие поля
