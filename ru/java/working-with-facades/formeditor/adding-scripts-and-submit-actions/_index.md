Java `FormEditorExamples` класс демонстрирует, как работать с действиями полей после того, как структура формы уже создана.
Используйте этот раздел для:

- добавить действие JavaScript к полю
- заменить существующий скрипт поля
- настроить URL отправки и флаг отправки
- удалить действие поля
