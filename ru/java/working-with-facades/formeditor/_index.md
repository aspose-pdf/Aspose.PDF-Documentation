Класс Java `FormEditorExamples` демонстрирует основные рабочие процессы редактирования полей, доступные через API фасадов.

Используйте этот раздел, чтобы узнать, как:

- создать текст, флажок, поле со списком, поле списка, переключатель и поля кнопки отправки
- добавлять, удалять, перемещать, переименовывать, копировать или конвертировать существующие поля
- настроить выравнивание, внешний вид, пределы и номера гребенки
- прикреплять сценарии, отправлять URL-адреса и удалять действия с полями
