Java `FormEditorExamples` класс демонстрирует основные рабочие процессы редактирования полей, доступные через Facades API.

Используйте этот раздел, чтобы узнать, как:

- создавать поля текста, флажка, комбобокса, листа, радиокнопки и кнопки отправки
- добавлять, удалять, перемещать, переименовывать, копировать или преобразовывать существующие поля
- настраивать выравнивание, внешний вид, ограничения и количество ячеек comb
- прикреплять скрипты, URL-адреса отправки и удалять действия полей
