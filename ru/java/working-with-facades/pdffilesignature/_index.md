Java `PdfFileSignatureExamples` класс демонстрирует основные рабочие процессы подписи, доступные через Facades API.

Используйте этот раздел, чтобы узнать, как:

- подписывать и заверять документы PDF
- проверять имена подписей, данные подписанта и временные метки
- проверять действительность подписи и покрытие всего документа
- извлекать сертификат подписи и удалять существующую подпись
