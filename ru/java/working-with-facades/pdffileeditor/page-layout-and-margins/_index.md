Используйте эти рабочие процессы PdfFileEditor, когда PDF требует очистки макета без полного воссоздания документа.

В этом разделе объясняется, как:

- добавить поля к выбранным страницам
- изменить размер контентных блоков на конкретных страницах
- разделить страницу на заданной вертикальной позиции с разрывом страницы
