Используйте эти рабочие процессы PdfFileEditor, когда PDF-файл требует очистки макета без восстановления документа с нуля.

В этом разделе объясняется, как:

- добавить поля к выбранным страницам
- изменить размер полей содержимого на определенных страницах
- разделить страницу в определенной вертикальной позиции с разрывом страницы
