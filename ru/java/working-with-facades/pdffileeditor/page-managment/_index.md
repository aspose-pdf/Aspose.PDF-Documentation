Используйте эти рабочие процессы, когда вам нужно перестроить структуру документа без редактирования каждой страницы вручную.

В этом разделе описано, как:

- добавить страницы из другого PDF-файла
- удалить определенные страницы
- извлечь выбранные страницы в новый файл
- вставить выбранные страницы из одного PDF-файла в другой
