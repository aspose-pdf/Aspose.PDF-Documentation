Используйте эти рабочие процессы, когда необходимо восстановить структуру документа без ручного редактирования каждой страницы.

В этом разделе рассматривается, как:

- добавить страницы из другого PDF
- удалить определённые страницы
- извлечь выбранные страницы в новый файл
- вставить выбранные страницы из одного PDF в другой
