Класс Java `PdfFileEditorExamples` включает прямой пример `concatenate` для объединения PDF-файлов.

В этом разделе вы можете найти:

- покрытие слиянием на основе исходного кода для рабочего процесса `concatenate` на основе массива
- руководство по эквивалентной статье из двух файлов, в которой используется тот же образец Java
- явные примечания к области действия для крупнопакетных, оптимизированных, специфичных для формы вариантов слияния и `try` вариантов слияния, которые не реализованы как выделенные методы в текущем наборе примеров репозитория
