Класс `PdfFileEditorExamples` на Java включает пример объединения PDF-файлов с помощью `concatenate`.

В этом разделе вы найдете:

- покрытие слияния, поддерживаемое источником, для массивного `concatenate` workflow
- руководство по эквивалентной двухфайловой статье, использующей тот же пример Java
- явные примечания к области для крупно‑пакетных, оптимизированных, специфичных для формы и `try` объединить варианты, которые не реализованы как отдельные методы в текущем наборе примеров репозитория
