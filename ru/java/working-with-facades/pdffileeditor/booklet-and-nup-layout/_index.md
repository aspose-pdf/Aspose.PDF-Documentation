Используйте фасад PdfFileEditor, когда вам нужно переформатировать существующий PDF-файл для печати или компактного просмотра.

В этом разделе описано, как:

- создать готовый PDF-файл из существующего документа
- разместить несколько исходных страниц на каждом выходном листе с макетом N-Up
- обрабатывать возвращаемое логическое значение, используемое примерами стиля `try` в наборе образцов Java
