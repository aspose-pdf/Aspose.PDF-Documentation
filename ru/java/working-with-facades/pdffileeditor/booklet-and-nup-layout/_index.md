Используйте фасад PdfFileEditor, когда необходимо переработать существующий PDF для печати или компактного просмотра.

В этом разделе рассматривается, как:

- создать PDF, подготовленный для брошюры, из существующего документа
- разместить несколько исходных страниц на каждом листе вывода с компоновкой N-Up
- обработайте логическое возвращаемое значение, используемое `try` примеры стилей в наборе образцов Java
