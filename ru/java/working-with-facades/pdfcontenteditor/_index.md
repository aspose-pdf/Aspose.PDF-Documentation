Класс Java `PdfContentEditorExamples` демонстрирует основные рабочие процессы редактирования контента, предоставляемые Facades API.

Используйте этот раздел, чтобы узнать, как:

- добавлять текстовые, линейные, полигональные, видеоролики и аннотации с резиновыми штампами
- добавить или удалить вложения документа
- связать PDF-файл из потока и сохранить результат
- добавить или удалить действия по открытию документа
- заменить текст и изображения
- получать и изменять предпочтения зрителя
