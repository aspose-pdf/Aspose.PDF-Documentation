Java `PdfContentEditorExamples` класс демонстрирует основные рабочие процессы редактирования контента, предоставляемые Facades API.

Используйте этот раздел, чтобы узнать, как:

- добавлять текст, линию, полигон, видео и аннотации‑резиновую печать
- добавлять или удалять вложения документа
- привязывать PDF из потока и сохранять результат
- добавлять или удалять действия при открытии документа
- заменять текст и изображения
- получать и изменять параметры просмотра
