В этом разделе группируются рабочие процессы аннотаций Java, используемые для создания, проверки, удаления и передачи аннотаций в файлах PDF.

Текущий репозиторий не включает специальный класс `PdfAnnotationEditorExamples.java`. Содержимое статьи для этого раздела взято из примеров Java в разделе `en/java/src/main/java/com/aspose/pdf/examples/workingwithannotations`.

Используйте этот раздел, чтобы:

- [Добавить, удалить и получить аннотацию](/pdf/java/pdfannotationeditor-class/add-delete-and-get-annotation/) для сгруппированных семейств аннотаций.
- [Импорт и экспорт аннотаций](/pdf/java/pdfannotationeditor-class/import-export-annotations/) для копирования аннотаций между файлами PDF.
