Разбор PDF-документов подразумевает извлечение структурированного или необработанного контента из существующих PDF-файлов, чтобы его можно было проверять, экспортировать, индексировать или повторно использовать в других процессах.

В этом разделе рассматривается, как:

- [Извлечь текст из PDF](/pdf/ru/java/extract-text-from-pdf/) используя `TextAbsorber`, `ParagraphAbsorber`, и связанные API.
- [Извлечь изображения из PDF](/pdf/ru/java/extract-images-from-the-pdf-file/) из ресурсов страницы.
- [Извлечь шрифты из PDF](/pdf/ru/java/extract-fonts-from-pdf/) для проверки используемых в документе шрифтов.
- [Извлечь данные из AcroForm](/pdf/ru/java/extract-data-from-acroform/) и экспортировать значения полей в JSON, XML, FDF или XFDF.
- [Извлечь данные из таблицы](/pdf/ru/java/extract-data-from-table-in-pdf/) используя `TableAbsorber` или экспортировать обнаруженные таблицы в Excel.
- [Извлечь векторные данные из PDF](/pdf/ru/java/extract-vector-data-from-pdf/) с `GraphicsAbsorber` и методы экспорта SVG.
