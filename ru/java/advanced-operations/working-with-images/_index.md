Aspose.PDF для Java обеспечивает как высокоуровневые, так и низкоуровневые рабочие процессы обработки изображений для PDF-документов. Вы можете размещать изображения на страницах, удалять или заменять встроенные изображения, извлекать ресурсы изображений, а также проверять размещение, тип, альтернативный текст и эффективное разрешение изображений.
