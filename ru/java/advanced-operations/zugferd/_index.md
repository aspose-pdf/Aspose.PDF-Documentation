ZUGFeRD объединяет удобочитаемый счет в формате PDF со структурированными данными XML, встроенными в документ. В текущем наборе примеров Java рассматриваемый рабочий процесс заключается в прикреплении XML-счета к PDF-файлу и преобразовании результата в `PDF_A_3A`.
