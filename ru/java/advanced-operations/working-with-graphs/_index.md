Aspose.PDF for Java предоставляет `Graph` контейнер для рисования векторных фигур непосредственно внутри страниц PDF. Вы можете добавлять базовую геометрию, применять заливки и границы, размещать текст внутри фигур и проверять, помещаются ли фигуры внутри границ графика.
