Aspose.PDF для Java предоставляет контейнер `Graph` для рисования векторных фигур непосредственно внутри страниц PDF. Вы можете добавлять базовую геометрию, применять заливки и границы, размещать текст внутри фигур и проверять, помещаются ли фигуры в границы графика.
