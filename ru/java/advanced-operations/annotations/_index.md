Аннотации — это интерактивные элементы PDF, которые позволяют добавлять заметки, выделять текст, рисовать фигуры, создавать ссылки, применять редактирование (redactions) и улучшать процессы рецензирования документов в существующих PDF‑файлах.

Используйте этот раздел для:

- [Добавлять, удалять и получать аннотацию](/pdf/ru/java/add-delete-and-get-annotation/) для группированных семейств аннотаций.
- [Импортировать и экспортировать аннотации](/pdf/ru/java/import-export-annotations/) для копирования аннотаций между PDF‑файлами.
