Аннотации — это интерактивные элементы PDF, которые позволяют добавлять примечания, выделять текст, рисовать фигуры, создавать ссылки, применять исправления и обогащать рабочие процессы проверки документов в существующих файлах PDF.

Используйте этот раздел, чтобы:

- [Добавить, удалить и получить аннотацию](/pdf/java/add-delete-and-get-annotation/) для сгруппированных семейств аннотаций.
- [Импорт и экспорт аннотаций](/pdf/java/import-export-annotations/) для копирования аннотаций между файлами PDF.
