{{% alert color="primary" %}}

Обязательно воспользуйтесь бесплатной оценочной версией Aspose.PDF для JasperReports, поскольку она не имеет ограничений по времени, а для пользователей оценочной версии также предоставляется бесплатная техническая поддержка.

{{% /alert %}}

{{% alert color="primary" %}}

Это одна и та же загрузка как для ознакомительной, так и для платной версии Aspose.PDF для JasperReports. Просто скачайте Aspose.PDF для JasperReports со страницы загрузки, установите его, и по умолчанию он будет работать в ознакомительном режиме.

В режиме оценки в экспортированные документы вводится предупреждение об оценке. Когда вы приобрели лицензию, просто примените ее, и Aspose.PDF для JasperReports будет работать в лицензионном режиме.

**Aspose.PDF для JasperReports вводит предупреждение об оценке при работе в режиме оценки.**
