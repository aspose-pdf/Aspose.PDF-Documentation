## Поддерживаемые форматы загрузки

В следующей таблице указаны форматы файлов, которые может загружать Aspose.PDF для JasperReports.

|**Формат**|**Описание**|
| :- | :- |
|JRXML|Файл макета JasperReports|

## Поддерживаемые форматы сохранения

В следующей таблице указаны форматы файлов, в которых документ можно сохранить с помощью Aspose.PDF для JasperReports. 

|**Формат**|**Описание**|
| :- | :- |
|[PDF](https://docs.fileformat.com/view/pdf/)|Сохраняет документ в формате PDF.|
|PDF/А|Сохраняет документ в формате PDF/A.|
|[ППТХ](https://docs.fileformat.com/presentation/pptx/)|Сохраняет документ в формате презентаций Microsoft PowerPoint.|
