## Добро пожаловать в документацию Aspose.PDF для JasperReports.

Aspose.PDF для JasperReports — это гибкий компонент, предназначенный для экспорта отчетов из JasperReports и JasperServer в формат переносимых документов (PDF). Важные функции отчета, такие как таблицы, диаграммы и изображения, преобразуются в PDF с высочайшей степенью точности.

{{% /alert %}}

### Описание продукта

Для создания документов PDF Aspose.PDF for JasperReports использует встроенную версию [Aspose.PDF for Java](https://products.aspose.com/pdf/java/), ведущей библиотеки от Aspose. Adobe Acrobat Professional не обязательно должен быть установлен в системе для создания PDF-документов с помощью Aspose.PDF для JasperReports.
