{{% alert color="primary" %}}

Aspose.PDF для JasperReports — это расширение экспорта для [ДжасперРепортс](http://www.jaspersoft.com/jasperreports).

Aspose.PDF для JasperReports предоставляется в виде одного файла JAR и может быть легко интегрирован с JasperReports и JasperServer.

{{% /alert %}}

Чтобы установить Aspose.PDF для JasperReports, просто скопируйте файл **Aspose-pdf-jasperreports.jar** в нужную папку (JasperReports\lib). Для интеграции с JasperServer вам также необходимо отредактировать файл конфигурации JasperServer. [Прочитайте раздел установки](/pdf/ru/jasperreports/installation/) подробные инструкции по установке.
