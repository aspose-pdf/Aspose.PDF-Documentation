{{% alert color="primary" %}}

Для запуска Aspose.PDF for JasperReports требуется следующее программное обеспечение:

- Платформа Java 2 Standard Edition 5.0 или выше.
- JasperReports 6.7.0 or higher.
- JasperServer 6.7.0 or higher (if you want to use Aspose.PDF for JasperReports with JasperServer).

{{% /alert %}}
