{{% alert color="primary" %}}

Aspose.PDF for JasperReports — это расширение экспорта для [JasperReports](http://www.jaspersoft.com/jasperreports).

Aspose.PDF for JasperReports предоставляется в виде одного файла JAR и может быть легко интегрирован с JasperReports и JasperServer.

{{% /alert %}}

Чтобы установить Aspose.PDF for JasperReports, просто скопируйте файл **Aspose-pdf-jasperreports.jar** в нужную папку (JasperReports\lib). Для интеграции с JasperServer вам также необходимо отредактировать файл конфигурации JasperServer. [Прочитайте раздел установки](/pdf/ru/jasperreports/installation/) для получения подробных инструкций по установке.
