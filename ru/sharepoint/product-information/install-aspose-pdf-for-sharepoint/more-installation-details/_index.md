## Развертывание

{{% alert color="primary" %}}

**Aspose.PDF для SharePoint выполняет следующие действия во время развертывания:**
- Установите Aspose.PDF.SharePoint.dll в глобальный кэш сборок и добавьте запись SafeControl в файл web.config.
- Установите манифест функции и другие необходимые файлы в соответствующие каталоги.
- Зарегистрируйте функцию в базе данных SharePoint и сделайте ее доступной для активации в области функции.

{{% /alert %}}

## Активация

{{% alert color="primary" %}}

**Aspose.PDF для SharePoint упакован как функция уровня сайта (семейства сайтов), и его можно активировать и деактивировать в семействах сайтов.**

{{% /alert %}}

{{% alert color="primary" %}}

Во время активации функция вносит некоторые изменения в виртуальный каталог родительского веб-приложения семейства сайтов: добавляет страницу настроек преобразования в файл карты сайта. Скопируйте необходимые файлы ресурсов в папку App_GlobalResources в виртуальном каталоге.

{{% /alert %}}
