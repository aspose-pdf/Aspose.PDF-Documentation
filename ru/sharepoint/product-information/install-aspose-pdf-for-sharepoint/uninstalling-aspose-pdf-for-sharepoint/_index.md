{{% alert color="primary" %}}

Чтобы удалить Aspose.PDF для SharePoint, просто запустите программу установки. Если Aspose.PDF for SharePoint уже установлен, программа установки предложит его удалить.

![Удалить Aspose.PDF для SharePoint](uninstalling-aspose-pdf-for-sharepoint_1.png)

Во время удаления программа установки деактивирует функцию Aspose.PDF for SharePoint для всех семейств сайтов и отзывает решение из фермы серверов.

{{% /alert %}}
