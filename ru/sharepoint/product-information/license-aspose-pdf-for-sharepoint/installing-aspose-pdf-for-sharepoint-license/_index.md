Этот архив содержит:

- Aspose.PDF.SharePoint.License.wsp

Файл пакета решения SharePoint. Лицензия Aspose.PDF for SharePoint упакована как решение SharePoint для облегчения развертывания/отзыва лицензии на всей ферме серверов.

- readme.txt

Инструкция по установке лицензии. Установка лицензии осуществляется с консоли сервера через stsadm.exe. Шаги, необходимые для установки лицензии, приведены ниже.

**Примечание.** Пути опущены для ясности. Возможно, вам придется добавить фактический путь к stsadm.exe и/или файлу решения при их выполнении.

1. Запустите stsadm, чтобы добавить решение в хранилище решений SharePoint:

stsadm.exe -o addsolution -имя файла Aspose.PDF.SharePoint.License.wsp

2. Разверните решение на всех серверах фермы:

stsadm.exe -o Deploysolution -name Aspose.PDF.SharePoint.License.wsp -immediate -force

3. Выполните задания административного таймера, чтобы немедленно завершить развертывание.

stsadm.exe -o execadmsvcjobs

**Примечание.** Вы получите предупреждение при выполнении этапа развертывания, если служба администрирования Windows SharePoint Services не запущена. Stsadm.exe использует эту службу и службу таймера Windows SharePoint для репликации данных решения по всей ферме. Если эти службы не работают на вашей ферме серверов, вам может потребоваться развернуть лицензию на каждом сервере.
