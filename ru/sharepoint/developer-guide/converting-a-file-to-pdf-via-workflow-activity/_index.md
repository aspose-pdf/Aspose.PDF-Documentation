{{% alert color="primary" %}}

Поддержка рабочих процессов — ключевая функция Microsoft Office SharePoint Server. Рабочие процессы помогают автоматизировать перемещение документов в соответствии с бизнес-логикой и оптимизировать затраты и время на организацию документов. В этой статье показано, как использовать Aspose.PDF для SharePoint в рабочем процессе преобразования документа в PDF.

{{% /alert %}}

## Настройка рабочего процесса

В этом примере создается рабочий процесс, который преобразует любой новый элемент в библиотеке документов в формат PDF и сохраняет его в другой библиотеке документов. В примере используется библиотека **Личные документы** в качестве исходной библиотеки и подпапка **Pdf** в библиотеке **Общие документы** в качестве целевой библиотеки.

Aspose.PDF для SharePoint поддерживает преобразование HTML, текстовых файлов и файлов изображений.

### Разработка рабочего процесса с помощью SharePoint Designer

1. Откройте **SharePoint Designer** и подключитесь к сайту, на котором будет реализован рабочий процесс.
1. Выберите **Рабочие процессы** из **объектов сайта**, а затем откройте **Список рабочих процессов**.
1. Выберите библиотеку **Личные документы**, чтобы создать и прикрепить новый рабочий процесс списка к библиотеке документов.

   **Выбор личных документов из меню**

![Преобразование файла в PDF с помощью Workflow Activity_1](converting-a-file-to-pdf-via-workflow-activity_1.png)

1. Создайте и прикрепите рабочий процесс списка к библиотеке **Личные документы**, введя имя и описание рабочего процесса.
1. Нажмите **ОК**, чтобы завершить этот шаг.

   **Создание рабочего процесса списка**

![Преобразование файла в PDF с помощью Workflow Activity_2](converting-a-file-to-pdf-via-workflow-activity_2.png)

Появится редактор шагов рабочего процесса. Это используется для определения условий и действий для рабочих процессов. Теперь добавьте действие для преобразования нового документа в PDF без каких-либо условий из **Aspose Actions**.

1. Выберите действие **Преобразовать файл в PDF с помощью Aspose.PDF** в меню **Действие**.

   **Выбор и действие**

![Преобразование файла в PDF с помощью Workflow Activity_3](converting-a-file-to-pdf-via-workflow-activity_3.png)

1. Настройте параметры действия:
   1. Установите параметр **thisfolder** в качестве папки назначения.
   1. Либо оставьте остальные параметры действия как значения по умолчанию, либо установите их в окне свойств действия. Значение по умолчанию для параметра **Overwrite** — false.

      **Редактор рабочих процессов**

![Преобразование файла в PDF с помощью Workflow Activity_4](converting-a-file-to-pdf-via-workflow-activity_4.png)

**Настройка целевой библиотеки**

![Преобразование файла в PDF с помощью Workflow Activity_5](converting-a-file-to-pdf-via-workflow-activity_5.png)

**Настройка свойств**

![Преобразование файла в PDF с помощью Workflow Activity_6](converting-a-file-to-pdf-via-workflow-activity_6.png)

1. В меню **Рабочий процесс** выберите **Настройки рабочего процесса**.
1. Выберите **автоматически запускать рабочий процесс при создании нового элемента** и снимите другие параметры в разделе **Параметры запуска**.

   **Настройка параметров запуска**

![Преобразование файла в PDF с помощью Workflow Activity_7](converting-a-file-to-pdf-via-workflow-activity_7.png)

Проектирование рабочего процесса завершено.

1. Сохраните и опубликуйте рабочий процесс, чтобы реализовать его на сайте SharePoint.

### Тестирование рабочего процесса

Чтобы протестировать рабочий процесс:

1. Откройте сайт SharePoint и загрузите новый документ в библиотеку документов **Личные документы**.
   Aspose.PDF для SharePoint поддерживает преобразование файлов HTML, текстовых файлов и изображений (JPG, PNG, GIF, TIFF и BMP*) в PDF. Рабочий процесс настроен на автоматический запуск при создании нового элемента, поэтому файлы обрабатываются автоматически.
1. Обновите браузер.
   Статус рабочего процесса отображается в столбце рабочего процесса, в данном случае **Aspose.PDF Workflow**.

   **Добавление документа в исходную библиотеку**

![Преобразование файла в PDF с помощью Workflow Activity_8](converting-a-file-to-pdf-via-workflow-activity_8.png)

1. Откройте целевую библиотеку документов, чтобы просмотреть преобразованный документ. **Общие документы/Pdf** — это путь в этом примере.

   **Целевая библиотека**

![Преобразование файла в PDF с помощью Workflow Activity_9](converting-a-file-to-pdf-via-workflow-activity_9.png)
