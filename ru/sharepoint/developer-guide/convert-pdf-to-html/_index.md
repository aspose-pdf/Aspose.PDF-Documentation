{{% alert color="primary" %}}

Aspose.PDF для SharePoint поддерживает функцию преобразования PDF-документов из библиотеки документов SharePoint в формат HTML. В этой статье мы продемонстрируем преобразование PDF в HTML.

{{% /alert %}}

## Преобразование PDF-документа в HTML

Преобразуйте PDF-документ из библиотеки документов SharePoint в HTML следующим образом:

1. Нажмите **Преобразовать в HTML** в меню ECB PDF-документа.

![Конвертировать PDF в HTML-пример 1](convert-pdf-to-html_1.png)

2. Загрузите и сохраните полученный HTML-файл на диск.

![Конвертировать PDF в HTML-пример 2](convert-pdf-to-html_2.png)
