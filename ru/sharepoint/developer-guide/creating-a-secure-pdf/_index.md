{{% alert color="primary" %}}

Aspose.PDF для SharePoint поддерживает создание защищенных PDF-файлов. При установке Aspose.PDF для SharePoint в настройках сайта добавляется опция **Настройки безопасности PDF**. Здесь вы можете установить пароль пользователя, пароль владельца и любое значение из списка алгоритмов для шифрования выходного PDF-файла. В списке алгоритмов представлены различные комбинации алгоритмов шифрования и размеров ключей. Передайте значение по вашему выбору.

В этой статье показано, как использовать Aspose.PDF для SharePoint для создания зашифрованного PDF-файла.

{{% /alert %}}

## Создание безопасного PDF-файла

Чтобы продемонстрировать эту функцию, сначала мы настроим параметр **Настройка безопасности PDF** для пароля владельца и пользователя и алгоритма шифрования. Затем в примере объединяются два документа из библиотеки документов.

### Настройка параметров защиты PDF

Откройте опцию **Настройки безопасности PDF** в настройках сайта и установите алгоритм, пароль владельца и пароль пользователя.

Укажите разные пароли пользователя и владельца при шифровании PDF-файла.

- Пароль пользователя, если он установлен, — это то, что вам необходимо ввести, чтобы открыть PDF-файл. Acrobat Reader предлагает пользователю ввести пароль пользователя. Если это неправильно, документ не откроется.
- Пароль владельца, если он установлен, управляет такими разрешениями, как печать, редактирование, извлечение, комментирование и т. д. Acrobat Reader запрещает эти функции в зависимости от настроек разрешений. Acrobat требует этот пароль, если вы хотите установить/изменить разрешения.

![Настройки безопасности PDF-файлов](creating-a-secure-pdf_1.png)

### Объединить документы

Объедините два документа, используя опцию **Конвертировать в PDF**. Эта функция объединяет несколько файлов, отличных от PDF (HTML, текст или изображение), в один PDF-файл.

1. Откройте библиотеку документов и выберите нужные документы из списка.

![Объединить документы](creating-a-secure-pdf_2.png)

1. Используйте параметр **Объединить в PDF** в разделе «Инструменты библиотеки», чтобы сохранить выходной файл. Вам будет предложено сохранить выходной файл на диск.

![Объединить в PDF](creating-a-secure-pdf_3.png)

### Выход

Выходной файл зашифрован.
