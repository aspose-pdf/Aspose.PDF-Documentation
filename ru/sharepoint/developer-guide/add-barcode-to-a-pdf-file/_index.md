## Добавьте штрих-код в PDF-файл

{{% alert color="primary" %}}

Aspose.PDF для SharePoint позволяет добавлять штрих-код в документ PDF. Пользователи могут добавить штрих-код в левый нижний угол каждой страницы PDF-документа, добавленного в библиотеку. Изображение ниже дает представление о том, как может выглядеть PDF-документ с добавленным штрих-кодом.

### Штрих-код в левом нижнем углу

![Добавить штрих-код в PDF-файл — пример 1](add-barcode-to-a-pdf-file_1.png)

{{% /alert %}}

{{% alert color="primary" %}}

Чтобы включить функцию штрих-кода для определенной библиотеки, используйте кнопку **Watermark Settings** на вкладке **Aspose Tools** в разделе **Library Tools**, как показано ниже.

### Watermark Settings

![Добавить штрих-код в PDF-файл — пример 2](add-barcode-to-a-pdf-file_2.png)

После того, как вы включите штрих-коды для конкретной библиотеки, Aspose.PDF для SharePoint добавит штрих-код в любой PDF-документ, добавленный в эту библиотеку.

{{% /alert %}}
