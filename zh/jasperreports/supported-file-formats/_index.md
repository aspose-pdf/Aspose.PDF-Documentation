## 支持的保存格式

The following table indicates the file formats in which the document can be saved by using Aspose.PDF for JasperReports. 

|**格式**|**描述**|
| :- | :- |
|[PDF](https://docs.fileformat.com/view/pdf/)|保存文档为PDF格式|
|PDF/A|以 PDF/A 格式保存文档|
|[PPTX](https://docs.fileformat.com/presentation/pptx/)|以 Microsoft PowerPoint 演示文稿格式保存文档|
