{{% alert color="primary" %}}

Aspose.PDF for JasperReports 是一个导出扩展 [贾斯珀报告](http://www.jaspersoft.com/jasperreports).

Aspose.PDF for JasperReports 作为单个 JAR 文件提供，可以轻松与 JasperReports 和 JasperServer 集成。

{{% /alert %}}

要安装 Aspose.PDF for JasperReports，只需将 **Aspose-pdf-jasperreports.jar** 文件复制到正确的文件夹 (JasperReports\lib)。要与 JasperServer 集成，您还需要编辑 JasperServer 配置文件。 [阅读安装部分](/pdf/zh/jasperreports/installation/) 了解详细的安装步骤。
