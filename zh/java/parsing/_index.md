解析 PDF 文档意味着从现有 PDF 文件中提取结构化或原始内容，以便可以在其他工作流程中检查、导出、索引或重用。

本节介绍如何：

- [从 PDF 中提取文本](/pdf/java/extract-text-from-pdf/) 使用 `TextAbsorber`、`ParagraphAbsorber` 和相关 API。
- [从 PDF 中提取图像](/pdf/java/extract-images-from-the-pdf-file/) 从页面资源中。
- [从 PDF 中提取字体](/pdf/java/extract-fonts-from-pdf/) 检查文档中使用的字体。
- [从 AcroForm 中提取数据](/pdf/java/extract-data-from-acroform/) 并将字段值导出为 JSON、XML、FDF 或 XFDF。
- 使用`TableAbsorber` [从表中提取数据](/pdf/java/extract-data-from-table-in-pdf/) 或将检测到的表导出到 Excel。
- [从 PDF 中提取矢量数据](/pdf/java/extract-vector-data-from-pdf/) 使用 `GraphicsAbsorber` 和 SVG 导出方法。
