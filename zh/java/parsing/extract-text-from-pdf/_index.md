使用本节中的文章可以：

- [从所有页面或单个页面提取文本](/pdf/java/basic-text-extraction/)。
- [限制提取到特定页面区域或检查段落几何形状](/pdf/java/region-based-extraction/)。
- [从突出显示、图章注释以及上标或下标内容中提取文本](/pdf/java/annotation-and-special-text/)。
- [改进多列布局的提取](/pdf/java/text-extraction-from-multi-column-pdf/)。
