## 一般特点

- 完全用 Java 编写，适用于 JDK 1.8 及更高版本
- 支持所有Java应用程序
- JavaDoc 格式的 API 参考
- 32 位操作系统支持。
- 64 位操作系统支持。

## 支持的 PDF 版本

Aspose.PDF for Java 支持 PDF 版本 1.2、1.3、1.4、1.5、1.6 和 1.7。

## 图形

- 支持直线、圆、圆弧、曲线等不同形状的图形。
- 可以在坐标指定的任何页面位置上绘制图形。
- 图形可以旋转、缩放或填充，并且可以定义虚线和多虚线样式。
- 图形是根据坐标绘制的，并且具有过时的位置而不是相对位置。
- 支持 CMYK 和灰色颜色空间。
