**基本操作** 部分描述了使用 Aspose.PDF for Java 可以执行的首个且最简单的 PDF 任务：

- [创建 PDF 文档](/pdf/zh/java/create-document/) - 以 Java 编程方式创建新的 PDF 文档。
- [打开 PDF 文档](/pdf/zh/java/open-pdf-document/) - 从路径、流或使用密码打开 PDF 文件。
- [保存 PDF 文档](/pdf/zh/java/save-pdf-document/) - 将文档保存为文件、流，或符合 PDF 标准。
- [合并 PDF](/pdf/zh/java/merge-pdf/) - 将多个 PDF 文件合并为一个输出文档。
- [拆分 PDF](/pdf/zh/java/split-pdf/) - 将 PDF 页拆分为单页 PDF 文件。
- [加密和解密 PDF 文件](/pdf/zh/java/protect-pdf-file/) - 为 PDF 文件应用密码、权限和解密。
