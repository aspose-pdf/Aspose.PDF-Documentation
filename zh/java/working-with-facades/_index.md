Facades API 为常见 PDF 任务提供了更高级别的帮助程序，而无需直接使用较低级别的文档对象模型。

使用本部分了解如何：

- 填写和编辑 PDF 表单
- 使用注释和内容
- 合并、拆分和重组 PDF 文件
- 检查元数据和页面信息
- 应用安全性、签名、印章和页码
- 使用查看器外观将 PDF 页面渲染为图像
