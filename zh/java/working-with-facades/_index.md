Facades API 为常见 PDF 任务提供更高级的帮助程序，而无需直接使用底层文档对象模型。

使用本节了解如何：

- 填写并编辑 PDF 表单
- 处理注释和内容
- 合并、拆分和重构 PDF 文件
- 检查元数据和页面信息
- 应用安全性、签名、印章和页码
- 使用查看器类将 PDF 页面渲染为图像
