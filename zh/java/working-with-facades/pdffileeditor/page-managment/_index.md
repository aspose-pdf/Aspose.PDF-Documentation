当您需要在不手动编辑每页的情况下重建文档结构时，请使用这些工作流。

本节介绍如何：

- 从另一个 PDF 附加页面
- 删除特定页面
- 将选定页面提取为新文件
- 将选定页面从一个 PDF 插入到另一个 PDF
