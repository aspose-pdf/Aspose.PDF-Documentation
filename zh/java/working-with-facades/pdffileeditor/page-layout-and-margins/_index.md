当 PDF 需要在不从头重新构建文档的情况下进行布局清理时，请使用这些 PdfFileEditor 工作流。

本节说明如何：

- 为所选页面添加边距
- 调整特定页面上的内容框大小
- 在定义的垂直位置处通过分页符拆分页面
