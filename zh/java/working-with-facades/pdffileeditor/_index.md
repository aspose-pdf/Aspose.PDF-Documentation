Java `PdfFileEditorExamples` class 演示了 Facades API 所公开的主要文档编辑工作流。

使用本节学习如何：

- 合并 PDF 文件 与 `concatenate` 方法
- 将文档从开始到结束拆分，或拆分为单页文件
- 提取、删除、插入和追加页面
- 创建小册子和 N-Up 打印输出
- 添加页边距，调整页面内容大小，并插入分页符
