Java `PdfContentEditorExamples` 类演示了 Facades API 所公开的主要内容编辑工作流。

使用本节学习如何：

- 添加文本、线条、多边形、视频和橡皮图章批注
- 添加或删除文档附件
- 从流绑定 PDF 并保存结果
- 添加或删除文档打开操作
- 替换文本和图像
- 获取并更改查看器首选项
