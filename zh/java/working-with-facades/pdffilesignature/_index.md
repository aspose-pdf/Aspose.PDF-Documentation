Java `PdfFileSignatureExamples` 类展示了通过 Facades API 可用的主要签名工作流。

使用本节学习如何：

- 签署并认证 PDF 文档
- 检查签名名称、签署者详细信息和时间戳
- 验证签名有效性及整个文档的覆盖范围
- 提取签名证书并删除现有签名
