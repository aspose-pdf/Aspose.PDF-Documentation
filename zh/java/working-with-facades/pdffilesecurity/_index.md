Java `PdfFileSecurityExamples` 类演示了通过 Facades API 可用的主要安全工作流。

使用本节了解如何：

- 使用用户密码和所有者密码加密 PDF
- 应用或更新文档权限
- 使用所有者密码解密 PDF
- 更改密码并可选择重置安全设置
