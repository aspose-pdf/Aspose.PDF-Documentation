Java `FormEditorExamples` 类演示了通过 Facades API 可用的主要字段编辑工作流。

使用本节了解如何：

- 创建文本、复选框、组合框、列表框、单选按钮和提交按钮字段
- 添加、删除、移动、重命名、复制或转换现有字段
- 自定义对齐方式、外观、限制和梳形字符数
- 附加脚本、提交 URL，并删除字段操作
