Java `FormExamples` 类演示了主要内容 `Form.fillField(...)` 和 `Form.fillBarcodeField(...)` 用于填充交互式 PDF 表单的工作流。

使用本节查看如何：

- 按字段名称填写文本字段
- 选择复选框和单选按钮的值
- 设置列表框的值
- 填充条形码字段
- 在您自己的循环中对动态名称-值对应用相同的字段填充 API
