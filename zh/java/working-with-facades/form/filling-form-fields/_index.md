Java `FormExamples` 类演示了用于填充交互式 PDF 表单的主要 `Form.fillField(...)` 和 `Form.fillBarcodeField(...)` 工作流程。

使用本节了解如何：

- 按字段名称填充文本字段
- 选择复选框和单选按钮值
- 设置列表框值
- 填充条形码字段
- 在您自己的循环中对动态名称-值对应用相同的字段填充 API
