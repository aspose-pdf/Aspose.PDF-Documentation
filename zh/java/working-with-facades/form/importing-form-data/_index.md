Java `FormExamples` 类包括这些格式的直接导入工作流：

- 带有 XML `form.importXml(...)`
- 带有 FDF `form.importFdf(...)`
- XFDF 与 `form.importXfdf(...)`

请使用本节中的子页面获取具体示例。目前此仓库中的 Java 示例集未包含专用的 `Form` 用于 JSON 导入或 XFA 替换的外观示例，因此这些页面被维护为范围注释。
