Java `FormExamples` 类包括这些格式的直接导入工作流程：

- XML 与 `form.importXml(...)`
- FDF 与 `form.importFdf(...)`
- XFDF 与 `form.importXfdf(...)`

使用本节中的子页面来获取具体示例。此存储库中当前的 Java 示例集不包含用于 JSON 导入或 XFA 替换的专用 `Form` 外观示例，因此这些页面将作为范围注释进行维护。
