Java `FormExamples` 类演示了 Facades API 公开的主要表单处理工作流程。

使用本部分了解如何：

- 填充文本、复选框、单选按钮、列表框和条形码字段
- 将表单数据导出为 XML、FDF 和 XFDF
- 从 XML、FDF 和 XFDF 导入表单数据
- 展平所有表单字段并重命名现有字段
- 检查字段名称和当前值
- 从输入流填充图像按钮字段
