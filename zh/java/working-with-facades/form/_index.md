Java `FormExamples` 类演示了 Facades API 提供的主要表单处理工作流。

使用本节了解如何：

- 填写文本、复选框、单选按钮、列表框和条形码字段
- 将表单数据导出为 XML、FDF 和 XFDF
- 从 XML、FDF 和 XFDF 导入表单数据
- 将所有表单字段扁平化并重命名现有字段
- 检查字段名称和当前值
- 从输入流填写图像按钮字段
