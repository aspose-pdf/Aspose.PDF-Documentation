Java `FormExamples` 类包括这些格式的直接导出工作流程：

- XML 与 `form.exportXml(...)`
- FDF 与 `form.exportFdf(...)`
- XFDF 与 `form.exportXfdf(...)`

使用本节中的子页面来获取具体示例。此存储库中当前的 Java 示例集不包括用于 JSON 导出或 XFA 提取的专用 `Form` 外观示例，因此这些页面作为范围注释而不是合成代码演练进行维护。
