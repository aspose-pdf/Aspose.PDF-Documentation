Java `FormExamples` 类包括这些格式的直接导出工作流：

- XML 与 `form.exportXml(...)`
- 带有 FDF `form.exportFdf(...)`
- XFDF 与 `form.exportXfdf(...)`

使用本节中的子页面作为具体示例。此仓库中的当前 Java 示例集未包含专用的 `Form` 用于 JSON 导出或 XFA 提取的外观示例，因此这些页面保留为范围说明，而不是合成代码演练。
