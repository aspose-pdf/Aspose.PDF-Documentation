Java `PdfFileStampExamples` 类演示了通过 Facades API 可用的主要冲压工作流程。

使用本部分了解如何：

- 将图像图章添加到 PDF
- 放置文本和图像页眉或页脚
- 控制页眉和页脚边距
- 使用默认、基于坐标、对齐或罗马编号布局添加页码
