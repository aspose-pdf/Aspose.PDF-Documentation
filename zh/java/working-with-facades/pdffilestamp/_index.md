Java `PdfFileStampExamples` 类演示了通过 Facades API 可用的主要印章工作流。

使用本节了解如何：

- 向 PDF 添加图像印章
- 放置文本和图像页眉或页脚
- 控制页眉和页脚的边距
- 添加页码，使用默认、基于坐标、对齐或罗马数字布局
