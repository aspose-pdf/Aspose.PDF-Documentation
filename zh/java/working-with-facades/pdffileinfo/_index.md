Java `PdfFileInfoExamples` 类演示了通过 Facades API 可用的主要检查和元数据工作流。

使用本节学习如何：

- 读取 PDF 版本和文档权限
- 检查页面宽度、高度、旋转和偏移量
- 获取、设置、清除并使用 XMP 保存文档元数据
