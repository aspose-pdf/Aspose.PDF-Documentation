Java `PdfFileInfoExamples` 类演示了通过 Facades API 可用的主要检查和元数据工作流程。

使用本部分了解如何：

- 阅读PDF版本和文档权限
- 检查页面宽度、高度、旋转和偏移
- 使用 XMP 获取、设置、清除和保存文档元数据
