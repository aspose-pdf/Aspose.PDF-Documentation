## 欢迎使用 Aspose.PDF for Java

Aspose.PDF 是一个 Java 组件，旨在让开发者以编程方式实时创建 PDF 文档，无论是简单还是复杂的。Aspose.PDF for Java 允许开发者向 PDF 文档中插入表格、图表、图像、超链接、自定义字体——以及更多内容。此外，还可以压缩 PDF 文档。Aspose.PDF for Java 提供出色的安全功能，以创建安全的 PDF 文档。而 Aspose.PDF for Java 最显著的特性是它支持通过 API 或 XML 模板两种方式创建 PDF 文档。

Aspose.PDF for Java 提供以下关键特性：

- 将文档从 HTML、DOC/DOCX、PPTX、Markdown、JPEG 等格式转换。
- 支持多种 AI 提供商，并具备从 PDF 文档加载数据的能力。
- 支持通过 API 和 XML 文件两种方式创建 PDF 文档。
- 卓越的基于证书的安全性和密码保护功能，可用于开发安全的 PDF 文档。
- 兼容强大的数字签名。
- PDF 表单创建（交互式表单、AcroForms、动态 XFA 表单）。
