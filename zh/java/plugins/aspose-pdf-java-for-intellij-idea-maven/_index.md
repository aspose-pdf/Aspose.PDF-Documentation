## 简介

### IntelliJ IDEA

IntelliJ IDEA 是面向软件开发人员的 Java 集成开发环境 (IDE)。它由 JetBrains 开发。最初是为 Java 创建的，如今它支持多种语言，包括 JavaScript、Groovy、HTML、CSS、RSS、R、Haskell、PHP、Ruby、Python、Scala、Clojure 和 Kotlin。

在 2010 年的 Infoworld 报告中，IntelliJ 在四大 Java 编程工具（Eclipse、IntelliJ IDEA、NetBeans 和 Oracle JDeveloper）中获得了最高的测试中心分数。

### Aspose.PDF for Java

Aspose.PDF for Java 是一个 PDF 文档创建组件，使您的 Java 应用程序能够读取、写入和操作 PDF 文档，而无需使用 Adobe Acrobat。

### 适用于 IntelliJ IDEA 的 Aspose.PDF Java - Maven

- Aspose.PDF Java for IntelliJ IDEA (Maven) 是一个 IntelliJ IDEA 插件，允许您创建 Maven 项目（即创建的项目包含 Aspose.PDF for Java API 的 Maven 依赖），并下载 API\u0412\u00A0 的源代码示例，以使用 Aspose.PDF for Java API。
- 此插件帮助您在喜爱的 IntelliJ IDEA 中使用 Aspose.PDF for Java API。

向导 1：Aspose.PDF Maven 项目

- 创建的项目将始终包含最新可用版本的 Maven 依赖，用于 Aspose.PDF for Java API。
- 向导步骤还В 提供下载选项。 [使用 Aspose.PDF for Java API 的源代码示例。](https://github.com/aspose-pdf/Aspose.PDF-for-Java)

向导 2：Aspose.PDF 示例。

- Aspose.PDF 示例向导可让您创建/复制已下载的В 源代码示例（Aspose.PDF for Java API）到您的项目。所选类别的所有示例将复制到项目’sВ  "com.aspose.pdf.examples" 包文件夹，并连同运行示例所需的资源一起放入 "src/main/resources" 文件夹。
- Aspose.PDF for Java API 的源代码示例旨在演示该 API 的不同用法。

## 下载中

### 正在下载 IntelliJ IDEA

您需要先安装 IntelliJ IDEA CE / UE，然后才能下载 Aspose.PDF Java for IntelliJ IDEA (Maven) 插件。

下载 IntellliJ IDEA

1. 转到 <https://www.jetbrains.com/idea/download/>
1. 选择您使用的操作系统
1. 点击 UE 或 CE 下载。

### 正在下载 Aspose.PDF Java for IntelliJ IDEA 插件 (Maven)

- 插件可以直接从以下位置下载 [JetBrains 插件托管 URL](https://goo.gl/z06gC0) - 在 IntelliJ IDEA 插件仓库上
  随后可以使用 IDE 选项进行安装：
  - 转到 File > Settings...>Plugins
  - 选择 “Install plugin from Disk”
- 或者可以直接使用 IDE 选项进行安装（无需手动从 JetBrains 插件托管 URL 下载）：
  - 转到 File > Settings...>Plugins
  - 选择 “Browse Repositories”
  - 在搜索框中键入："Aspose"
  - 选择 "Aspose.PDF Java for IntelliJ IDEA Maven" 插件进行安装。
