## 安装

### 在 IntelliJ IDEA (Maven) 中安装 Aspose.PDF Java

以下步骤演示如何安装 **Aspose.PDF Java for IntelliJ IDEA (Maven)** 插件。

TheВ 插件列在 IntelliJ IDEA 的 CE 中 [官方插件网站](https://plugins.jetbrains.com/plugin/7974-aspose-pdf-java-for-intellij-idea-maven/) - 插件仓库为 **Aspose.PDF Java for IntelliJ IDEA Maven**，因此您无需手动下载并从磁盘安装，但此额外选项在 IntelliJ IDEA 中仍然存在。

**Aspose.PDF Java for IntelliJ IDEA (Maven)** 插件可以轻松安装（无需手动下载），直接在 IntelliJ IDEA 中进行。操作如下：

1. 从 **File** 菜单中选择 **Settings**。
2. 点击 **Plugins**，然后在 IntelliJ IDEA 中浏览仓库。

![todo:image_alt_text](https://i.imgur.com/NDZtoKw.jpg)

### Aspose.PDF Maven 项目向导

**Aspose.PDF Maven Project** \u0432\u0402\u201C 导入 IntelliJ IDEA，这将使您能够创建基于 Aspose.PDF Maven 的项目以使用 [Aspose.PDF for Java API。](https://products.aspose.com/pdf/java/)。

![todo:image_alt_text](https://i.imgur.com/hd2mYnW.jpg)

### Aspose.PDF 示例向导

创建选项 [使用 Aspose.PDF for Java API 的示例源代码](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples) 在项目中，安装后也会出现在 "New" 菜单下（使用右键 -> New **OR** File 菜单 -> New）

## 使用

### Aspose.PDF Maven 项目向导

创建用于使用 Aspose.PDF 的 Maven 项目 [Aspose.PDF for Java API](https://products.aspose.com/pdf/java/) 在 IntelliJ IDEA 中，您需要有互联网连接。

然后遵循以下步骤：

1. 选择 **New Project**。
2. 选择 **Aspose.PDF Maven Project**。
3. 单击 **Next**。

![todo:image_alt_text](https://i.imgur.com/hd2mYnW.jpg)

4. 为您的 Maven 项目提供 **GroupId, ArtifactId** 和В Version
针对您的 Maven 项目并单击 Next。

![todo:image_alt_text](https://i.imgur.com/aNlx0Qe.jpg)

5. 您可以选择“Also Download Examples Source Code”复选框以下载 API 的示例使用例子（如上截图所示）

6. 提供一个 **Project Name** 和 **Location**，就像创建任何 Java 应用程序时一样

![todo:image_alt_text](https://i.imgur.com/8VEeFun.jpg)

7. 点击 **Finish**。

这将检索 [Aspose.PDF for Java API](https://products.aspose.com/pdf/java/) 来自 Aspose Cloud Maven Repository 的最新 Maven 依赖引用，并在 pom.xml 中进行配置
如果您已选择“Also Download Examples Source Code”复选框，示例的下载也将从此开始 [Aspose.PDF for Java API GitHub 仓库](https://goo.gl/cPAbJM)

![todo:image_alt_text](https://i.imgur.com/bG2mdam.jpg)

![todo:image_alt_text](https://i.imgur.com/aNYhLl5.jpg)

恭喜！  您已成功创建 Aspose.PDF Maven 项目用于使用 [Aspose.PDF for Java API](https://products.aspose.com/pdf/java/)。

![todo:image_alt_text](https://i.imgur.com/UJlSbuM.jpg)

已创建的 Aspose.PDF for Java API Maven 项目已准备好根据您的项目需求进行修改。

如果您选择下载 [示例源代码](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples)。

### Aspose.PDF 示例向导

导入/复制 [示例源代码](https://goo.gl/cPAbJM) 使用 **Aspose.PDF Examples Wizard** 将其导入/复制到项目中，您需要先在 Aspose.PDF Maven Project Wizard 上通过选择\u0412\u00A0 \u0022Also Download Examples Source Code\u0022 来下载示例。

然后在 IntelliJ IDEA 中遵循以下步骤：

1. 选择 **File** \u003E **New -** 如下所示：

![todo:image_alt_text](https://i.imgur.com/N8tT9Q0.jpg)

-OR- **Right Click** (on project window) =\u003E **New**\u0412\u00A0 - 如下所示：

![todo:image_alt_text](https://i.imgur.com/aUBWkhp.jpg)

2. 从菜单中选择 **Aspose.PDF Example** 选项 - 如下所示：

![todo:image_alt_text](https://i.imgur.com/hvH2V0m.jpg)

向导将刷新 / 检查最新可用的\u0412 [Aspose.PDF for Java API 示例](https://goo.gl/cPAbJM)

![todo:image_alt_text](https://i.imgur.com/5PZwsuq.jpg)

3. **Aspose.PDF 示例向导** 对话框将出现，您可以选择任意示例类别，将示例创建 / 复制到您的项目中
选择任意示例类别并点击 **创建**：

![todo:image_alt_text](https://i.imgur.com/l2oGUBW.jpg)

这将创建 / 复制\u0412\u00A0 所选类别的示例到项目中 **com.aspose.pdf.examples** 包下。
此外，示例执行所需的任何资源也会被复制到 **src/main/resources** 文件夹 - 如下所示：

![todo:image_alt_text](https://i.imgur.com/8GQL3Yb.jpg)

恭喜В ! 您已成功完成以下操作：

1. 您已使用 Aspose.PDF Maven 项目向导创建了 Aspose.PDF Maven 项目，

2. 您已下载 [Aspose.PDF for Java API - 示例源代码](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples)
3. 您已通过使用 Aspose.PDF 示例向导创建/复制示例源代码到您的项目中。
