## 安装中

### 如何为 IntelliJ IDEA 安装 Aspose.PDF Java (Maven)

以下步骤演示了如何安装 **Aspose.PDF Java for IntelliJ IDEA (Maven)** 插件。

该插件在 IntelliJ IDEA 的 CE [官方插件网站](https://plugins.jetbrains.com/plugin/7974-aspose-pdf-java-for-intellij-idea-maven/) 上列出 - 插件存储库为 **Aspose.PDF Java for IntelliJ IDEA Maven**，因此您不需要手动下载它并从磁盘安装它，但这个额外的选项仍然存在于 IntelliJ IDEA 中。

**Aspose.PDF Java for IntelliJ IDEA (Maven)** 插件可以从 IntelliJ IDEA 中轻松安装（无需手动下载）。要做到这一点：

1. 从 **文件** 菜单中选择 **设置**。
2. 单击 **Plugins**，然后浏览 IntelliJ IDEA 中的存储库。

![todo:image_alt_text](https://i.imgur.com/NDZtoKw.jpg)

### Aspose.PDF Maven 项目向导

**Aspose.PDF Maven 项目** – 进入 IntelliJ IDEA，这将使您能够创建基于 Aspose.PDF Maven 的项目以使用 [Aspose.PDF for Java API](https://products.aspose.com/pdf/java/)。

![todo:image_alt_text](https://i.imgur.com/hd2mYnW.jpg)

### Aspose.PDF 示例向导

安装后，在项目中创建 [使用 Aspose.PDF for Java API 的示例源代码](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples) 的选项也会出现在“新建”菜单下（使用右键单击 -> 新建 **或** 文件菜单 -> 新建）

## 使用

### Aspose.PDF Maven 项目向导

要在 IntelliJ IDEA 中创建 Aspose.PDF Maven 项目以使用 [Aspose.PDF for Java API](https://products.aspose.com/pdf/java/)，您需要有互联网连接。

然后按照以下步骤操作：

1. 选择**新项目**。
2. 选择 **Aspose.PDF Maven 项目**。
3. 单击**下一步**。

![todo:image_alt_text](https://i.imgur.com/hd2mYnW.jpg)

4. 提供 **GroupId、ArtifactId** 和版本
选择您的 Maven 项目，然后单击“下一步”。

![todo:image_alt_text](https://i.imgur.com/aNlx0Qe.jpg)

5. 您可以选择“同时下载示例源代码”复选框来下载 API 的示例使用示例（如上快照所示）

6. 提供 **项目名称** 和 **位置**，就像创建任何 Java 应用程序时一样

![todo:image_alt_text](https://i.imgur.com/8VEeFun.jpg)

7. 单击**完成**。

这将从 Aspose Cloud Maven 存储库检索 [Aspose.PDF for Java API](https://products.aspose.com/pdf/java/) 最新的 Maven 依赖项引用并在 pom.xml 中配置它
如果您选择了“同时下载示例源代码”复选框。示例的下载也将从 [Aspose.PDF for Java API GitHub 存储库](https://goo.gl/cPAbJM) 开始

![todo:image_alt_text](https://i.imgur.com/bG2mdam.jpg)

![todo:image_alt_text](https://i.imgur.com/aNYhLl5.jpg)

恭喜！  您已成功创建了使用 [Aspose.PDF for Java API](https://products.aspose.com/pdf/java/) 的 Aspose.PDF Maven 项目。

![todo:image_alt_text](https://i.imgur.com/UJlSbuM.jpg)

创建的 Aspose.PDF for Java API Maven 项目已准备好根据您的项目要求进行修改。

如果您选择下载[示例源代码](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples)。

### Aspose.PDF 示例向导

要使用 **Aspose.PDF 示例向导** 将 [示例源代码](https://goo.gl/cPAbJM) 导入/复制到项目中，您需要首先通过在 Aspose.PDF Maven 项目向导上选择“同时下载示例源代码”来下载示例。

然后在 IntelliJ IDEA 上按照以下步骤操作：

1. 选择**文件** > **新建-** 如下图：

![todo:image_alt_text](https://i.imgur.com/N8tT9Q0.jpg)

-或- **右键单击**（在项目窗口上）=> **新建**В - 如下所示：

![todo:image_alt_text](https://i.imgur.com/aUBWkhp.jpg)

2. 从菜单中选择 **Aspose.PDF Example** 选项 - 如下所示：

![todo:image_alt_text](https://i.imgur.com/hvH2V0m.jpg)

该向导将刷新/检查最新可用的[Aspose.PDF for Java API Examples](https://goo.gl/cPAbJM)

![todo:image_alt_text](https://i.imgur.com/5PZwsuq.jpg)

3. **Aspose.PDF 示例向导** 对话框将出现，您可以在其中选择任何示例类别来创建/将示例复制到您的项目中
选择任何示例类别并单击 **创建**：

![todo:image_alt_text](https://i.imgur.com/l2oGUBW.jpg)

这将创建/复制所选类别示例到 **com.aspose.pdf.examples** 包下的项目中。
此外，执行示例所需的任何资源都将复制到 **src/main/resources** 文件夹 - 如下所示：

![todo:image_alt_text](https://i.imgur.com/8GQL3Yb.jpg)

恭喜您！您已成功完成以下操作：

1. 您已经使用 Aspose.PDF Maven 项目向导创建了 Aspose.PDF Maven 项目，

2. 您已下载[Aspose.PDF for Java API - 示例源代码](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples)
3. 您已使用 Aspose.PDF 示例向导创建/复制示例源代码到您的项目中。
