## 如何配置源代码

请按照以下简单步骤操作，以便在使用时打开和扩展源代码：

1. 仅从以下位置安装 Python 2.7.x.x：<https://www.python.org/downloads/>
2. 从以下位置安装 JPype：<http://sourceforge.net/projects/jpype/files/JPype/>
3. 从以下位置安装 Java JDK：<http://www.oracle.com/technetwork/java/javase/downloads>
4. 从以下位置下载要在 Python 项目中使用的 Aspose.PDF for Java API：<http://www.aspose.com/community/files/72/java-components/default.aspx> 并将下载的 API 的 .jar 复制到 %Python%/lib 文件夹中。
5. 从 github 克隆 [Aspose.PDF Java for Python Examples](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Plugins/Aspose_Pdf_Java_for_Python)。
6. 从 CodePlex 克隆 [Aspose.PDF Java for Python Examples](http://asposepdfjavapython.codeplex.com/)。
