要使用 **Aspose.PDF Java for Python** 获取 Pdf 文档的页数，只需调用 **GetNumberOfPages** 类即可。

```Python
doc= self.Document()
pdf = self.Document()
pdf=self.dataDir + 'input1.pdf'
page_count = pdf.getPages().size()
print "Page Count:" . page_count

```
