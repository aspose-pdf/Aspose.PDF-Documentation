## 安装中

**Aspose.PDF Java (Maven) for Eclipse** 插件可以从插件对话框中的可用 **插件** 选项卡轻松安装。

- 要打开它，请从 Eclipse 的 **工具** 菜单中选择 **插件**。

![todo:image_alt_text](https://i.imgur.com/PCMRMUT.png)

- 这会在 Eclipse IDE 的“新建项目”向导中添加 **Aspose.PDF Maven 项目**，并在“新建文件”向导中添加 **Aspose.PDF 代码示例**。

## 使用

### Aspose.PDF Maven 项目（向导）

通过向导创建 **Maven 项目**以使用 [Aspose.PDF for Java API](http://www.aspose.com/java/pdf-component.aspx)：

1. 选择**新项目**。
1. 在 **Maven** 类别中选择 **Aspose.PDF Maven 项目**。
1. 单击**下一步**。

![todo:image_alt_text](https://i.imgur.com/6iywqND.png)

1. 提供 Maven 项目的 **项目名称、位置、GroupId、ArtifactId** 和 **版本**，然后单击 **完成。**

![todo:image_alt_text](https://i.imgur.com/zURjIn1.png)

1. 这将从 [Aspose Cloud Maven 存储库](https://repository.aspose.com/webapp/#/artifacts/browse/tree/General/repo) 检索 [Aspose.PDF for Java](http://www.aspose.com/java/pdf-component.aspx) 最新的 [Maven 依赖项](https://repository.aspose.com/webapp/#/artifacts/browse/tree/General/repo/com/aspose/aspose-pdf/) 引用，并在 **pom.xml** 中对其进行配置。如果您选择了**同时下载代码示例**，**代码示例**的下载也将从 [Aspose.PDF for Java API Examples Repository](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples)
1. 完成向导后，将在您的 **Eclipse IDE** 上创建以下 **Maven** 项目：

![todo:image_alt_text](https://i.imgur.com/xRfHrku.png)

1. 创建的 **Maven 项目** 配置为使用 **Aspose.PDF for Java API**，并准备好根据您的项目要求进行增强。
   如果您选择下载[代码示例](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples)，您可以使用 **Aspose.PDF 代码示例（向导）** 将 [Aspose.PDF for Java](http://www.aspose.com/java/pdf-component.aspx) API 所需的 **代码示例** 导入到您的项目中。

### Aspose.PDF 代码示例（向导）

**Aspose.PDF 代码示例向导** 允许您尝试为 [Aspose.PDF for Java](http://www.aspose.com/java/pdf-component.aspx) API 提供的许多示例。

{{% alert color="primary" %}}

为了能够舒适地使用 **Aspose.PDF 代码示例向导**：建议在 **Aspose.PDF Maven 项目** **向导** 上创建 **Maven 项目**时始终选择 **同时下载代码示例**，

{{% /alert %}}

要使用示例，只需：

1. 在 **Eclipse** 中单击 **新建文件**。
1. 选择您的项目，然后在 **Java** 类别中选择 **Aspose.PDF 代码示例**。
1. 单击**下一步**。

![todo:image_alt_text](https://i.imgur.com/AuWybe8.png)

 展开树以选择“**代码示例**”类别，然后单击“**完成**”。

![todo:image_alt_text](https://i.imgur.com/PToFZjJ.png)

1. 这会将所选类别 **代码示例** Java 文件复制到 **com.aspose.pdf.examples** 包下的项目中。此外，代码示例所需的任何必需资源都将复制到 **src/main/resources** 文件夹中
1. 查看示例代码，编译并运行。
1. 您现在可以测试其他示例并开始使用 [Aspose.PDF for Java API](http://www.aspose.com/java/pdf-component.aspx) 构建您自己的应用程序
