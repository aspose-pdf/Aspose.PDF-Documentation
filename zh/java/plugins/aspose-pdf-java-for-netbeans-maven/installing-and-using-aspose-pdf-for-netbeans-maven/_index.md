## 安装中

**Aspose.PDF Java for NetBeans (Maven)** 插件可以从插件对话框中的可用 **插件** 选项卡轻松安装。

- 要打开它，请从 NetBeans 的 **工具** 菜单中选择 **插件**。

![todo:image_alt_text](installing-and-using-aspose-pdf-for-netbeans-maven_1.png)

- 这将在 NetBeans IDE 的“新建项目”向导中添加 **Aspose.PDF Maven 项目**，并在“新建文件”向导中添加 **Aspose.PDF 代码示例**。

## 使用

### Aspose.PDF Maven 项目（向导）

通过向导创建 **Maven 项目**以使用 [Aspose.PDF for Java API](http://www.aspose.com/java/pdf-component.aspx)：

1. 选择**新项目**。
2. 在 **Maven** 类别中选择 **Aspose.PDF Maven 项目**。
3. 单击**下一步**。

提供 Maven 项目的 **项目名称、位置、GroupId、ArtifactId** 和 **版本**，然后单击 **完成。**

这将从 [Aspose Cloud Maven 存储库](https://repository.aspose.com/webapp/#/artifacts/browse/tree/General/repo) 检索 [Aspose.PDF for Java](http://www.aspose.com/java/pdf-component.aspx) 最新的 [Maven 依赖项](http://maven.aspose.com/repository/ext-release-local/com/aspose/aspose-pdf/) 引用，并在 **pom.xml** 中对其进行配置。如果您选择了**同时下载代码示例，**也将从 [Aspose.PDF for Java API Examples Repository] ​​开始下载 **代码示例**。 ](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples)

要使用示例，只需：

1. 单击 **NetBeans** 中的 **新建文件**。
2. 选择您的项目，然后在 **Java** 类别中选择 **Aspose.PDF 代码示例**。
3. 单击**下一步**。

展开树以选择“**代码示例**”类别，然后单击“**完成**”。
