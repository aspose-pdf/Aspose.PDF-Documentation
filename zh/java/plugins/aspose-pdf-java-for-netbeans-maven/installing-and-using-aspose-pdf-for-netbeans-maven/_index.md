## 安装

**Aspose.PDF Java for NetBeans (Maven)** 插件可以轻松地从插件对话框中的可用 **Plugin** 选项卡进行安装。

- 要打开它，请从 NetBeans 的 **Tools** 菜单中选择 **Plugins**。

![todo:image_alt_text](installing-and-using-aspose-pdf-for-netbeans-maven_1.png)

- 这会在 NetBeans IDE 的 New Project 向导中添加 **Aspose.PDF Maven Project**，并在 New File 向导中添加 **Aspose.PDF Code Example**。

## 使用

### Aspose.PDF Maven Project (向导)

通过向导创建 **Maven Project** 以使用 [Aspose.PDF for Java API](http://www.aspose.com/java/pdf-component.aspx):

1. 选择 **New Project**。
2. 在 **Maven** 类别中选择 **Aspose.PDF Maven Project**。
3. 点击 **Next**。

为您的 Maven 项目提供 **Project Name, Location, GroupId, ArtifactId** 和 **Version**，然后点击 **Finish.**

这将检索 [Aspose.PDF for Java](http://www.aspose.com/java/pdf-component.aspx) 最新 [Maven 依赖](http://maven.aspose.com/repository/ext-release-local/com/aspose/aspose-pdf/) 引用自 [Aspose Cloud Maven 仓库](https://repository.aspose.com/webapp/#/artifacts/browse/tree/General/repo) 并在 **pom.xml** 中进行配置。如果您已选择 **Also Download Code Examples,**，**Code Examples** 的下载也将从以下位置开始 [Aspose.PDF for Java API 示例仓库。 ](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples)
完成向导后，将在您的 **NetBeans IDE** 中创建以下 **Maven** 项目：

创建的 **Maven 项目** 已配置为使用 **Aspose.PDF for Java API**，并可根据您的项目需求进行增强。
   如果您已经选择下载 [代码示例](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples)，您可以使用 **Aspose.PDF Code Example (wizard)** 来导入所需的 **Code Examples** [Aspose.PDF for Java](http://www.aspose.com/java/pdf-component.aspx) API 到您的项目中。

### Aspose.PDF Code Example (wizard)

**Aspose.PDF Code Example wizard** 允许您尝试提供的众多示例 [Aspose.PDF for Java](http://www.aspose.com/java/pdf-component.aspx) API。

为了能够舒适地使用 **Aspose.PDF Code Example wizard**，建议在 **Aspose.PDF Maven Project** **wizard** 上创建 **Maven Project** 时始终选择 **Also Download Code Examples**，

{{% /alert %}}

要使用示例，只需：

1. 在 **NetBeans** 中单击 **New File**。
2. 选择您的项目，然后在 **Java** 类别中选择 **Aspose.PDF Code Example**。
3. 点击 **Next**。

展开树结构，选择 **Code Example** 类别并单击 **Finish**。
