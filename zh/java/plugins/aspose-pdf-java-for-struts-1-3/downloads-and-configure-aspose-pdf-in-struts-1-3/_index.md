## 下载 Aspose.PDF Java for Struts 1.3

您可以从以下位置下载/查看项目源代码：

- [Github](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Plugins/Aspose_Pdf_for_Struts)

## 从源代码构建 Aspose.PDF Java for Struts 1.3

从上述任何存储库检查源代码后，应用以下 mvn 命令：

{{< highlight java >}}

 $ mvn -U 清理包

{{< /highlight >}}

这将在目标 tolder 中构建“Strutsbookapp.war”。

要部署 .war 文件，只需将其复制到正在运行的 Apache tomcat 服务器 webapp 目录。
