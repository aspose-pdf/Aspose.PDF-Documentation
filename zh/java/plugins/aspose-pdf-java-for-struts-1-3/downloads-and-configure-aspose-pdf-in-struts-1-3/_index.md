## 下载 Aspose.PDF Java for Struts 1.3

您可以从以下位置下载/检出项目源代码：

- [GitHub](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Plugins/Aspose_Pdf_for_Struts)

## 从源代码构建 Aspose.PDF Java for Struts 1.3

从上述任意仓库检出源代码后，执行以下 mvn 命令：

{{< highlight java >}}

 $ mvn -U clean package

{{< /highlight >}}

这将在 target 文件夹中生成 “Strutsbookapp.war”。

要部署 .war 文件，只需将其复制到正在运行的 Apache Tomcat 服务器的 webapp 目录。
