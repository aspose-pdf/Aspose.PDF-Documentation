{{% alert color="primary" %}}

Aspose.PDF for SharePoint 允许您转换多个文档，或一次转换一个文档。本文介绍如何从列表中导出项目。

{{% /alert %}}

要从列表中导出特定项目：从项目的编辑控制块 (ECB) 中选择 **导出为 Pdf**。
