{{% alert color="primary" %}}

将多个 PDF 文件合并/串联为单个 PDF 文件是 PDF 文件处理应用程序中非常流行且要求很高的功能。我们在 [Aspose.PDF for SharePoint 2.2.0](https://releases.aspose.com/pdf/sharepoint/new-releases/aspose.pdf-for-sharepoint-2.2.0/) 版本中引入了这一重要功能。合并两个文件是通过将第二个文件添加到第一个文件的末尾来创建单个文件。

{{% /alert %}}

## 合并 PDF 文件

将 SharePoint 文档库中的多个 PDF 文件合并到单个 PDF 中，如下所示：

1.  从 SharePoint 文档库中选择要合并的 PDF 文件。

![Selecting PDF files](merge-pdf-files_1.png)

2.  Click Aspose Tools tab in Library Tools.

![Click Aspose Tools](merge-pdf-files_2.png)

3.  Click Merge to PDF option from Library Tools to merge all the selected PDF files to resultant PDF.

![Merge to PDF](merge-pdf-files_3.png)

4.  将显示提示以适当的名称下载/保存生成的 PDF 文件。

![Output](merge-pdf-files_4.png)
