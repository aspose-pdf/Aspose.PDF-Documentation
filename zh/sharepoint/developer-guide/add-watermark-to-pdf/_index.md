{{% alert color="primary" %}}

Aspose.PDF for SharePoint 允许您向 PDF 文档添加水印。该功能将文本水印添加到添加到库的 PDF 文档中每个页面的左下角。

## 水印文字位于左下角

![在 PDF 上新增浮水印 - 範例 1](add-watermark-to-pdf_1.jpg)

{{% /alert %}}

{{% alert color="primary" %}}

要为特定库启用水印功能：

1. 单击“库工具”对话框中“Aspose 工具”选项卡中的“水印设置”。

   **图书馆工具**

![在 PDF 上新增浮水印 - 範例 2](add-watermark-to-pdf_2.jpg)

水印设置是特定于列表的，因此您可以为不同的库选择不同的水印设置。以下屏幕截图显示了 **共享文档** 库的“水印设置”对话框。

## 水印设置

![在 PDF 上新增浮水印 - 範例 3](add-watermark-to-pdf_3.jpg)

- 选择**启用水印**以启用特定列表的水印功能。
- **水印文本** – 将作为水印显示在页面上的文本。
- **字体** – 用于水印的字体。
- **颜色** – 水印的颜色。

为特定库启用水印后，Aspose.PDF 会将水印添加到添加到该库的每个 PDF 文档。
