{{% alert color="primary" %}}

Aspose.PDF for SharePoint 允许将 HTML 文件、文本文件和图像（JPG、PNG、GIF、TIFF、BMP）转换为 PDF 格式。

{{% /alert %}}

## 将文档转换为 PDF

{{% alert color="primary" %}}

要将文档转换为 PDF：

1. 单击 ECB 菜单中的 **转换为 PDF**。
1. 下载并保存生成的 PDF 文件。

ECB 菜单中的“转换为 PDF”选项

![转换为 PDF](convert-to-pdf_1.jpg)

{{% /alert %}}

## PDF 创建者信息

{{% alert color="primary" %}}

- 请注意，您无法针对 **Application** 和 **Producer** 字段设置值，因为 Aspose Ltd. 和 Aspose.PDF for SharePoint x.x.x 将针对这些字段显示。 

{{% /alert %}}
