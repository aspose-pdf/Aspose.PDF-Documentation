## 欢迎使用 Aspose.PDF for SharePoint 文档！

Aspose.PDF for SharePoint 是一个允许用户将列表、列表项和 SharePoint Wiki 页面导出为 PDF 文件格式的解决方案。

{{% /alert %}}

{{% alert color="primary" %}}
Aspose.PDF for SharePoint 设计为与 Microsoft SharePoint Server 2010 一起使用。除了 Microsoft SharePoint Server 2010 之外，没有其他系统要求。

本文档介绍 Aspose.PDF for SharePoint 的[功能](/pdf/zh/sharepoint/features/)、[安装](/pdf/zh/sharepoint/install-aspose-pdf-for-sharepoint/)、[评估限制](/pdf/zh/sharepoint/evaluate-aspose-pdf/)、[许可](/pdf/zh/sharepoint/license-aspose-pdf-for-sharepoint/)、常见用例和设置。
