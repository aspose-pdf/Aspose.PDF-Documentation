{{% alert color="primary" %}}

在安装过程中，Aspose.PDF for SharePoint 会针对所有选定的网站集激活。安装后，您可以使用网站集根网站上的“网站操作”菜单来激活和停用 Aspose.PDF for SharePoint。

{{% /alert %}}
