{{% alert color="primary" %}}

要卸载 Aspose.PDF for SharePoint，只需运行安装程序即可。如果已安装 Aspose.PDF for SharePoint，安装程序建议将其删除。

![Uninstall Aspose.PDF for SharePoint](uninstalling-aspose-pdf-for-sharepoint_1.png)

在卸载过程中，安装程序会停用所有网站集的 Aspose.PDF for SharePoint 功能，并从服务器场中撤回该解决方案。

{{% /alert %}}
