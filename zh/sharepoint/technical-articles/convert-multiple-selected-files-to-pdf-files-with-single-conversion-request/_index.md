{{% alert color="primary" %}}

本文介绍如何使用 Aspose.PDF for SharePoint 通过一次转换操作将多个选定文件转换为 PDF 文件。

{{% /alert %}}

## 将多个选定文件转换为 PDF

{{% alert color="primary" %}}

要转换多个选定的文件，请执行以下步骤：

1. 选择要转换的文件

![選擇文件](convert-multiple-selected-files-to-pdf-files-with-single-conversion-request_1.jpg)

2. 单击“库工具”中的“Aspose 工具”选项卡

![點選 Aspose 工具](convert-multiple-selected-files-to-pdf-files-with-single-conversion-request_2.jpg)

3. 单击“转换为 PDF”将所有选定的文件转换为结果 PDF 文件。

![轉換為 PDF](convert-multiple-selected-files-to-pdf-files-with-single-conversion-request_3.jpg)

4. 将显示提示下载转换后的文件。

![下載轉換後的文件](convert-multiple-selected-files-to-pdf-files-with-single-conversion-request_4.jpg)

![下載轉換後的文件](convert-multiple-selected-files-to-pdf-files-with-single-conversion-request_5.jpg)
