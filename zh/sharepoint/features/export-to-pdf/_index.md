{{% alert color="primary" %}}

使用 Aspose.PDF for SharePoint，您可以将列表、列表项和 SharePoint Wiki 页面从 SharePoint 库导出为 PDF 格式。

{{% /alert %}}

{{% alert color="primary" %}}

为了生成文档，Aspose.PDF for SharePoint 依赖于内置版本的 [Aspose.PDF for .NET](http://www.aspose.com/categories/.net-components/Aspose.PDF-for-.net/default.aspx)。

{{% /alert %}}
