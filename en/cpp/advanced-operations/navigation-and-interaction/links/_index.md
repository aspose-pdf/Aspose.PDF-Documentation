A link annotation defines an interactive page region and an associated action. The examples in this section create links on the first page or inspect and update links already present there.

- [Create Links](/pdf/cpp/create-links/) - Add internal, remote PDF, URI, and file launch links.
- [Update Links](/pdf/cpp/update-links/) - Change annotation color, recolor text in link regions, and update web destinations.
- [Extract Links](/pdf/cpp/extract-links/) - Read link page indexes, rectangles, and web destination URIs.
