Use Aspose.PDF for C++ to create text content in new PDF documents and inspect or modify text in existing files. Choose a guide below for the task you need. Each guide explains the supplied C++ examples and links to the API types it uses.

- [Add Text to PDF in C++](/pdf/cpp/add-text-to-pdf-file/) - Insert fragments and paragraphs, apply font styles and gradients, add HTML or LaTeX, and use custom fonts.
- [Add Tooltips to PDF Text in C++](/pdf/cpp/pdf-tooltip/) - Add tooltips over searched text and show a hidden field on hover.
- [Use FloatingBox for PDF Layout in C++](/pdf/cpp/floating-box/) - Create bordered containers, columns, backgrounds, and positioned text blocks.
- [Replace Text in PDF with C++](/pdf/cpp/replace-text-in-pdf/) - Replace text and fonts, fit replacement content, and remove text from documents, pages, or regions.
- [Rotate PDF Text in C++](/pdf/cpp/rotate-text-inside-pdf/) - Rotate individual fragments, paragraph lines, and complete paragraphs.
- [Search and Extract PDF Text in C++](/pdf/cpp/search-and-get-text-from-pdf/) - Extract text strings, inspect fragment details, search with patterns, and turn matches into links.
- [Format PDF Text in C++](/pdf/cpp/text-formatting-inside-pdf/) - Set spacing, create lists, add footnotes and endnotes, and control inline content and tabs.
