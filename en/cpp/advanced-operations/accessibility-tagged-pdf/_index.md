Tagged PDF documents describe content through a logical structure tree. Headings, paragraphs, figures, form fields, and tables give assistive technologies information about the content and its organization. Aspose.PDF for C++ provides APIs to create and inspect this structure and validate a document against PDF/UA-1.

- [Create Tagged PDF](/pdf/cpp/create-tagged-pdf/) — Create tagged PDFs in C++ with headings, figures, forms, tables of contents, automatic tagging, and PDF/UA validation.
- [Extract Tagged Content](/pdf/cpp/extract-tagged-content-from-tagged-pdfs/) — Access tagged PDF content in C++, inspect structure roots and child elements, and update accessibility metadata.
- [Setting Structure Elements Properties](/pdf/cpp/setting-structure-elements-properties/) — Set tagged PDF structure properties in C++, including text, language, alternative descriptions, links, notes, and custom tag names.
- [Working with Table in Tagged PDFs](/pdf/cpp/working-with-table-in-tagged-pdfs/) — Create and style tagged PDF tables in C++, including headers, body rows, footers, merged cells, summaries, and positioning.
