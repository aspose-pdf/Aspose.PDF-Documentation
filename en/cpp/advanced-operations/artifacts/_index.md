PDF artifacts are page elements that are separate from the document's logical content, such as background decoration and repeated pagination elements. Aspose.PDF for C++ exposes them through the [Artifact](https://reference.aspose.com/pdf/cpp/aspose.pdf/artifact/) class and the page [Artifacts](https://reference.aspose.com/pdf/cpp/aspose.pdf/page/get_artifacts/) collection.

Use the following guides to add, inspect, and remove artifacts:

- [Adding backgrounds](/pdf/cpp/add-backgrounds/) - add image backgrounds, set background opacity or color, and remove background artifacts from PDF files
- [Adding Bates Numbering](/pdf/cpp/add-bates-numbering/) - configure six-digit Bates numbering, apply it with pagination APIs, and remove Bates numbers
- [Adding Watermark](/pdf/cpp/add-watermarks/) - create a styled text watermark artifact, read watermark text and bounds, and delete watermark artifacts
- [Manage PDF Headers and Footers](/pdf/cpp/artifacts-header-footer/) - add styled header and footer artifacts and delete matching pagination artifacts from a PDF page
- [Counting Artifacts](/pdf/cpp/counting-artifacts/) - count watermark, background, header, and footer pagination artifacts on a PDF page
