Use Aspose.PDF for C++ to add tables to PDF reports, turn CSV data into a PDF table, or process tables in an existing document.

- [Adding Tables](/pdf/cpp/adding-tables/) – create PDF tables with cell spans, images, borders, padding, and repeating headers.
- [Extracting Tables](/pdf/cpp/extracting-table/) – read table rows, cells, and text segments from an existing PDF.
- [Integrating Tables with Data Sources](/pdf/cpp/integrate-table/) – read selected CSV columns and write a table to a PDF.
- [Manipulating Tables](/pdf/cpp/manipulating-tables/) – change cell text or replace a detected table on the first page of a PDF.
- [Removing Tables](/pdf/cpp/removing-tables/) – remove the first detected table or all detected tables from a selected PDF page.
