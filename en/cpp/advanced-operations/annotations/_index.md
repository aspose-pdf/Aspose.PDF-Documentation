Annotations in PDFs let you add notes, highlight text, draw review shapes, and associate actions or media with a page. Use them for document review, content markup, and interactive navigation.

Aspose.PDF for C++ supports annotation workflows for notes and popups, text markup, links and buttons, shapes, watermarks, multimedia, and redaction. You can also copy annotations between PDF documents.

Use this section to choose the workflow that matches your task, whether you need to create annotations, inspect existing ones, remove them, or transfer them to another PDF.

## Annotation Topics

The following guides cover the main annotation workflows and the annotation families used in the C++ examples:

- [Add, Delete and Get Annotation](/pdf/cpp/add-delete-and-get-annotation/) - browse annotation categories and examples for creating, inspecting, and removing annotations.
- [Import and Export Annotations](/pdf/cpp/import-export-annotations/) - copy annotations from the first page of a source PDF to a new PDF document.

### Annotation Groups

The grouped annotation guide includes these topics:

- [Text Annotations](/pdf/cpp/text-based-annotations/) - create, inspect, and delete free text, highlight, underline, squiggly, and strikeout annotations; extract underlined text and flatten underlines.
- [Markup Annotations](/pdf/cpp/markup-annotations/) - work with sticky notes, caret markers, and grouped replacement markup for document review.
- [Interactive Annotations](/pdf/cpp/interactive-annotations/) - manage URI links and create line annotations, page navigation buttons, and a print button.
- [Shape Annotations](/pdf/cpp/shape-annotations/) - add, inspect, and delete line, square, circle, polygon, and polyline annotations.
- [Media Annotations](/pdf/cpp/media-annotations/) - create sound, screen, rich media, and 3D annotations, inspect multimedia annotations, and remove rich media annotations.
- [Security Annotations](/pdf/cpp/security-annotations/) - mark matching text or an image area for redaction and apply existing redaction annotations.
- [Watermark Annotations](/pdf/cpp/watermark-annotations/) - add a text watermark annotation, inspect its rectangle, and remove watermark annotations.
