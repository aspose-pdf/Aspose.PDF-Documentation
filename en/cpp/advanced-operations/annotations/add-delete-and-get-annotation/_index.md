Use the following guides to work with PDF annotations in C++. Each guide describes the supplied C++ examples and includes steps linked to the relevant API Reference.

- [Text annotations](/pdf/cpp/text-based-annotations/) - create, inspect, and delete free text, highlight, strikeout, squiggly, and underline annotations in PDF files.
- [Markup annotations](/pdf/cpp/markup-annotations/) - add, inspect, and delete sticky notes, caret markers, and grouped replacement annotations in PDF files.
- [Interactive annotations](/pdf/cpp/interactive-annotations/) - add, inspect, and delete PDF links and create line annotations, navigation buttons, and a print button.
- [Shape annotations](/pdf/cpp/shape-annotations/) - add, inspect, and delete square, circle, polygon, polyline, and line annotations in PDF documents.
- [Media annotations](/pdf/cpp/media-annotations/) - create and inspect PDF sound, screen, rich media, and 3D annotations and delete rich media annotations.
- [Security annotations](/pdf/cpp/security-annotations/) - mark text and image areas for redaction and apply existing redaction annotations in PDF files.
- [Watermark annotations](/pdf/cpp/watermark-annotations/) - add a text watermark annotation, inspect its rectangle, and delete watermark annotations from a PDF page.
