Use [PdfFileSignature](https://reference.aspose.com/pdf/cpp/aspose.pdf.facades/pdffilesignature/) to sign or certify PDF documents, inspect and verify signatures, extract certificates, and remove a signature.

Signing examples require a certificate file using the sample password Aspose2021. Inspection, extraction, verification, and removal examples select the first existing signature, so a signed input PDF is required. Use the appropriate certificate and password for your documents.

Choose a topic below for task-specific instructions and C++ examples.

## Topics

- [Sign PDF Documents](/pdf/cpp/pdf-signing/) - Set the certificate and sign page 1 with approval details and the visible flag set to false. Configure a PKCS7 certificate object and sign page 1 with the visible flag set to false.
- [PDF Certification](/pdf/cpp/pdf-certification/) - Create a PKCS7 signature and certify page 1 with FillingInForms modification permissions and a visible signature.
- [Signature Extraction](/pdf/cpp/signature-extraction/) - Extract the certificate for the first signature and copy it to outputFile.
- [Signature Information](/pdf/cpp/signature-information/) - List signature names and print the first signature's signer, date, reason, and location.
- [Signature Management](/pdf/cpp/signature-management/) - Remove the first signature and save the modified PDF.
- [Signature Verification](/pdf/cpp/signature-verification/) - Print the first signature's verification result and whether it covers the whole document.
