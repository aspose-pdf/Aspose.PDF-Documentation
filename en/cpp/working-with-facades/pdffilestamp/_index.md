Use [PdfFileStamp](https://reference.aspose.com/pdf/cpp/aspose.pdf.facades/pdffilestamp/) to add text and image headers or footers, image stamps, and page numbers with configurable position and style.

The examples bind an existing PDF and save the stamped result. Image variants require imageFile. The # placeholder in page-number text is replaced by the generated page number.

Choose a topic below for task-specific instructions and C++ examples.

## Topics

- [Add Footer to PDF](/pdf/cpp/add-footer/) - Add formatted footer text using the overload with three margin values set to 20. Add an image footer from a file stream with a margin value of 20. Add Sample Footer as formatted text with a margin value of 20.
- [Add Header to PDF](/pdf/cpp/add-header/) - Add a blue 12-point Helvetica header using margin values of 20. Add an image header from a file stream with a margin value of 20. Add Sample Header as formatted text with a margin value of 20.
- [Add Page Number to PDF](/pdf/cpp/page-number/) - Add Page # numbering at (300, 20). Add Page # numbering using default positioning. Add Page # numbering at PosBottomRight with all four margins set to 10. Set uppercase Roman numbering, start at 42, and add the page number at PosUpperRight.
- [Add Stamp to PDF](/pdf/cpp/add-stamp/) - Bind an image to a Stamp and apply it with PdfFileStamp.
