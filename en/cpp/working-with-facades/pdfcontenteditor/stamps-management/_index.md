Create and inspect stamps, read a stamp image, and move stamps by index or identifier.

## Stamp management tutorials

- [Add Rubber Stamp](/pdf/cpp/add-rubber-stamp/) - Create a green Approved rubber-stamp annotation on page 1.
- [Create a Sample Image Stamp](/pdf/cpp/create-stamp-sample/) - Write a sample PNG image, create a one-page PDF, and apply an image stamp with ID 1.
- [Extract an Image from a Stamp](/pdf/cpp/extract-image-from-stamp/) - Read page 1 stamps and save the first stamp image as PNG. Throw an error if no stamps are found.
- [List Stamps](/pdf/cpp/list-stamps/) - Print the number of stamps returned for page 1.
- [Move Stamp By ID](/pdf/cpp/move-stamp-by-id-example/) - Move stamp ID 1 on page 1 to (200, 200).
- [Move Stamp By Index](/pdf/cpp/move-stamp-by-index/) - Move stamp index 0 on page 1 to (200, 200).
