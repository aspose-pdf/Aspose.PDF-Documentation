Use [FormEditor](https://reference.aspose.com/pdf/cpp/aspose.pdf.facades/formeditor/) to create, copy, move, decorate, rename, and remove form fields and configure lists, scripts, and submission actions.

Most examples edit existing named fields. CopyInnerField uses page 2, so its input must contain at least two pages. JavaScript and submit actions depend on viewer support when the output is opened.

Choose a topic below for task-specific instructions and C++ examples.

## Topics

- [Modifying Form Fields](/pdf/cpp/modifying-form-fields/) - Copy, move, remove, and rename fields, manage choice items, and enable multiline input.
- [Customizing Field Appearance](/pdf/cpp/customizing-field-appearance/) - Decorate fields with colors and alignment or set text alignment directly.
- [Adding Scripts and Submit Actions](/pdf/cpp/adding-scripts-and-submit-actions/) - Configure field JavaScript and form submission targets and flags.
- [Creating Form Field](/pdf/cpp/creating-form-field/) - Create checkbox, combo box, and text fields with initial values and page coordinates.
