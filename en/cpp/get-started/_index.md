Create a PDF by constructing a [Document](https://reference.aspose.com/pdf/cpp/aspose.pdf/document/), adding pages and content, and saving the result. The examples in this section introduce two ways to add text: placing a fragment with TextBuilder and adding content to the page Paragraphs collection.

## Before you begin

Configure your C++ project with the Aspose.PDF for C++ SDK headers and libraries. The examples use the System types supplied with the SDK.

Choose a writable output PDF path. The Hello World example uses Times New Roman; the complex example uses Arial, Times New Roman, and Helvetica. Make these fonts available in the execution environment. For the complex example, also supply a readable image file.

## Start with these tutorials

- [Hello World Example](/pdf/cpp/hello-world-example/) - create a PDF with positioned, styled text.
- [Creating a complex PDF](/pdf/cpp/complex-pdf-example/) - combine an image, a heading, a paragraph, and a formatted table.
