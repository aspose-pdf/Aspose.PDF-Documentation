Use Aspose.PDF for C++ to create PDF documents from image, text, markup, and page-description files. This section covers the conversions demonstrated by the supplied C++ examples and the removal of PDF/A compliance information from existing documents.

The guides below also cover PDF export to editable documents, web content, and images, plus PDF standard conversion and validation.

## Convert other formats to PDF 

- [Convert Images to PDF](/pdf/cpp/convert-images-format-to-pdf/) — Convert BMP, JPEG, PNG, EMF, DICOM, TIFF, CGM, and SVG images to PDF in C++ using Aspose.PDF.
- [Convert other file formats to PDF](/pdf/cpp/convert-other-files-to-pdf/) — Convert text, LaTeX, Markdown, PostScript, XPS, and XML with XSL-FO stylesheets to PDF using Aspose.PDF for C++.
- [Convert PDF/A to PDF](/pdf/cpp/convert-pdfa-to-pdf/) — Remove PDF/A compliance information and save a standard PDF document in C++ using Aspose.PDF.


## Convert PDF to other formats

- [Convert PDF to Word](/pdf/cpp/convert-pdf-to-word/) - Export PDFs to DOC or DOCX and configure text recognition, line endings, bullet recognition, and image resolution.
- [Convert PDF to Spreadsheets](/pdf/cpp/convert-pdf-to-excel/) - Export PDFs to XLSX, XLSM, CSV, ODS, or SpreadsheetML and configure worksheet and column options.
- [Convert PDF to HTML](/pdf/cpp/convert-pdf-to-html/) - Export PDFs to HTML and configure image folders, page splitting, SVG graphics, background images, body markup, text, and layers.
- [Convert PDF to Images](/pdf/cpp/convert-pdf-to-images/) - Render PDF pages as BMP, GIF, JPEG, PNG, or multipage TIFF and export SVG files.
- [Convert PDF to PowerPoint](/pdf/cpp/convert-pdf-to-powerpoint/) - Export PDFs to PPTX with default settings, image-based slides, or a configured image resolution.
- [Convert PDF to Other Formats](/pdf/cpp/convert-pdf-to-other-formats/) - Export PDFs to EPUB, TeX, text, XPS, XML, Markdown, and MobiXML.

## Additional input formats

- [Convert Additional Images to PDF](/pdf/cpp/convert-additional-images-to-pdf/) - Create PDFs from GIF and CDR files or rasterize EMF through PNG before placing it on a PDF page.
- [Convert OFD, EPS, and PCL to PDF](/pdf/cpp/convert-additional-files-to-pdf/) - Load OFD, EPS, and PCL files with format-specific options and save them as PDF.

## PDF standards

- [Convert PDF to PDF/A](/pdf/cpp/convert-pdf-to-pdfa/) - Convert PDFs to PDF/A-1b, PDF/A-3a, or PDF/A-4 with logging, font substitution, attachments, and automatic tagging.
- [Convert PDF to PDF/E](/pdf/cpp/convert-pdf-to-pdfe/) - Convert PDFs to PDF/E-1 and validate documents against the PDF/E-1 standard.
- [Convert PDF to PDF/X](/pdf/cpp/convert-pdf-to-pdfx/) - Convert PDFs to PDF/X-4 using conversion options, an output intent, and an optional ICC profile.
- [Convert PDF/UA to PDF](/pdf/cpp/convert-pdfua-to-pdf/) - Remove PDF/UA compliance information from an existing document and save the result.
