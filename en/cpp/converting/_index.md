Use Aspose.PDF for C++ to create PDF documents from image, text, markup, and page-description files. This section covers the conversions demonstrated by the supplied C++ examples and the removal of PDF/A compliance information from existing documents.
- [Convert Images to PDF](/pdf/cpp/convert-images-format-to-pdf/) — Convert BMP, JPEG, PNG, EMF, DICOM, TIFF, CGM, and SVG images to PDF in C++ using Aspose.PDF.
- [Convert other file formats to PDF](/pdf/cpp/convert-other-files-to-pdf/) — Convert text, LaTeX, Markdown, PostScript, XPS, and XML with XSL-FO stylesheets to PDF using Aspose.PDF for C++.
- [Convert PDF/A to PDF](/pdf/cpp/convert-pdfa-to-pdf/) — Remove PDF/A compliance information and save a standard PDF document in C++ using Aspose.PDF.

## Use the conversion examples

Configure your project to include and link Aspose.PDF for C++ before calling these helper functions. Supply existing input files and create output directories in advance. For examples that use fonts, stylesheets, or custom font folders, make those resources available on your system.

Most format-specific examples construct a [Document](https://reference.aspose.com/pdf/cpp/aspose.pdf/document/) with load options and write the result with [Save()](https://reference.aspose.com/pdf/cpp/aspose.pdf/document/save/). Image placement and text examples create a new document and add content to its pages.
