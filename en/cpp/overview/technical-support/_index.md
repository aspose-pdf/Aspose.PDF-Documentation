Use the [Aspose.PDF support forum](https://forum.aspose.com/c/pdf/10) for product questions, issues, and feature requests. The [paid support helpdesk](https://helpdesk.aspose.com/) provides a separate support channel.

## Before reporting an issue

1. Check the [documentation](/pdf/cpp/) and [API Reference](https://reference.aspose.com/pdf/cpp/) for the relevant operation.
1. Review the [release notes](https://releases.aspose.com/pdf/cpp/) and test a current release when possible.
1. Reduce the issue to a small C++ example.

## Include reproducible details

Provide the following information:

- Aspose.PDF for C++ version.
- Operating system, architecture, compiler, and build configuration.
- Minimal source code and the required input files.
- Expected behavior and actual output or error.
- Steps needed to reproduce the issue.

For a conversion or rendering problem, include the original document and relevant output. Remove passwords, license files, private keys, and unrelated confidential data from the reproduction.

Use the forum's available attachment and privacy controls when supplying sample files.
