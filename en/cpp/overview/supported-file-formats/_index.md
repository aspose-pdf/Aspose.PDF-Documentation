Aspose.PDF for C++ supports loading PDF files and converting other formats to PDF, as well as exporting PDF content. Choose the conversion direction before selecting load or save options.

## Create PDF output

The following inputs are covered by the C++ conversion examples:

| Input | Workflow |
| --- | --- |
| BMP, JPEG, PNG, EMF, DICOM, TIFF, CGM, SVG | [Convert images to PDF](/pdf/cpp/convert-images-format-to-pdf/) |
| Text, Markdown, LaTeX, PostScript, XPS | [Convert other formats to PDF](/pdf/cpp/convert-other-files-to-pdf/) |
| XML with an XSL-FO stylesheet | [Convert XML to PDF](/pdf/cpp/convert-other-files-to-pdf/#convert-xml-with-an-xsl-fo-stylesheet) |
| PDF/A | [Remove PDF/A compliance information](/pdf/cpp/convert-pdfa-to-pdf/) |

## Export PDF content

The [product feature guide](https://products.aspose.com/pdf/cpp/) lists export workflows for Word, Excel, PowerPoint, HTML, and image formats.

Input and output support are separate capabilities. For example, exporting a PDF to DOCX does not imply that a DOCX file can be loaded with Document.

See the [conversion guide](/pdf/cpp/converting/) and the [API Reference](https://reference.aspose.com/pdf/cpp/) for the options used by a particular workflow.
