_This page is an overview of Aspose.PDF for C++ features._

**Aspose.PDF for C++** is a native PDF processing API that lets developers create and manipulate PDF documents without Adobe Acrobat. Visit the [Aspose.PDF for C++ product page](https://products.aspose.com/pdf/cpp/) for more information about the library and its capabilities.

Aspose.PDF for C++ supports a wide variety of operations:

- Create PDF documents and work with PDF standards and specifications.
- Convert PDF pages to image formats, including BMP, JPEG, PNG, and TIFF.
- Read and update document information, such as the title, author, and creator.
- Configure page dimensions, rotation, margins, and page boxes.
- Add page numbers, bookmarks, hyperlinks, and tables of contents.
- Work with text, paragraphs, headings, images, tables, vector graphics, attachments, and annotations.
- Optimize document resources and apply encryption and digital signatures.

In addition, Aspose.PDF for C++ can convert images, text, Markdown, LaTeX, PostScript, XPS, and XML with XSL-FO stylesheets to PDF. It also supports exporting PDF content to other formats. See [Supported File Formats](/pdf/cpp/supported-file-formats/) for details.

Try the [Online Apps](https://products.aspose.app/pdf/applications) to explore common PDF workflows.
