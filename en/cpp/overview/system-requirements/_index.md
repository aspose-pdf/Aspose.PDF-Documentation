Aspose.PDF for C++ requires a native C++ development environment and a compatible SDK distribution. Check the requirements of the package version you install.

## Development environment

The [Aspose.PDF.Cpp NuGet package](https://www.nuget.org/packages/Aspose.PDF.Cpp/) documents Microsoft Visual Studio 2017 or later for its Windows development workflow.

| Component | Check |
| --- | --- |
| Compiler and toolset | Match the installed SDK distribution. |
| Target architecture | Use matching application and library architectures. |
| Build configuration | Select compatible runtime and library settings. |
| Package restoration | Provide NuGet access or install the downloaded SDK. |
| Runtime files | Deploy the native dependencies required by the package. |

For other deployment environments, consult the [download distributions and release notes](https://releases.aspose.com/pdf/cpp/) for the selected release.

## Fonts and files

Make fonts used by your documents available to the application. Provide readable input paths and writable output directories.

Adobe Acrobat is not required for document creation or processing. Inspect generated files with a suitable PDF viewer.
