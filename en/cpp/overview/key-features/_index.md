Aspose.PDF for C++ is a native PDF processing library. Applications can create and modify PDFs without installing Adobe Acrobat.

## Document processing

- Create pages with text, images, tables, and vector graphics.
- Merge, split, extract, insert, and rearrange pages.
- Optimize images and document resources.
- Read or update document information and XMP metadata.

## Navigation and interaction

- Create links, bookmarks, and tables of contents.
- Add and manage annotations and attachments.
- Work with interactive PDF forms.
- Apply stamps, watermarks, and other page artifacts.

## Extraction and conversion

Extract text and images from existing PDFs. Convert supported input files to PDF or export PDF content to other document and image formats.

See [Supported File Formats](/pdf/cpp/supported-file-formats/) for conversion directions.

## Document security

Configure encryption and permissions and work with digital signatures. See [Securing and Signing](/pdf/cpp/securing-and-signing/) for examples.

Continue with [Working with Documents](/pdf/cpp/working-with-documents/) or the [product feature guide](https://products.aspose.com/pdf/cpp/).
