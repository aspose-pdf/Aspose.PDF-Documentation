Aspose.PDF Facades provides helper classes for common PDF operations in Java. Use these guides to edit documents, process forms, apply security, work with signatures, add stamps, and inspect PDF information.

## Why use Facades in Java

Facades provide a simpler entry point for tasks such as merging documents, filling existing forms, replacing text, and applying page numbers. Choose the class that matches your workflow, then follow its task-specific tutorials.

## Popular PDF facade workflows

- Merge, split, extract, and rearrange PDF pages.
- Fill form fields and transfer values through XML, FDF, or XFDF.
- Update PDF text, attachments, document actions, and viewer preferences.
- Apply encryption and privileges, or sign and verify documents.
- Add stamps, headers, footers, and page numbers.
- Inspect metadata and render PDF pages to images.
