Cette galerie présente les rapports PDF exportés par Aspose.PDF pour Reporting Services.

La plupart des rapports présentés ici proviennent de la base de données Adventure Works. Adventure Works est un exemple de base de données pour Microsoft SQL Server, disponible en téléchargement depuis Microsoft [ici](http://www.microsoft.com/downloads/details.aspx?familyid=E719ECF7-9F46-4312-AF89-6AD8702E4E6E&displaylang=en).
