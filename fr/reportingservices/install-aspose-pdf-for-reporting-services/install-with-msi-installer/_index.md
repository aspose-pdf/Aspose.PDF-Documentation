Vous pouvez installer Aspose.PDF pour Reporting Services à l'aide d'un programme d'installation MSI. Exécutez Aspose.Pdf.ReportingServices.msi et suivez les étapes proposées par le programme d'installation. Le programme d'installation copiera l'assembly et les autres fichiers dans le répertoire spécifié et installera le produit sur l'instance par défaut de Reporting Services. Vous n'avez pas besoin de copier ou de modifier des fichiers manuellement, sauf si vous souhaitez ajouter des paramètres de configuration spéciaux comme décrit dans la section « Configurer Aspose.PDF pour Reporting Services ».

L'installation automatique est la meilleure option qui fonctionne dans la plupart des cas. Cependant, vous devrez peut-être installer le produit manuellement dans certaines situations telles que :

- L'installation automatique échoue en raison de problèmes de sécurité d'E/S.
- Vous devez installer le produit sur une instance nommée (et non par défaut) de Reporting Services 2016 ou sur plusieurs instances.
- Vous effectuez une mise à niveau vers la dernière version et souhaitez simplement remplacer l'assemblage au lieu de désinstaller l'ancienne version et d'installer la nouvelle à l'aide du programme d'installation MSI.
 
{{% alert color="primary" %}}

Remarque : Notez que dans ce dernier cas, vous risquez de vous retrouver avec d'autres composants (tels que la documentation hors ligne) non mis à niveau vers la version correspondante.

{{% /alert %}}
