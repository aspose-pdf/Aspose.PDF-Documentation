{{% alert color="primary" %}}

In RDL Specification for RS2016, RS2017, RS2019, RS2022, and Power BI, almost every report item can be extended by adding custom properties. Currently Aspose.PDF for Reporting Services 2016, 2017, 2019, 2022, and Power BI supports three such properties, namely:

- Table des matières, liste de tableaux ou de figures.
- Flèches de ligne.
- Note de bas de page/Note de fin.

Découvrez comment les utiliser dans l'article [Développer les propriétés des éléments de rapport] (/pdf/reportingservices/expand-report-items-properties/).
