{{% alert color="primary" %}}

Aspose.PDF for JasperReports is an export extension for [JasperReports](http://www.jaspersoft.com/jasperreports).

Aspose.PDF pour JasperReports est fourni sous forme de fichier JAR unique et peut facilement être intégré à JasperReports et JasperServer.

{{% /alert %}}

Pour installer Aspose.PDF pour JasperReports, copiez simplement le fichier **Aspose-pdf-jasperreports.jar** dans le dossier approprié (JasperReports\lib). Pour intégrer JasperServer, vous devez également modifier un fichier de configuration JasperServer. [Lisez la section d'installation] (/pdf/jasperreports/installation/) pour les étapes d'installation détaillées.
