## 
Introduction à Aspose.PDF Java pour Python


## 
JPype

JPype is an effort to allow python programs full access to java class libraries. Ceci n'est pas réalisé en réimplémentant Python, comme l'a fait Jython/JPython, mais plutôt en interfaçant au niveau natif dans les deux machines virtuelles.



En savoir plus sur [readthedocs.org] (http://jpype.readthedocs.org/en/latest/userguide.html)


## 
Aspose.PDF pour Java



Aspose.PDF pour Java est une bibliothèque de classes avancée pour Java qui vous permet d'effectuer une large gamme de tâches de traitement de documents directement dans vos applications Java.



Aspose.PDF pour Java prend en charge le traitement de mots (DOC, DOCX, OOXML, RTF), HTML, OpenDocument, PDF, EPUB, XPS, SWF et tous les formats d'image. Avec Aspose.PDF, vous pouvez générer, modifier et convertir des documents sans utiliser Microsoft Word.

En savoir plus sur [aspose.com] (https://products.aspose.com/words/java)


## 
Aspose.PDF Java pour Python



Le projet Aspose.PDF pour Python montre comment différentes tâches peuvent être effectuées à l'aide des API Java Aspose.PDF en Python. Ce projet vise à fournir des exemples utiles aux développeurs Python qui souhaitent utiliser Aspose.PDF pour Java dans leurs projets Python en utilisant [JPype] (http://jpype.readthedocs.org/en/latest/userguide.html).
