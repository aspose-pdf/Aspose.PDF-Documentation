## 
Comment configurer le code source



Veuillez suivre ces étapes simples afin d'ouvrir et d'étendre le code source tout en utilisant :


1. 
Installez uniquement Python 2.7.x.x à partir de : <https://www.python.org/downloads/>
2. Installez JPype depuis : <http://sourceforge.net/projects/jpype/files/JPype/>

3. 
Installez Java JDK à partir de : <http://www.oracle.com/technetwork/java/javase/downloads>

4. 
Téléchargez Aspose.PDF pour les API Java que vous souhaitez utiliser dans vos projets Python à partir de : <http://www.aspose.com/community/files/72/java-components/default.aspx> et copiez les fichiers .jars des API téléchargées dans le dossier %Python%/lib.

5. 
Clonez [Aspose.PDF Java pour les exemples Python] (https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Plugins/Aspose_Pdf_Java_for_Python) depuis github.

6. 
Clonez [Aspose.PDF Java pour les exemples Python] (http://asposepdfjavapython.codeplex.com/) à partir de CodePlex.
