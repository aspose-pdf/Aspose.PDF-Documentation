### Télécharger les bibliothèques requises

Téléchargez les bibliothèques requises mentionnées ci-dessous. Ce sont les éléments requis pour l’exécution des exemples Aspose.PDF Java pour Python.

- Aspose : [Aspose.PDF pour le composant Java](https://downloads.aspose.com/pdf/java)

- [JPype](https://pypi.python.org/pypi/JPype1)

## Télécharger des exemples à partir de plateformes d’hébergement de code

Les versions suivantes d'exemples exécutables sont disponibles en téléchargement sur les plateformes d’hébergement de code mentionnées ci-dessous :

### GitHub

- Aspose.PDF Java pour exemples Python

  - [Aspose.PDF Java pour Python](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Plugins/Aspose_Pdf_Java_for_Python)

## Configurer le code source

Veuillez suivre ces étapes simples afin d'ouvrir et d'étendre le code source tout en utilisant :

1. Installez uniquement Python 2.7.x.x à partir de : <https://www.python.org/downloads/>
2. Installez JPype depuis : <http://sourceforge.net/projects/jpype/files/JPype/>

3. Installez Java JDK à partir de : <http://www.oracle.com/technetwork/java/javase/downloads>

4. Téléchargez Aspose.PDF pour les API Java que vous souhaitez utiliser dans vos projets Python à partir de : <http://www.aspose.com/community/files/72/java-components/default.aspx> et copiez les fichiers .jars des API téléchargées dans le dossier %Python%/lib.

5. Clonez [Aspose.PDF Java pour les exemples Python](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Plugins/Aspose_Pdf_Java_for_Python) depuis github.

6. Clonez [Aspose.PDF Java pour les exemples Python](http://asposepdfjavapython.codeplex.com/) à partir de CodePlex.
