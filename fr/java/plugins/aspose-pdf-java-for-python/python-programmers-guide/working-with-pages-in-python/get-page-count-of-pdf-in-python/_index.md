Pour obtenir le nombre de pages d'un document PDF à l'aide de **Aspose.PDF Java pour Python**, invoquez simplement la classe **GetNumberOfPages**.


```Python
doc= self.Document()
pdf = self.Document()
pdf=self.dataDir + 'input1.pdf'
```
