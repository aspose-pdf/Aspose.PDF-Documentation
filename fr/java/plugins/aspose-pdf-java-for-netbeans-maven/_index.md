## 
Introduction


### 
EDI NetBeans

NetBeans est un IDE Java complet écrit entièrement en Java. Il est principalement destiné au développement en Java mais prend également en charge d'autres langages, notamment PHP, C/C++ et HTML5.



L'EDI NetBeans vous permet de développer rapidement et facilement des applications Java de bureau, mobiles et Web, ainsi que des applications HTML5 avec HTML, JavaScript et CSS. Il s'agit d'un logiciel gratuit et open source qui compte une large communauté d'utilisateurs et de développeurs à travers le monde.



L'équipe NetBeans soutient activement le produit et recherche des suggestions de fonctionnalités auprès de la communauté au sens large. Chaque version est précédée d'une période de test et de commentaires de la communauté.


### 
Aspose.PDF pour Java



[Aspose.PDF for Java] (https://products.aspose.com/pdf/java/) est une API robuste de création de documents PDF qui permet à vos applications Java de lire, d'écrire et de manipuler des documents PDF sans utiliser Adobe Acrobat.

Aspose.PDF pour Java offre une incroyable richesse de fonctionnalités, notamment des options de compression PDF, la création et la manipulation de tableaux, la prise en charge de graphiques, des fonctions d'image, une fonctionnalité étendue de liens hypertexte, des contrôles de sécurité étendus et une gestion des polices personnalisées.


### 
Aspose.PDF Java pour NetBeans (Maven)


- 
Aspose.PDF Java for NetBeans (Maven) est un plugin pour **NetBeans IDE** par **Aspose.** Le plugin destiné aux développeurs utilisant la plateforme Maven pour les développements Java et souhaitant utiliser Aspose.PDF for Java dans leurs projets. Le plugin vous permet de créer des projets Maven pour utiliser Aspose.PDF pour l'API Java et également de télécharger des [exemples de code] (https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples) de l'API.

-

## 
MAGICIENS

Le plugin contient deux assistants


### 
Projet Aspose.PDF Maven (assistant)


- 
Cet assistant de nouveau projet permet aux développeurs de créer un projet **Maven** pour utiliser Aspose.PDF pour Java à partir de Nouveau projet -> Maven-> Projet Aspose.PDF Maven.

- 
La référence de la dépendance maven de l'API Java Aspose.PDF est automatiquement extraite du [Aspose Maven Repository] (https://repository.aspose.com/webapp/#/artifacts/browse/tree/General/repo/com/aspose/aspose-pdf) et est ajoutée dans le pom.xml.

- 
Le projet créé contiendra toujours la version disponible la plus récente **Maven** Dépendance pour Aspose.PDF pour l'API Java.
- Les étapes de l'assistant proposent également la possibilité de télécharger des exemples de code pour utiliser Aspose.PDF pour l'API Java.


### 
Exemple de code Aspose.PDF (assistant)


- 
Cet assistant de nouveau fichier vous permet de copier les [exemples de code] (https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples) téléchargés dans votre projet pour utiliser Aspose.PDF pour Java à partir de **Nouveau fichier -> Java -> Exemple de code Aspose.PDF.**

- 
Les échantillons disponibles sont affichés sous forme d'arborescence à partir de laquelle l'utilisateur peut les sélectionner de manière catégorique.

- 
Tous les exemples de la catégorie sélectionnée seront copiés dans le dossier du package **com.aspose.pdf.examples** du projet avec les ressources requises dans le dossier **src/main/resources** nécessaires pour exécuter les exemples.
- Les exemples de code d'Aspose.PDF pour l'API Java sont destinés à démontrer la variété de l'API.

- 
L'assistant recherchera également et mettra à jour les nouveautés disponibles à partir du [référentiel d'exemples Aspose.PDF pour Java.] (https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples)

## Téléchargement


### 
Télécharger NetBeans



Vous devez avoir l'IDE NetBeans préinstallé avant de télécharger le plug-in **Aspose.PDF Java pour NetBeans (Maven)**.



**Le plug-in Aspose.PDF Java pour NetBeans (Maven)** prend en charge **NetBeans IDE8.0 et 8.1**. Nous vous recommandons d'utiliser uniquement la dernière version de l'EDI NetBeans.



Pour télécharger l'EDI NetBeans,

1. Accédez à :<https://netbeans.apache.org/download/index.html>

1. 
Cliquez sur Télécharger pour télécharger le bundle approprié de l'EDI NetBeans.



Téléchargez uniquement le pack de téléchargement NetBeans pris en charge par Java EE / SE de la dernière version actuelle, à savoir **NetBeans IDE 8.1**.


### 
Télécharger Aspose.PDF Java pour NetBeans (Maven)


- 
Le plugin peut être directement téléchargé depuis l'URL d'hébergement du plugin NetBeans :<http://plugins.netbeans.org/plugin/63218>
  et versions ultérieures peuvent être installées à l'aide de l'option IDE :

  - 
Aller à**Outils**>**Plugins**>**Téléchargé

  - 
Cliquez sur **Ajouter des plugins...** et recherchez le fichier de plug-in d'extension .nbm téléchargé pour **Aspose.PDF Java pour NetBeans (Maven)**.

  - 
Cliquez**"Installer"**pour installer le plugin

- 
Ou il peut être installé directement (sans téléchargement manuel depuis l'URL d'hébergement du plugin NetBeans) à l'aide des options de l'EDI :
  - Aller à**Outils**>**Plugins**>**Plugins disponibles**

  - 
Dans le champ de recherche, tapez : "Aspose"

  - 
Sélectionnez le plug-in **Aspose.PDF Java NetBeans (Maven)**

  - 
Cliquez**"Installer"**

### 
Comment appliquer la licence Aspose ?



Ce plugin utilise une version d'évaluation d'Aspose.PDF. Une fois que vous êtes satisfait de votre évaluation, vous pouvez acheter une licence sur le [site Web Aspose] (https://purchase.aspose.com/buy).
Pour supprimer le message d'évaluation et les limitations des fonctionnalités, une licence de produit doit être appliquée. Vous recevrez un fichier de licence après avoir acheté le produit. Veuillez suivre les étapes ci-dessous pour appliquer la licence.


- 
Assurez-vous que le fichier de licence est nommé **Aspose.PDF.Java.lic

- 
Placez le fichier **Aspose.PDF.Java.lic** dans le dossier contenant le fichier Aspose.PDF.jar.

- 
Utilisez le code suivant pour activer la licence :


```java
License license = new License();
license.setLicense("Aspose.PDF.Java.lic");
```
