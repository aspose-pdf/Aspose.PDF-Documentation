## Aspose.PDF - Convertir un PDF en DOC ou DOCX

Pour convertir un document PDF au format DOC ou DOCX à l'aide de **Aspose.PDF Java pour PHP**, utilisez le module **PdfToDoc**.

Code PHP

```php

# Open the target document
$pdf = new Document($dataDir . 'input1.pdf');

# Save the concatenated output file (the target document)
$pdf->save($dataDir . "output.doc");

print "Document has been converted successfully";

```

**Télécharger l’exemple de code**

Téléchargez **Convertir un PDF en DOC ou DOCX (Aspose.PDF)** à partir de l'un des plateformes d’hébergement de code mentionnées ci-dessous :

- [GitHub](https://github.com/aspose-pdf/Aspose.PDF-for-Java/blob/master/Plugins/Aspose_Pdf_Java_for_PHP/src/Aspose/Pdf/WorkingWithDocumentConversion/PdfToDoc.php)
