Aspose.PDF vous permet d'utiliser un support technique gratuit pour tous ses produits. Si vous avez des questions sur Aspose.PDF, consultez l'article suivant :

- La source d'assistance la plus populaire est [Aspose.Forums](https://forum.aspose.com/). Dans la section [Forum Aspose.PDF](https://forum.aspose.com/c/pdf/10), vous pouvez poser votre question et obtenir une réponse dans les plus brefs délais.

- Il faut savoir qu'Aspose ne fournit pas d'assistance technique par téléphone. Les appels sont réservés aux questions commerciales.

- Les différences de fuseau horaire peuvent influer sur le délai de réponse.

Si vous avez besoin d'aide pour résoudre un problème avec Aspose.PDF, suivez les recommandations suivantes pour vous assurer qu'il est résolu de la manière la plus efficace :

- Aspose héberge toutes les API Java sur [Aspose Repository](https://repository.aspose.com/webapp/#/artifacts/browse/tree/General/repo/com/aspose/aspose-pdf). Vous pouvez facilement utiliser l'API Aspose.PDF for Java directement dans vos projets Maven avec une configuration simple.

- Consultez le forum, la documentation et la [référence de l’API](https://reference.aspose.com/pdf/java) avant de signaler le problème : une solution existe peut-être déjà.

- Lorsque vous formulez votre question, veuillez inclure le document original et éventuellement un fragment de votre code à l'origine du problème. Si vous avez plusieurs fichiers, regroupez-les dans une archive.

- Seuls vous et les développeurs d’Aspose avez accès aux fichiers joints.
