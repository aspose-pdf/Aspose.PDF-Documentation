Abstract: Aspose.PDF pour Python via .NET est une API de traitement PDF conçue pour permettre aux développeurs de gérer des documents PDF sans avoir besoin de Microsoft Office ou d'Adobe Acrobat Automation. Il prend en charge le développement d'applications Python 32 bits et 64 bits sur divers systèmes d'exploitation, notamment Windows et Linux, sur lesquels Python 3.5 ou version ultérieure est installé. L'API est compatible avec plusieurs versions de Windows, de Windows XP à Windows 11, et les principales distributions Linux comme Ubuntu, OpenSUSE et CentOS. Pour les systèmes Linux, les exigences spécifiques incluent les bibliothèques d'exécution GCC-6, les dépendances de .NET Core Runtime (sans avoir besoin du runtime lui-même) et la version pymalloc de Python pour les versions 3.5 à 3.7. De plus, une bibliothèque libpython partagée est nécessaire, ce qui peut nécessiter des ajustements de configuration pour une reconnaissance correcte du chemin de bibliothèque.

## Aperçu



Pour produire des documents PDF, la machine qui exécute [Aspose.PDF for Java] (https://products.aspose.com/pdf/java/) n'a pas besoin d'avoir [Adobe Acrobat] (https://www.adobe.com/acrobat/acrobat-pro.html) installé car Aspose.PDF pour Java lui-même est un moteur de création de documents PDF. Cependant, pour visualiser les documents PDF produits par Aspose.PDF pour Java, la machine a besoin d'au moins un [Adobe Acrobat Reader] (https://www.adobe.com/acrobat/pdf-reader.html). Il peut être téléchargé gratuitement.
