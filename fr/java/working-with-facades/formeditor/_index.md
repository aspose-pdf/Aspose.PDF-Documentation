La classe Java `FormEditorExamples` présente les principaux workflows d'édition de champs disponibles via l'API Facades.



Utilisez cette section pour apprendre à :


- 
créer des champs de texte, de case à cocher, de zone de liste déroulante, de zone de liste, de bouton radio et de bouton d'envoi

- 
ajouter, supprimer, déplacer, renommer, copier ou convertir des champs existants

- 
personnaliser l'alignement, l'apparence, les limites et les numéros de peigne
- joindre des scripts, soumettre des URL et supprimer des actions sur le terrain
