La classe Java `FormEditorExamples` crée plusieurs types de champs courants sur les pages PDF existantes en liant le document d'entrée, en appelant `addField(...)` ou `addSubmitBtn(...)` et en enregistrant le résultat.



Utilisez les pages enfants de cette section pour des exemples concrets de création de champs.
