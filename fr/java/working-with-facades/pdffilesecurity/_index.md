La classe Java `PdfFileSecurityExamples` présente les principaux workflows de sécurité disponibles via l'API Facades.



Utilisez cette section pour apprendre à :


- 
chiffrer un PDF avec les mots de passe utilisateur et propriétaire

- 
appliquer ou mettre à jour les privilèges relatifs aux documents

- 
décrypter un PDF avec un mot de passe propriétaire
- modifier les mots de passe et éventuellement réinitialiser les paramètres de sécurité
