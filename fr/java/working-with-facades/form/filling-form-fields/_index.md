Abstract: Cette section couvre les workflows de remplissage de formulaires Java implémentés dans les exemples de façade de formulaire pour Aspose.PDF pour Java. L'ensemble d'échantillons comprend des champs de texte de remplissage, des champs de case à cocher, des champs de boutons radio, des champs de zone de liste, des champs de code-barres et un modèle de remplissage de nom-valeur réutilisable construit sur la même API `fillField(...)`.
---
La classe Java `FormExamples` présente les principaux flux de travail `Form.fillField(...)` et `Form.fillBarcodeField(...)` utilisés pour remplir les formulaires PDF interactifs.



Utilisez cette section pour voir comment :


- 
remplir les champs de texte par nom de champ

- 
sélectionner les valeurs des cases à cocher et des boutons radio

- 
définir les valeurs de la zone de liste
- remplir un champ de code à barres

- 
appliquez la même API de remplissage de champ dans votre propre boucle pour les paires nom-valeur dynamiques
