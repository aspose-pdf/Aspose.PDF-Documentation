Abstract: Cette section couvre les exemples d'importation de formulaires Java implémentés avec la façade Form dans Aspose.PDF pour Java. L'ensemble d'exemples actuel inclut l'importation de données AcroForm à partir de XML, FDF et XFDF, tandis que les sujets de remplacement JSON et XFA non pris en charge sont explicitement notés pour que la documentation reste alignée sur les sources du référentiel.
---
La classe Java `FormExamples` inclut des workflows d'importation directe pour ces formats :


- 
XML avec `form.importXml(...)`

- 
FDF avec `form.importFdf(...)`

- 
XFDF avec `form.importXfdf(...)`



Utilisez les pages enfants de cette section pour les exemples concrets. L'ensemble d'exemples Java actuel dans ce référentiel n'inclut pas d'exemple de façade `Form` dédié pour l'importation JSON ou le remplacement XFA, ces pages sont donc conservées en tant que notes de portée.
