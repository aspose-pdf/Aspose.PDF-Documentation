Abstract: Cette section couvre les exemples d'exportation de formulaires Java implémentés avec la façade de formulaire dans Aspose.PDF pour Java. L'ensemble d'exemples actuel inclut l'exportation de données AcroForm vers XML, FDF et XFDF, tandis que les sujets JSON et XFA non pris en charge sont explicitement notés pour éviter de fabriquer des chemins de code qui ne sont pas présents dans ce référentiel.
---
La classe Java `FormExamples` inclut des workflows d'exportation directe pour ces formats :


- 
XML avec `form.exportXml(...)`

- 
FDF avec `form.exportFdf(...)`

- 
XFDF avec `form.exportXfdf(...)`



Utilisez les pages enfants de cette section pour les exemples concrets. L'ensemble d'exemples Java actuel dans ce référentiel n'inclut pas d'exemple de façade `Form` dédié pour l'exportation JSON ou l'extraction XFA, de sorte que ces pages sont conservées sous forme de notes de portée plutôt que de procédures pas à pas de code synthétique.
