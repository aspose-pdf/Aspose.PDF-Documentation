## Bienvenue dans la documentation Aspose.PDF for SharePoint!

Aspose.PDF for SharePoint est une solution qui permet aux utilisateurs d'exporter des listes, des éléments de liste et des pages Wiki SharePoint au format PDF.

{{% /alert %}}

{{% alert color="primary" %}}
Aspose.PDF for SharePoint est conçu pour être utilisé avec Microsoft SharePoint Server 2010. Il n'y a aucune configuration système supplémentaire en dehors de Microsoft SharePoint Server 2010.

Cette documentation décrit les [fonctionnalités](/pdf/sharepoint/features/), [l'installation](/pdf/sharepoint/install-aspose-pdf-for-sharepoint/), les [limites d'évaluation](/pdf/sharepoint/evaluate-aspose-pdf/) et les [licences](/pdf/sharepoint/license-aspose-pdf-for-sharepoint/) d'Aspose.PDF for SharePoint, les cas d'utilisation courants et les paramètres.
