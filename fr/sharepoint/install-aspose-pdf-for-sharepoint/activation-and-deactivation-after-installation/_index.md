{{% alert color="primary" %}}

Lors de l'installation, Aspose.PDF for SharePoint est activé pour toutes les collections de sites sélectionnées. Après l'installation, vous pouvez utiliser le menu Actions du site sur le site Web racine d'une collection de sites pour activer et désactiver Aspose.PDF for SharePoint.

{{% /alert %}}
