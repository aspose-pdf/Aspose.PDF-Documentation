{{% alert color="primary" %}}

Aspose.PDF pour SharePoint vous permet d'ajouter un filigrane à un document PDF. La fonctionnalité ajoute un filigrane de texte dans le coin inférieur gauche de chaque page d'un document PDF ajouté à la bibliothèque.

Pour activer la fonctionnalité de filigrane pour une bibliothèque spécifique :

1. Cliquez sur **Paramètres du filigrane** dans l'onglet **Aspose Tools** de la boîte de dialogue **Outils de bibliothèque**.

   **Outils de bibliothèque**

![Add Watermark to PDF-example 2](add-watermark-to-pdf_2.jpg)

Les paramètres de filigrane sont spécifiques à une liste, vous pouvez donc choisir différents paramètres de filigrane pour différentes bibliothèques. La capture d'écran suivante montre la boîte de dialogue Paramètres de filigrane pour la bibliothèque **Documents partagés**.

## Paramètres du filigrane

![Add Watermark to PDF-example 3](add-watermark-to-pdf_3.jpg)

- Sélectionnez **Activer le filigrane pour** pour activer la fonction de filigrane pour une liste spécifique.
- **Texte du filigrane** – le texte qui apparaîtra sur la page sous forme de filigrane.
- **Police** – la police utilisée pour le filigrane.
- **Couleur** – la couleur du filigrane.

Après avoir activé le filigrane pour une bibliothèque spécifique, Aspose.PDF ajoute des filigranes à chaque document PDF ajouté à cette bibliothèque.
