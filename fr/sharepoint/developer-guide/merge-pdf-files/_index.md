{{% alert color="primary" %}}

La fusion/concaténation de plusieurs fichiers PDF en un seul fichier PDF est une fonctionnalité très populaire et exigeante dans les applications de traitement de fichiers PDF. Nous avons introduit cette fonctionnalité importante dans [Aspose.PDF for SharePoint 2.2.0](https://releases.aspose.com/pdf/sharepoint/new-releases/aspose.pdf-for-sharepoint-2.2.0/) version. Fusionner deux fichiers consiste à créer un seul fichier en ajoutant un deuxième fichier à la fin du premier fichier.

{{% /alert %}}

## Fusionner des fichiers PDF

Fusionnez plusieurs fichiers PDF de la bibliothèque de documents SharePoint en un seul PDF comme suit :

1.  Sélectionnez les fichiers PDF de la bibliothèque de documents SharePoint à fusionner.

![Sélection de fichiers PDF](merge-pdf-files_1.png)

2.  Cliquez sur l'onglet Outils Aspose dans Outils de bibliothèque.

![Cliquez sur Outils Aspose](merge-pdf-files_2.png)

3.  Cliquez sur l'option Fusionner vers PDF dans les outils de bibliothèque pour fusionner tous les fichiers PDF sélectionnés dans le PDF résultant.

![Fusionner en PDF](merge-pdf-files_3.png)

4.  Une invite sera affichée pour télécharger/enregistrer le fichier PDF résultant avec le nom approprié.

![Sortir](merge-pdf-files_4.png)
