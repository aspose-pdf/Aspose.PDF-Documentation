## Bienvenue dans la documentation Aspose.PDF pour SharePoint !

Aspose.PDF for SharePoint is a solution that allows the users to export lists, list items and SharePoint Wiki pages to the PDF file format.

{{% /alert %}}

{{% alert color="primary" %}}
Aspose.PDF pour SharePoint est conçu pour être utilisé avec Microsoft SharePoint Server 2010. Il n'y a aucune configuration système supplémentaire en dehors de Microsoft SharePoint Server 2010.

Cette documentation décrit les [fonctionnalités] (/pdf/sharepoint/features/), [l'installation] (/pdf/sharepoint/install-aspose-pdf-for-sharepoint/), les [limites d'évaluation] (/pdf/sharepoint/evaluate-aspose-pdf/) et les [licences] (/pdf/sharepoint/license-aspose-pdf-for-sharepoint/) d'Aspose.PDF pour SharePoint, les cas d'utilisation courants et les paramètres.
