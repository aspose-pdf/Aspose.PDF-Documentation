{{% alert color="primary" %}}

Aspose.PDF for SharePoint permite converter arquivos HTML, arquivos de texto e imagens (JPG, PNG, GIF, TIFF, BMP) para o formato PDF.

{{% /alert %}}

## Converter um Documento para PDF

{{% alert color="primary" %}}

Para converter um documento para PDF:

1. Clique **Converter para PDF** no menu ECB.
1. Baixe e salve o arquivo PDF resultante.

Opção Converter para PDF no menu ECB

{{% /alert %}}

## Informação do PDF Creator

{{% alert color="primary" %}}

- Observe que você não pode definir valores nos campos **Application** e **Producer**, pois a Aspose Ltd. e o Aspose.PDF for SharePoint x.x.x serão exibidos nesses campos.
