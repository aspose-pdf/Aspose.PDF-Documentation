{{% alert color="primary" %}}

A fusão/concatenação de vários arquivos PDF em um único arquivo PDF é um recurso muito popular e exigente em aplicativos de processamento de arquivos PDF. Introduzimos esse importante recurso em [Aspose.PDF para SharePoint 2.2.0](https://releases.aspose.com/pdf/sharepoint/new-releases/aspose.pdf-for-sharepoint-2.2.0/) versão. Mesclar dois arquivos é criar um único arquivo adicionando um segundo arquivo ao final do primeiro arquivo.

{{% /alert %}}

## Mesclar arquivos PDF

Mesclar vários arquivos PDF da biblioteca de documentos do SharePoint em um único PDF da seguinte forma:

1.  Selecione os arquivos PDF da biblioteca de documentos do SharePoint a serem mesclados.

![Selecionando arquivos PDF](merge-pdf-files_1.png)

2.  Clique na guia Aspose Tools em Library Tools.

![Clique em Ferramentas Aspose](merge-pdf-files_2.png)

3.  Clique na opção Mesclar para PDF em Ferramentas de biblioteca para mesclar todos os arquivos PDF selecionados no PDF resultante.

![Mesclar em PDF](merge-pdf-files_3.png)

4.  Será mostrado um prompt para baixar/salvar o arquivo PDF resultante com o nome apropriado.

![Saída](merge-pdf-files_4.png)
