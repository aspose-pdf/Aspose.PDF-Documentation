{{% alert color="primary" %}}

Aspose.PDF para SharePoint permite adicionar marca d'água a um documento PDF. O recurso adiciona uma marca d'água de texto no canto inferior esquerdo de cada página de um documento PDF adicionado à biblioteca.

## Texto de marca d'água no canto inferior esquerdo

![Adicionar marca d’água ao PDF – exemplo 1](add-watermark-to-pdf_1.jpg)

{{% /alert %}}

{{% alert color="primary" %}}

Para ativar o recurso de marca d'água para uma biblioteca específica:

1. Clique em **Configurações de marca d'água** na guia **Ferramentas Aspose** na caixa de diálogo **Ferramentas de biblioteca**.

   **Ferramentas de biblioteca**

![Adicionar marca d’água ao PDF – exemplo 2](add-watermark-to-pdf_2.jpg)

As configurações de marca d'água são específicas da lista, então você pode escolher diferentes configurações de marca d'água para diferentes bibliotecas. A captura de tela a seguir mostra a caixa de diálogo Configurações de marca d'água para a biblioteca **Documentos compartilhados**.

## Configurações de marca d’água

![Adicionar marca d’água ao PDF – exemplo 3](add-watermark-to-pdf_3.jpg)

- Selecione **Ativar marca d'água para** para ativar o recurso de marca d'água para uma lista específica.
- **Texto de marca d’água** – o texto que aparecerá na página como marca d’água.
- **Fonte** – a fonte usada para a marca d’água.
- **Cor** – a cor da marca d'água.

Depois de ativar a marca d'água para uma biblioteca específica, o Aspose.PDF adiciona marcas d'água a cada documento PDF adicionado a essa biblioteca.
