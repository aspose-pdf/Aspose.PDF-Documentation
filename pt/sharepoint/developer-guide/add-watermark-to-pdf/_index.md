{{% alert color="primary" %}}

Aspose.PDF for SharePoint permite que você adicione marca d'água a um documento PDF. O recurso adiciona uma marca d'água de texto no canto inferior esquerdo de cada página de um documento PDF adicionado à biblioteca.

## Texto da marca d'água no canto inferior esquerdo

{{% alert color="primary" %}}

Para habilitar o recurso de marca d'água para uma biblioteca específica:

1. Clique **Watermark Settings** na aba **Aspose Tools** na caixa de diálogo **Library Tools**.

   **Library Tools**

![Adicionar Marca d'água ao PDF - exemplo 2](add-watermark-to-pdf_2.jpg)

As configurações de marca d'água são específicas da lista, portanto você pode escolher configurações de marca d'água diferentes para diferentes bibliotecas. A captura de tela a seguir mostra a caixa de diálogo Watermark Settings para a biblioteca **Shared Documents**.

## Configurações de marca d'água

![Adicionar marca d'água ao PDF-example 3](add-watermark-to-pdf_3.jpg)

- Selecione **Enable watermarking for** para ativar o recurso de marca d'água para uma lista específica.
- **Watermark text** – o texto que aparecerá na página como marca d'água.
- **Font** – a fonte usada para a marca d'água.
- **Color** – a cor da marca d'água.

Depois de ativar a marca d'água para uma biblioteca específica, Aspose.PDF adiciona marcas d'água a cada documento PDF adicionado a essa biblioteca.
