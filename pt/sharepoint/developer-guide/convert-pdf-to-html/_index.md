{{% alert color="primary" %}}

Aspose.PDF for SharePoint suporta recurso para converter documento PDF da biblioteca de documentos do SharePoint para o formato HTML. Neste artigo, demonstraremos a conversão de PDF para HTML.

{{% /alert %}}

## Convertendo documento PDF para HTML

Converter documento PDF da biblioteca de documentos do SharePoint para HTML conforme a seguir:

1. Clique **Convert to HTML** no menu ECB do documento PDF.

![Converter PDF para HTML‑exemplo 1](convert-pdf-to-html_1.png)

2. Baixe e salve o arquivo HTML resultante no disco.

![Converter PDF para HTML‑exemplo 2](convert-pdf-to-html_2.png)
