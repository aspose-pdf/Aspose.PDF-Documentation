{{% alert color="primary" %}}

Aspose.PDF para SharePoint suporta recurso para converter a biblioteca de documentos do SharePoint em formato de documento PDF para o formato HTML. Neste artigo iremos demonstrar a conversão de PDF para HTML.

{{% /alert %}}

## Convertendo documento PDF para HTML

Converta o documento PDF da biblioteca de documentos do SharePoint para HTML da seguinte forma:

1. Clique em **Converter para HTML** no menu BCE do documento PDF.

![Converter PDF em HTML – exemplo 1](convert-pdf-to-html_1.png)

2. Baixe e salve o arquivo HTML resultante em disco.

![Converter PDF em HTML – exemplo 2](convert-pdf-to-html_2.png)
