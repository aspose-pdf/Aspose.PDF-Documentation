## Adicionar código de barras a um arquivo PDF

{{% alert color="primary" %}}

Aspose.PDF for SharePoint permite que você adicione um código de barras a um documento PDF. Os usuários podem adicionar um código de barras ao canto inferior esquerdo de cada página de um documento PDF adicionado à biblioteca. A imagem abaixo dá uma ideia de como pode ficar um documento PDF com um código de barras adicionado.

### Código de barras no canto inferior esquerdo

![Adicionar Código de Barras a um Arquivo PDF-exmample 1](add-barcode-to-a-pdf-file_1.png)

{{% /alert %}}

{{% alert color="primary" %}}

Para habilitar o recurso de código de barras para uma biblioteca específica, use o botão **Watermark Settings** na aba **Aspose PDF Watermark Tools** em **Library Tools**, conforme mostrado abaixo.

### Configurações de marca d'água PDF

![Adicionar Código de Barras a um Arquivo PDF-example 2](add-barcode-to-a-pdf-file_2.png)

Depois de habilitar códigos de barras para a biblioteca específica, Aspose.PDF for SharePoint adiciona um código de barras a qualquer documento PDF adicionado a essa biblioteca.

{{% /alert %}}
