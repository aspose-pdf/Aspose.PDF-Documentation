## Bem-vindo à Documentação do Aspose.PDF for SharePoint!

Aspose.PDF for SharePoint é uma solução que permite que os usuários exportem listas, itens de lista e páginas Wiki do SharePoint para o formato de arquivo PDF.

{{% /alert %}}

{{% alert color="primary" %}}
Aspose.PDF for SharePoint foi projetado para ser usado com o Microsoft SharePoint Server 2010. Não há requisitos de sistema adicionais além do Microsoft SharePoint Server 2010.

Esta documentação descreve o Aspose.PDF for SharePoint [recursos](/pdf/sharepoint/features/), [instalação](/pdf/sharepoint/install-aspose-pdf-for-sharepoint/), [limitações de avaliação](/pdf/sharepoint/evaluate-aspose-pdf/), [licenciamento](/pdf/sharepoint/license-aspose-pdf-for-sharepoint/), casos de uso comuns e configurações.
