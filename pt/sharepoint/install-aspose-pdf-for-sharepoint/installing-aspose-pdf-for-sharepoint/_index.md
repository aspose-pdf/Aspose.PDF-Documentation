{{% alert color="primary" %}}

Aspose.PDF for SharePoint pode ser baixado como o arquivo Aspose.PDF.SharePoint.zip.

{{% /alert %}}

Este arquivo contém:

- Aspose.PDF.SharePoint.wsp
  Arquivo de solução SharePoint. Aspose.PDF for SharePoint é empacotado como uma solução SharePoint para facilitar a implantação/retração e a ativação/desativação de recursos em toda a fazenda de servidores.
- Aspose_LicenseAgreement.rtf

**Contrato de licença do usuário final:**

- Aspose.PDF for SharePoint.pdf

**Documentação do usuário:**

- Aspose.PDF for SharePoint Documentação.chm

**Documentação do usuário com referência da API Pública:**

- setup.exe

**Programa de instalação:**

- setup.exe.config

**Arquivo de configuração da instalação:**

O programa de instalação verifica as seguintes condições antes de prosseguir:

- O SharePoint 2010 está instalado.
- O usuário tem permissão para instalar soluções do SharePoint.
- O banco de dados do SharePoint está online.
- O serviço de Administração do SharePoint está iniciado.
- O serviço de Timer do SharePoint está iniciado. O serviço de Administração do SharePoint e o serviço de Timer são necessários porque algumas ações de instalação dependem de um trabalho de timer para ser propagado a todos os servidores na fazenda de servidores.

**Para instalar Aspose.PDF for SharePoint:**

- Descompacte o zip Aspose.PDF.SharePoint para a unidade local.
- Execute setup.exe e siga as instruções na tela.

**O programa de instalação realiza as seguintes ações:**

- Verifique os pré‑requisitos de instalação. A instalação não continuará se alguma verificação falhar.

![Verificar Pré‑requisitos de Instalação](installing-aspose-pdf-for-sharepoint_1.png)

- Exibir Contrato de Licença de Usuário Final. O usuário deve aceitar o contrato para prosseguir.

![Exibir Contrato de Licença](installing-aspose-pdf-for-sharepoint_2.png)

- Exibir caixa de diálogo de seleção de destino de implantação. O usuário seleciona aplicações web e coleções de sites onde o recurso será ativado. Veja a figura abaixo.

![Exibir Seleção de Destino de Implantação](installing-aspose-pdf-for-sharepoint_3.png)

- Implantar o recurso na fazenda de servidores.

![Implantar Recurso](installing-aspose-pdf-for-sharepoint_4.png)

- Ative o recurso para as coleções de sites selecionadas e configure seus aplicativos web pai.
- Exiba uma lista de aplicativos web e coleções de sites onde o recurso foi implantado e ativado.

![Exibir Recursos Implantados](installing-aspose-pdf-for-sharepoint_5.png)
