{{% alert color="primary" %}}

Para desinstalar o Aspose.PDF for SharePoint, basta executar o programa de configuração. Se o Aspose.PDF for SharePoint já estiver instalado, o programa de configuração sugere removê-lo.

![Desinstalar Aspose.PDF for SharePoint](uninstalling-aspose-pdf-for-sharepoint_1.png)

Durante a desinstalação, o programa de configuração desativa o recurso Aspose.PDF for SharePoint para todas as coleções de sites e retira a solução da fazenda de servidores.

{{% /alert %}}
