{{% alert color="primary" %}}

Durante a instalação, o Aspose.PDF for SharePoint é ativado para todos os conjuntos de sites selecionados. Após a instalação, você pode usar o menu Ações do Site no site raiz de um conjunto de sites para ativar e desativar o Aspose.PDF para SharePoint.

{{% /alert %}}
