{{% alert color="primary" %}}

Para desinstalar o Aspose.PDF for SharePoint, basta executar o programa de instalação. Se o Aspose.PDF for SharePoint já estiver instalado, o programa de instalação sugere removê-lo.

![Desinstalar Aspose.PDF para SharePoint](uninstalling-aspose-pdf-for-sharepoint_1.png)

Durante a desinstalação, o programa de instalação desativa o recurso Aspose.PDF for SharePoint para todos os conjuntos de sites e retira a solução do farm de servidores.

{{% /alert %}}
