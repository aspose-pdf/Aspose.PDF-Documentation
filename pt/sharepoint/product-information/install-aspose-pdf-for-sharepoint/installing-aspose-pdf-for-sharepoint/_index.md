{{% alert color="primary" %}}

Aspose.PDF for SharePoint is downloadable as Aspose.PDF.SharePoint.zip archive.

{{% /alert %}}

Este arquivo contém:

- Aspose.PDF.SharePoint.wsp
  Arquivo de solução do SharePoint. Aspose.PDF para SharePoint é empacotado como uma solução SharePoint para facilitar a implantação/retração e ativação/desativação de recursos em todo o farm de servidores.
- Aspose_LicenseAgreement.rtf

**Contrato de licença do usuário final:**

- Aspose.PDF para SharePoint.pdf

**Documentação do usuário:**

- Aspose.PDF para documentação do SharePoint.chm

**Documentação do usuário com referência de API pública:**

- setup.exe

**Programa de configuração:**

- setup.exe.config

**Arquivo de configuração de instalação:**

O programa de configuração verifica as seguintes condições antes de continuar:

- O SharePoint 2010 está instalado.
- O usuário tem permissão para instalar soluções do SharePoint.
- O banco de dados do SharePoint está online.
- O serviço de administração do SharePoint é iniciado.
- O serviço de timer do SharePoint foi iniciado. O serviço de Administração do SharePoint e o serviço de Timer são necessários porque algumas ações de configuração dependem de um trabalho de timer para se propagar para todos os servidores no farm de servidores.

**Para instalar o Aspose.PDF para SharePoint:**

- Descompacte o zip Aspose.PDF.SharePoint na unidade local.
- Execute setup.exe e siga as instruções na tela.

**O programa de configuração executa as seguintes ações:**

- Verifique os pré-requisitos de instalação. A instalação não continuará se alguma verificação falhar.

![Check Installation Prerequisites](installing-aspose-pdf-for-sharepoint_1.png)

- Exibir Contrato de Licença do Usuário Final. O usuário deve aceitar o acordo para prosseguir.

![Display License Agreement](installing-aspose-pdf-for-sharepoint_2.png)

- Exibir caixa de diálogo de seleção de destino de implantação. O usuário seleciona aplicativos da web e conjuntos de sites onde o recurso será ativado. Veja a figura abaixo.

![Display Deployment Target Selection](installing-aspose-pdf-for-sharepoint_3.png)

- Implante o recurso no farm de servidores.

![Deploy Feature](installing-aspose-pdf-for-sharepoint_4.png)

- Ative o recurso para os conjuntos de sites selecionados e configure seus aplicativos Web pai.
- Exiba uma lista de aplicativos Web e conjuntos de sites onde o recurso foi implementado e ativado.

![Display Deployed Features](installing-aspose-pdf-for-sharepoint_5.png)
