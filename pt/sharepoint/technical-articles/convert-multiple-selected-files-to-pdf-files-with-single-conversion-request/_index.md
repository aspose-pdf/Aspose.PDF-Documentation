Este artigo mostra como converter vários arquivos selecionados em arquivos PDF com uma única operação de conversão usando Aspose.PDF for SharePoint.

{{% /alert %}}

## Converter Vários Arquivos Selecionados para PDF

{{% alert color="primary" %}}

Para converter vários arquivos selecionados, execute as seguintes etapas:

1. Selecione os arquivos a serem convertidos

![Selecionar Arquivos](convert-multiple-selected-files-to-pdf-files-with-single-conversion-request_1.jpg)

2. Clique na guia Aspose Tools em Library Tools

![Clique em Aspose Tools](convert-multiple-selected-files-to-pdf-files-with-single-conversion-request_2.jpg)

3. Clique em Convert to PDF para converter todos os arquivos selecionados em arquivos PDF resultantes.

![Converter para PDF](convert-multiple-selected-files-to-pdf-files-with-single-conversion-request_3.jpg)

4. Será exibido um prompt para baixar os arquivos convertidos.

![Baixar arquivos convertidos](convert-multiple-selected-files-to-pdf-files-with-single-conversion-request_4.jpg)

![Baixar arquivos convertidos](convert-multiple-selected-files-to-pdf-files-with-single-conversion-request_5.jpg)
