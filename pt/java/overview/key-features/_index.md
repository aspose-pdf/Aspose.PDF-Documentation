Abstract: Aspose.PDF para Python via .NET é uma biblioteca robusta que oferece amplos recursos para gerenciamento e manipulação de documentos PDF. Ele suporta padrões PDF estabelecidos e facilita a leitura e exportação de PDFs em vários formatos de imagem, como BMP, GIF, JPEG e PNG. Os usuários podem configurar propriedades do documento, atributos de página e gerenciar texto, parágrafos, hiperlinks, gráficos e anexos. A biblioteca é excelente em recursos de conversão, permitindo a transformação perfeita de PDFs em formatos Word, Excel, PowerPoint e HTML, entre outros, ao mesmo tempo que converte vários formatos de volta para PDF.

## Recursos Gerais

- Escrito totalmente em Java, funciona com JDK 1.8 e superior
- Suporta todos os aplicativos Java
- Referência de API em formato JavaDoc
- Suporte a sistema operacional de 32 bits.
- Suporte a sistema operacional de 64 bits.

## Versões PDF suportadas

Aspose.PDF para Java suporta versões de PDF 1.2, 1.3, 1.4, 1.5, 1.6 e 1.7.

## Gráfico

- São suportadas diferentes formas de gráficos, como linha, círculo, arco e curva.
- Os gráficos podem ser desenhados em qualquer local da página especificado por coordenadas.
- Os gráficos podem ser girados, dimensionados ou preenchidos, e estilos de linhas tracejadas e politraçadas podem ser definidos.
- Os gráficos são desenhados com base em coordenadas e possuem posição obsoleta em vez de relativa.
- Espaços de cores CMYK e cinza são suportados.
