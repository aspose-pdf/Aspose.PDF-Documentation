Abstract: O Aspose.PDF for Python via .NET é uma biblioteca robusta que oferece recursos extensivos para gerenciar e manipular documentos PDF. Ela suporta padrões estabelecidos de PDF e facilita a leitura e exportação de PDFs para vários formatos de imagem, como BMP, GIF, JPEG e PNG. Os usuários podem configurar propriedades do documento, atributos de página e gerenciar texto, parágrafos, hyperlinks, gráficos e anexos. A biblioteca se destaca nas capacidades de conversão, permitindo a transformação perfeita de PDFs para formatos Word, Excel, PowerPoint e HTML, entre outros, além de converter vários formatos de volta para PDF.

## Recursos gerais

- Escrito completamente em Java, funciona com JDK 1.8 e superior
- Suporta todas as aplicações Java
- Referência da API em formato JavaDoc
- Suporte a sistemas operacionais de 32 bits.
- Suporte a sistemas operacionais de 64 bits.

## Versões de PDF suportadas

Aspose.PDF for Java suporta as versões de PDF 1.2, 1.3, 1.4, 1.5, 1.6 e 1.7.

## Gráfico

- São suportados diferentes tipos de gráficos, como linha, círculo, arco e curva.
- Os gráficos podem ser desenhados em qualquer localização da página especificada por coordenadas.
- Os gráficos podem ser rotacionados, dimensionados ou preenchidos, e estilos de linha tracejada e poli‑tracejada podem ser definidos.
- Os gráficos são desenhados com base em coordenadas e possuem posição obsoleta em vez de relativa.
- Os espaços de cores CMYK e Cinza são suportados.
