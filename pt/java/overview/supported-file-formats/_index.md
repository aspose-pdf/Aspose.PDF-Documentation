Abstract: Este artigo fornece uma tabela abrangente detalhando os formatos de arquivo que o Aspose.PDF para Python pode suportar. Ele descreve os recursos da biblioteca para carregar e salvar vários tipos de documentos, oferecendo insights sobre sua versatilidade para gerenciar diferentes formatos de arquivo. Os formatos abordados incluem tipos conhecidos como PDF, EPUB, HTML e XML, que podem ser carregados e salvos pela biblioteca. Ele também suporta formatos de imagem como JPEG, PNG e TIFF para ambas as operações. No entanto, alguns formatos como CGM, MHT, PCL, PS, XSLFO e MD estão disponíveis apenas para carregamento, enquanto outros como XLS, XLSX, PPTX, DOC, DOCX e MobiXML estão disponíveis apenas para salvamento. Esta tabela serve como um guia prático para usuários que buscam entender a compatibilidade de formato do Aspose.PDF para Python, destacando seus pontos fortes e limitações no suporte a formatos de documentos e imagens.
