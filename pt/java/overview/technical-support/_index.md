Aspose.PDF permite que você use suporte técnico gratuito para todos os seus produtos. Se você tiver dúvidas sobre o Aspose.PDF, verifique o próximo artigo:

- A fonte de suporte mais popular é [Aspose.Forums](https://forum.aspose.com/). Na seção [fórum Aspose.PDF](https://forum.aspose.com/c/pdf/10), você pode fazer sua pergunta e obter uma resposta o mais rápido possível.

- Você deve saber que o Aspose não fornece suporte técnico por telefone. Você pode ligar está disponível apenas para dúvidas sobre vendas e compras.

- Lembre-se de que temos diferenças de fuso horário, isso pode afetar a velocidade das respostas para você.

Se precisar de ajuda com um problema com Aspose.PDF, siga as próximas recomendações para garantir que seja resolvido da maneira mais eficiente:

- Aspose hospeda todas as APIs Java em [Repositório Aspose](https://repository.aspose.com/webapp/#/artifacts/browse/tree/General/repo/com/aspose/aspose-pdf). Você pode usar facilmente a API Aspose.PDF for Java diretamente em seus projetos Maven com configurações simples

- Talvez a solução para o seu problema já tenha sido discutida e tenha solução, para isso estude o fórum e a documentação, verifique [Referência da API](https://reference.aspose.com/pdf/java) antes de reportar o problema.

- Ao formular sua pergunta, inclua o documento original e possivelmente um fragmento do seu código que causa o problema. Você pode compactar esses arquivos em um documento, se houver vários.

- Não se preocupe, somente você e os desenvolvedores do Aspose têm acesso aos arquivos fixos.
