ZUGFeRD combina uma fatura em PDF legível com dados XML estruturados incorporados ao documento. No conjunto de exemplos Java atual, o fluxo de trabalho coberto é anexar o XML da fatura a um PDF e converter o resultado em `PDF_A_3A`.
