ZUGFeRD combina uma fatura PDF legível por humanos com dados XML estruturados incorporados ao documento. No conjunto atual de exemplos Java, o fluxo de trabalho coberto é anexar o XML da fatura a um PDF e converter o resultado para `PDF_A_3A`.
