As anotações são elementos PDF interativos que permitem adicionar notas, destacar texto, desenhar formas, criar links, aplicar redações e enriquecer fluxos de trabalho de revisão de documentos em arquivos PDF existentes.

Use esta seção para:

- [Adicionar, excluir e obter anotação](/pdf/java/add-delete-and-get-annotation/) para famílias de anotações agrupadas.
- [Importar e exportar anotações](/pdf/java/import-export-annotations/) para copiar anotações entre arquivos PDF.
