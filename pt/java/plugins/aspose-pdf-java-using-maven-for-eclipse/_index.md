## Introdução

### EclipseIDE

Eclipse IDE é um famoso Java Integrated Development Environment (IDE). O IDE é definitivamente o produto mais conhecido do projeto Eclipse Open Source. Hoje é o ambiente de desenvolvimento líder para Java, com uma participação de mercado de aproximadamente 60%.

O Eclipse IDE pode ser estendido com componentes de software adicionais. O Eclipse chama esses componentes de software de Plug-ins. Vários projetos e empresas de código aberto estenderam o Eclipse IDE ou criaram aplicativos independentes (Eclipse RCP) sobre a estrutura Eclipse.

### Aspose.PDF para Java

[Aspose.PDF for Java](https://products.aspose.com/pdf/java/)é uma API robusta de criação de documentos PDF que permite que seus aplicativos Java leiam, escrevam e manipulem documentos PDF sem usar o Adobe Acrobat.

Aspose.PDF para Java oferece uma riqueza incrível de recursos, incluindo opções de compactação de PDF, criação e manipulação de tabelas, suporte a gráficos, funções de imagem, extensa funcionalidade de hiperlink, controles de segurança estendidos e manipulação de fontes personalizadas.

### Aspose.PDF Java (Maven) para Eclipse

- Aspose.PDF Java (Maven) para Eclipse é um plug-in para **Eclipse IDE** da **Aspose.** Este plug-in é destinado a desenvolvedores que usam a plataforma Maven para desenvolvimentos Java e desejam usar Aspose.PDF para Java em seus projetos. O plug-in permite criar projetos maven para usar Aspose.PDF para Java API e também baixar [Exemplos de código](https://github.com/aspose-pdf/Aspose.Pdf-for-Java) da API.
- O plug-in fornece os seguintes recursos para trabalhar confortavelmente com Aspose.PDF for Java API dentro do **Eclipse IDE**:

**ASSISTENTES**:
O plugin contém dois assistentes

**Projeto Aspose.PDF Maven (assistente)**

- Este assistente de Novo Projeto permite que os desenvolvedores criem um projeto **Maven** para usar Aspose.PDF para Java em Novo -> Projeto -> Maven-> Projeto Aspose.PDF Maven.
- A referência da dependência maven do Aspose.PDF para Java API é obtida automaticamente do [Aspose Cloud Maven Repository](https://repository.aspose.com/webapp/#/artifacts/browse/tree/General/repo) e adicionada ao pom.xml.
- O projeto criado sempre conterá a versão mais recente disponível **Maven** Dependency for Aspose.PDF for Java API.
- As etapas do assistente também apresentam a opção de download de [Exemplos de código](https://github.com/aspose-pdf/Aspose.Pdf-for-Java) para usar Aspose.PDF para API Java.
Exemplo de código Aspose.PDF (assistente)

- Este assistente de novo arquivo permite copiar os [exemplos de código](https://github.com/aspose-pdf/Aspose.Pdf-for-Java) baixados em seu projeto para usar Aspose.PDF para Java em Novo -> Outro -> Java -> Exemplo de código Aspose.PDF.
- As amostras disponíveis são exibidas em formato de árvore, onde o usuário pode selecioná-las categoricamente.
- Todos os exemplos dentro da categoria selecionada serão copiados para a pasta do pacote "**com.aspose.pdf.examples**" do projeto junto com os recursos necessários dentro da pasta "**src/main/resources**" necessários para executar os exemplos.
- Exemplos de código de Aspose.PDF para API Java destinam-se a demonstrar as várias funções da API.
- O assistente também procurará e atualizará os exemplos de código recentemente disponíveis) no repositório de exemplos Aspose.PDF para Java.

### Como aplicar a Licença Aspose?

Este plugin usa uma versão de avaliação do Aspose.PDF. Quando estiver satisfeito com sua avaliação, você poderá adquirir uma licença no [site Aspose](https://purchase.aspose.com/buy).
Para remover a mensagem de avaliação e as limitações de recursos, uma licença do produto deve ser aplicada. Você receberá um arquivo de licença após adquirir o produto. Siga as etapas abaixo para aplicar a licença

- Certifique-se de que o arquivo de licença tenha o nome Aspose.PDF.Java.lic
- Coloque o arquivo **Aspose.PDF.Java.lic** na pasta que contém o Aspose.PDF.jar
- Use o seguinte código para ativar a licença:

{{< highlight java >}}

 Licença licença = nova Licença();

licença.setLicense("Aspose.PDF.Java.lic");

{{< /highlight >}}

### Como configurar o código-fonte do Aspose.PDF Java (Maven) para Eclipse

As etapas simples abaixo levarão suavemente à configuração bem-sucedida do código-fonte do plug-in **"Aspose.PDF Java (Maven) para Eclipse"** no Eclipse IDE

1. Baixe / clone o código-fonte.
1. Escolha **Arquivo** > Importar > Geral > Projetos Existentes no Workspace
1. Navegue até a fonte do projeto mais recente que você baixou
1. Selecione o projeto Eclipse que você deseja importar
1. Clique em Concluir
1. O código do plugin Aspose.PDF Java para Eclipse agora está pronto para ser aprimorado.
