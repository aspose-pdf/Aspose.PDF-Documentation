## Introdução

### Eclipse IDE

Eclipse IDE é um famoso Ambiente de Desenvolvimento Integrado (IDE) para Java. A IDE é definitivamente o produto mais conhecido do projeto de código aberto Eclipse. Hoje, é o principal ambiente de desenvolvimento para Java, com uma participação de mercado de aproximadamente 60%.

O Eclipse IDE pode ser estendido com componentes de software adicionais. O Eclipse chama esses componentes de software de Plug-ins. Vários projetos de código aberto e empresas estenderam o Eclipse IDE ou criaram aplicações independentes (Eclipse RCP) sobre a estrutura Eclipse.

### Aspose.PDF for Java

[Aspose.PDF for Java](https://products.aspose.com/pdf/java/)é uma API robusta de criação de documentos PDF que permite que suas aplicações Java leiam, escrevam e manipulem documentos PDF sem usar o Adobe Acrobat.

Aspose.PDF for Java oferece uma incrível variedade de recursos, incluindo opções de compressão de PDF, criação e manipulação de tabelas, suporte a gráficos, funções de imagem, funcionalidade extensa de hyperlinks, controles de segurança avançados e manipulação de fontes personalizadas.

### Aspose.PDF Java (Maven) for Eclipse

- Aspose.PDF Java (Maven) for Eclipse é um Plugin para **Eclipse IDE** da **Aspose.** Este Plugin destina‑se a desenvolvedores que utilizam a plataforma Maven para desenvolvimento Java e que desejam usar o Aspose.PDF for Java em seus projetos. O Plugin permite que você crie projetos Maven para usar a API Aspose.PDF for Java e também faça download [Exemplos de Código](https://github.com/aspose-pdf/Aspose.Pdf-for-Java) da API.
- O plugin fornece os seguintes recursos para trabalhar com a API Aspose.PDF for Java dentro do **Eclipse IDE** confortavelmente:

**ASSISTENTES**:
O plugin contém dois assistentes

**Aspose.PDF Maven Project (assistente)**

- Este assistente Novo Projeto permite que os desenvolvedores criem um **Maven** projeto para usar Aspose.PDF for Java a partir de Novo -> Projeto -> Maven -> Aspose.PDF Maven Project.
- A referência da dependência Maven da API Aspose.PDF for Java é buscada automaticamente de [Repositório Maven da Aspose Cloud](https://repository.aspose.com/webapp/#/artifacts/browse/tree/General/repo) e é adicionada no pom.xml.
- O projeto criado sempre conterá a versão mais recente disponível da **Maven** Dependency para a API Aspose.PDF for Java.
- As etapas do assistente também apresentam a opção de download [Exemplos de Código](https://github.com/aspose-pdf/Aspose.Pdf-for-Java) para usar a API Aspose.PDF for Java.
Exemplo de Código Aspose.PDF (assistente)

- Este Assistente Novo Arquivo permite que você copie o baixado [Exemplos de Código](https://github.com/aspose-pdf/Aspose.Pdf-for-Java) para o seu projeto para usar o Aspose.PDF for Java a partir de Novo -> Outro -> Java -> Exemplo de Código Aspose.PDF.
- Amostras disponíveis são exibidas em formato de árvore de onde o usuário pode selecioná‑las por categoria.
- Todos os exemplos dentro da categoria selecionada serão copiados para a pasta do pacote "**com.aspose.pdf.examples**" do projeto, juntamente com os recursos necessários dentro da pasta "**src/main/resources**" necessários para executar os exemplos.
- Exemplos de Código da API Aspose.PDF for Java destinam‑se a demonstrar as várias funções da API.
- O assistente também buscará e atualizará novos Exemplos de Código disponíveis) do repositório de exemplos Aspose.PDF for Java.

### Como aplicar a Licença Aspose?

Este Plugin usa uma versão de avaliação do Aspose.PDF. Quando estiver satisfeito com sua avaliação, você pode comprar uma licença em [Site da Aspose](https://purchase.aspose.com/buy).
Para remover a mensagem de avaliação e as limitações de recursos, deve ser aplicada uma licença do produto. Você receberá um arquivo de licença após comprar o produto. Por favor, siga os passos abaixo para aplicar a licença.

- Certifique-se de que o arquivo de licença esteja nomeado como Aspose.PDF.Java.lic
- Coloque o arquivo **Aspose.PDF.Java.lic** na pasta que contém o Aspose.PDF.jar
- Use o código a seguir para ativar a licença:

{{< highlight java >}}

 License license = new License();

license.setLicense("Aspose.PDF.Java.lic");

### Como configurar o código-fonte do Aspose.PDF Java (Maven) for Eclipse

Abaixo, etapas simples levarão de forma tranquila à configuração bem-sucedida do código-fonte do plug-in **"Aspose.PDF Java (Maven) for Eclipse"** no Eclipse IDE

1. Baixe / Clone o código-fonte.
1. Escolha **File** > Import > General > Existing Projects into Workspace
1. Navegue até o código-fonte do projeto mais recente que você baixou
1. Selecione o Projeto Eclipse que você deseja importar
1. Clique em Concluir
1. O código do plug-in Aspose.PDF Java for Eclipse está agora pronto para ser aprimorado.
