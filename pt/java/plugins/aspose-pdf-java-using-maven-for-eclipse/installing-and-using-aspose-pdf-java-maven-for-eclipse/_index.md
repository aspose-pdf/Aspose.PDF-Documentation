## Instalar

**Aspose.PDF Java (Maven) for Eclipse** plugin pode ser facilmente instalado a partir da aba **Plugin** disponível na caixa de diálogo de Plugins.

- Para abri-lo, selecione **Plugins** no menu **Tools** do Eclipse.

![todo:image_alt_text](https://i.imgur.com/PCMRMUT.png)

- Isso adiciona o **Aspose.PDF Maven Project** no assistente Novo Projeto e o **Aspose.PDF Code Example** no assistente Novo Arquivo do IDE Eclipse.

## Usar

### Aspose.PDF Maven Project (assistente)

Para criar **Maven Project** por assistente para usar [Aspose.PDF for Java API](http://www.aspose.com/java/pdf-component.aspx):

1. Selecione **New Project**.
1. Selecione **Aspose.PDF Maven Project** na categoria **Maven**.
1. Clique **Next**.

![todo:image_alt_text](https://i.imgur.com/6iywqND.png)

1. Forneça **Project Name, Location, GroupId, ArtifactId** e **Version** para o seu projeto Maven e clique **Finish.**

![todo:image_alt_text](https://i.imgur.com/zURjIn1.png)

1. Isso buscará o [Aspose.PDF for Java](http://www.aspose.com/java/pdf-component.aspx) mais recente [Dependência Maven](https://repository.aspose.com/webapp/#/artifacts/browse/tree/General/repo/com/aspose/aspose-pdf/) referência de [Repositório Maven da Aspose Cloud](https://repository.aspose.com/webapp/#/artifacts/browse/tree/General/repo) e configure‑o em **pom.xml**. Se você optou por **Também Baixar Exemplos de Código,** o download dos **Exemplos de Código** também começará a partir de [Repositório de Exemplos de API Aspose.PDF para Java.](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples)
1. O seguinte Projeto **Maven** será criado em sua **Eclipse IDE** ao concluir o assistente:

![todo:image_alt_text](https://i.imgur.com/xRfHrku.png)

1. O **Maven Project** criado está configurado para usar a **Aspose.PDF for Java API** e pronto para ser aprimorado de acordo com os requisitos do seu Projeto.
   Se você optou por baixar [Exemplos de Código](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples), você pode usar **Aspose.PDF Code Example (wizard)** para importar os **Code Examples** necessários de [Aspose.PDF for Java](http://www.aspose.com/java/pdf-component.aspx) API para o seu projeto.

### Aspose.PDF Code Example (wizard)

**Aspose.PDF Code Example wizard** permite que você experimente muitos exemplos fornecidos para [Aspose.PDF for Java](http://www.aspose.com/java/pdf-component.aspx) API.

{{% alert color="primary" %}}

Para poder usar **Aspose.PDF Code Example wizard** confortavelmente: recomenda‑se sempre selecionar **Also Download Code Examples** ao criar **Maven Project** no **Aspose.PDF Maven Project** **wizard**,

{{% /alert %}}

Para usar os exemplos, basta:

1. Clique em **New File** no **Eclipse**.
1. Escolha o seu projeto e então selecione **Aspose.PDF Code Example** na categoria **Java**.
1. Clique **Next**.

![todo:image_alt_text](https://i.imgur.com/AuWybe8.png)

 Expanda a árvore para selecionar a categoria **Code Example** e clique em **Finish**.

![todo:image_alt_text](https://i.imgur.com/PToFZjJ.png)

1. Isso copiará os arquivos Java da categoria selecionada **Code Examples** para o projeto sob o pacote **com.aspose.pdf.examples**. Também quaisquer recursos necessários pelos Code Examples serão copiados para a pasta **src/main/resources**.
1. Revise o código de exemplo, compile e execute.
1. Agora você pode testar outros exemplos e começar a construir sua própria aplicação usando [Aspose.PDF for Java API](http://www.aspose.com/java/pdf-component.aspx)
