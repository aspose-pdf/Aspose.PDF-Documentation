## Instalando

O plug-in **Aspose.PDF Java (Maven) para Eclipse** pode ser facilmente instalado na guia **Plugin** Disponível na caixa de diálogo Plug-in.

- Para abri-lo, selecione **Plugins** no menu **Ferramentas** no Eclipse.

![todo:image_alt_text](https://i.imgur.com/PCMRMUT.png)

- Isso adiciona o **Projeto Aspose.PDF Maven** no assistente de Novo Projeto e **Exemplo de código Aspose.PDF** no assistente de Novo Arquivo do Eclipse IDE.

## Usando

### Projeto Aspose.PDF Maven (assistente)

Para criar **Projeto Maven** pelo assistente para usar [Aspose.PDF for Java API](http://www.aspose.com/java/pdf-component.aspx):

1. Selecione **Novo Projeto**.
1. Selecione **Projeto Aspose.PDF Maven** na categoria **Maven**.
1. Clique em **Próximo**.

![todo:image_alt_text](https://i.imgur.com/6iywqND.png)

1. Forneça **Nome do projeto, localização, GroupId, ArtifactId** e **Versão** para seu projeto Maven e clique em **Concluir.**

![todo:image_alt_text](https://i.imgur.com/zURjIn1.png)

1. Isso recuperará a referência [Aspose.PDF for Java](http://www.aspose.com/java/pdf-component.aspx) mais recente [Maven Dependency](https://repository.aspose.com/webapp/#/artifacts/browse/tree/General/repo/com/aspose/aspose-pdf/) do [Aspose Cloud Maven Repository](https://repository.aspose.com/webapp/#/artifacts/browse/tree/General/repo) e a configurará em **pom.xml**. Se você optou por **Baixar também exemplos de código,** o download de **Exemplos de código** também começará no [Repositório de exemplos de API Aspose.PDF para Java.](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples)
1. O seguinte projeto **Maven** será criado em seu **Eclipse IDE** após a conclusão do assistente:

![todo:image_alt_text](https://i.imgur.com/xRfHrku.png)

1. O **Projeto Maven** criado está configurado para usar **Aspose.PDF para Java API** e pronto para ser aprimorado de acordo com os requisitos do projeto.
   Se você optou por baixar [Exemplos de código](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples), você pode usar **Exemplo de código Aspose.PDF (assistente)** para importar **Exemplos de código** necessários da API [Aspose.PDF para Java](http://www.aspose.com/java/pdf-component.aspx) para o seu projeto.

### Exemplo de código Aspose.PDF (assistente)

**O assistente de exemplo de código Aspose.PDF** permite que você experimente vários exemplos fornecidos para a API [Aspose.PDF for Java](http://www.aspose.com/java/pdf-component.aspx).

{{% alert color="primary" %}}

Para poder usar o **aspose.PDF Code Sample Wizard** confortavelmente: é recomendado sempre selecionar **Também baixar exemplos de código** ao criar o **Maven Project** no **Aspose.PDF Maven Project** **wizard**,

{{% /alert %}}

Para usar exemplos, basta:

1. Clique em **Novo arquivo** em **Eclipse**.
1. Escolha seu projeto e selecione **Exemplo de código Aspose.PDF** na categoria **Java**.
1. Clique em **Próximo**.

![todo:image_alt_text](https://i.imgur.com/AuWybe8.png)

 Expanda a árvore para selecionar a categoria **Exemplo de código** e clique em **Concluir**.

![todo:image_alt_text](https://i.imgur.com/PToFZjJ.png)

1. Isso copiará os arquivos Java **Exemplos de código** da categoria selecionada para o projeto no pacote **com.aspose.pdf.examples**. Além disso, quaisquer recursos necessários para os exemplos de código serão copiados para a pasta **src/main/resources**
1. Revise o código de exemplo, compile e execute.
1. Agora você pode testar outros exemplos e começar a construir seu próprio aplicativo usando [Aspose.PDF for Java API](http://www.aspose.com/java/pdf-component.aspx)
