## Apoiar

{{% alert color="primary" %}}

- Se você gosta de ver problemas conhecidos/relatados (pelos usuários ou pela equipe de controle de qualidade) no aplicativo.
- Ou você deseja relatar qualquer problema encontrado no aplicativo
- Tem alguma sugestão de melhoria ou gostaria de fazer alguma solicitação de recurso

Use qualquer um dos seguintes rastreadores de problemas do projeto:

- [Github](https://github.com/aspose-pdf/Aspose.PDF-for-Java/issues)

{{% /alert %}}

## Estenda e contribua

Aspose.PDF Java for Struts 1.3 é de código aberto e seu código-fonte está disponível nos principais sites de codificação social listados abaixo. Os desenvolvedores são incentivados a baixar o código-fonte e contribuir sugerindo ou adicionando novos recursos ou melhorando os existentes, para que outros também possam se beneficiar dele.

## Código Fonte

Você pode obter o código-fonte mais recente em um dos seguintes locais

- [CodePlex](https://asposepdfforstruts.codeplex.com)
- [Github](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Plugins/Aspose_Pdf_for_Struts)
