## Framework Web Apache Struts

O framework web Apache Struts é uma solução gratuita e de código aberto para criar aplicações web Java.

Aplicações web diferem de sites convencionais porque podem gerar uma resposta dinâmica. Muitos sites fornecem apenas páginas estáticas. Uma aplicação web pode interagir com bancos de dados e motores de lógica de negócios para personalizar uma resposta.

Uma maneira de separar responsabilidades em uma aplicação de software é usar uma arquitetura Model-View-Controller (MVC). O Modelo representa o código de negócios ou de banco de dados, a Visão representa o código de design da página, e o Controlador representa o código de navegação. O framework Struts foi projetado para ajudar os desenvolvedores a criar aplicações web que utilizam uma arquitetura MVC.

[Saiba mais](http://struts.apache.org/birdseye.html)

### Aspose.PDF for Java

Aspose.PDF for Java é um componente de criação de documentos PDF que permite que suas aplicações Java leiam, escrevam e manipulem documentos PDF sem usar o Adobe Acrobat.

Aspose.PDF for Java é um componente com preço acessível que oferece uma incrível quantidade de recursos, incluindo: opções de compressão de PDF, criação e manipulação de tabelas, suporte a gráficos, funções de imagem, funcionalidade extensa de hyperlink, controles de segurança avançados e manipulação de Font personalizada.

Aspose.PDF for Java permite criar arquivos PDF diretamente através da API fornecida e de modelos XML. Usar o Aspose.PDF for Java também permitirá adicionar recursos PDF às suas aplicações em pouco tempo.

## Aspose.Words Java for Struts 1.3

Aspose.Words Java for Struts 1.3 é um aplicativo web simples de livraria escrito usando Struts 1.3 e Maven.

- O aplicativo web tem a intenção de mostrar a integração e o uso de [Aspose.Words for Java](https://products.aspose.com/words/java/) dentro do framework Struts 1.3 e Maven.
- Ele roda em um contêiner web como Apache Tomcat e requer Maven para compilar o arquivo .war do aplicativo web para implantação.
- O caso de uso atual no aplicativo exporta registros da grade de livros para o formato de documento MS-WORD criando um documento MS-WORD, criando uma tabela nele e escrevendo textos/dados nele.

## Requisitos do Sistema

A seguir estão os requisitos do sistema para Aspose.PDF Java para aplicação web Struts 1.3:

- Java 1.6 ou superior instalado.
- Apache Tomcat Server 7 ou superior
- Maven 3
- Componente Aspose.PDF.

## Plataformas Suportadas

A seguir estão as plataformas suportadas:

- Aspose.PDF 10.4.0 ou superior.
- IDE Java (Eclipse, NetBeans, IntelliJ, ...).
