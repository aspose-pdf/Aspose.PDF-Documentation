## Estrutura Web Apache Struts

A estrutura da web Apache Struts é uma solução gratuita de código aberto para a criação de aplicativos da web Java.

Os aplicativos da Web diferem dos sites convencionais porque os aplicativos da Web podem criar uma resposta dinâmica. Muitos sites oferecem apenas páginas estáticas. Um aplicativo Web pode interagir com bancos de dados e mecanismos de lógica de negócios para personalizar uma resposta.

Uma maneira de separar preocupações em um aplicativo de software é usar uma arquitetura Model-View-Controller (MVC). O Modelo representa o código comercial ou do banco de dados, a Visualização representa o código de design da página e o Controlador representa o código de navegação. A estrutura Struts foi projetada para ajudar os desenvolvedores a criar aplicações web que utilizam uma arquitetura MVC.

[Saiba mais](http://struts.apache.org/birdseye.html)

### Aspose.PDF para Java

Aspose.PDF for Java é um componente de criação de documentos PDF que permite que seus aplicativos Java leiam, escrevam e manipulem documentos PDF sem usar o Adobe Acrobat.

Aspose.PDF para Java é um componente de preço acessível que oferece uma riqueza incrível de recursos, incluindo: opções de compactação de PDF, criação e manipulação de tabelas, suporte gráfico, funções de imagem, ampla funcionalidade de hiperlink, controles de segurança estendidos e manipulação de fontes personalizadas.

Aspose.PDF para Java permite que você crie arquivos PDF diretamente por meio da API fornecida e dos modelos XML. Usar Aspose.PDF para Java também permitirá que você adicione recursos de PDF aos seus aplicativos rapidamente.

## Aspose.Words Java para Struts 1.3

Aspose.Words Java for Struts 1.3 é um aplicativo simples baseado na web para uma livraria, escrito usando Struts 1.3 e Maven.

- A aplicação web pretende mostrar a integração e utilização de [Aspose.Words for Java](https://products.aspose.com/words/java/) dentro do Struts 1.3 e do framework Maven.
- Ele é executado em um contêiner da web como o Apache Tomcat e requer maven para construir o aplicativo da web .war para implantação.
- O caso de uso atual no aplicativo exporta registros da grade de livros para o formato de documento MS-WORD criando um documento MS-WORD, criando uma tabela nele e gravando textos/dados nele.

{{% alert color="primary" %}}

Aspose.Words for Java API é muito rico em recursos, no entanto, este aplicativo da web de demonstração mostra apenas uma fração disso! Para obter a lista completa de recursos do Aspose.Words for Java API, é altamente recomendável verificar a documentação da API em: <https://products.aspose.com/words/java/>

## Requisitos do sistema

A seguir estão os requisitos de sistema para o aplicativo da web Aspose.PDF Java for Struts 1.3:

- Java 1.6 ou superior instalado.
- Servidor Apache Tomcat 7 ou superior
- Maven 3
- Componente Aspose.PDF.

## Plataformas Suportadas

A seguir estão as plataformas suportadas:

- Aspose.PDF 10.4.0 ou superior.
- IDE Java (Eclipse, NetBeans, IntelliJ, ...).
