## Introdução

### IDE do NetBeans

NetBeans é um IDE Java completo escrito totalmente em Java. Destina-se principalmente ao desenvolvimento em Java, mas também oferece suporte a outras linguagens, em particular PHP, C/C++ e HTML5.

O NetBeans IDE permite desenvolver de forma rápida e fácil aplicativos Java para desktop, dispositivos móveis e web, bem como aplicativos HTML5 com HTML, JavaScript e CSS. É gratuito e de código aberto e possui uma grande comunidade de usuários e desenvolvedores em todo o mundo.

A equipe do NetBeans apoia ativamente o produto e busca sugestões de recursos da comunidade em geral. Cada lançamento é precedido por um tempo para testes e comentários da comunidade.

### Aspose.PDF para Java

[Aspose.PDF for Java](https://products.aspose.com/pdf/java/)é uma API robusta de criação de documentos PDF que permite que seus aplicativos Java leiam, escrevam e manipulem documentos PDF sem usar o Adobe Acrobat.

Aspose.PDF para Java oferece uma riqueza incrível de recursos, incluindo opções de compactação de PDF, criação e manipulação de tabelas, suporte a gráficos, funções de imagem, extensa funcionalidade de hiperlink, controles de segurança estendidos e manipulação de fontes personalizadas.

### Aspose.PDF Java para NetBeans (Maven)

- Aspose.PDF Java para NetBeans (Maven) é um plug-in para **NetBeans IDE** da **Aspose.** O plug-in destinado a desenvolvedores que usam a plataforma Maven para desenvolvimentos Java e desejam usar Aspose.PDF para Java em seus projetos. O plug-in permite criar projetos maven para usar Aspose.PDF para Java API e também baixar [Exemplos de código](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples)da API.

## ASSISTENTES

O plugin contém dois assistentes

### Projeto Aspose.PDF Maven (assistente)

- Este assistente de Novo Projeto permite que os desenvolvedores criem um projeto **Maven** para usar Aspose.PDF para Java em Novo Projeto -> Maven-> Projeto Aspose.PDF Maven.
- A referência da dependência maven do Aspose.PDF para Java API é obtida automaticamente no [Repositório Aspose Maven](https://repository.aspose.com/webapp/#/artifacts/browse/tree/General/repo/com/aspose/aspose-pdf) e adicionada ao pom.xml.
- O projeto criado sempre conterá a versão mais recente disponível **Maven** Dependency for Aspose.PDF for Java API.
- As etapas do assistente também apresentam a opção de baixar exemplos de código para usarAspose.PDF para API Java.

### Exemplo de código Aspose.PDF (assistente)

- Este assistente de Novo Arquivo permite copiar os [Exemplos de Código](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples) baixados em seu projeto para usar Aspose.PDF para Java em **Novo Arquivo -> Java -> Exemplo de Código Aspose.PDF.**
- As amostras disponíveis são exibidas em formato de árvore, onde o usuário pode selecioná-las categoricamente.
- Todos os exemplos dentro da categoria selecionada serão copiados para a pasta do pacote **com.aspose.pdf.examples** do projeto junto com os recursos necessários dentro da pasta **src/main/resources** necessários para executar os exemplos.
- Exemplos de código de Aspose.PDF para API Java destinam-se a demonstrar a variedade da API.
- O assistente também procurará e atualizará os recém-disponíveis no [repositório de exemplos Aspose.PDF para Java.](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples)

## Baixando

### Baixar NetBeans

Você deve ter o NetBeans IDE pré-instalado antes de baixar o plug-in **Aspose.PDF Java para NetBeans (Maven)**.

**O plug-in **Aspose.PDF Java para NetBeans (Maven)** suporta **NetBeans IDE8.0 e 8.1**. Recomendamos usar apenas a versão mais recente do NetBeans IDE.

Para baixar o NetBeans IDE,

1. Navegue para:<https://netbeans.apache.org/download/index.html>
1. Clique em Download para baixar o pacote apropriado do NetBeans IDE.

Baixe apenas o pacote de download NetBeans compatível com Java EE/SE da versão mais recente atual, ou seja, **NetBeans IDE 8.1**.

### Baixe Aspose.PDF Java para NetBeans (Maven)

- O plugin pode ser baixado diretamente do URL de hospedagem do plugin NetBeans:<http://plugins.netbeans.org/plugin/63218>
  e posteriores podem ser instalados usando a opção IDE:
  - Vá para **Ferramentas**>**Plugins**>**Baixados
  - Clique em **Adicionar plug-ins...** e procure o arquivo de plug-in de extensão .nbm baixado para **Aspose.PDF Java para NetBeans (Maven)**.
  - Clique em **"Instalar"** para instalar o plugin
- Ou pode ser instalado diretamente (sem download manual do URL de hospedagem do plugin NetBeans) usando as opções do IDE:
  - Vá para **Ferramentas**>**Plugins**>**Plugins disponíveis**
  - Na caixa de pesquisa digite: "Aspose"
  - Selecione o plug-in **Aspose.PDF Java NetBeans (Maven)**
  - Clique em **"Instalar"**

### Como aplicar a licença Aspose?

Este plugin usa uma versão de avaliação do Aspose.PDF. Quando estiver satisfeito com sua avaliação, você poderá adquirir uma licença no [site Aspose](https://purchase.aspose.com/buy).
Para remover a mensagem de avaliação e as limitações de recursos, uma licença do produto deve ser aplicada. Você receberá um arquivo de licença após adquirir o produto. Siga as etapas abaixo para aplicar a licença.

- Certifique-se de que o arquivo de licença tenha o nome **Aspose.PDF.Java.lic
- Coloque o arquivo **Aspose.PDF.Java.lic** na pasta que contém o Aspose.PDF.jar
- Use o seguinte código para ativar a licença:

```java
License license = new License();
license.setLicense("Aspose.PDF.Java.lic");
```
