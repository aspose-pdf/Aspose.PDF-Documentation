## Instalando

### Como instalar Aspose.PDF Java para IntelliJ IDEA (Maven)

As etapas abaixo demonstram como instalar o plugin **Aspose.PDF Java para IntelliJ IDEA (Maven)**.

O plug-in está listado no CE do IntelliJ IDEA [site oficial do plugin](https://plugins.jetbrains.com/plugin/7974-aspose-pdf-java-for-intellij-idea-maven/) - repositório de plugins como **Aspose.PDF Java para IntelliJ IDEA Maven**, então você não precisa baixá-lo manualmente e instalá-lo a partir do disco, mas esta opção extra ainda existe no IntelliJ IDEA.

**O plug-in **Aspose.PDF Java para IntelliJ IDEA (Maven)** pode ser facilmente instalado (sem download manual) de dentro do IntelliJ IDEA. Para fazer isso:

1. Selecione **Configurações** no menu **Arquivo**.
2. Clique em **Plugins** e navegue pelos repositórios no IntelliJ IDEA.

![tarefa:image_alt_text](https://i.imgur.com/NDZtoKw.jpg)

### Assistente de projeto Aspose.PDF Maven

**Aspose.PDF Maven Project** - no IntelliJ IDEA, que permitirá que você crie um projeto baseado em Aspose.PDF Maven para usar [Aspose.PDF para API Java.](https://products.aspose.com/pdf/java/).

![tarefa:image_alt_text](https://i.imgur.com/hd2mYnW.jpg)

### Assistente de exemplo Aspose.PDF

Uma opção para criar [Exemplos de códigos-fonte para usar Aspose.PDF para API Java](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples) no projeto, também aparecerá após a instalação no menu "Novo" (usando o botão direito -> Novo **OU** menu Arquivo->Novo)

## Usando

### Assistente de projeto Aspose.PDF Maven

Para criar o projeto Aspose.PDF Maven para usar [Aspose.PDF para API Java](https://products.aspose.com/pdf/java/) no IntelliJ IDEA, você precisa ter conexão com a internet.

Em seguida, siga as etapas abaixo:

1. Selecione **Novo Projeto**.
2. Selecione **Projeto Aspose.PDF Maven**.
3. Clique em **Próximo**.

![tarefa:image_alt_text](https://i.imgur.com/hd2mYnW.jpg)

4. Forneça um **GroupId, ArtifactId** e uma versão
para o seu projeto maven e clique em Avançar.

![tarefa:image_alt_text](https://i.imgur.com/aNlx0Qe.jpg)

5. Você pode marcar a caixa de seleção "Baixar também o código-fonte dos exemplos" para baixar os exemplos de uso da API (conforme mostrado no instantâneo acima)

6. Forneça um **Nome do projeto** e um **Local** como ao criar qualquer aplicativo Java

![tarefa:image_alt_text](https://i.imgur.com/8VEeFun.jpg)

7. Clique em **Concluir**.

Isto irá recuperar o [Aspose.PDF para API Java](https://products.aspose.com/pdf/java/) referência de dependência maven mais recente do Aspose Cloud Maven Repository e configure-a em pom.xml
Se você marcou a caixa de seleção "Baixar também o código-fonte dos exemplos". O download dos exemplos também começará a partir do [Aspose.PDF para repositório GitHub da API Java](https://goo.gl/cPAbJM)

![tarefa:image_alt_text](https://i.imgur.com/bG2mdam.jpg)

![tarefa:image_alt_text](https://i.imgur.com/aNYhLl5.jpg)

Parabéns!  Você criou com sucesso o projeto Aspose.PDF Maven para usar [Aspose.PDF para API Java](https://products.aspose.com/pdf/java/).

![tarefa:image_alt_text](https://i.imgur.com/UJlSbuM.jpg)

O projeto Aspose.PDF para Java API Maven criado está pronto para ser modificado de acordo com os requisitos do seu projeto.

Se você optou por baixar [Exemplos de códigos-fonte](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples).

### Assistente de exemplos Aspose.PDF

Para importar/copiar [Exemplos de códigos-fonte](https://goo.gl/cPAbJM)no projeto usando o **Aspose.PDF Exemplos Wizard**, primeiro você precisa baixar os exemplos optando por "Baixar também o código-fonte dos exemplos" no Aspose.PDF Maven Project Wizard.

Em seguida, siga as etapas abaixo no IntelliJ IDEA:

1. Selecione **Arquivo** > **Novo -** Conforme mostrado abaixo:

![tarefa:image_alt_text](https://i.imgur.com/N8tT9Q0.jpg)

-OU- **Clique com o botão direito** (na janela do projeto) => **Novo**Â  - Conforme mostrado abaixo:

![tarefa:image_alt_text](https://i.imgur.com/aUBWkhp.jpg)

2. Selecione a opção **Exemplo Aspose.PDF** no menu - conforme mostrado abaixo:

![tarefa:image_alt_text](https://i.imgur.com/hvH2V0m.jpg)

O assistente irá atualizar/verificar o mais recente disponível [Exemplos de API Aspose.PDF para Java](https://goo.gl/cPAbJM)

![tarefa:image_alt_text](https://i.imgur.com/5PZwsuq.jpg)

3. **A caixa de diálogo do assistente de exemplos Aspose.PDF** aparecerá, onde você pode selecionar qualquer categoria de exemplos para criar/copiar os exemplos em seu projeto
Selecione qualquer categoria de exemplos e clique em **Criar**:

![tarefa:image_alt_text](https://i.imgur.com/l2oGUBW.jpg)

Isso criará/copiará os exemplos de categoria selecionados no projeto no pacote **com.aspose.pdf.examples**.
Além disso, quaisquer recursos necessários para a execução dos exemplos serão copiados para a pasta **src/main/resources** - conforme mostrado abaixo:

![tarefa:image_alt_text](https://i.imgur.com/8GQL3Yb.jpg)

Parabéns! Você fez o seguinte com sucesso:

1. Você criou o Aspose.PDF Maven Project usando o Aspose.PDF Maven Project Wizard,

2. Você baixou [Aspose.PDF para API Java - Exemplos de códigos-fonte](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples)
3. Você criou/copiou códigos-fonte de exemplos em seu projeto usando o assistente de exemplo Aspose.PDF.
