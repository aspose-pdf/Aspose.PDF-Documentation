## Introdução

### Rjb - Ponte Ruby Java

RJB é um programa ponte que conecta Ruby e Java com Java Native Interface. Rake + Rjb é a ferramenta de construção mais poderosa e útil que Maven e Ant. Você pode testar sua própria classe de lógica de negócios Java com a simulação do Rjb. Ajuda a migrar o objeto modelo do Struts para sua aplicação RoR. Mas cuidado com o aplicativo buildSwing, Ruby (e Rjb) não considera o manuseio de threads nativos da JVM.

### Aspose.PDF para Java

Aspose.PDF for Java é um componente de criação de documentos PDF que permite que seus aplicativos Java leiam, escrevam e manipulem documentos PDF sem usar o Adobe Acrobat.

Aspose.PDF para Java é um componente de preço acessível que oferece uma riqueza incrível de recursos, incluindo: opções de compactação de PDF, criação e manipulação de tabelas, suporte gráfico, funções de imagem, ampla funcionalidade de hiperlink, controles de segurança estendidos e manipulação de fontes personalizadas.

Aspose.PDF para Java permite que você crie arquivos PDF diretamente por meio da API fornecida e dos modelos XML. Usar Aspose.PDF para Java também permitirá que você adicione recursos de PDF aos seus aplicativos rapidamente.

### Aspose.PDF Java para Ruby

O projeto Aspose.PDF Java para Ruby mostra como diferentes tarefas podem ser executadas usando APIs Aspose.PDF Java em Ruby. Este projeto tem como objetivo fornecer exemplos úteis para desenvolvedores Ruby que desejam utilizar Aspose.PDF para Java em seus projetos Ruby usando Rjb (Ruby Java Bridge).

## Instalação e uso

### Instalando

É muito simples e fácil instalar Aspose.PDF Java para Ruby gem, siga estas etapas simples:

1. Execute o seguinte comando.

{{< highlight java >}}

 $ gem instalar aspose-pdfjava

{{< /highlight >}}

1. Baixe o Aspose.PDF necessário para o componente Java no link a seguir.
   <https://downloads.aspose.com/pdf/java>
1. Crie a pasta "jars" na raiz da gem Aspose.PDF Java para Ruby e copie o componente baixado nela.

### Usando

Inclua os arquivos necessários para trabalhar com o exemplo helloworld.

{{< highlight java >}}

 requer Arquivo.dirname(File.dirname(File.dirname(__FILE__))) + '/lib/aspose-pdfjava'

incluir Asposepdfjava

incluir Asposepdfjava::HelloWorld

inicializar_aspose_pdf
