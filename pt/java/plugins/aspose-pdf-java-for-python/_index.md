## Introdução ao Aspose.PDF Java para Python

## JPype

JPype é um esforço para permitir aos programas python acesso total às bibliotecas de classes java. Isso é conseguido não através da reimplementação do Python, como o Jython/JPython fez, mas sim através da interface no nível nativo em ambas as máquinas virtuais.

Leia mais em [readthedocs.org](http://jpype.readthedocs.org/en/latest/userguide.html)

## Aspose.PDF para Java

Aspose.PDF for Java é uma biblioteca de classes avançada para Java que permite executar uma grande variedade de tarefas de processamento de documentos diretamente em seus aplicativos Java.

Aspose.PDF para Java suporta processamento de texto (DOC, DOCX, OOXML, RTF) HTML, OpenDocument, PDF, EPUB, XPS, SWF e todos os formatos de imagem. Com Aspose.PDF você pode gerar, modificar e converter documentos sem usar o Microsoft Word.

Leia mais em [aspose.com](https://products.aspose.com/words/java)

## Aspose.PDF Java para Python

O projeto Aspose.PDF para Python mostra como diferentes tarefas podem ser executadas usando APIs Java Aspose.PDF em Python. Este projeto tem como objetivo fornecer exemplos úteis para desenvolvedores Python que desejam utilizar Aspose.PDF para Java em seus projetos Python usando [JPype](http://jpype.readthedocs.org/en/latest/userguide.html).
