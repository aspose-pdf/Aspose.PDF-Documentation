Para obter a contagem de páginas do documento PDF usando **Aspose.PDF Java para Python**, basta invocar a classe **GetNumberOfPages**.

```Python
doc= self.Document()
pdf = self.Document()
pdf=self.dataDir + 'input1.pdf'
page_count = pdf.getPages().size()
print "Page Count:" . page_count

```
