A classe Java `PdfFileEditorExamples` demonstra os principais fluxos de trabalho de edição de documentos expostos pela API Facades.

Use esta seção para aprender como:

- mesclar arquivos PDF com o método `concatenate`
- dividir um documento do início ao fim ou em arquivos de uma única página
- extrair, excluir, inserir e anexar páginas
- crie livretos e saída N-Up para impressão
- adicione margens, redimensione o conteúdo da página e insira quebras de página
