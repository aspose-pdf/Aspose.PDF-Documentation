O Java `PdfFileEditorExamples` classe demonstra os principais fluxos de trabalho de edição de documentos expostos pela API Facades.

Use esta seção para aprender a:

- mesclar arquivos PDF com o `concatenate` método
- dividir um documento do início ao fim ou em arquivos de página única
- extrair, excluir, inserir e anexar páginas
- criar saída tipo livreto e N-Up para impressão
- adicionar margens, redimensionar o conteúdo da página e inserir quebras de página
