Use a fachada PdfFileEditor quando precisar refluir um PDF existente para impressão ou revisão compacta.

Esta seção aborda como:

- crie um PDF pronto para livreto a partir de um documento existente
- coloque várias páginas de origem em cada folha de saída com um layout N-Up
- manipular o valor de retorno booleano usado pelos exemplos de estilo `try` no conjunto de amostras Java
