Use a fachada PdfFileEditor quando precisar reformatar um PDF existente para impressão ou revisão compacta.

Esta seção cobre como:

- criar um PDF pronto para livreto a partir de um documento existente
- colocar múltiplas páginas de origem em cada folha de saída com um layout N-Up
- manuseie o valor de retorno booleano usado por `try` exemplos de estilo no conjunto de amostras Java
