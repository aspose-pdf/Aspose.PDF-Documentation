O Java `PdfFileEditorExamples` classe inclui um direto `concatenate` exemplo para mesclar arquivos PDF.

Nesta seção você pode encontrar:

- cobertura de mesclagem suportada por fonte para o baseado em array `concatenate` workflow
- Orientação sobre o artigo equivalente de dois arquivos que utiliza o mesmo exemplo Java
- notas de escopo explícitas para lotes grandes, otimizados, específicos de formulário e `try` mesclar variantes que não estão implementadas como métodos dedicados no conjunto de exemplos atual do repositório
