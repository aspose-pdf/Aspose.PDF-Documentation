A classe Java `PdfFileEditorExamples` inclui um exemplo direto `concatenate` para mesclar arquivos PDF.

Nesta seção você pode encontrar:

- cobertura de mesclagem baseada na origem para o fluxo de trabalho `concatenate` baseado em array
- orientação sobre o artigo equivalente de dois arquivos que usa a mesma amostra Java
- notas de escopo explícitas para variantes de mesclagem de lote grande, otimizadas, específicas de formulário e `try` que não são implementadas como métodos dedicados no conjunto de exemplos de repositório atual
