Use esses fluxos de trabalho do PdfFileEditor quando um PDF precisar de limpeza de layout sem reconstruir o documento do zero.

Esta seção explica como:

- adicionar margens às páginas selecionadas
- redimensionar caixas de conteúdo em páginas específicas
- dividir uma página em uma posição vertical definida com uma quebra de página
