Use esta seção quando um documento precisar ser dividido em saídas menores para reutilização, distribuição ou processamento subsequente.

Esta seção cobre como:

- extraia as primeiras páginas para um novo PDF
- extraia todas as páginas a partir de uma página escolhida até o final
- exporte cada página para um arquivo próprio com um padrão de nomenclatura de saída
