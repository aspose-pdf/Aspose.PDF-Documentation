A classe Java `PdfFileSignatureExamples` demonstra os principais fluxos de trabalho de assinatura disponíveis através da API Facades.

Use esta seção para aprender como:

- assinar e certificar documentos PDF
- inspecionar nomes de assinaturas, detalhes de signatários e carimbos de data/hora
- verificar a validade da assinatura e a cobertura de todo o documento
- extrair um certificado de assinatura e remover uma assinatura existente
