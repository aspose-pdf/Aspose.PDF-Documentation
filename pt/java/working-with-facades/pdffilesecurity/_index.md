A classe Java `PdfFileSecurityExamples` demonstra os principais fluxos de trabalho de segurança disponíveis através da API Facades.

Use esta seção para aprender como:

- criptografar um PDF com senhas de usuário e proprietário
- aplicar ou atualizar privilégios de documento
- descriptografar um PDF com uma senha de proprietário
- alterar senhas e, opcionalmente, redefinir as configurações de segurança
