O Java `PdfFileSecurityExamples` classe demonstra os principais fluxos de trabalho de segurança disponíveis através da API Facades.

Use esta seção para aprender como:

- criptografar um PDF com senhas de usuário e proprietário
- aplicar ou atualizar privilégios do documento
- descriptografar um PDF com senha de proprietário
- alterar senhas e, opcionalmente, redefinir configurações de segurança
