O conjunto de amostras inclui preenchimento de campos de texto, campos de caixa de seleção, campos de botão de opção, campos de caixa de listagem, campos de código de barras e um padrão de preenchimento de nome-valor reutilizável criado na mesma API `fillField(...)`.
---
A classe Java `FormExamples` demonstra os principais fluxos de trabalho `Form.fillField(...)` e `Form.fillBarcodeField(...)` usados ​​para preencher formulários PDF interativos.

Use esta seção para ver como:

- preencher campos de texto por nome de campo
- selecione os valores da caixa de seleção e do botão de opção
- definir valores da caixa de listagem
- preencher um campo de código de barras
- aplique a mesma API de preenchimento de campo em seu próprio loop para pares dinâmicos de nome-valor
