O conjunto de exemplos atual inclui a exportação de dados do AcroForm para XML, FDF e XFDF, enquanto os tópicos JSON e XFA não suportados são anotados explicitamente para evitar a fabricação de caminhos de código que não estão presentes neste repositório.
---
A classe Java `FormExamples` inclui fluxos de trabalho de exportação direta para estes formatos:

- XML com `form.exportXml(...)`
- FDF com `form.exportFdf(...)`
- XFDF com `form.exportXfdf(...)`

Use as páginas secundárias nesta seção para exemplos concretos. O conjunto de amostra Java atual neste repositório não inclui um exemplo de fachada `Form` dedicado para exportação JSON ou extração XFA, portanto, essas páginas são mantidas como notas de escopo em vez de orientações de código sintético.
