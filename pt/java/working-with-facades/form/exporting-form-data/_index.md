O conjunto atual de exemplos inclui a exportação de dados AcroForm para XML, FDF e XFDF, enquanto tópicos não suportados como JSON e XFA são explicitamente observados para evitar a criação de caminhos de código que não existem neste repositório.
---
O Java `FormExamples` classe inclui fluxos de trabalho de exportação direta para estes formatos:

- XML com `form.exportXml(...)`
- FDF com `form.exportFdf(...)`
- XFDF com `form.exportXfdf(...)`

Use as páginas filhas nesta seção para os exemplos concretos. O conjunto atual de amostras Java neste repositório não inclui um dedicado `Form` exemplo de fachada para exportação JSON ou extração XFA, de modo que essas páginas sejam mantidas como notas de escopo ao invés de tutoriais sintéticos de código.
