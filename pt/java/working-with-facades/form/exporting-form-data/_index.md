O conjunto atual de exemplos inclui a exportação de dados AcroForm para XML, FDF e XFDF, enquanto tópicos não suportados como JSON e XFA são explicitamente observados para evitar a criação de caminhos de código que não existem neste repositório.
---
A classe Java `FormExamples` inclui fluxos de trabalho de exportação direta para estes formatos:

- XML com `form.exportXml(...)`
- FDF com `form.exportFdf(...)`
- XFDF com `form.exportXfdf(...)`

Use as páginas filhas nesta seção para os exemplos concretos. O conjunto atual de amostras Java neste repositório não inclui um exemplo dedicado da fachada `Form` para exportação JSON ou extração XFA, por isso, essas páginas são mantidas como notas de escopo em vez de tutoriais com exemplos de código artificiais.
