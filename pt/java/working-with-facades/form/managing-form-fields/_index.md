A classe Java `FormExamples` inclui exemplos diretos para:

- `flattenAllFields(...)`
- `renameFormFields(...)`

O repositório atualmente não contém um exemplo de fachada Java `Form` separado para nivelar apenas um subconjunto selecionado de campos, de modo que a página filha seja documentada como uma nota de escopo em vez de um código de amostra fabricado.
