- `flattenAllFields(...)`
- `renameFormFields(...)`

O repositório atualmente não contém um Java separado `Form` exemplo de fachada para achatar apenas um subconjunto selecionado de campos, de modo que a página filha seja documentada como uma nota de escopo em vez de código de amostra fabricado.
