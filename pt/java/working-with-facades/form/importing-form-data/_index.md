O conjunto de exemplos atual inclui a importação de dados AcroForm de XML, FDF e XFDF, enquanto os tópicos de substituição JSON e XFA não suportados são anotados explicitamente para manter a documentação alinhada com as fontes do repositório.
---
A classe Java `FormExamples` inclui fluxos de trabalho de importação direta para estes formatos:

- XML com `form.importXml(...)`
- FDF com `form.importFdf(...)`
- XFDF com `form.importXfdf(...)`

Use as páginas secundárias nesta seção para exemplos concretos. O conjunto de amostra Java atual neste repositório não inclui um exemplo de fachada `Form` dedicado para importação JSON ou substituição XFA, portanto, essas páginas são mantidas como notas de escopo.
