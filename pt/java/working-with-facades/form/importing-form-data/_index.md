Abstract: Esta seção abrange os exemplos de importação de formulário em Java implementados com a fachada Form em Aspose.PDF for Java. O conjunto atual de exemplos inclui a importação de dados AcroForm de XML, FDF e XFDF, enquanto tópicos não suportados como JSON e substituição XFA são anotados explicitamente para manter a documentação alinhada com as fontes do repositório.
---
A classe Java `FormExamples` inclui fluxos de trabalho de importação direta para estes formatos:

- XML com `form.importXml(...)`
- FDF com `form.importFdf(...)`
- XFDF com `form.importXfdf(...)`

Use as páginas filhas nesta seção para os exemplos concretos. O conjunto atual de exemplos Java neste repositório não inclui um exemplo dedicado da fachada `Form` para importação de JSON ou substituição de XFA, por isso, essas páginas são mantidas como notas de escopo.
