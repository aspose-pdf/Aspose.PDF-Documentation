A classe Java `FormExamples` demonstra os principais fluxos de trabalho de processamento de formulários expostos pela API Facades.

Use esta seção para aprender como:

- Preencher campos de texto, caixa de seleção, botão de opção, caixa de lista e código de barras
- Exportar dados do formulário para XML, FDF e XFDF
- Importar dados do formulário de XML, FDF e XFDF
- Aplanar todos os campos do formulário e renomear os campos existentes
- Inspecionar nomes dos campos e valores atuais
- Preencher um campo de botão de imagem a partir de um fluxo de entrada
