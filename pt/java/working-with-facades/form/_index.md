A classe Java `FormExamples` demonstra os principais fluxos de trabalho de processamento de formulários expostos pela API Facades.

Use esta seção para aprender como:

- Preencha campos de texto, caixa de seleção, botão de opção, caixa de listagem e código de barras
- Exporte dados de formulário para XML, FDF e XFDF
- Importe dados de formulário de XML, FDF e XFDF
- Achate todos os campos do formulário e renomeie os campos existentes
- Inspecione nomes de campos e valores atuais
- Preencher um campo de botão de imagem a partir de um fluxo de entrada
