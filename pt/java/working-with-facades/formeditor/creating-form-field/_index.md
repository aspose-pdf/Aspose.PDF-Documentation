A classe Java `FormEditorExamples` cria vários tipos de campos comuns em páginas PDF existentes vinculando o documento de entrada, chamando `addField(...)` ou `addSubmitBtn(...)` e salvando o resultado.

Use as páginas secundárias nesta seção para exemplos concretos de criação de campos.
