O Java `FormEditorExamples` classe cria vários tipos de campo comuns em páginas PDF existentes vinculando o documento de entrada, chamando `addField(...)` ou `addSubmitBtn(...)`, e salvando o resultado.

Use as páginas filhas nesta seção para exemplos concretos de criação de campos.
