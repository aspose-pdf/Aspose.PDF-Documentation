A classe Java `FormEditorExamples` demonstra como trabalhar com ações de campo após a estrutura do formulário já ter sido criada.
Use esta seção para:

- adicione uma ação JavaScript a um campo
- substituir um script de campo existente
- configurar um URL de envio e um sinalizador de envio
- remover uma ação de campo
