O Java `FormEditorExamples` classe demonstra como trabalhar com ações de campo depois que a estrutura do formulário já foi criada.
Use esta seção para:

- adicionar uma ação JavaScript a um campo
- substituir um script de campo existente
- configurar uma URL de envio e um indicador de envio
- remover uma ação de campo
