Esta seção agrupa os fluxos de trabalho de anotação Java usados ​​para criar, inspecionar, excluir e transferir anotações em arquivos PDF.

O repositório atual não inclui uma classe `PdfAnnotationEditorExamples.java` dedicada. Para esta seção, o conteúdo do artigo é proveniente dos exemplos Java em `en/java/src/main/java/com/aspose/pdf/examples/workingwithannotations`.
