A classe Java `PdfFileInfoExamples` demonstra os principais fluxos de trabalho de inspeção e metadados disponíveis por meio da API Facades.

Use esta seção para aprender como:

- leia a versão em PDF e privilégios do documento
- inspecionar largura, altura, rotação e deslocamentos da página
- obtenha, defina, limpe e salve metadados de documentos com XMP
