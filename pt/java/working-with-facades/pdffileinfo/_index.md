A classe Java `PdfFileInfoExamples` demonstra os principais fluxos de inspeção e metadados disponíveis através da API Facades.

Use esta seção para aprender como:

- ler a versão do PDF e os privilégios do documento
- inspecionar largura, altura, rotação e deslocamentos da página
- obter, definir, limpar e salvar os metadados do documento com XMP
