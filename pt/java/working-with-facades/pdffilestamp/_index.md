A classe Java `PdfFileStampExamples` demonstra os principais fluxos de trabalho de estampagem disponíveis através da API Facades.

Use esta seção para aprender como:

- adicionar um carimbo de imagem a um PDF
- coloque cabeçalhos ou rodapés de texto e imagem
- controlar margens de cabeçalho e rodapé
- adicione números de página com layouts padrão, baseados em coordenadas, alinhados ou numeração romana
