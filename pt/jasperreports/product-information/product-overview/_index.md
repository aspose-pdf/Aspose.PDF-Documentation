## Bem-vindo à documentação do Aspose.PDF para JasperReports

Aspose.PDF para JasperReports é um componente flexível projetado para exportar relatórios de JasperReports e JasperServer para Portable Document Format (PDF). Recursos importantes de relatórios, como tabelas, gráficos e imagens, são convertidos para PDF com o mais alto grau de precisão.

{{% /alert %}}

### Descrição do produto

Para criar documentos PDF, o Aspose.PDF for JasperReports conta com uma versão integrada do [Aspose.PDF for Java](https://products.aspose.com/pdf/java/), a biblioteca líder de mercado da Aspose. O Adobe Acrobat Professional não precisa estar instalado no sistema para gerar documentos PDF com Aspose.PDF para JasperReports.
