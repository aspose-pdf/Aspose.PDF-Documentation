## Bem-vindo à documentação do Aspose.PDF for JasperReports

O Aspose.PDF for JasperReports é um componente flexível projetado para exportar relatórios do JasperReports e do JasperServer para Portable Document Format (PDF). Recursos importantes dos relatórios, como tabelas, gráficos e imagens, são convertidos para PDF com o mais alto grau de precisão.

{{% /alert %}}

### Descrição do Produto

Para criar documentos PDF, Aspose.PDF for JasperReports depende de uma versão incorporada de [Aspose.PDF for Java](https://products.aspose.com/pdf/java/), a biblioteca líder de mercado da Aspose. O Adobe Acrobat Professional não precisa ser instalado no sistema para gerar documentos PDF com Aspose.PDF for JasperReports.
