{{% alert color="primary" %}}

Aspose.PDF for JasperReports requer o seguinte software para executar:

- Java 2 Platform Standard Edition 5.0 ou superior.
- JasperReports 6.7.0 ou superior.
- JasperServer 6.7.0 ou superior (se você quiser usar Aspose.PDF for JasperReports com JasperServer).

{{% /alert %}}
