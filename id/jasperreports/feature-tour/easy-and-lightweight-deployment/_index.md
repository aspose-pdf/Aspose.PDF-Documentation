{{% alert color="primary" %}}

Aspose.PDF for JasperReports adalah ekstensi ekspor untuk [Laporan Jasper](http://www.jaspersoft.com/jasperreports).

Aspose.PDF for JasperReports disediakan sebagai satu file JAR dan dapat dengan mudah diintegrasikan dengan JasperReports dan JasperServer.

{{% /alert %}}

Untuk menginstal Aspose.PDF for JasperReports, cukup salin file **Aspose-pdf-jasperreports.jar** ke folder yang benar (JasperReports\lib). Untuk berintegrasi dengan JasperServer Anda juga perlu mengedit file konfigurasi JasperServer. [Baca bagian instalasi](/pdf/id/jasperreports/installation/) untuk langkah-langkah instalasi rinci.
