Kelas `PdfContentEditorExamples` dalam Java menunjukkan alur kerja pengeditan konten utama yang diekspos oleh API Facades.

Gunakan bagian ini untuk mempelajari cara:

- tambahkan anotasi teks, garis, poligon, film, dan cap karet
- tambahkan atau hapus lampiran dokumen
- ikat PDF dari aliran dan simpan hasilnya
- tambahkan atau hapus tindakan pembukaan dokumen
- ganti teks dan gambar
- dapatkan dan ubah preferensi penampil
