Java `PdfFileStampExamples` kelas menunjukkan alur kerja stamping utama yang tersedia melalui Facades API.

Gunakan bagian ini untuk mempelajari cara:

- tambahkan stempel gambar ke PDF
- letakkan teks dan gambar pada header atau footer
- kontrol margin header dan footer
- tambahkan penomoran halaman dengan tata letak default, berbasis koordinat, rata, atau penomoran Romawi
