Kelas `FormExamples` dalam Java mencakup alur kerja ekspor langsung untuk format berikut:

- XML dengan `form.exportXml(...)`
- FDF dengan `form.exportFdf(...)`
- XFDF dengan `form.exportXfdf(...)`

Gunakan halaman anak di bagian ini untuk contoh konkret. Set contoh Java saat ini di repositori ini tidak termasuk yang khusus `Form` contoh fasad untuk ekspor JSON atau ekstraksi XFA, sehingga halaman-halaman tersebut dipertahankan sebagai catatan ruang lingkup daripada walkthrough kode sintetis.
