Kelas `FormExamples` dalam Java mencakup alur kerja impor langsung untuk format-format ini:

- XML dengan `form.importXml(...)`
- FDF dengan `form.importFdf(...)`
- XFDF dengan `form.importXfdf(...)`

Gunakan halaman anak di bagian ini untuk contoh konkret. Set contoh Java saat ini di repositori ini tidak menyertakan yang khusus `Form` contoh fasad untuk impor JSON atau penggantian XFA, sehingga halaman tersebut dipertahankan sebagai catatan ruang lingkup.
