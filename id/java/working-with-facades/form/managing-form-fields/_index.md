- `flattenAllFields(...)`
- `renameFormFields(...)`

Repositori saat ini tidak berisi Java yang terpisah. `Form` contoh facade untuk meratakan hanya subset bidang yang dipilih, sehingga halaman anak didokumentasikan sebagai catatan lingkup alih‑alih kode contoh yang dibuat‑buat.
