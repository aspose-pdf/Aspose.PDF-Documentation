Kelas `FormExamples` dalam Java mencakup contoh langsung untuk:

- `flattenAllFields(...)`
- `renameFormFields(...)`

Repositori saat ini tidak berisi Java yang terpisah. `Form` contoh fasad untuk meratakan hanya subset bidang yang dipilih, sehingga halaman anak didokumentasikan sebagai catatan lingkup alih‑alih kode contoh yang dibuat‑buat.
