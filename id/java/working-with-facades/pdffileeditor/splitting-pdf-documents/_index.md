Gunakan bagian ini ketika sebuah dokumen perlu dipecah menjadi output yang lebih kecil untuk digunakan kembali, distribusi, atau pemrosesan lanjutan.

Bagian ini mencakup cara:

- ekstrak halaman pertama ke PDF baru
- ekstrak semua halaman mulai dari halaman yang dipilih hingga akhir
- ekspor setiap halaman ke file terpisah dengan pola penamaan output
