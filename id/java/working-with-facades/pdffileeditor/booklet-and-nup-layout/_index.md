Gunakan fasad PdfFileEditor ketika Anda perlu menata ulang PDF yang ada untuk pencetakan atau peninjauan ringkas.

Bagian ini mencakup cara:

- buat PDF siap booklet dari dokumen yang ada
- letakkan beberapa halaman sumber pada setiap lembar output dengan tata letak N-Up
- menangani nilai kembali boolean yang digunakan oleh `try` contoh gaya dalam kumpulan contoh Java
