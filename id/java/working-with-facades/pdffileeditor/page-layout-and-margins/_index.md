Gunakan alur kerja PdfFileEditor ini ketika PDF membutuhkan pembersihan tata letak tanpa harus membuat ulang dokumen dari nol.

Bagian ini menjelaskan cara:

- tambahkan margin ke halaman yang dipilih
- ubah ukuran kotak konten pada halaman tertentu
- bagilah halaman pada posisi vertikal yang ditentukan dengan jeda halaman
