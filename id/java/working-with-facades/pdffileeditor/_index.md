Kelas `PdfFileEditorExamples` dalam Java menunjukkan alur kerja utama penyuntingan dokumen yang diekspos oleh Facades API.

Gunakan bagian ini untuk mempelajari cara:

- gabungkan file PDF dengan metode `concatenate`
- pisahkan dokumen dari awal hingga akhir, atau menjadi file satu halaman
- ekstrak, hapus, sisipkan, dan tambahkan halaman
- buat booklet dan output N-Up untuk pencetakan
- tambahkan margin, ubah ukuran konten halaman, dan sisipkan jeda halaman
