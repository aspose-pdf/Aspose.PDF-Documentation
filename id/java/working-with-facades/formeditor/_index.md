Java `FormEditorExamples` kelas mendemonstrasikan alur kerja utama penyuntingan bidang yang tersedia melalui API Facades.

Gunakan bagian ini untuk mempelajari cara:

- buat bidang teks, kotak centang, kotak kombo, kotak daftar, tombol radio, dan bidang tombol submit
- tambahkan, hapus, pindahkan, ganti nama, salin, atau konversi bidang yang ada
- sesuaikan perataan, tampilan, batas, dan angka comb
- lampirkan skrip, URL submit, dan hapus aksi bidang
