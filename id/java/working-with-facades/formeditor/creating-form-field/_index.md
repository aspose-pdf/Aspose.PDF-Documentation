Kelas `FormEditorExamples` dalam Java membuat beberapa tipe bidang umum pada halaman PDF yang ada dengan mengikat dokumen input, memanggil `addField(...)` atau `addSubmitBtn(...)`, dan menyimpan hasilnya.

Gunakan halaman anak dalam bagian ini untuk contoh pembuatan bidang yang konkret.
