Java `FormEditorExamples` kelas menunjukkan cara bekerja dengan aksi bidang setelah struktur formulir sudah dibuat.
Gunakan bagian ini untuk:

- tambahkan aksi JavaScript ke bidang
- ganti skrip bidang yang ada
- konfigurasikan URL kiriman dan flag kiriman
- hapus aksi bidang
