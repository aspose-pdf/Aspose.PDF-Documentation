Bagian ini mengelompokkan alur kerja anotasi Java yang digunakan untuk membuat, memeriksa, menghapus, dan mentransfer anotasi dalam file PDF.

Repositori saat ini tidak menyertakan yang khusus kelas `PdfAnnotationEditorExamples.java`. Untuk bagian ini, konten artikel bersumber dari contoh Java di bawah `en/java/src/main/java/com/aspose/pdf/examples/workingwithannotations`.

Gunakan bagian ini untuk:

- [Tambah, Hapus, dan Dapatkan Anotasi](/pdf/id/java/pdfannotationeditor-class/add-delete-and-get-annotation/) untuk keluarga anotasi yang dikelompokkan.
- [Impor dan Ekspor Anotasi](/pdf/id/java/pdfannotationeditor-class/import-export-annotations/) untuk menyalin anotasi antara file PDF.
