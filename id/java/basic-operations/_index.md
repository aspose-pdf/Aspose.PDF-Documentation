**Operasi dasar** bagian menjelaskan tugas PDF pertama dan paling sederhana yang dapat Anda lakukan dengan Aspose.PDF for Java:

- [Buat Dokumen PDF](/pdf/id/java/create-document/) - buat dokumen PDF baru secara programatis dalam Java.
- [Buka Dokumen PDF](/pdf/id/java/open-pdf-document/) - buka file PDF dari jalur, dari aliran, atau dengan kata sandi.
- [Simpan Dokumen PDF](/pdf/id/java/save-pdf-document/) - simpan dokumen ke file, ke aliran, atau sebagai standar PDF.
- [Gabungkan PDF](/pdf/id/java/merge-pdf/) - gabungkan beberapa file PDF menjadi satu dokumen keluaran.
- [Pisahkan PDF](/pdf/id/java/split-pdf/) - pisahkan halaman PDF menjadi file PDF satu halaman terpisah.
- [Enkripsi dan Dekripsi File PDF](/pdf/id/java/protect-pdf-file/) - terapkan kata sandi, izin, dan dekripsi pada file PDF.
