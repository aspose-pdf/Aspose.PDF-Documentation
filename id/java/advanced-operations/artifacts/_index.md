Artefak dalam dokumen PDF adalah elemen halaman non‑konten seperti header, footer, watermarks, latar belakang, dan penanda paginasi. Mereka biasanya digunakan untuk branding, tata letak, identifikasi, dan alur kerja manajemen dokumen.
