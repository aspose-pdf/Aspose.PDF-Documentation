## Pendahuluan

### IDE NetBeans

NetBeans adalah IDE Java yang lengkap dengan semua fitur, ditulis sepenuhnya dalam Java. IDE ini terutama ditujukan untuk pengembangan Java tetapi juga mendukung bahasa lain, khususnya PHP, C/C++, dan HTML5.

IDE NetBeans memungkinkan Anda dengan cepat dan mudah mengembangkan aplikasi desktop, seluler, dan web Java, serta aplikasi HTML5 dengan HTML, JavaScript, dan CSS. Ini bersifat gratis dan sumber terbuka serta memiliki komunitas besar pengguna dan pengembang di seluruh dunia.

Tim NetBeans secara aktif mendukung produk dan mencari saran fitur dari komunitas yang lebih luas. Setiap rilis didahului dengan waktu untuk pengujian dan umpan balik komunitas.

### Aspose.PDF for Java

[Aspose.PDF for Java](https://products.aspose.com/pdf/java/) adalah API pembuatan dokumen PDF yang kuat yang memungkinkan aplikasi Java Anda membaca, menulis, dan memanipulasi dokumen PDF tanpa menggunakan Adobe Acrobat.

Aspose.PDF for Java menawarkan beragam fitur luar biasa, termasuk opsi kompresi PDF, pembuatan dan manipulasi tabel, dukungan grafik, fungsi gambar, fungsionalitas hyperlink yang luas, kontrol keamanan yang diperluas, dan penanganan font khusus.

### Aspose.PDF Java untuk NetBeans (Maven)

- Aspose.PDF Java untuk NetBeans (Maven) adalah Plugin untuk **NetBeans IDE** oleh **Aspose.** Plugin ini ditujukan bagi pengembang yang menggunakan platform Maven untuk pengembangan Java dan ingin menggunakan Aspose.PDF for Java dalam proyek mereka. Plugin ini memungkinkan Anda membuat proyek Maven untuk menggunakan Aspose.PDF for Java APIand juga mengunduh [Code Examples](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples)of the API.
- Plugin ini menyediakan fitur berikut untuk bekerja dengan Aspose.PDF for Java APIwithin **NetBeans IDE** dengan nyaman:

## WIZARD

Plugin ini berisi dua wizard

### Wizard Aspose.PDF Maven Project

- Wizard Proyek Baru ini memungkinkan pengembang membuat proyek **Maven** untuk menggunakan Aspose.PDF for Java dari New Project -> Maven -> Aspose.PDF Maven Project.
- Referensi dependensi Maven API Aspose.PDF for Java secara otomatis diambil dari [Aspose Maven Repository](https://repository.aspose.com/webapp/#/artifacts/browse/tree/General/repo/com/aspose/aspose-pdf) dan ditambahkan ke pom.xml.
- Proyek yang dibuat akan selalu berisi versi terbaru yang tersedia dari dependensi **Maven** untuk API Aspose.PDF for Java.
- Langkah-langkah wizard juga menampilkan opsi untuk mengunduh Contoh Kode untuk menggunakan API Aspose.PDF for Java.

### Wizard Aspose.PDF Code Example

- Wizard New File ini memungkinkan Anda menyalin [Code Examples](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples)] yang diunduh ke dalam proyek Anda untuk menggunakan Aspose.PDF for Java dari **New File -> Java -> Aspose.PDF Code Example.**
- Contoh yang tersedia ditampilkan dalam format pohon, sehingga pengguna dapat memilihnya secara kategori.
- Semua contoh dalam kategori yang dipilih akan disalin ke folder paket **com.aspose.pdf.examples** proyek, bersama dengan sumber daya yang diperlukan dalam folder **src/main/resources** yang dibutuhkan untuk menjalankan contoh.
- Contoh Kode Aspose.PDF for Java API ditujukan untuk mendemonstrasikan variasi API.
- Wizard juga akan mencari dan memperbarui yang baru tersedia dari [Aspose.PDF for Java contoh repositori.](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples)

## Mengunduh

### Mengunduh NetBeans

Anda harus memiliki IDE NetBeans terpasang sebelumnya sebelum mengunduh **Aspose.PDF Java untuk NetBeans (Maven)**plugin.

**Aspose.PDF Java for NetBeans (Maven)** plugin mendukung **NetBeans IDE8.0 dan 8.1**. Kami menyarankan untuk hanya menggunakan versi terbaru dari NetBeans IDE.

Unduh NetBeans IDE,

1. Buka <https://netbeans.apache.org/download/index.html>.
1. Klik Unduh untuk mengunduh paket NetBeans IDE yang sesuai.

Unduh hanya paket NetBeans yang mendukung Java EE / SE dari rilis terbaru saat ini, yaitu **NetBeans IDE 8.1**.

### Mengunduh Aspose.PDF Java for NetBeans (Maven)

- Plugin dapat diunduh langsung dari URL hosting plugin NetBeans:<http://plugins.netbeans.org/plugin/63218>
  dan kemudian dapat dipasang menggunakan opsi IDE:
  - Buka **Tools**>**Plugins**>**Downloaded**
  - Klik **Add Plugins...** dan telusuri file plugin ekstensi .nbm yang diunduh untuk **Aspose.PDF Java for NetBeans (Maven)**.
  - Klik**"Install"**untuk memasang plugin
- Atau dapat dipasang langsung (tanpa mengunduh secara manual dari URL hosting plugin NetBeans) menggunakan opsi IDE:
  - Buka**Tools**>**Plugins**>**Available Plugins**
  - Ketik di kotak pencarian: "Aspose"
  - Pilih plugin **Aspose.PDF Java NetBeans (Maven)**
  - Klik**"Install"**

### Menerapkan lisensi Aspose

Plugin ini menggunakan versi evaluasi dari Aspose.PDF. Setelah Anda puas dengan evaluasi, Anda dapat membeli lisensi di [Aspose website](https://purchase.aspose.com/buy).
Untuk menghapus pesan evaluasi dan batasan fitur, lisensi produk harus diterapkan. Anda akan menerima file lisensi setelah membeli produk. Silakan ikuti langkah-langkah di bawah ini untuk menerapkan lisensi.

- Pastikan file lisensi bernama **Aspose.PDF.Java.lic**
- Letakkan file **Aspose.PDF.Java.lic** di folder yang berisi **Aspose.PDF.jar**
- Gunakan kode berikut untuk mengaktifkan lisensi:

```java
License license = new License();
license.setLicense("Aspose.PDF.Java.lic");
```
