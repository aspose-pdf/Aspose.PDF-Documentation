## Menginstal

**Aspose.PDF Java untuk NetBeans (Maven)** plugin dapat dengan mudah dipasang dari tab **Plugin** yang tersedia di dialog Plugin.

- Untuk membukanya, pilih **Plugins** dari menu **Tools** di NetBeans.

![todo:image_alt_text](installing-and-using-aspose-pdf-for-netbeans-maven_1.png)

- Ini menambahkan **Aspose.PDF Maven Project** di wizard New Project dan **Aspose.PDF Code Example** di wizard New File pada NetBeans IDE.

## Menggunakan

### Aspose.PDF Maven Project (wizard)

Untuk membuat **Maven Project** dengan wizard untuk menggunakan [Aspose.PDF for Java API](http://www.aspose.com/java/pdf-component.aspx):

1. Pilih **New Project**.
2. Pilih **Aspose.PDF Maven Project** di kategori **Maven**.
3. Klik **Next**.

Berikan **Project Name, Location, GroupId, ArtifactId** dan **Version** untuk Maven Project Anda dan klik **Finish.**

Ini akan mengambil [Aspose.PDF for Java](http://www.aspose.com/java/pdf-component.aspx) yang terbaru [Dependensi Maven](http://maven.aspose.com/repository/ext-release-local/com/aspose/aspose-pdf/) referensi dari [Repositori Maven Aspose Cloud](https://repository.aspose.com/webapp/#/artifacts/browse/tree/General/repo) dan konfigurasikan dalam **pom.xml**. Jika Anda telah memilih **Also Download Code Examples,** pengunduhan **Code Examples** juga akan dimulai dari [Repositori Contoh API Aspose.PDF for Java. ](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples)
Proyek **Maven** berikut akan dibuat di **NetBeans IDE** Anda setelah wizard selesai:

Proyek **Maven Project** yang dibuat telah dikonfigurasi untuk menggunakan **Aspose.PDF for Java API** dan siap ditingkatkan sesuai dengan kebutuhan **Proyek** Anda.
   Jika Anda telah memilih untuk mengunduh [Contoh Kode](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples), Anda dapat menggunakan **Aspose.PDF Code Example (wizard)** untuk mengimpor **Contoh Kode** yang diperlukan dari [Aspose.PDF for Java](http://www.aspose.com/java/pdf-component.aspx) API ke dalam proyek Anda.

### Aspose.PDF Code Example (wizard)

**Aspose.PDF Code Example wizard** memungkinkan Anda untuk mencoba banyak contoh yang disediakan untuk [Aspose.PDF for Java](http://www.aspose.com/java/pdf-component.aspx) API.

{{% alert color="primary" %}}

Agar dapat menggunakan **Aspose.PDF Code Example wizard** dengan nyaman: disarankan selalu memilih **Also Download Code Examples** saat membuat **Maven Project** pada **Aspose.PDF Maven Project** **wizard**,

{{% /alert %}}

Untuk menggunakan contoh, cukup:

1. Klik **New File** di **NetBeans**.
2. Pilih proyek Anda lalu pilih **Aspose.PDF Code Example** dalam kategori **Java**.
3. Klik **Next**.

Perluas pohon untuk memilih kategori **Code Example** dan klik **Finish**.

 Ini akan menyalin file Java kategori **Code Examples** yang dipilih ke dalam proyek di bawah paket **com.aspose.pdf.examples**. Juga semua sumber daya yang diperlukan oleh **Code Examples** akan disalin ke folder **src/main/resources**, seperti yang ditunjukkan di bawah ini:

 Tinjau kode contoh, kompilasi, dan jalankan.
 Anda sekarang dapat menguji contoh lain dan mulai membangun aplikasi Anda sendiri menggunakan [Aspose.PDF for Java API](http://www.aspose.com/java/pdf-component.aspx).
