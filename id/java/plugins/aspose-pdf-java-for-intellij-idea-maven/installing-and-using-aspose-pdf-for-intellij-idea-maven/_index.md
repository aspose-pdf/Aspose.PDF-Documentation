## Menginstal

### Menginstal Aspose.PDF Java untuk IntelliJ IDEA (Maven)

Langkah‑langkah di bawah ini menunjukkan cara menginstal plugin **Aspose.PDF Java untuk IntelliJ IDEA (Maven)**.

Plugin terdaftar di IntelliJ IDEA CE [situs resmi plugin](https://plugins.jetbrains.com/plugin/7974-aspose-pdf-java-for-intellij-idea-maven/) - repositori plugin sebagai **Aspose.PDF Java for IntelliJ IDEA Maven**, sehingga Anda tidak perlu mengunduhnya secara manual dan menginstalnya dari disk, tetapi opsi tambahan ini masih ada di IntelliJ IDEA.

**Aspose.PDF Java for IntelliJ IDEA (Maven)** plugin dapat dengan mudah dipasang (tanpa mengunduh secara manual) dari dalam IntelliJ IDEA. Untuk melakukannya:

1. Pilih **Settings** dari menu **File**.
2. Klik **Plugins**, lalu telusuri repositori di IntelliJ IDEA.

![todo:image_alt_text](https://i.imgur.com/NDZtoKw.jpg)

### Wizard Aspose.PDF Maven Project

**Aspose.PDF Maven Project** – ke IntelliJ IDEA, yang akan memungkinkan Anda membuat proyek berbasis Aspose.PDF Maven untuk menggunakan [API Aspose.PDF for Java.](https://products.aspose.com/pdf/java/).

![todo:image_alt_text](https://i.imgur.com/hd2mYnW.jpg)

### Panduan contoh Aspose.PDF

Opsi untuk membuat [Contoh Kode Sumber untuk menggunakan API Aspose.PDF for Java](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples) di proyek, juga akan muncul setelah instalasi di bawah menu “New” (menggunakan Klik Kanan -> New **OR** menu File->New)

Contoh Aspose.PDF

![todo:image_alt_text](https://i.imgur.com/l2oGUBW.jpg)

## Menggunakan

### Wizard Aspose.PDF Maven Project

Untuk membuat proyek Maven Aspose.PDF untuk menggunakan [API Aspose.PDF for Java](https://products.aspose.com/pdf/java/) di dalam IntelliJ IDEA, Anda harus memiliki koneksi internet.

Kemudian ikuti langkah-langkah di bawah ini:

1. Pilih **New Project**.
2. Pilih **Aspose.PDF Maven Project**.
3. Klik **Next**.

![todo:image_alt_text](https://i.imgur.com/hd2mYnW.jpg)

4. Masukkan **GroupId**, **ArtifactId**, dan **Version** untuk proyek Maven, lalu klik **Next**.


![todo:image_alt_text](https://i.imgur.com/aNlx0Qe.jpg)

5. Pilih kotak centang **Also Download Examples Source Code** jika ingin mengunduh contoh penggunaan API, seperti pada tangkapan layar di atas.

6. Berikan **Project Name** dan **Location** seperti saat membuat aplikasi Java apa pun.

![todo:image_alt_text](https://i.imgur.com/8VEeFun.jpg)

7. Klik **Finish**.

Ini akan mengambil [API Aspose.PDF for Java](https://products.aspose.com/pdf/java/) referensi dependensi maven terbaru dari Aspose Cloud Maven Repository dan mengkonfigurasikannya di pom.xml
Jika Anda telah memilih kotak centang "Also Download Examples Source Code". Pengunduhan contoh juga akan dimulai dari [Repositori GitHub API Aspose.PDF for Java](https://goo.gl/cPAbJM)

![todo:image_alt_text](https://i.imgur.com/bG2mdam.jpg)

![todo:image_alt_text](https://i.imgur.com/aNYhLl5.jpg)

Proyek Maven Aspose.PDF telah dibuat untuk menggunakan [API Aspose.PDF for Java](https://products.aspose.com/pdf/java/).

![todo:image_alt_text](https://i.imgur.com/UJlSbuM.jpg)

Proyek Maven API Aspose.PDF for Java yang dibuat siap untuk dimodifikasi sesuai dengan kebutuhan proyek Anda.

Jika Anda telah memilih untuk mengunduh [Contoh Kode Sumber](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples).

### Wizard contoh Aspose.PDF

Untuk mengimpor/ menyalin [Contoh Kode Sumber](https://goo.gl/cPAbJM)ke dalam proyek menggunakan **Aspose.PDF Examples Wizard**, Anda harus terlebih dahulu mengunduh contoh dengan memilih  "Also Download Examples Source Code" pada Aspose.PDF Maven Project Wizard.

Kemudian ikuti langkah-langkah di bawah ini pada IntelliJ IDEA:

1. Pilih **File** > **New** seperti yang ditunjukkan di bawah ini:

![todo:image_alt_text](https://i.imgur.com/N8tT9Q0.jpg)

-OR- **Right Click** (pada jendela proyek) => **New**  - Seperti yang ditunjukkan di bawah ini:

![todo:image_alt_text](https://i.imgur.com/aUBWkhp.jpg)

2. Pilih Opsi **Aspose.PDF Example** dari Menu - Seperti yang ditunjukkan di bawah ini:

![todo:image_alt_text](https://i.imgur.com/hvH2V0m.jpg)

Wizard akan menyegarkan / memeriksa versi terbaru yang tersedia [Contoh API Aspose.PDF for Java](https://goo.gl/cPAbJM)

![todo:image_alt_text](https://i.imgur.com/5PZwsuq.jpg)

3. Di dialog **Aspose.PDF Examples wizard**, pilih kategori contoh yang akan disalin ke proyek, lalu klik **Create**:

![todo:image_alt_text](https://i.imgur.com/l2oGUBW.jpg)

Ini akan membuat / menyalin  contoh kategori yang dipilih ke dalam proyek di bawah paket **com.aspose.pdf.examples**.
Selain itu, semua sumber daya yang diperlukan untuk menjalankan contoh akan disalin ke folder **src/main/resources** - Seperti yang ditunjukkan di bawah:

![todo:image_alt_text](https://i.imgur.com/8GQL3Yb.jpg)

Hasil konfigurasi:

- Proyek Aspose.PDF Maven Project telah dibuat menggunakan Aspose.PDF Maven Project Wizard.

- Anda telah mengunduh [Aspose.PDF for Java API - Contoh Kode Sumber](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples).
- Anda telah membuat / menyalin Contoh Kode Sumber ke dalam proyek Anda dengan menggunakan Aspose.PDF Example Wizard.
