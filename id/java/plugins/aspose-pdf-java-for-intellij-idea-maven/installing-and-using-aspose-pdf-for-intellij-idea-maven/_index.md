## Menginstal

### Cara Menginstal Aspose.PDF Java untuk IntelliJ IDEA (Maven)

Langkah‑langkah di bawah ini menunjukkan cara menginstal plugin **Aspose.PDF Java untuk IntelliJ IDEA (Maven)**.

Plugin\u0412\u00A0 terdaftar di IntelliJ IDEA CE [situs resmi plugin](https://plugins.jetbrains.com/plugin/7974-aspose-pdf-java-for-intellij-idea-maven/) - repositori plugin sebagai **Aspose.PDF Java for IntelliJ IDEA Maven**, sehingga Anda don\u0432\u0402\u2122t perlu mengunduhnya secara manual dan menginstalnya dari disk, tetapi opsi tambahan ini masih ada di IntelliJ IDEA.

**Aspose.PDF Java for IntelliJ IDEA (Maven)** plugin dapat dengan mudah dipasang (tanpa mengunduh secara manual) dari dalam IntelliJ IDEA. Untuk melakukannya:

1. Pilih **Settings** dari menu **File**.
2. Klik **Plugins**, lalu telusuri repositori di IntelliJ IDEA.

## Menggunakan

### Panduan Proyek Maven Aspose.PDF

Untuk membuat proyek Maven Aspose.PDF untuk menggunakan [API Aspose.PDF for Java](https://products.aspose.com/pdf/java/) di dalam IntelliJ IDEA, Anda harus memiliki koneksi internet.

Kemudian ikuti langkah-langkah di bawah ini:

1. Pilih **New Project**.
2. Pilih **Aspose.PDF Maven Project**.
3. Klik **Next**.

![todo:image_alt_text](https://i.imgur.com/hd2mYnW.jpg)

4. Berikan **GroupId, ArtifactId** danВ Version
untuk proyek maven Anda dan klik Next.

![todo:image_alt_text](https://i.imgur.com/aNlx0Qe.jpg)

5. Anda dapat memilih kotak centang "Also Download Examples Source Code" untuk mengunduh contoh penggunaan sampel API (seperti yang ditunjukkan pada tangkapan layar di atas)

6. Berikan **Project Name** dan **Location** seperti saat membuat aplikasi Java apa pun

![todo:image_alt_text](https://i.imgur.com/8VEeFun.jpg)

7. Klik **Finish**.

Ini akan mengambil [API Aspose.PDF for Java](https://products.aspose.com/pdf/java/) referensi dependensi maven terbaru dari Aspose Cloud Maven Repository dan mengkonfigurasikannya di pom.xml
Jika Anda telah memilih kotak centang "Also Download Examples Source Code". Pengunduhan contoh juga akan dimulai dari [Repositori GitHub API Aspose.PDF for Java](https://goo.gl/cPAbJM)

![todo:image_alt_text](https://i.imgur.com/bG2mdam.jpg)

![todo:image_alt_text](https://i.imgur.com/aNYhLl5.jpg)

Selamat !  Anda telah berhasil membuat proyek Maven Aspose.PDF untuk digunakan [API Aspose.PDF for Java](https://products.aspose.com/pdf/java/).

![todo:image_alt_text](https://i.imgur.com/UJlSbuM.jpg)

Proyek Maven API Aspose.PDF for Java yang dibuat siap untuk dimodifikasi sesuai dengan kebutuhan proyek Anda.

Jika Anda telah memilih untuk mengunduh [Contoh Kode Sumber](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples).
