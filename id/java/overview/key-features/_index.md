- Ditulis sepenuhnya dalam Java, bekerja dengan JDK 1.8 ke atas
- Mendukung semua aplikasi Java

## Grafik

- Berbagai bentuk grafik, seperti garis, lingkaran, busur, dan kurva didukung.
- Grafik dapat digambar pada lokasi halaman mana pun yang ditentukan oleh koordinat.
- Grafik dapat diputar, diskalakan, atau diisi, dan gaya garis dash dan poly-dash dapat didefinisikan.
- Grafik digambar berdasarkan koordinat dan memiliki posisi usang daripada relatif.
- Ruang warna CMYK dan Gray didukung.
