## Gambaran umum

Untuk menghasilkan dokumen PDF, mesin untuk menjalankan [Aspose.PDF for Java](https://products.aspose.com/pdf/java/) tidak perlu memiliki [Adobe Acrobat](https://www.adobe.com/acrobat/acrobat-pro.html) diinstal karena Aspose.PDF for Java sendiri adalah mesin pembuatan dokumen PDF. Namun untuk melihat dokumen PDF yang dihasilkan oleh Aspose.PDF for Java, mesin tersebut setidaknya memerlukan sebuah [Adobe Acrobat Reader](https://www.adobe.com/acrobat/pdf-reader.html). Itu dapat diunduh secara gratis.

## Sistem operasi yang didukung

Aspose.PDF for Java mendukung sistem operasi 32-bit atau 64-bit apa pun yang menjalankan runtime Java termasuk, tetapi tidak terbatas pada:

### Windows

- Microsoft Windows 2000 Professional ( x64, x86)
- Microsoft Windows 2000 Server (x64, x86)
- Microsoft Windows 2003 Server (x64, x86)
- Microsoft Windows 2008 Server (x64, x86)
- Microsoft Windows 2012 Server (x64, x86)
- Microsoft Windows 2012 R2 Server (x64, x86)
- Microsoft Windows 2016 Server (x64, x86)
- Microsoft Windows 2019 Server (x64, x86)
- Microsoft Windows Vista (x64, x86)
- Microsoft Windows XP (x64, x86)
- Microsoft Windows 7 (x64, x86)
- Microsoft Windows 8, 8.1 (x64, x86)
- Microsoft Windows 10 (x64, x86)
- Microsoft Azure

### Linux

- Linux (Ubuntu, CentOS, dan lainnya)

### Mac

- Mac OS X

## Versi Java yang didukung

Aspose.PDF for Java mendukung versi Java berikut:

- J2SE 8.0 (1.8) atau lebih tinggi (*misalnya Java 10*)В
- Dukungan Aspose.PDF for Java pada IBM i (Iseries atau As/400)
