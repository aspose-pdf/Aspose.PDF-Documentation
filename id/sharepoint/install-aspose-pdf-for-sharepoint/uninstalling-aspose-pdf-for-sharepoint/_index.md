{{% alert color="primary" %}}

Untuk mencopot pemasangan Aspose.PDF for SharePoint, cukup jalankan program setup. Jika Aspose.PDF for SharePoint sudah terpasang, program setup menyarankan untuk menghapusnya.

![Copot pemasangan Aspose.PDF for SharePoint](uninstalling-aspose-pdf-for-sharepoint_1.png)

Selama proses pencopotan, program setup menonaktifkan fitur Aspose.PDF for SharePoint untuk semua koleksi situs dan menarik kembali solusi dari server farm.

{{% /alert %}}
