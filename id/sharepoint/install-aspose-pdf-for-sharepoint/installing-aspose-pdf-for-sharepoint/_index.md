{{% alert color="primary" %}}

Aspose.PDF for SharePoint dapat diunduh sebagai arsip Aspose.PDF.SharePoint.zip.

{{% /alert %}}

Arsip ini berisi:

- Aspose.PDF.SharePoint.wsp
  File solusi SharePoint. Aspose.PDF for SharePoint dikemas sebagai solusi SharePoint untuk memudahkan penyebaran/pengembalian dan aktivasi/deaktivasi fitur di seluruh server farm.
- Aspose_LicenseAgreement.rtf

**Perjanjian lisensi pengguna akhir:**

- Aspose.PDF for SharePoint.pdf

**Dokumentasi pengguna:**

- Aspose.PDF for SharePoint Documentation.chm

**Dokumentasi pengguna dengan referensi API Publik:**

- setup.exe

**Program instalasi:**

- setup.exe.config

**File konfigurasi pengaturan:**

Program pengaturan memeriksa kondisi berikut sebelum melanjutkan:

- SharePoint 2010 terpasang.
- Pengguna memiliki izin untuk memasang solusi SharePoint.
- Database SharePoint online.
- Layanan Administrasi SharePoint dimulai.
- Layanan Timer SharePoint dimulai. Layanan Administrasi SharePoint dan layanan Timer diperlukan karena beberapa tindakan pengaturan bergantung pada pekerjaan timer untuk menyebar ke semua server di farm server.

**Untuk menginstal Aspose.PDF for SharePoint:**

- Ekstrak zip Aspose.PDF.SharePoint ke drive lokal.
- Jalankan setup.exe dan ikuti petunjuk di layar.

**Program instalasi melakukan tindakan berikut:**

- Periksa prasyarat instalasi. Instalasi tidak akan dilanjutkan jika ada pemeriksaan yang gagal.

![Periksa Prasyarat Instalasi](installing-aspose-pdf-for-sharepoint_1.png)

- Tampilkan Perjanjian Lisensi Pengguna Akhir. Pengguna harus menerima perjanjian tersebut untuk melanjutkan.

![Tampilkan Perjanjian Lisensi](installing-aspose-pdf-for-sharepoint_2.png)

- Tampilkan dialog pemilihan target penyebaran. Pengguna memilih aplikasi web dan koleksi situs di mana fitur akan diaktifkan. Lihat gambar di bawah.

![Tampilkan Pemilihan Target Penyebaran](installing-aspose-pdf-for-sharepoint_3.png)

- Sebarkan fitur ke farm server.

![Sebarkan Fitur](installing-aspose-pdf-for-sharepoint_4.png)

- Aktifkan fitur untuk koleksi situs yang dipilih dan konfigurasikan aplikasi web induknya.
- Tampilkan daftar aplikasi web dan koleksi situs di mana fitur telah diterapkan dan diaktifkan.

![Tampilkan Fitur yang Diterapkan](installing-aspose-pdf-for-sharepoint_5.png)
