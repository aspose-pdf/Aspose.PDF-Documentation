{{% alert color="primary" %}}

Untuk menguji apakah lisensi telah diinstal dengan benar, konversikan dokumen apa pun ke format yang diinginkan. Jika dokumen tidak berisi Peringatan Evaluasi, lisensi berhasil diaktifkan.

{{% /alert %}}
