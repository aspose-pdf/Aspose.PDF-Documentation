{{% alert color="primary" %}}

Penggabungan/penyambungan beberapa file PDF menjadi satu file PDF adalah fitur yang sangat populer dan banyak diminta dalam aplikasi pemrosesan file PDF. Kami telah memperkenalkan fitur penting ini di [Aspose.PDF for SharePoint 2.2.0](https://releases.aspose.com/pdf/sharepoint/new-releases/aspose.pdf-for-sharepoint-2.2.0/) versi. Menggabungkan dua file adalah, membuat satu file dengan menambahkan file kedua ke akhir file pertama.

{{% /alert %}}

## Gabungkan file PDF

Gabungkan beberapa file PDF dari SharePoint Document library menjadi satu PDF sebagai berikut:

1.  Pilih file PDF dari SharePoint Document library yang akan digabungkan.

![Memilih file PDF](merge-pdf-files_1.png)

2.  Klik tab Aspose Tools di Library Tools.

![Klik Aspose Tools](merge-pdf-files_2.png)

3.  Klik opsi Merge to PDF dari Library Tools untuk menggabungkan semua file PDF yang dipilih menjadi PDF hasil.

![Merge to PDF](merge-pdf-files_3.png)

4.  Prompt akan ditampilkan untuk mengunduh/menyimpan file PDF hasil dengan nama yang sesuai.

![Output](merge-pdf-files_4.png)
