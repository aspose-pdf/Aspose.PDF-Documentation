{{% alert color="primary" %}}

Menggabungkan/menggabungkan beberapa file PDF menjadi satu file PDF adalah fitur yang sangat populer dan menuntut dalam aplikasi pemrosesan file PDF. Kami telah memperkenalkan fitur penting ini di [Aspose.PDF untuk SharePoint 2.2.0](https://releases.aspose.com/pdf/sharepoint/new-releases/aspose.pdf-for-sharepoint-2.2.0/) versi. Menggabungkan dua file berarti membuat satu file dengan menambahkan file kedua di akhir file pertama.

{{% /alert %}}

## Gabungkan file PDF

Gabungkan beberapa file PDF dari pustaka Dokumen SharePoint dalam satu PDF sebagai berikut:

1.  Pilih file PDF dari pustaka Dokumen SharePoint yang akan digabungkan.

![Memilih file PDF](merge-pdf-files_1.png)

2.  Klik tab Aspose Tools di Library Tools.

![Klik Alat Aspose](merge-pdf-files_2.png)

3.  Klik opsi Gabung ke PDF dari Alat Perpustakaan untuk menggabungkan semua file PDF yang dipilih ke PDF yang dihasilkan.

![Gabungkan ke PDF](merge-pdf-files_3.png)

4.  Prompt akan ditampilkan untuk mengunduh/menyimpan file PDF yang dihasilkan dengan nama yang sesuai.

![Keluaran](merge-pdf-files_4.png)
