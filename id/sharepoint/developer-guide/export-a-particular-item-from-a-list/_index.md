Aspose.PDF untuk SharePoint memungkinkan Anda mengonversi beberapa dokumen, atau satu per satu. Artikel ini memperlihatkan cara mengekspor item dari daftar.

{{% /alert %}}

Untuk mengekspor item tertentu dari daftar: pilih **Ekspor ke Pdf** dari Edit Control Block (ECB) item.
