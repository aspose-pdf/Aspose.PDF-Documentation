توضح هذه المقالة كيفية تحويل عدة ملفات محددة إلى ملفات PDF بعملية تحويل واحدة باستخدام Aspose.PDF لـ SharePoint.

{{% /alert %}}

## Convert Multiple Selected Files to PDF

{{% alert color="primary" %}}

لتحويل عدة ملفات محددة، قم بالخطوات التالية:

1. حدد الملفات المراد تحويلها

![Select Files](convert-multiple-selected-files-to-pdf-files-with-single-conversion-request_1.jpg)

2. انقر فوق علامة التبويب Aspose Tools في أدوات المكتبة

![Click Aspose Tools](convert-multiple-selected-files-to-pdf-files-with-single-conversion-request_2.jpg)

3. انقر فوق تحويل إلى PDF لتحويل جميع الملفات المحددة إلى ملفات PDF الناتجة.

![Convert to PDF](convert-multiple-selected-files-to-pdf-files-with-single-conversion-request_3.jpg)

4. Prompt will be shown to download the converted files.

![Download Converted Files](convert-multiple-selected-files-to-pdf-files-with-single-conversion-request_4.jpg)

![Download Converted Files](convert-multiple-selected-files-to-pdf-files-with-single-conversion-request_5.jpg)
