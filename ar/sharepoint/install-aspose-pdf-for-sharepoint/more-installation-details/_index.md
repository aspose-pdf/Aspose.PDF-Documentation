## النشر

{{% alert color="primary" %}}

**يقوم Aspose.PDF for SharePoint بتنفيذ الإجراءات التالية أثناء النشر:**
- قم بتثبيت Aspose.PDF.SharePoint.dll في ذاكرة التخزين المؤقت للتجميع العمومي وأضف إدخال SafeControl إلى ملف web.config.
- قم بتثبيت بيان الميزات والملفات الضرورية الأخرى إلى الدلائل المناسبة.
- قم بتسجيل الميزة في قاعدة بيانات SharePoint وإتاحتها للتنشيط في نطاق الميزة.

{{% /alert %}}

## التنشيط

{{% alert color="primary" %}}

**يتم تجميع Aspose.PDF for SharePoint كميزة على مستوى الموقع (مجموعة الموقع) ويمكن تنشيطه وإلغاء تنشيطه في مجموعات الموقع.**

{{% /alert %}}

{{% alert color="primary" %}}

أثناء التنشيط، تقوم الميزة بإجراء بعض التغييرات على الدليل الظاهري لتطبيق الويب الأصلي لمجموعة الموقع: أضف صفحة إعدادات التحويل إلى ملف مخطط الموقع. انسخ ملفات الموارد الضرورية إلى المجلد App_GlobalResources في الدليل الظاهري.

{{% /alert %}}
