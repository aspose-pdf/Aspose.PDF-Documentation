{{% alert color="primary" %}}

أثناء التثبيت، يتم تنشيط Aspose.PDF for SharePoint لجميع مجموعات الموقع المحددة. بعد التثبيت، يمكنك استخدام قائمة "إجراءات الموقع" في موقع الويب الجذر لمجموعة مواقع مشتركة لتنشيط وإلغاء تنشيط Aspose.PDF for SharePoint.

{{% /alert %}}
