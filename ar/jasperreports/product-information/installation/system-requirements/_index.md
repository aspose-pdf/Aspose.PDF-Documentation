{{% alert color="primary" %}}

يتطلب تشغيل Aspose.PDF for JasperReports البرنامج التالي:

- Java 2 Platform Standard Edition 5.0 أو أعلى.
- JasperReports 6.7.0 أو أعلى.
- JasperServer 6.7.0 أو أحدث (إذا كنت تريد استخدام Aspose.PDF for JasperReports مع JasperServer).

{{% /alert %}}
