يقوم قسم العمليات المتقدمة بتجميع مسارات عمل Java المستخدمة لتحرير مستندات PDF الموجودة وفحصها وتأمينها وإثرائها بما يتجاوز عمليات الإنشاء والفتح والحفظ والدمج والتقسيم الأساسية.

- [العمل مع المستندات](/pdf/java/working-with-documents/) - ضغط المستندات وتقسيمها ودمجها وإجراء عمليات أخرى على المستند بأكمله.
- [التعامل مع الصفحات](/pdf/java/working-with-pages/) - إضافة الصفحات أو نقلها أو إزالتها أو قصها أو إضافة علامات مائية أو طوابع وما إلى ذلك.
- [العمل مع الصور](/pdf/java/working-with-images/) - إضافة الصور أو استخراجها أو إزالتها من مستندات PDF.
- [المرفقات](/pdf/java/attachments/) - ستتعلم كيفية إضافة وحذف المرفق من PDF برمجيًا باستخدام Python.
- [التنقل والتفاعل](/pdf/java/navigation-and-interaction/) - التعامل مع الإجراءات والإشارات المرجعية والتنقل بين الصفحات.
- [التعليقات التوضيحية](/pdf/java/annotations/) - تسمح التعليقات التوضيحية للمستخدمين بإضافة محتوى مخصص على صفحات PDF. يمكنك إضافة وحذف وتعديل التعليقات التوضيحية من مستندات PDF.
- [العمل مع الجداول](/pdf/java/working-with-tables/) - إدراج الجدول وتزيينه في ملف PDF واستخراج البيانات الجدولية.
- [العمل مع النماذج](/pdf/java/working-with-forms/) - التعامل مع مستندات PDF التفاعلية، وإضافة حقول النماذج، واستخراج البيانات.
- [العمل مع النص](/pdf/java/working-with-text/) - إضافة نص في PDF وتنسيقه والبحث عنه واستبداله.
- [مقارنة مستندات PDF](/pdf/java/compare-pdf-documents/) - إمكانية مقارنة محتوى مستندات PDF.
- [البيانات الوصفية في ملفات PDF](/pdf/java/pdf-file-metadata/) - احصل على البيانات الوصفية في المستندات أو قم بتعيينها، مع التعامل مع بيانات XMP.
- [التعامل مع الرسوم البيانية](/pdf/java/working-with-graphs/) - التعامل مع الأشكال الموجودة على الصفحة.
- [المصنوعات اليدوية](/pdf/java/artifacts/) - التعامل مع العلامات المائية والكائنات الخاصة الأخرى في ملف PDF.
- [العمل مع طبقات PDF](/pdf/working-with-pdf-layers/) - قفل الطبقات، واستخراج العناصر، وتسوية، ودمج طبقات PDF.
