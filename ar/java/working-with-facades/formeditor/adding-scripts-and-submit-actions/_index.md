توضح فئة Java `FormEditorExamples` كيفية العمل مع الإجراءات الميدانية بعد إنشاء بنية النموذج بالفعل.
استخدم هذا القسم من أجل:

- إضافة إجراء JavaScript إلى الحقل
- استبدال البرنامج النصي الميداني الموجود
- قم بتكوين عنوان URL للإرسال وعلامة الإرسال
- إزالة الإجراء الميداني
