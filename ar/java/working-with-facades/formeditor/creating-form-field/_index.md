تقوم فئة Java `FormEditorExamples` بإنشاء العديد من أنواع الحقول الشائعة على صفحات PDF الموجودة عن طريق ربط مستند الإدخال، واستدعاء `addField(...)` أو `addSubmitBtn(...)`، وحفظ النتيجة.

استخدم الصفحات الفرعية في هذا القسم للحصول على أمثلة ملموسة لإنشاء الحقول.
