توفر واجهة برمجة تطبيقات Facades مساعدات على مستوى أعلى للمهام الشائعة في PDF دون الحاجة للعمل مباشرةً مع نموذج كائن الوثيقة منخفض المستوى.

استخدم هذا القسم لتتعلم كيفية:

- ملء وتحرير نماذج PDF
- العمل مع التعليقات التوضيحية والمحتوى
- دمج وتقسيم وإعادة هيكلة ملفات PDF
- فحص بيانات التعريف ومعلومات الصفحة
- تطبيق الأمان والتوقيعات والدمغات وترقيم الصفحات
- تحويل صفحات PDF إلى صور باستخدام واجهة المشاهد
