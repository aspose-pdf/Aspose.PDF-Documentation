توفر واجهة برمجة التطبيقات Facades أدوات مساعدة عالية المستوى لمهام PDF الشائعة دون العمل مباشرةً مع نموذج كائن المستند ذي المستوى الأدنى.

استخدم هذا القسم لتتعلم كيفية:

- ملء وتحرير نماذج PDF
- العمل مع التعليقات التوضيحية والمحتوى
- دمج وتقسيم وإعادة هيكلة ملفات PDF
- فحص البيانات الوصفية ومعلومات الصفحة
- تطبيق الأمان والتوقيعات والطوابع وترقيم الصفحات
- تقديم صفحات PDF إلى صور باستخدام واجهة العارض
