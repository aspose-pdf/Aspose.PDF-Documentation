Java الفئة `PdfFileEditorExamples` تتضمن مباشرة `concatenate` مثال لدمج ملفات PDF.

في هذا القسم يمكنك العثور على:

- تغطية الدمج المدعومة بالمصدر للمصفوفة `concatenate` Workflow
- إرشادات حول المقال المكافئ المكوّن من ملفين والذي يستخدم عينة Java نفسها
- ملاحظات نطاق صريحة للدفعات الكبيرة، المحسّنة، الخاصة بالنماذج، و `try` دمج المتغيّرات التي لم يتم تنفيذها كطرق مخصصة في مجموعة أمثلة المستودع الحالية
