تتضمن فئة Java `PdfFileEditorExamples` نموذجًا مباشرًا `concatenate` لدمج ملفات PDF.

في هذا القسم يمكنك أن تجد:

- تغطية دمج مدعومة من المصدر لسير العمل `concatenate` القائم على الصفيف
- إرشادات حول المقالة المكافئة المكونة من ملفين والتي تستخدم نفس نموذج Java
- ملاحظات نطاق واضحة لمتغيرات الدمج ذات الدُفعات الكبيرة، والمحسّنة، والخاصة بالنموذج، و`try` والتي لم يتم تنفيذها كطرق مخصصة في مجموعة أمثلة المستودع الحالية
