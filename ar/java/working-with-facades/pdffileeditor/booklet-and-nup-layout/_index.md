استخدم واجهة PdfFileEditor عندما تحتاج إلى إعادة تنسيق PDF موجود للطباعة أو المراجعة المدمجة.

يغطي هذا القسم كيفية:

- إنشاء PDF جاهز للكتيب من مستند موجود
- وضع صفحات مصدر متعددة على كل ورقة إخراج باستخدام تخطيط N‑Up
- معالجة قيمة الإرجاع المنطقية المستخدمة بواسطة `try` أمثلة الأنماط في مجموعة عينات Java
