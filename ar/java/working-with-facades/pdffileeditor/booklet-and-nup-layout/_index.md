استخدم واجهة PdfFileEditor عندما تحتاج إلى إعادة تدفق ملف PDF موجود للطباعة أو المراجعة المضغوطة.

يتناول هذا القسم كيفية:

- إنشاء ملف PDF جاهز للكتيب من مستند موجود
- ضع صفحات مصدر متعددة على كل ورقة إخراج باستخدام تخطيط N-Up
- معالجة قيمة الإرجاع المنطقية التي تستخدمها أمثلة النمط `try` في مجموعة نماذج Java
