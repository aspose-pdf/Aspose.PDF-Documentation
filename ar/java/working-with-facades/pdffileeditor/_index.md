الجافا الفئة `PdfFileEditorExamples` تُظهر سير عمل تحرير المستندات الرئيسي الذي تُقدِّمه Facades API.

استخدم هذه الفقرة لتعلم كيفية:

- دمج ملفات PDF مع `concatenate` طريقة
- تقسيم مستند من البداية إلى النهاية، أو إلى ملفات صفحة واحدة
- استخراج، حذف، إدراج، وإلحاق الصفحات
- إنشاء كتيب وإخراج N-Up للطباعة
- إضافة هوامش، تغيير حجم محتوى الصفحات، وإدراج فواصل الصفحات
