الجافا `PdfFileInfoExamples` الفئة توضح سير عمل الفحص والبيانات الوصفية الرئيسية المتاحة عبر واجهة Facades API.

استخدم هذا القسم لتعلم كيفية:

- قراءة إصدار PDF وصلاحيات المستند
- فحص عرض الصفحة، الارتفاع، الدوران، والإزاحات
- الحصول على، تعيين، مسح، وحفظ بيانات تعريف المستند باستخدام XMP
