توضح فئة Java `PdfFileStampExamples` سير عمل الختم الرئيسي المتاح من خلال واجهة برمجة التطبيقات للواجهات.

استخدم هذا القسم لتتعلم كيفية:

- إضافة ختم صورة إلى ملف PDF
- وضع رؤوس أو تذييلات النص والصور
- التحكم في هوامش الرأس والتذييل
- إضافة أرقام الصفحات باستخدام التخطيطات الافتراضية أو القائمة على الإحداثيات أو المحاذاة أو ذات الترقيم الروماني
