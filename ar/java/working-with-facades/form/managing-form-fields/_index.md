تتضمن فئة Java `FormExamples` أمثلة مباشرة لـ:

- `flattenAllFields(...)`
- `renameFormFields(...)`

لا يحتوي المستودع حاليًا على مثال واجهة Java `Form` منفصل لتسوية مجموعة فرعية محددة فقط من الحقول، بحيث يتم توثيق هذه الصفحة الفرعية كملاحظة نطاق بدلاً من نموذج التعليمات البرمجية المُصنَّع.
