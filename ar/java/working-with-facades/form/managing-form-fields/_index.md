الجافا `FormExamples` الفئة تشمل أمثلة مباشرة لـ:

- `flattenAllFields(...)`
- `renameFormFields(...)`

المستودع لا يحتوي حالياً على نسخة Java منفصلة `Form` مثال للواجهة لتسطير مجموعة محددة فقط من الحقول، بحيث يتم توثيق الصفحة الفرعية كملاحظة نطاق بدلاً من شفرة عينة مصطنعة.
