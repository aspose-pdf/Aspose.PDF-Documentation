توضح فئة Java `FormExamples` مسارات عمل معالجة النماذج الرئيسية التي كشفت عنها واجهة برمجة التطبيقات Facades.

استخدم هذا القسم لتتعلم كيفية:

- قم بملء النص وخانة الاختيار وزر الاختيار ومربع القائمة وحقول الرمز الشريطي
- تصدير بيانات النموذج إلى XML، وFDF، وXFDF
- استيراد بيانات النموذج من XML وFDF وXFDF
- قم بتسوية كافة حقول النموذج وإعادة تسمية الحقول الموجودة
- فحص أسماء الحقول والقيم الحالية
- املأ حقل زر الصورة من دفق الإدخال
