الجافا الفئة `FormExamples` تتضمن سير عمل استيراد مباشر لهذه الصيغ:

- XML مع `form.importXml(...)`
- FDF مع `form.importFdf(...)`
- XFDF مع `form.importXfdf(...)`

استخدم الصفحات الفرعية في هذا القسم للأمثلة العملية. لا تتضمن مجموعة عينات Java الحالية في هذا المستودع مجموعة مخصصة `Form` مثال الواجهة للاستيراد JSON أو استبدال XFA، وبالتالي يتم الحفاظ على تلك الصفحات كملاحظات نطاق.
