تتضمن فئة Java `FormExamples` مهام سير عمل الاستيراد المباشر لهذه التنسيقات:

- XML مع `form.importXml(...)`
- FDF مع `form.importFdf(...)`
- XFDF مع `form.importXfdf(...)`

استخدم الصفحات الفرعية في هذا القسم للحصول على أمثلة ملموسة. لا تشتمل مجموعة نماذج Java الحالية في هذا المستودع على مثال واجهة `Form` مخصص لاستيراد JSON أو استبدال XFA، لذلك يتم الاحتفاظ بهذه الصفحات كملاحظات للنطاق.
