تتضمن فئة Java `FormExamples` سير عمل التصدير المباشر لهذه التنسيقات:

- XML مع `form.exportXml(...)`
- FDF مع `form.exportFdf(...)`
- XFDF مع `form.exportXfdf(...)`

استخدم الصفحات الفرعية في هذا القسم للحصول على أمثلة ملموسة. لا تشتمل مجموعة نماذج Java الحالية في هذا المستودع على مثال واجهة `Form` مخصص لتصدير JSON أو استخراج XFA، لذلك يتم الاحتفاظ بتلك الصفحات كملاحظات نطاق بدلاً من إرشادات تعليمات برمجية تركيبية.
