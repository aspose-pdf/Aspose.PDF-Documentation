الجافا `FormExamples` الفئة تشمل تدفقات تصدير مباشرة لهذه الصيغ:

- XML مع `form.exportXml(...)`
- FDF مع `form.exportFdf(...)`
- XFDF مع `form.exportXfdf(...)`

استخدم الصفحات الفرعية في هذا القسم للأمثلة العملية. مجموعة عينات Java الحالية في هذا المستودع لا تشمل مخصصة `Form` مثال واجهة أمامية لتصدير JSON أو استخراج XFA، لذا يتم الحفاظ على تلك الصفحات كملاحظات نطاق بدلاً من شروحات شفرة اصطناعية.
