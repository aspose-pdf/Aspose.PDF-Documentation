الجاڤا `PdfFileSignatureExamples` الفئة توضح سير عمل التوقيع الرئيسي المتاح عبر واجهة برمجة التطبيقات Facades.

استخدم هذا القسم لتتعلم كيفية:

- توقيع وتصديق مستندات PDF
- فحص أسماء التوقيع وتفاصيل الموقع والطوابع الزمنية
- التحقق من صحة التوقيع وتغطية المستند بأكمله
- استخراج شهادة التوقيع وإزالة توقيع موجود
