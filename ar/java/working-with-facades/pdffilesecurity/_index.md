الجافا `PdfFileSecurityExamples` الفئة توضح تدفقات العمل الأمنية الرئيسية المتاحة عبر واجهة برمجة تطبيقات Facades.

استخدم هذا القسم لتتعرف على كيفية:

- تشفير PDF باستخدام كلمات مرور المستخدم والمالك
- تطبيق أو تحديث امتيازات المستند
- فك تشفير PDF باستخدام كلمة مرور المالك
- تغيير كلمات المرور وإعادة تعيين إعدادات الأمان بصورة اختيارية
