استخدم هذا القسم لتتعلم كيفية:

- تشفير ملف PDF بكلمات مرور المستخدم والمالك
- تطبيق أو تحديث امتيازات المستند
- فك تشفير ملف PDF بكلمة مرور المالك
- تغيير كلمات المرور وإعادة تعيين إعدادات الأمان اختياريًا
