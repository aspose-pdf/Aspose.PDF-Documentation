## مقدمة

### Eclipse IDE

Eclipse IDE هو بيئة تطوير متكاملة (IDE) شهيرة للغة Java. IDE هو بالتأكيد أكثر المنتجات شهرة في مشروع Eclipse مفتوح المصدر. اليوم هو بيئة التطوير الرائدة للغة Java بحصة سوقية تقارب 60٪.

يمكن توسيع Eclipse IDE بمكونات برمجية إضافية. تُطلق Eclipse على هذه المكونات البرمجية اسم Plug-ins. عدة مشاريع مفتوحة المصدر وشركات قامت بتمديد Eclipse IDE أو إنشاء تطبيقات مستقلة (Eclipse RCP) فوق إطار عمل Eclipse.

### Aspose.PDF for Java

[Aspose.PDF for Java](https://products.aspose.com/pdf/java/)هو واجهة برمجة تطبيقات قوية لإنشاء مستندات PDF تتيح لتطبيقات Java الخاصة بك قراءة وكتابة وتعديل مستندات PDF دون الحاجة إلى استخدام Adobe Acrobat.

يوفر Aspose.PDF for Java مجموعة هائلة من الميزات، والتي تشمل خيارات ضغط PDF، إنشاء الجداول وتعديلها، دعم الرسوم البيانية، وظائف الصور، وظيفة الروابط التشعبية الواسعة، ضوابط الأمن الموسعة ومعالجة الخطوط المخصصة.

### Aspose.PDF Java (Maven) for Eclipse

- Aspose.PDF Java (Maven) for Eclipse هو ملحق لـ **Eclipse IDE** من **Aspose.** يهدف هذا الملحق إلى المطورين الذين يستخدمون منصة Maven لتطوير Java ويرغبون في استخدام Aspose.PDF for Java في مشاريعهم. يتيح لك الملحق إنشاء مشاريع Maven لاستخدام واجهة برمجة تطبيقات Aspose.PDF for Java وكذلك التحميل [أمثلة على التعليمات البرمجية](https://github.com/aspose-pdf/Aspose.Pdf-for-Java) من API.

## تنزيل

### تحميل Eclipse IDE

ستحتاج إلى تثبيت Eclipse IDE أولاً قبل تنزيل إضافة Aspose.PDF Java (Maven) لـ Eclipse.

لتنزيل Eclipse IDE

1. اذهب إلى [https://eclipse.org](https://eclipse.org/).
1. نزّل وتثبيت Eclipse IDE الموصى به لمطوري Java SE / EE..

### تنزيل Aspose.PDF Java (Maven) لـ Eclipse

فيما يلي ثلاث طرق موصى بها للتحميل والتثبيت الناجح لإضافة Aspose.PDF Java (Maven) لـ Eclipse:

- تثبيت السحب والإفلات من [Eclipse Marketplace](https://marketplace.eclipse.org/content/asposepdf-java-maven-eclipse) إلى مساحة عمل Eclipse الخاصة بك.
- أو انتقل إلى **Help** > **Install New Software...** > أدخل عنوان URL لموقع التحديث التالي في **Work with**
ثم اختر "Aspose.PDF Java (Maven) for Eclipse" و **Finish**. اقبل اتفاقية الترخيص وقم بتثبيت الإضافة.

### تكوين رمز المصدر لـ Aspose.PDF Java (Maven) for Eclipse

ستؤدي الخطوات البسيطة التالية بسلاسة إلى تكوين ناجح لرمز مصدر إضافة **"Aspose.PDF Java (Maven) for Eclipse"** في بيئة Eclipse IDE.

1. نزّل / استنساخ رمز المصدر.
1. اختر **File** \u003E Import \u003E General \u003E Existing Projects into Workspace.
1. تصفح إلى أحدث مصدر للمشروع الذي قمت بتنزيله
1. حدّد مشروع Eclipse الذي تريد استيراده.
1. انقر على إنهاء.
1. رمز ملحق Aspose.PDF Java for Eclipse جاهز الآن للتعزيز.
