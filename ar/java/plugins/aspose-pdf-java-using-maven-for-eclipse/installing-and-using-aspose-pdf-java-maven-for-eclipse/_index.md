## التثبيت

يمكن تثبيت المكون الإضافي **Aspose.PDF Java (Maven) for Eclipse** بسهولة من علامة التبويب **Plugin** المتوفرة في مربع حوار البرنامج المساعد.

- لفتحه، حدد **المكونات الإضافية** من قائمة **الأدوات** في Eclipse.

![todo:image_alt_text](https://i.imgur.com/PCMRMUT.png)

- يؤدي هذا إلى إضافة **Aspose.PDF Maven Project** في معالج New Project و**Aspose.PDF Code Exemple** في معالج New File في Eclipse IDE.

## استخدام

### Aspose.PDF Maven Project (المعالج)

لإنشاء **Maven Project** بواسطة المعالج لاستخدام [Aspose.PDF for Java API](http://www.aspose.com/java/pdf-component.aspx):

1. حدد **مشروع جديد**.
1. حدد **Aspose.PDF Maven Project** في فئة **Maven**.
1. انقر **التالي**.

![todo:image_alt_text](https://i.imgur.com/6iywqND.png)

1. قم بتوفير **اسم المشروع، والموقع، ومعرف المجموعة، وArtifactId**، و**الإصدار** لمشروع Maven الخاص بك، ثم انقر فوق **Finish.**

![todo:image_alt_text](https://i.imgur.com/zURjIn1.png)

1. سيؤدي هذا إلى استرداد مرجع [Aspose.PDF for Java](http://www.aspose.com/java/pdf-component.aspx) الأحدث [تبعية Maven](https://repository.aspose.com/webapp/#/artifacts/browse/tree/General/repo/com/aspose/aspose-pdf/) من [Aspose Cloud Maven Repository](https://repository.aspose.com/webapp/#/artifacts/browse/tree/General/repo) وتكوينه في **pom.xml**. إذا اخترت **تنزيل أمثلة التعليمات البرمجية أيضًا**، فسيبدأ تنزيل **أمثلة التعليمات البرمجية** أيضًا من [Aspose.PDF for Java API examples Repository.](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples)
1. سيتم إنشاء مشروع **Maven** التالي على **Eclipse IDE** عند الانتهاء من المعالج:

![todo:image_alt_text](https://i.imgur.com/xRfHrku.png)

1. تم تكوين **Maven Project** الذي تم إنشاؤه لاستخدام **Aspose.PDF for Java API** وهو جاهز للتحسين وفقًا لمتطلبات مشروعك.
   إذا اخترت تنزيل [أمثلة التعليمات البرمجية](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples)، فيمكنك استخدام **مثال رمز Aspose.PDF (المعالج)** لاستيراد **أمثلة التعليمات البرمجية** المطلوبة لواجهة برمجة التطبيقات [Aspose.PDF for Java](http://www.aspose.com/java/pdf-component.aspx) في مشروعك.

### مثال على كود Aspose.PDF (المعالج)

**يسمح لك معالج مثال رمز Aspose.PDF** بتجربة العديد من العينات المتوفرة لواجهة برمجة التطبيقات [Aspose.PDF for Java](http://www.aspose.com/java/pdf-component.aspx).

{{% alert color="primary" %}}

لتتمكن من استخدام **معالج مثال رمز Aspose.PDF** بشكل مريح: يوصى دائمًا بتحديد **تنزيل أمثلة التعليمات البرمجية أيضًا** أثناء إنشاء **مشروع Maven** على **Aspose.PDF Maven Project** **المعالج**،

{{% /alert %}}

لاستخدام الأمثلة، فقط:

1. انقر فوق **ملف جديد** في **Eclipse**.
1. اختر مشروعك ثم حدد **Aspose.PDF Code Exemple** في فئة **Java**.
1. انقر **التالي**.

![todo:image_alt_text](https://i.imgur.com/AuWybe8.png)

 قم بتوسيع الشجرة لتحديد فئة **مثال الكود** ثم انقر **إنهاء**.

![todo:image_alt_text](https://i.imgur.com/PToFZjJ.png)

1. سيؤدي هذا إلى نسخ ملفات جافا الفئة المحددة **أمثلة التعليمات البرمجية** إلى المشروع ضمن الحزمة **com.aspose.pdf.examples**. سيتم أيضًا نسخ أي موارد مطلوبة تحتاجها "أمثلة التعليمات البرمجية" إلى المجلد **src/main/resources**
1. قم بمراجعة رمز المثال وتجميعه وتشغيله.
1. يمكنك الآن اختبار أمثلة أخرى والبدء في إنشاء التطبيق الخاص بك باستخدام [Aspose.PDF for Java API](http://www.aspose.com/java/pdf-component.aspx)
