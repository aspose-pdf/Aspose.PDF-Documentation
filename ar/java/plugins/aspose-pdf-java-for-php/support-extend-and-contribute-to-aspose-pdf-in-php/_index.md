## الدعم

منذ الأيام الأولى لـ Aspose، علمنا أن تقديم منتجات جيدة لعملائنا لن يكون كافيًا. كنا بحاجة أيضًا إلى تقديم خدمة ممتازة. نحن مطورون بأنفسنا ونفهم مدى الإحباط عندما تتسبب مشكلة تقنية أو خلل في البرنامج في منعك من القيام بما تحتاج إليه. نحن\u0027 هنا لحل المشكلات، لا لخلقها.

لهذا السبب نقدم دعمًا مجانيًا. أي شخص يستخدم منتجنا، سواءً كان قد اشتراه أو يستخدم نسخة تجريبية، يستحق كل اهتمامنا واحترامنا.

يمكنك تسجيل أي مشكلات أو اقتراحات تتعلق بـ\u0412\u00A0Aspose.Cells Java لــ PHP باستخدام أي من المنصات التالية:

- [Github](https://github.com/aspose-pdf/Aspose.PDF-for-Java/issues)

## التوسيع والمساهمة

Aspose.PDF Java for PHP هو مفتوح المصدر ورمز المصدر الخاص به متاح على المواقع الاجتماعية للبرمجة الكبرى المذكورة أدناه. يُشجع المطورون على تنزيل رمز المصدر والمساهمة عن طريق اقتراح أو إضافة ميزات جديدة أو تحسين الميزات الحالية، حتى يتمكن الآخرون من الاستفادة منه أيضًا.
