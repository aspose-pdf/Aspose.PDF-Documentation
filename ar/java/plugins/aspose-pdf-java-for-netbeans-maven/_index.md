## مقدمة

### بيئة تطوير متكاملة نيتبيانز

NetBeans عبارة عن Java IDE كامل الميزات ومكتوب بالكامل بلغة Java. إنه مخصص في المقام الأول للتطوير في Java ولكنه يدعم أيضًا لغات أخرى، على وجه الخصوص، PHP وC/C++ وHTML5.

يتيح لك NetBeans IDE تطوير تطبيقات Java لسطح المكتب والهاتف المحمول والويب بسرعة وسهولة، بالإضافة إلى تطبيقات HTML5 مع HTML وJavaScript وCSS. إنه مجاني ومفتوح المصدر ولديه مجتمع كبير من المستخدمين والمطورين حول العالم.

يدعم فريق NetBeans المنتج بشكل فعال ويطلب اقتراحات الميزات من المجتمع الأوسع. يسبق كل إصدار وقت لاختبار المجتمع وتلقي التعليقات.

### Aspose.PDF لجافا

[Aspose.PDF for Java](https://products.aspose.com/pdf/java/) عبارة عن واجهة برمجة تطبيقات قوية لإنشاء مستندات PDF تمكن تطبيقات Java من قراءة مستندات PDF وكتابتها ومعالجتها دون استخدام Adobe Acrobat.

يوفر Aspose.PDF for Java ثروة لا تصدق من الميزات، بما في ذلك خيارات ضغط PDF وإنشاء الجدول ومعالجته ودعم الرسم البياني ووظائف الصور ووظيفة الارتباط التشعبي الشاملة وعناصر التحكم الأمنية الموسعة ومعالجة الخطوط المخصصة.

### Aspose.PDF جافا لـ NetBeans (Maven)

- Aspose.PDF Java for NetBeans (Maven) هو مكون إضافي لـ **NetBeans IDE** من **Aspose.** البرنامج الإضافي مخصص للمطورين الذين يستخدمون منصة Maven لتطوير Java ويريدون استخدام Aspose.PDF لـ Java في مشاريعهم. يتيح لك المكون الإضافي إنشاء مشاريع مخضرمة لاستخدام Aspose.PDF لـ Java API وكذلك تنزيل [أمثلة التعليمات البرمجية](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples) لواجهة برمجة التطبيقات.

## المعالجات

يحتوي البرنامج المساعد على معالجين

### Aspose.PDF Maven Project (المعالج)

- يتيح معالج المشروع الجديد للمطورين إنشاء مشروع **Maven** لاستخدام Aspose.PDF لـ Java من New Project -> Maven-> Aspose.PDF Maven Project.
- يتم جلب مرجع Aspose.PDF لتبعية Java API maven تلقائيًا من [Aspose Maven Repository](https://repository.aspose.com/webapp/#/artifacts/browse/tree/General/repo/com/aspose/aspose-pdf) ويتم إضافته في ملف pom.xml.
- سيحتوي المشروع الذي تم إنشاؤه دائمًا على أحدث إصدار متاح **Maven** Dependency for Aspose.PDF for Java API.
- توجد خطوات المعالج أيضًا مع خيار تنزيل أمثلة التعليمات البرمجية لاستخدامAspose.PDF لـ Java API.

### مثال على كود Aspose.PDF (المعالج)

- يتيح لك معالج الملف الجديد نسخ [أمثلة التعليمات البرمجية](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples) التي تم تنزيلها إلى مشروعك لاستخدام Aspose.PDF لـ Java من **ملف جديد -> Java -> مثال على رمز Aspose.PDF.**
- يتم عرض العينات المتاحة في شكل شجرة حيث يمكن للمستخدم تحديدها بشكل قاطع.
- سيتم نسخ جميع الأمثلة ضمن الفئة المحددة إلى مجلد الحزمة **com.aspose.pdf.examples** الخاص بالمشروع بالإضافة إلى الموارد المطلوبة داخل المجلد **src/main/resources** المطلوب لتشغيل الأمثلة.
- تهدف أمثلة التعليمات البرمجية لـ Aspose.PDF لـ Java API إلى توضيح تنوع واجهة برمجة التطبيقات.
- سيبحث المعالج أيضًا عن التحديثات المتوفرة حديثًا من [Aspose.PDF لمستودع أمثلة Java.](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Examples)

## جاري التحميل

### تحميل نت بينز

يجب أن يكون NetBeans IDE مثبتًا مسبقًا قبل تنزيل البرنامج الإضافي **Aspose.PDF Java for NetBeans (Maven)**.

** يدعم البرنامج المساعد Aspose.PDF Java for NetBeans (Maven) ** **NetBeans IDE8.0 و8.1**. نوصي باستخدام الإصدار الأحدث فقط من NetBeans IDE.

لتنزيل NetBeans IDE،

1. انتقل إلى:<https://netbeans.apache.org/download/index.html>
1. انقر فوق "تنزيل" لتنزيل الحزمة المناسبة لـ NetBeans IDE.

قم بتنزيل حزمة تنزيل NetBeans المدعومة بـ Java EE / SE فقط من أحدث إصدار حالي، أي **NetBeans IDE 8.1**.

### تنزيل Aspose.PDF Java لـ NetBeans (Maven)

- يمكن تنزيل المكون الإضافي مباشرةً من عنوان URL لاستضافة المكون الإضافي لـ NetBeans:<http://plugins.netbeans.org/plugin/63218>
  ويمكن تثبيته لاحقًا باستخدام خيار IDE:
  - انتقل إلى **الأدوات**>**المكونات الإضافية**>**تم التنزيل
  - انقر **إضافة مكونات إضافية...**واستعرض بحثًا عن ملف البرنامج الإضافي .nbm الذي تم تنزيله لـ **Aspose.PDF Java for NetBeans (Maven)**.
  - انقر فوق **"تثبيت"** لتثبيت البرنامج المساعد
- أو يمكن تثبيته مباشرةً (بدون التنزيل اليدوي من عنوان URL لاستضافة المكون الإضافي لـ NetBeans) باستخدام خيارات IDE:
  - انتقل إلى **الأدوات**>**المكونات الإضافية**>**المكونات الإضافية المتاحة**
  - في مربع البحث اكتب: "Aspose"
  - حدد **Aspose.PDF Java NetBeans (Maven)** البرنامج المساعد
  - انقر ** "تثبيت" **
