## تنزيل Aspose.PDF Java for Struts 1.3

يمكنك تنزيل/التحقق من أكواد مصدر المشروع من المواقع التالية:

- [جيثب](https://github.com/aspose-pdf/Aspose.PDF-for-Java/tree/master/Plugins/Aspose_Pdf_for_Struts)

## بناء Aspose.PDF Java for Struts 1.3 من أكواد المصدر

بعد التحقق من أكواد المصدر من أي من المستودعات المذكورة أعلاه، قم بتطبيق أوامر mvn التالية:

{{< highlight java >}}

 الحزمة النظيفة $ mvn -U

{{< /highlight >}}

سيؤدي هذا إلى إنشاء "Strutsbookapp.war" في جهاز الصراف المستهدف.

لنشر ملف .war، ما عليك سوى نسخه إلى دليل webapp الخاص بخادم Apache Tomcat قيد التشغيل.
