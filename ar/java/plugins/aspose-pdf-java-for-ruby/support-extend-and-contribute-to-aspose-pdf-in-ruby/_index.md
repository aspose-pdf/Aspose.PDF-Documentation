## الدعم

منذ الأيام الأولى لـ Aspose، كنا نعلم أن مجرد تقديم منتجات جيدة لعملائنا لن يكون كافيًا. كنا بحاجة أيضًا إلى تقديم خدمة جيدة. نحن مطورون أنفسنا ونفهم مدى الإحباط عندما تتسبب مشكلة تقنية أو خلل في البرنامج في إعاقة قيامك بما تحتاج إليه. نحن هنا لحل المشاكل، لا لإنشائها.

لهذا السبب نقدم دعمًا مجانيًا. أي شخص يستخدم منتجنا، سواء اشترى المنتج أو يستخدم نسخة تجريبية، يستحق كامل اهتمامنا واحترامنا.

يمكنك تسجيل أي مشكلات أو اقتراحات تتعلق بـ Aspose.PDF Java لـ Ruby باستخدام أي من المنصات التالية:

- [GitHub](https://github.com/aspose-pdf/Aspose.PDF-for-Java/issues)

## التوسيع والمساهمة

Aspose.PDF Java for Ruby هو مفتوح المصدر ورمز المصدر الخاص به متاح على مواقع الترميز الاجتماعية الكبرى المذكورة أدناه. يُشجع المطورون على تحميل رمز المصدر والمساهمة من خلال اقتراح أو إضافة ميزة جديدة أو تحسين الميزات الحالية، حتى يتمكن الآخرون من الاستفادة منه أيضًا.
