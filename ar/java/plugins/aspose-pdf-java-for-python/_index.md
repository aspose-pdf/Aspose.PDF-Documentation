## مقدمة إلى Aspose.PDF Java لبايثون

## JPype

JPype هو جهد للسماح لبرامج python بالوصول الكامل إلى مكتبات فئة java. يتم تحقيق ذلك ليس من خلال إعادة تنفيذ Python، كما فعل Jython/JPython، بل من خلال الواجهة على المستوى الأصلي في كلا الآلات الافتراضية.

اقرأ المزيد على [readthedocs.org](http://jpype.readthedocs.org/en/latest/userguide.html)

## Aspose.PDF for Java

Aspose.PDF for Java هي مكتبة فئة متقدمة لـ Java تتيح لك تنفيذ مجموعة واسعة من مهام معالجة المستندات مباشرة داخل تطبيقات Java الخاصة بك.

Aspose.PDF for Java يدعم معالجة Word (DOC، DOCX، OOXML، RTF) وHTML وOpenDocument وPDF وEPUB وXPS وSWF وجميع صيغ الصور. باستخدام Aspose.PDF يمكنك إنشاء المستندات وتعديلها وتحويلها دون استخدام Microsoft Word.

اقرأ المزيد على [aspose.com](https://products.aspose.com/words/java)

## Aspose.PDF Java لبايثون

يظهر مشروع Aspose.PDF for Python كيفية تنفيذ مهام مختلفة باستخدام Aspose.PDF Java APIs في Python. يهدف هذا المشروع إلى توفير أمثلة مفيدة لمطوري Python الذين يرغبون في استخدام Aspose.PDF for Java في مشاريع Python الخاصة بهم باستخدام [JPype](http://jpype.readthedocs.org/en/latest/userguide.html).
