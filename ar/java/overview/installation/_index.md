## تثبيت Aspose.PDF for Java من مستودع Aspose

تستضيف Aspose جميع واجهات برمجة التطبيقات Java على\u0412 [مستودع Aspose](https://releases.aspose.com/java/repo/com/aspose/aspose-pdf/). يمكنك\u0412\u00A0استخدام Aspose.PDF for Java API مباشرةً في مشروعات Maven الخاصة بك مع تكوينات بسيطة.

### حدد تكوين مستودع Aspose

أولاً، تحتاج إلى تحديد تكوين مستودع Aspose / موقعه في ملف pom.xml الخاص بـ Maven كما يلي:

```xml
 <repositories>
    <repository>
        <id>AsposeJavaAPI</id>
        <name>Aspose Java API</name>
        <url>https://releases.aspose.com/java/repo/</url>
    </repository>
</repositories>
```

### تعريف اعتماد Aspose.PDF for Java API

ثم قم بتعريف اعتماد Aspose.PDF for Java APIВ في pom.xml الخاص بك كما يلي:

```xml
 <dependencies>
    <dependency>
        <groupId>com.aspose</groupId>
        <artifactId>aspose-pdf</artifactId>
        <version>21.7</version>
    </dependency>
</dependencies>
```

بعد تنفيذ الخطوات أعلاه، سيتم تعريف تبعية Aspose.PDF for Java أخيرًا في مشروع Maven الخاص بك.

### دليل التوافق والاستخدام لـ JDK 11

تم تحسين واجهة برمجة التطبيقات لبيئة جافا 11 وجميع الاختبارات والوظائف تعمل بشكل جيد. ومع ذلك، بالنسبة لبعض الفئات يجب إضافة الاعتماد الخارجي لإضافة مسار الفئة: javax.xml.bind.annotation.adapters.HexBinaryAdapter، والتي تم حذفها من JRE.

على سبيل المثال:

```xml
 <dependency>
    <groupId>javax.xml.bind</groupId>
    <artifactId>jaxb-api</artifactId>
    <version>2.3.0</version>
</dependency>
```
