## الميزات العامة

- مكتوب بالكامل بلغة Java، يعمل مع JDK 1.8 وما فوق
- يدعم جميع تطبيقات Java
- مرجع API بصيغة JavaDoc
- دعم نظام تشغيل 32-بت.
- دعم نظام تشغيل 64-بت.

## الإصدارات المدعومة من PDF

يدعم Aspose.PDF for Java إصدارات PDF 1.2 و 1.3 و 1.4 و 1.5 و 1.6 و 1.7.

- يتم دعم أشكال مختلفة من الرسوم البيانية، مثل الخط، والدائرة، والقوس، والمنحنى.
