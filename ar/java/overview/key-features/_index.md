## الميزات العامة

- مكتوب بالكامل بلغة Java، ويعمل مع JDK 1.8 وما فوق
- يدعم كافة تطبيقات جافا
- مرجع API بتنسيق JavaDoc
- دعم نظام التشغيل 32 بت.
- دعم نظام التشغيل 64 بت.

## إصدارات PDF المدعومة

يدعم Aspose.PDF for Java إصدارات PDF 1.2 و1.3 و1.4 و1.5 و1.6 و1.7.

## رسم بياني

- يتم دعم أشكال مختلفة من الرسوم البيانية، مثل الخط والدائرة والقوس والمنحنى.
- يمكن رسم الرسوم البيانية على أي موقع صفحة محدد بالإحداثيات.
- يمكن تدوير الرسوم البيانية أو تغيير حجمها أو تعبئتها، كما يمكن تحديد أنماط خطوط الشرطة والشرطة المتعددة.
- يتم رسم الرسوم البيانية بناءً على الإحداثيات ولها موقع قديم وليس نسبيًا.
- يتم دعم مساحات الألوان CMYK والرمادي.
