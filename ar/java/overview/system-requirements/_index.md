## نظرة عامة

لإنشاء مستندات PDF، الآلة التي تُشغَّل [Aspose.PDF for Java](https://products.aspose.com/pdf/java/) ليس بحاجة إلى [Adobe Acrobat](https://www.adobe.com/acrobat/acrobat-pro.html) تم تثبيته لأن Aspose.PDF for Java نفسه هو محرك إنشاء مستندات PDF. ومع ذلك، من أجل عرض مستندات PDF التي تم إنتاجها بواسطة Aspose.PDF for Java يحتاج الجهاز على الأقل إلى [Adobe Acrobat Reader](https://www.adobe.com/acrobat/pdf-reader.html). يمكن تنزيله مجانًا.

## أنظمة التشغيل المدعومة

يدعم Aspose.PDF for Java أي نظام تشغيل 32‑بت أو 64‑بت الذي يشغّل بيئة تشغيل Java بما في ذلك، ولكن ليس حصرًا:

### ويندوز

- Microsoft Windows 2000 Professional ( x64, x86)
- Microsoft Windows 2000 Server (x64, x86)
- Microsoft Windows 2003 Server (x64, x86)
- Microsoft Windows 2008 Server (x64, x86)
- Microsoft Windows 2012 Server (x64, x86)
- Microsoft Windows 2012 R2 Server (x64, x86)
- Microsoft Windows 2016 Server (x64, x86)
- Microsoft Windows 2019 Server (x64, x86)
- Microsoft Windows Vista (x64, x86)
- Microsoft Windows XP (x64, x86)
- Microsoft Windows 7 (x64, x86)
- Microsoft Windows 8, 8.1 (x64, x86)
- Microsoft Windows 10 (x64, x86)
- مايكروسوفت أزور

### Linux

- Linux (أوبونتو، سنتوس، وغيرها)

### ماك

- ماك OS X

## إصدارات Java المدعومة

يدعم Aspose.PDF for Java الإصدارات التالية من Java:

- J2SE 8.0 (1.8) أو أعلى (*على سبيل المثال Java 10*)В
- دعم Aspose.Pdf for Java على IBM i (Iseries أو As/400)
