## ملخص

لإنتاج مستندات PDF، لا يحتاج الجهاز الذي يقوم بتشغيل [Aspose.PDF for Java](https://products.aspose.com/pdf/java/) إلى تثبيت [Adobe Acrobat](https://www.adobe.com/acrobat/acrobat-pro.html) لأن Aspose.PDF لـ Java نفسه هو محرك إنشاء مستندات PDF. ومع ذلك، من أجل عرض مستندات PDF التي تم إنتاجها بواسطة Aspose.PDF لـ Java، يحتاج الجهاز على الأقل إلى [Adobe Acrobat Reader](https://www.adobe.com/acrobat/pdf-reader.html). ويمكن تحميله مجانا.

- مايكروسوفت ويندوز 2016 خادم (x64، x86)
- خادم مايكروسوفت ويندوز 2019 (x64، x86)
