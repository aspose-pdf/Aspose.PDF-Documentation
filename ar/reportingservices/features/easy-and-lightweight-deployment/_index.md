**Aspose.PDF for Reporting Services** هو امتداد عرض مخصص لـ Microsoft SQL Server 2016/2017/2019/2022 Reporting Services وPower BI Report Server. يتم توفير Aspose.PDF لخدمات التقارير كمثبت MSI واحد يمكن تثبيته على أجهزة الكمبيوتر التي تعمل بأحد الأجهزة التالية:

- خدمات إعداد التقارير لـ Microsoft SQL Server 2016  
- خدمات إعداد التقارير لـ Microsoft SQL Server 2017  
- خدمات إعداد التقارير لـ Microsoft SQL Server 2019  
- خدمات إعداد التقارير لـ Microsoft SQL Server 2022  
- خادم تقارير Microsoft Power BI
 
من السهل نشر وإدارة Aspose.PDF لخدمات التقارير، حيث أنها تتألف من مجموعة .NET واحدة فقط Aspose.Pdf.ReportingServices.dll، مكتوبة بالكامل بلغة C#، ومتوافقة مع CLS وتحتوي فقط على تعليمات برمجية آمنة مُدارة. مطلوب منك تثبيت .NET Framework 4.8.1 على الخادم.

يجب نسخ Aspose.Pdf.ReportingServices.dll إلى دليل ReportServer\bin ويجب تحديث ملف التكوين حتى تكون خدمات التقارير على علم بملحق العرض الجديد. يتم تنفيذ هذه الخطوات بواسطة مثبت Aspose.PDF for Reporting Services، ولكن يمكنك أيضًا تنفيذها يدويًا كما هو موضح بمزيد من التفصيل في هذه الوثائق.
